# 注目とトランスフォーマー - すべてを変えたアーキテクチャ

現在の主要な言語モデルは、GPT、Claude、Gemini、Llama のいずれも Transformer アーキテクチャに基づいて構築されています。2017 年の画期的な論文 *Attention Is All You Need* で発表され、再帰を **セルフアテンション** という仕組みに置き換え、前例のない並列性と性能を実現しました。

## RNN が壁にぶつかる理由

リカレント ニューラル ネットワークは、一度に 1 つのトークンを処理し、隠れた状態を前方に伝えます。これにより、次の 2 つの重大な問題が発生します。

- **勾配の消失** - 勾配が数百のタイム ステップを逆伝播するまでに、勾配はゼロ近くまで縮小し、長距離の依存関係を学習することができなくなります。
- **シーケンシャルのボトルネック** - 各ステップは前のステップに依存するため、シーケンス全体でトレーニングを並列化することはできません。 1,000 トークンの入力には 1,000 回のシリアル操作が必要です。

LSTM と GRU は、勾配の消失を緩和するゲート メカニズムを追加しましたが、並列化の問題は解決されませんでした。トレーニングは依然として基本的に遅かった。

## 注意の直感

長い段落を読んで、*「CEO は何を発表しましたか?」* と尋ねられることを想像してください。あなたの目はすべての単語を順番に再読するのではなく、**関連する文にジャンプします**。アテンションも同様に機能します。各トークンが他のすべてのトークンを調べて、現在のコンテキストにとって最も重要なものを決定します。

**ステージ上のスポットライト**と考えてください。モデルは、ステージ全体を均一に照らすのではなく、目の前のタスクに最も関連する情報を運ぶトークンに明るいビームを当てることを学習します。

## クエリ、キー、値 - コアメカニズム

自己注意は、情報検索から用語を借用しています。トークンごとに、モデルは 3 つのベクトルを計算します。

- **クエリ (Q)** - *「何を探していますか?」*
- **キー (K)** - *「どのような情報が含まれていますか?」*
- **価値 (V)** - *「選ばれた場合、実際に何を貢献できますか?」*

2 つのトークン間のアテンション スコアは、**Q と K** の内積であり、値の爆発を防ぐために √d_k (キー ディメンション) でスケールされます。ソフトマックスを適用すると正規化された重みが得られ、出力はすべての V ベクトルの重み付き合計になります。

```
Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V
```

**ウォークスルー:** 文 *「疲れていたので猫はマットの上に座りました。」* を考えてみましょう。 *"it"* を処理するとき、*"it"* のクエリは *"cat"* (高い Q·K スコア) に最も強く対応し、曖昧な代名詞を解決します。再帰は必要ありません。

## マルチヘッド アテンション

1 つのアテンション ヘッドは、一度に 1 種類の関係しかキャプチャできません。 **マルチヘッド アテンション** は、それぞれが独自に学習した Q、K、V 投影を使用して複数のアテンション ヘッドを並行して実行し、結果を連結して投影します。

```
MultiHead(Q, K, V) = Concat(head₁, ..., headₕ) · Wᴼ
```

異なる頭は異なる言語パターンを学習します。ある頭は構文の依存関係に注目し、別の頭は意味上の類似性に、そして 3 番目の頭は位置の近さに注意を払う可能性があります。 GPT-3 は 96 個のヘッドを使用します。それぞれは、完全な 12,288 次元空間の 128 次元のスライスを見ます。

<FunFact>Google の研究者は、BERT の個々のアテンションヘッドが著しく専門化していることを発見しました。すべて明示的な監督なしで、主語と動詞の一致を追跡するもの、共参照の解決を処理するもの、依存関係の解析を学習するものさえあります。
</FunFact>

## 位置エンコーディング

Self-attention は **順列不変** です。位置情報を注入しない限り、*「犬が人を噛む」* を *「人間が犬を噛む」* と同じように扱います。オリジナルの Transformer は正弦波エンコーディングを使用していました。

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

各位置には、異なる周波数のサイン波とコサイン波の固有のパターンが得られます。 `PE(pos+k)` は `PE(pos)` の一次関数として表現できるため、これによりモデルは相対位置を学習できます。最新のモデル (GPT、LLaMA) は、相対位置を Q/K ドット積に直接エンコードする **Rotary Positional Embeddings (RoPE)** を使用します。

## 完全なトランス アーキテクチャ

元の Transformer には **エンコーダー-デコーダー** 構造があります。

- **エンコーダー** - 双方向のセルフアテンションで完全な入力を処理します (すべてのトークンが他のトークンに注目します)。セルフアテンション + フィードフォワード ブロックの N 層を、残りの接続と層の正規化でスタックします。
- **デコーダー** - **因果的 (マスクされた) セルフアテンション** (各トークンは前のトークンのみに注目できる) とエンコーダー出力へのクロスアテンションを使用して、出力を自動回帰的に生成します。

各サブレイヤーはパターン `LayerNorm(x + Sublayer(x))` に従います。ここでは、残りの接続により、勾配が深いスタックを自由に流れることが保証されます。

<ThinkAboutIt>Transformer の残りの接続により、グラデーションが 100 以上のレイヤーに直接流れることができます。これらがなければ、96 層 GPT-3 をトレーニングすることはほぼ不可能になります。これは、ResNets をディープ コンピューター ビジョンで実現できるようにしたスキップ接続とどのように関係しているのでしょうか?
</ThinkAboutIt>

## トランスフォーマーが並列化される理由

重要な洞察: セルフアテンションは、**単一の行列乗算**ですべてのペアごとのトークン相互作用を計算します。長さ n のシーケンスの場合、n×n アテンション行列全体が GPU ハードウェアで同時に計算されます。これを、利用可能なコンピューティングに関係なく n 回の連続ステップを必要とする RNN と比較してください。

RNN の O(n) 深さに対してこの O(1) 深さ (一定の逐次操作) が、まさに Transformers がトレーニング中に数千のトークンのシーケンスにスケールする理由です。

## デコーダのみ vs エンコーダのみ vs エンコーダ-デコーダ

元の設計から 3 つのアーキテクチャのバリエーションが生まれました。

|バリアント |注意 |例 |最適な用途 |
|----------|-----------|----------|----------|
| **エンコーダのみ** |双方向 |ロベルタ・バート |分類、NER、埋め込み |
| **デコーダのみ** |因果関係 (左から右) | GPT、LLaMA、クロード |テキスト生成、チャット、推論 |
| **エンコーダ-デコーダ** |両方 | T5、BART、ウィスパー |翻訳、要約 |

**生成はユニバーサル インターフェイス**であるため、今日ではデコーダーのみのモデルが主流です。あらゆる NLP タスクをテキスト生成としてフレーム化できます。このアーキテクチャのシンプルさは、より予測可能な形で拡張することもできます。
