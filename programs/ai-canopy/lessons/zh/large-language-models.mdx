# 大型语言模型 - 现代人工智能背后的引擎

大型语言模型从根本上改变了机器处理文本、代码和推理的能力。在本课中，我们将揭开它们的工作原理、它们为何如此强大以及它们仍有哪些不足之处。

## 法学硕士到底是什么？

**大型语言模型**是一种神经网络，经过大量文本训练来预测序列中的下一个标记。 “大”是指**参数**的数量 - 对训练数据中的模式进行编码的可学习权重。

- **GPT-6 Astra** 代表当前的 OpenAI frontier，模型内部细节尚未公开。
- **Llama 4 Scout 和 Maverick** 使用 mixture-of-experts 设计，拥有 170 亿活跃参数和更大的总参数规模。
- **Mistral 7B** 表明较小的型号可以远超其重量。

这些模型接受了来自书籍、网站、代码存储库和学术论文的数千亿个单词的训练。数据和参数的庞大规模赋予了法学硕士非凡的多功能性。

**令牌，而不是单词：**法学硕士不处理整个单词 - 它们使用**令牌**，即子单词单元。 “理解”这个词可以分为“under”+“stand”+“ing”。一个典型的英语单词平均大约有 1.3 个标记。这种标记化方案允许模型处理稀有单词、技术术语，甚至多种语言，而无需大到难以置信的词汇量。

<FunFact>训练一个 frontier language model 在计算、数据、能源和工程都计入后可能花费数亿美元。这大约是一部大片的预算，只是这个“演员”可以说每种编程语言。</FunFact>
</FunFact>

## Transformer 架构

每个现代法学硕士都建立在**变压器**的基础上，该变压器在 2017 年论文“Attention Is All You Need”中介绍。关键的创新是“自我关注”——一种让模型权衡输入中每个单词相对于其他单词的重要性的机制。

**自我注意力如何工作（简化）：**
1. 每个 token 被转换为三个向量：**Query**、**Key** 和 **Value**。
2. 该模型通过将每个查询与每个键进行比较来计算注意力分数。
3. 这些分数决定了每个令牌对其他每个令牌的“关注”程度。
4. 值的加权和产生上下文感知的表示。

注意力核心的数学公式是：

**注意力(Q,K,V) = softmax(QK^T / √d) × V**

除以 √d（关键维度的平方根）可以防止点积变得太大，否则会将 softmax 函数推入梯度极小的区域。这个简单的缩放技巧是使深度 Transformer 训练稳定的关键见解之一。

这在多个**注意力头**中并行重复，允许模型同时捕获不同类型的关系——一个头中的语法，另一个头中的语义。

## 景观中的关键模型

|型号|创作者|显着特点|
|--------|---------|-----------------|
| **GPT-6 Astra** | OpenAI | 前沿推理、编程、研究和多模态输入 |
| **Claude Opus 5.5** | Anthropic | 长时间运行的智能体编程与知识工作 |
| **Gemini 3.1 Pro** | Google DeepMind | 高级推理、编程和多模态 |
| **Llama 4** | Meta | 开放权重、原生多模态、长上下文 |
| **Mistral Large** | Mistral AI | 高效的欧洲替代方案 |

该领域发展得非常快——当您阅读本文时，更新的模型可能已经存在。

这个领域的一个关键区别是**闭源**模型（GPT、Claude、Gemini）和**开放权重**模型（Llama、Mistral）之间的区别。前者只提供 API，后者公开发布模型权重。开放权重模型允许组织在自己的基础设施上运行推理，针对特定领域进行微调，并检查模型行为，这些优势对隐私敏感行业非常重要。

<Callout>并非所有“开放”模型都是真正的开源。有些发布权重但限制商业用途或不共享训练数据和代码。在生产中部署开放权重模型之前，请务必检查许可证。
</Callout>

## 预训练、微调和 RLHF

LLM 是分阶段建立的：

1. **预训练** - 模型读取大量文本并学习预测下一个标记。这个阶段非常昂贵，并且生成一个可以完成文本的基本模型，但并不是特别有用。

2. **监督微调 (SFT)** - 人工编写的理想响应示例教会模型遵循指令并正确回答问题。

3. **RLHF（人类反馈强化学习）** - 人类评分者将模型输出从最好到最差进行排名。奖励模型学习这些偏好，并且法学硕士经过训练以最大化奖励。这就是模型变得有用、无害且诚实的原因。

## 新兴能力

随着模型规模的扩大，它们会发展出未经明确训练的能力：

- **复杂推理** - 多步骤逻辑演绎和数学问题解决。
- **代码生成** - 跨数十种语言编写、调试和解释代码。
- **多语言流畅性** - 用训练数据相对较少的语言翻译和生成文本。
- **情境学习** - 根据提示中提供的示例调整行为，无需任何权重更新。

这些新出现的属性是缩放最令人着迷的方面之一——一旦模型超过一定的尺寸阈值，这些能力几乎“免费”出现。

<FunFact>早期 frontier models 清楚地展示了这种模式：它们可以通过困难的专业考试，但当 prompt 暴露弱点时，仍可能在简单算术或计数任务上出错。</FunFact>
</FunFact>

## 您必须了解的限制

法学硕士很强大，但远非完美：

- **幻觉** - 模型生成听起来自信的文本，但实际上是错误的。他们不“了解”事实；他们预测可能的标记序列。
- **上下文窗口限制** - 每个模型都有最大输入大小，当前前沿系统从数十万到超过一百万 tokens 不等。超出此窗口的信息根本不可见。
- **成本和延迟** - 在大型模型上运行推理需要昂贵的 GPU 集群。顶级 frontier query 的成本明显高于小型或中型模型 query。
- **缺乏真正的理解** - 法学硕士操纵文本中的统计模式。这是否构成“理解”是一个深刻的哲学争论。
- **训练数据截止** - 模型在收集训练数据后不知道事件，除非使用检索系统进行增强。

<Callout>始终根据权威来源验证法学硕士输出的关键事实。将法学硕士视为才华横溢但不可靠的研究助理——非常有用，但永远不是事实的最终定论。
</Callout>

## 扩展性争论

多年来，人们普遍认为**越大越好**：更多参数、更多数据和更多计算会稳步提高性能。这种“缩放法则”在 GPT-2、GPT-3、GPT-4 这一代以及后来的前沿系统中都非常有效。

然而，最近的研究表明，仅就原始规模而言，我们可能正在接近收益递减。重点正在转向：
- **比数量更好的数据质量**（精心策划、去重的数据集）。
- **推理时间计算** - 让模型在难题上“思考得更久”，而不是让模型本身变得更大。
- **专业架构** - 专家混合模型，每次查询仅激活一小部分参数，从而在不牺牲功能的情况下提高效率。

## 总结

大型语言模型代表了计算领域真正的范式转变。对于任何认真从事人工智能工作的人来说，了解其架构、训练流程和局限性并不是可选的——随着该领域的不断发展，这些基础知识将为您提供良好的服务。
