# 注意力和变形金刚 - 改变一切的架构

当今的每个主要语言模型 - GPT-4、Claude、Gemini、LLaMA - 都是基于 Transformer 架构构建的。它发表在 2017 年具有里程碑意义的论文《Attention Is All You Need》中，用一种名为 **self-attention** 的机制取代了循环，解锁了前所未有的并行性和性能。

## 为什么 RNN 会碰壁

循环神经网络一次处理一个标记，向前传送隐藏状态。这会产生两个严重的问题：

- **梯度消失** - 当梯度通过数百个时间步传播回来时，它会缩小到接近零，从而无法学习长程依赖关系。
- **顺序瓶颈** - 每一步都依赖于前一步，因此您无法跨序列并行训练。 1,000 个令牌输入需要 1,000 次串行操作。

LSTM 和 GRU 添加了缓解梯度消失的门控机制，但它们从未解决并行化问题。训练基本上仍然缓慢。

## 注意力直觉

想象一下阅读很长的段落并被问到*“首席执行官宣布了什么？”*您的眼睛不会按顺序重新阅读每个单词 - 它们**跳到相关句子**。注意力的工作方式相同：它让每个标记查看其他所有标记，并决定哪些标记对其当前上下文最重要。

将其视为**舞台上的聚光灯**。该模型不是均匀地照亮整个舞台，而是学习将明亮的光束照射到带有与当前任务最相关的信息的标记上。

## 查询、键、值——核心机制

自注意力借用了信息检索中的术语。对于每个标记，模型计算三个向量：

- **查询 (Q)** - *“我在寻找什么？”*
- **密钥 (K)** - *“我包含什么信息？”*
- **价值 (V)** - *“如果被选中，我实际上会贡献什么？”*

两个标记之间的注意力分数是 Q 和 K** 的点积，按 √d_k（关键维度）缩放以防止值爆炸。应用 softmax 产生归一化权重，输出是所有 V 向量的加权和：

```
Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V
```

**演练：**考虑句子*“The cat sat on the mat because it was累了。”*在处理*“it”*时，对*“it”*的查询最强烈地关注*“cat”*（高Q·K分数），解决了模棱两可的代词 - 不需要重复。

## 多头注意力

单个注意力头一次只能捕获一种类型的关系。 **多头注意力**并行运行多个注意力头，每个注意力头都有自己学习的 Q、K、V 投影，然后连接并投影结果：

```
MultiHead(Q, K, V) = Concat(head₁, ..., headₕ) · Wᴼ
```

不同的大脑学习不同的语言模式——一个可能关注句法依赖性，另一个关注语义相似性，第三个关注位置接近度。 GPT-3使用96个头；每个人都看到完整 12,288 维空间的 128 维切片。

<FunFact>谷歌的研究人员发现，BERT 中的个体注意力头非常专业——一些跟踪主谓一致，另一些处理共指解析，还有一些甚至学习依存解析，所有这些都没有明确的监督。
</FunFact>

## 位置编码

自注意力是**排列不变** - 它对待*“狗咬人”*与*“人咬狗”*相同，除非我们注入位置信息。最初的 Transformer 使用正弦编码：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

每个位置都有不同频率的独特正弦波和余弦波模式。这使得模型能够学习相对位置，因为 `PE(pos+k)` 可以表示为 `PE(pos)` 的线性函数。现代模型（GPT、LLaMA）使用**旋转位置嵌入（RoPE）**，它将相对位置直接编码到 Q/K 点积中。

## 完整的 Transformer 架构

原始 Transformer 具有 **编码器-解码器** 结构：

- **编码器** - 通过双向自注意力处理完整输入（每个令牌都关注其他令牌）。堆叠 N 层自注意力+前馈块，具有残差连接和层归一化。
- **解码器** - 使用**因果（屏蔽）自注意力**（每个令牌只能关注先前的令牌）以及对编码器输出的交叉注意力来自动生成输出。

每个子层都遵循模式：`LayerNorm(x + Sublayer(x))`，其中残差连接确保梯度在深堆栈中自由流动。

<ThinkAboutIt>Transformer 的残差连接允许梯度直接流过 100 多个层。如果没有它们，96 层 GPT-3 几乎不可能训练。这与使 ResNets 适用于深度计算机视觉的跳跃连接有何关系？
</ThinkAboutIt>

## 为什么 Transformer 需要并行化

关键见解：自注意力在**单矩阵乘法**中计算所有成对令牌交互。对于长度为 n 的序列，整个 n×n 注意力矩阵在 GPU 硬件上同时计算。将此与 RNN 进行对比，无论可用的计算如何，RNN 都需要 n 个连续步骤。

这种 O(1) 深度（恒定顺序操作）与 RNN 的 O(n) 深度相比，正是 Transformer 在训练期间扩展到数千个标记序列的原因。

## 仅解码器 vs 仅编码器 vs 编码器-解码器

原始设计中出现了三种架构变体：

|变体 |注意|示例|最适合 |
|--------|---------|---------|---------|
| **仅编码器** |双向|伯特，罗伯塔 |分类、NER、嵌入 |
| **仅解码器** |因果关系（从左到右）| GPT、LLaMA、克劳德 |文本生成、聊天、推理 |
| **编码器-解码器** |两者 | T5、BART、耳语 |翻译、摘要 |

仅解码器模型如今占据主导地位，因为**生成是通用接口** - 任何 NLP 任务都可以被定义为文本生成。这种架构的简单性也可以更可预测地扩展。
