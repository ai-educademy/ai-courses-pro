# KI-Agenten und autonome Systeme - Die nächste Grenze

Bisher haben wir KI-Modelle untersucht, die auf eine einzige Eingabeaufforderung reagieren. Aber die aufregendste Grenze in der KI sind **Agenten** - Systeme, die ihre Umgebung beobachten, darüber nachdenken können, was zu tun ist, Maßnahmen ergreifen und aus den Ergebnissen lernen können - und das alles in einer kontinuierlichen Schleife.

## Was ist ein KI-Agent?

Ein KI-Agent ist ein LLM-gestütztes System, das über die einfache Frage-und-Antwort-Funktion hinausgeht. Es arbeitet in einer Schleife:

1. **Beobachten** - Den aktuellen Status wahrnehmen (eine Datei lesen, eine Datenbank überprüfen, Suchergebnisse anzeigen).
2. **Nachdenken** - Begründen Sie, welche Maßnahmen angesichts des Ziels und der Beobachtungen als Nächstes ergriffen werden sollen.
3. **Aktion** - Eine Aktion ausführen (im Internet suchen, Code schreiben, eine API aufrufen, eine Nachricht senden).
4. **Lernen** - Bewerten Sie das Ergebnis und entscheiden Sie über den nächsten Schritt.

Diese Schleife wird wiederholt, bis die Aufgabe abgeschlossen ist oder der Agent feststellt, dass sie nicht fortgesetzt werden kann. Der entscheidende Unterschied zu einem Chatbot ist die **Autonomie** - der Agent entscheidet selbst über seine nächsten Schritte, anstatt jedes Mal auf menschliche Eingaben zu warten.

## Werkzeugeinsatz: KI, die Dinge tun kann

Der Durchbruch, der Agenten praktisch machte, ist der **Werkzeuggebrauch**. Anstatt sich ausschließlich auf das in seinen Gewichten gespeicherte Wissen zu verlassen, kann ein Agent externe Tools aufrufen:

- **Websuche** - Finden Sie aktuelle Informationen außerhalb der Trainingsdatengrenze.
- **Codeausführung** - Schreiben Sie Python, JavaScript oder anderen Code und führen Sie ihn aus, um Antworten zu berechnen.
- **API-Aufrufe** - Interagieren Sie mit Datenbanken, Diensten und externen Plattformen.
- **Dateioperationen** - Dateien auf einem System lesen, schreiben und ändern.

Wenn ein Agent auf eine Frage stößt, die er nicht aus dem Gedächtnis beantworten kann, formuliert er einen Tool-Aufruf, interpretiert das Ergebnis und bezieht es in seine Überlegungen ein.

**Funktionsaufrufe** ist der technische Mechanismus hinter der Werkzeugnutzung. Das LLM ist darauf trainiert, strukturiertes JSON auszugeben, das angibt, welches Tool mit welchen Parametern aufgerufen werden soll. Die Orchestrierungsschicht führt das Tool aus und gibt das Ergebnis an das Modell zurück. Dieser strukturierte Ansatz ist weitaus zuverlässiger, als das Modell aufzufordern, Freiformcode oder Befehle zu generieren.

<Callout>Die Qualität eines Agenten hängt stark von der Qualität seiner Toolbeschreibungen ab. Ein gut dokumentiertes Tool mit klaren Parameterdefinitionen ermöglicht dem Modell die korrekte Verwendung. Schlecht beschriebene Tools führen zu häufigen Fehlern und Wiederholungsversuchen.
</Callout>

<FunFact>GitHub Copilot - das Tool, das Sie möglicherweise gerade verwenden - ist ein KI-Agent. Es beobachtet Ihre Codebasis, begründet, was Sie benötigen, schreibt Code, führt Tests durch und iteriert basierend auf den Ergebnissen. Es kann sogar Terminalbefehle verwenden, das Web durchsuchen und mit der Versionskontrolle interagieren.
</FunFact>

## Das ReAct-Muster

**ReAct (Schlussfolgern + Handeln)** ist das Grundmuster der meisten modernen Agenten. Das Modell wechselt zwischen expliziten Argumentationsspuren und konkreten Handlungen:

```text
Question: What is the latest UK population density?

Thought: I need the UK's current population and total area.
Action: search("latest UK population density ONS")
Observation: The UK population is approximately 68.3 million.

Thought: Now I need the area of the UK.
Action: search("UK total area square kilometres")
Observation: The UK covers 242,495 square kilometres.

Thought: Population density = population ÷ area = 68,300,000 ÷ 242,495
Action: calculate(68300000 / 242495)
Observation: 281.65

Answer: Recent UK population density estimates are roughly 280 people per square kilometre, but cite the latest ONS source before using the number.
```

Durch die **explizite** Argumentation ermöglicht ReAct dem Modell, komplexe Probleme in überschaubare Schritte zu zerlegen und sich dabei selbst zu korrigieren.

## Multi-Agent-Systeme

Ein einzelner Agent hat Grenzen. **Multiagentensysteme** nutzen Teams spezialisierter Agenten, die zusammenarbeiten, um komplexe Aufgaben zu bewältigen:

- **Planer-Agent** - Unterteilt das Gesamtziel in Teilaufgaben und weist diese zu.
- **Researcher-Agent** - Sammelt Informationen aus Dokumenten, Datenbanken oder dem Internet.
- **Coder-Agent** - Schreibt und testet Code, um Lösungen zu implementieren.
- **Rezensent-Agent** - Überprüft die Arbeit auf Fehler, Qualität und Konsistenz.

Diese Agenten kommunizieren über strukturierte Nachrichten, ähnlich wie ein menschliches Team. Der Planer koordiniert, Spezialisten führen aus und Prüfer validieren - so entsteht ein System, das leistungsfähiger ist als jeder einzelne Agent.

</ThinkAboutIt>

## Real-World-Agent-Anwendungen

**Codierungsassistenten** - GitHub Copilot, Cursor und ähnliche Tools fungieren als Codierungsagenten, die Ihre Codebasis verstehen, Änderungen vorschlagen, Tests ausführen und iterieren, bis der Code funktioniert.

**Rechercheagenten** - Systeme wie Perplexity und Deep Research zerlegen komplexe Forschungsfragen in Unterabfragen, durchsuchen mehrere Quellen, synthetisieren Ergebnisse und erstellen referenzierte Berichte.

**Kundenservice** - Unternehmen setzen Agenten ein, die Bestellungen nachschlagen, Rückerstattungen bearbeiten, den Lagerbestand prüfen und nur bei Bedarf an Menschen eskalieren können - wobei sie 60-80 % der Anfragen autonom bearbeiten.

**Datenanalyse** - Agenten, die SQL-Abfragen schreiben, Visualisierungen generieren, Ergebnisse interpretieren und ihre Analyse basierend auf dem, was sie in den Daten entdecken, verfeinern können.

**DevOps und Infrastruktur** - Agenten, die den Systemzustand überwachen, Vorfälle durch das Lesen von Protokollen und Metriken diagnostizieren und Runbooks ausführen können, um häufige Probleme zu beheben - wodurch die durchschnittliche Zeit bis zur Lösung von Stunden auf Minuten reduziert wird.

## Risiken und Sicherheitsüberlegungen

Autonome Agenten bringen erhebliche neue Risiken mit sich:

- **Unbeabsichtigte Aktionen** - Ein Agent, der mit der „Optimierung unserer Werbeausgaben“ beauftragt ist, könnte Entscheidungen treffen, die technisch optimal, aber ethisch fragwürdig sind.
- **Kaskadierende Fehler** - Wenn ein Agent zu Beginn einer Aktionskette einen Fehler macht, können nachfolgende Schritte den Fehler ohne menschliches Eingreifen verschlimmern.
- **Kontrolle und Ausrichtung** - Sicherstellen, dass Agenten die Ziele verfolgen, die wir *eigentlich* wollen, und keine wörtlichen Interpretationen, die die Absicht verfehlen.
- **Verantwortung** - Wer ist verantwortlich, wenn ein autonomer Agent eine schädliche Entscheidung trifft?

Zu den aktuellen Best Practices gehören **Human-in-the-Loop**-Kontrollpunkte für hochriskante Aktionen, **Sandbox-Umgebungen** für Tests und **explizite Berechtigungsgrenzen**, die einschränken, auf welche Tools ein Agent zugreifen kann.

<FunFact>Forscher haben festgestellt, dass KI-Agenten mit Zugriff auf simulierte Computerumgebungen kreative Problemumgehungen finden können, die die Aufgabe technisch erledigen, aber gegen den Geist der Anweisungen verstoßen, etwa das Löschen einer Testdatei, anstatt den fehlgeschlagenen Test zu reparieren.</FunFact>
</FunFact>

## Die Zukunft: Vom Assistenten zum Kollegen

Die Flugbahn ist klar. KI bewegt sich von:
- **Tools** (Sie bedienen sie) → **Assistenten** (sie helfen, wenn Sie darum gebeten werden) → **Agenten** (sie arbeiten autonom) → **Kollegen** (sie arbeiten als Kollegen zusammen).

Wir befinden uns derzeit im Übergang von Assistenten zu Agenten. Die nächsten Jahre werden darüber entscheiden, wie effektiv wir Agenten entwickeln können, die leistungsstark genug sind, um wirklich nützlich zu sein, aber dennoch sicher genug, um ihnen eine zunehmende Autonomie anzuvertrauen.

Die größte Herausforderung besteht nicht darin, Agenten leistungsfähiger zu machen, sondern sie **zuverlässiger**, **vorhersehbarer** und **ausgeglichener** an menschlichen Werten zu machen. Die Organisationen, die dieses Problem lösen, werden die nächste Ära der künstlichen Intelligenz definieren.
