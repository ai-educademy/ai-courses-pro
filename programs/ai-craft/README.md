## Overview

Learn system design for modern AI products: model gateways, retrieval services, async workloads, streaming, caches, rate limits, tenancy, and resilient APIs.

This private repo contains Pro subscriber lessons for this programme.

## Programme facts

| Field | Value |

| Lessons | 10 |
| Estimated study time | 18 hours |
| Audience | Mid-to-senior engineers designing distributed AI systems |
| Prerequisites | Comfort with APIs, databases, and distributed-system basics |

## Topics

- AI platform and model gateways
- RAG and vector retrieval services
- Queues, streaming, and async inference
- Caching, rate limits, and tenancy
- Resilience, security, and observability

## Outcomes

- Produce a clear architecture with justified trade-offs
- Design for failure, scale, and operational visibility
- Estimate AI cost and capacity before implementation
- Defend an AI system design in a technical review
