# तकनीकी रिज़्यूमे मास्टरक्लास - ATS पार करके interviews तक पहुँचें

आपके रिज़्यूमे को मानव ध्यान के **छह सेकंड** मिलते हैं, वह भी अगर वह किसी मानव तक पहुँचे। ज़्यादातर बड़ी कंपनियों में Applicant Tracking System (ATS) किसी recruiter के देखने से पहले आपके रिज़्यूमे को parse और rank करता है। ATS सॉफ़्टवेयर कैसे काम करता है, यह समझना interview तक पहुँचने का पहला चरण है।

## ATS सॉफ़्टवेयर असल में कैसे काम करता है

ATS (Applicant Tracking System) एक सॉफ़्टवेयर है जो resumes को keywords के लिए scan करता है, उम्मीदवारों को rank करता है, और job description से मेल न खाने वाले applications फ़िल्टर कर देता है। Workday, Greenhouse और Lever जैसी कंपनियाँ Fortune 500 firms में से 95% से ज़्यादा की hiring को power करती हैं।

ATS तीन काम करता है:

1. रिज़्यूमे को structured fields में **parse** करता है (name, email, experience, skills)
2. Job description के keywords को आपके content से **match** करता है
3. आपको बाकी applicants के मुकाबले **rank** करता है

<FunFact>75% से ज़्यादा resumes मानव के पढ़ने से पहले ATS सॉफ़्टवेयर द्वारा reject कर दिए जाते हैं। अच्छी तरह formatted, keyword-optimised रिज़्यूमे आपके chances काफ़ी बढ़ाता है।</FunFact>

## One-page rule

जब तक 15+ साल का अनुभव न हो, इसे **एक page** में रखें। Google, Amazon और Meta के recruiters ने सार्वजनिक वार्ताओं में यह बार-बार confirm किया है। एक केंद्रित page हमेशा दो diluted pages से बेहतर है।

## रिज़्यूमे sections जो मायने रखते हैं

### 1. Header
नाम, email, phone, location (सिर्फ़ शहर), LinkedIn URL, GitHub URL, portfolio link। No photo, no date of birth, no marital status।

### 2. Professional Summary (2-3 lines)
एक संक्षिप्त pitch: role, वर्षों का अनुभव, key technologies, और एक headline achievement।

> *"Senior Backend Engineer with 6 years building distributed systems in Java and Go. Led migration of payment service to event-driven architecture, reducing latency by 40% and saving £120K annually."*

### 3. अनुभव (core section)
हर bullet के लिए **XYZ formula** इस्तेमाल करें: *Accomplished **X** by doing **Y**, resulting in **Z**.*

| कमज़ोर | मज़बूत (XYZ) |
|------|--------------|
| "सर्च फ़ीचर पर काम किया" | "BM25 ranking लागू करके search relevance 23% बेहतर की, user engagement 15% बढ़ाया" |
| "CI/CD की ज़िम्मेदारी थी" | "GitHub Actions में parallel test stages पर migrate करके deployment time 45 मिनट से 8 मिनट किया" |

### 4. कौशल
Technologies ईमानदारी से list करें। उन्हें group करें: **Languages**, **Frameworks**, **Cloud/DevOps**, **Data**। Job description के exact terms से match करें। अगर listing "Kubernetes" कहती है तो "K8s" नहीं, "Kubernetes" लिखें।

### 5. Education
Degree, university, graduation year। Relevant coursework या thesis सिर्फ़ तब जोड़ें जब आप early-career हों।

## Action verbs जो ATS filters पास करें

हर bullet मज़बूत verb से शुरू करें: **Designed**, **Implemented**, **Migrated**, **Reduced**, **Orchestrated**, **Optimised**, **Automated**, **Scaled**, **Mentored**, **Delivered**।

कमज़ोर शुरुआत से बचें: "मदद की", "सहायता की", "ज़िम्मेदार था", "भाग लिया"।
## हर नौकरी विवरण के हिसाब से ढालना

नौकरी विवरण को किसी दस्तावेज़ में कॉपी करें। **शीर्ष 10 कीवर्ड** (तकनीकें, कार्यपद्धतियाँ, डोमेन शब्द) हाइलाइट करें। सुनिश्चित करें कि उन 10 में से कम से कम 7 आपके रिज़्यूमे में स्वाभाविक रूप से आएँ। यह सिस्टम से खेलना नहीं है - यह नियोक्ता की भाषा बोलना है।

अपने सारे अनुभव के साथ एक **मास्टर रिज़्यूमे** बनाएँ, फिर हर आवेदन के लिए उसकी अनुकूलित कॉपी बनाएँ। मास्टर को अपना एकल सत्य स्रोत रखें और भूमिका के हिसाब से छोटा करें। ML प्लेटफ़ॉर्म भूमिका के लिए आवेदन करने वाला बैकएंड इंजीनियर डेटा पाइपलाइन और इन्फ्रास्ट्रक्चर अनुभव पर ज़ोर देगा; वही व्यक्ति शुद्ध बैकएंड भूमिका के लिए API डिज़ाइन और स्केलेबिलिटी से शुरुआत करेगा।
<ThinkAboutIt>कोई job listing चुनें जिसमें आपकी रुचि है। शीर्ष 10 keywords पहचानें। आपके वर्तमान रिज़्यूमे में उनमें से कितने हैं? आप क्या जोड़ सकते हैं या फिर से लिख सकते हैं?</ThinkAboutIt>

## आम गलतियाँ जो applications ख़त्म कर देती हैं

- **Columns, tables या graphics वाले fancy templates** - ATS उन्हें parse नहीं कर सकता। Single-column, साफ़ layout इस्तेमाल करें।
- **कौशल के बारे में झूठ बोलना** - technical interviews तुरंत पकड़ लेंगे, और bridges permanent रूप से burn हो जाते हैं।
- **हर technology शामिल करना जिसे आपने कभी छुआ है** - सिर्फ़ वही list करें जिन पर आप interview में आत्मविश्वास से बात कर सकते हैं।
- **Images या scanned text वाली PDF** - word processor से export की गई text-based PDF इस्तेमाल करें।
- **Generic objective statement** - "seeking a challenging role" को targeted professional summary से बदलें, जिसमें company और role का नाम हो।
- **Dates छोड़ना** - interviewers notice करते हैं और मान लेते हैं कि आप employment gaps छिपा रहे हैं। पारदर्शी रहें, gaps सामान्य हैं।

## GitHub profile optimisation

GitHub आपका living portfolio है। Recruiters **जाँच करते हैं**।

- **4-6 सर्वश्रेष्ठ repositories pin करें** स्पष्ट README files के साथ (problem, solution, tech stack, how to run)
- **Profile README लिखें** (`username/username` repository) छोटी bio और links के साथ
- **Contribution graph बनाए रखें** - निरंतरता तीव्रता से ज़्यादा मायने रखती है
- **पुरानी repositories साफ़ करें** - archive करें या शर्मनाक ones private करें

## Portfolio links और personal sites

Personal site या portfolio हो, तो header में शामिल करें। Well-structured portfolio page में यह होना चाहिए:

- **Featured projects** live demos या screenshots के साथ
- छोटा **"About me"** section जो रिज़्यूमे summary से मेल खाए
- **लेख या वार्ताएँ के लिंक**
- तेज़ loading और mobile-friendly अनुभव

Generic subdomain की बजाय custom domain इस्तेमाल करें (e.g., `janedoe.dev`)। यह professionalism दिखाता है।

## LinkedIn synergy

LinkedIn और रिज़्यूमे **एक ही कहानी** अलग-अलग गहराई के साथ बताएं। LinkedIn ज़्यादा detail, media और recommendations की अनुमति देता है। Job titles, dates और companies ठीक-ठीक match करें। Discrepancies red flags उठाती हैं।

मुख्य LinkedIn optimisations:
- **Headline**: लक्षित भूमिका और key technologies इस्तेमाल करें, सिर्फ़ current title नहीं
- **About section**: अपने summary को narrative tone और call to action के साथ विस्तार दें
- **Featured section**: अपने सबसे अच्छे लेख, talks या project demos pin करें
- **सिफ़ारिशें**: 2-3 मैनेजर या वरिष्ठ सहयोगियों से अनुरोध करें जो विशिष्ट उपलब्धियों पर बोल सकें

## Submit करने से पहले रिज़्यूमे checklist

- [ ] Single-column, no graphics, no tables
- [ ] Contact info पूरी (email, phone, LinkedIn, GitHub)
- [ ] हर bullet XYZ या action-verb-plus-impact format इस्तेमाल करे
- [ ] Skills section job description keywords mirror करे
- [ ] No typos (spell-checker और human reviewer इस्तेमाल करें)
- [ ] Text-based PDF के रूप में save करें
- [ ] One page (unless 15+ years experience)
