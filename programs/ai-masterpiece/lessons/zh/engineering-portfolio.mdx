# 工程组合

在人工智能时代，你的投资组合是你最强大的职业资产。当您不在房间时，它会说话，在您睡觉时工作，并且可以同时联系数千名招聘经理。

一份精美的简历可以让你脱颖而出。强大的投资组合可以让您**摆脱困境**。

<Illustration src="/images/lessons/engineering-portfolio.svg" alt="显示连接在一起的 GitHub、博客和个人网站的开发者资料" caption="您的投资组合是一个生态系统 - 每一个部分都可以增强其他部分" />

## 为什么作品集胜过简历

简历告诉某人您声称做过什么。投资组合**证明**这一点。

人工智能和软件工程领域的招聘经理平均要花六秒钟的时间来写一份简历。但当他们点击进入精心设计的 GitHub 个人资料或个人网站时，他们会花费几分钟——有时甚至更长。这种额外的关注就是拒绝电子邮件和第一轮面试之间的区别。

<Callout>将您的投资组合视为一种产品，将招聘经理视为您的用户。每个要素都应该减少摩擦并建立信任。
</Callout>

## GitHub：您的公共研讨会

您的 GitHub 个人资料是技术招聘人员首先查看的地方。让它算数。

### 配置文件自述文件
在以您的用户名命名的存储库中创建一个 `README.md`。它出现在您的个人资料的顶部。包括：

- 关于您是谁以及您关注什么的一行摘要。
- 两到三个要点突出您最强的技能。
- 指向您最佳项目、博客和 LinkedIn 的链接。

### 固定存储库
您最多可以固定六个存储库。选择显示**范围和深度**的项目：

- 一个已部署的端到端 ML 项目。
- 一个展示工程严谨性的后端或系统项目。
- 一项开源贡献（甚至是具有有意义更改的分叉）。

### 贡献图
一致性比强度更重要。稳定的绿色方块图表示可靠性。目标是小规模、定期的提交，而不是零星的突发。

## 项目展示：构建什么

在招聘经理眼中，并非所有项目都是平等的。最好的投资组合项目具有三个共同特征：

1. **他们解决了一个真正的问题** - 即使是一个小问题。
2. **它们已部署且可访问** - 实时链接每次都胜过自述文件。
3. **其中包括一篇文章** - 解释您的决定、权衡和经验教训。

避免明显是教程后续项目。如果其他一千人用相同的代码构建了相同的东西，那并不会让你与众不同。

<ThinkAboutIt>看看您当前的项目。在面试中演示哪一个是您最自豪的？如果它们都不能让你兴奋，那就是你要创造新事物的信号。
</ThinkAboutIt>

## 撰写技术博客文章

博客是大多数工程师忽视的杠杆率最高的投资组合项目。

**为什么有效：**
- 它展示了工程学中稀缺的沟通技巧。
- 它吸引了招聘人员和合作者的兴趣。
- 它加深了你自己的理解 - 你无法解释你不真正知道的事情。

**要写什么：**
- 您做出的技术决定以及原因。
- 你花了几个小时调试的错误以及你学到的东西。
- 您评估的两种工具或方法的比较。

**发布地点：**
- **Dev.to** 或 **Hashnode** 用于可发现性。
- **您自己的网站**，可长期拥有。
- 交叉发布到两者以获得最大范围。

<FunFact>Stack Overflow 联合创始人杰夫·阿特伍德 (Jeff Atwood) 将他的博客“Coding Horror”视为他职业生涯中最重要的因素。他多年来一直坚持写作，直到它成为有史以来最重要的开发者平台之一。
</FunFact>

## 针对工程师的 LinkedIn 优化

许多工程师忽视了 LinkedIn，但招聘人员却住在那里。一些高影响力的调整：

- **标题**：跳过“X 的软件工程师”。相反，请尝试“ML 工程师 | 构建人工智能驱动的搜索系统 | 拥抱机遇”。
- **关于部分**：写三个简短的段落 - 您做什么、您构建了什么以及您正在寻找什么。
- **特色部分**：固定您最好的博客文章、项目演示或会议演讲。
- **技能**：列出具体技术（PyTorch、Kubernetes、FastAPI），而不是模糊的术语（解决问题、团队合作）。

## 个人网站：包含哪些内容

您的个人网站是您的大本营。保持简单和快速加载。

**包括：**
- 带有专业照片的简短简历。
- 通过屏幕截图或演示链接到您的前三个项目。
- 您的博客或其链接。
- 联系信息或简单的表格。

**跳过：**
- 精美的动画会减慢页面速度。
- 带有百分比条的技能部分 - 它们没有任何意义。
- 您曾经构建的每个项目。无情地策划。

<FunFact>谷歌的招聘研究发现，在控制经验水平和资格的情况下，拥有个人网站的候选人收到回电的可能性比没有个人网站的候选人高 27%。
</FunFact>

## 投资组合审查清单

在您考虑完成您的投资组合之前，请先浏览一下此列表：

- [ ] GitHub 配置文件有一个自述文件、六个固定存储库和一致的贡献图。
- [ ] 至少有一个项目已部署并带有实时链接。
- [ ] 每个固定项目都有一个明确的自述文件，其中包含目的、设置说明以及屏幕截图或演示。
- [ ] 您至少发表了一篇技术博客文章。
- [ ] LinkedIn 标题、关于部分和特色内容得到优化。
- [ ] 个人网站加载时间不到三秒，并且可以在移动设备上运行。
- [ ] 非技术朋友可以从您的网站了解您所做的事情。

<ThinkAboutIt>将你的作品集链接发送给科技领域以外的人，并询问他们：“你能告诉我我做什么以及我是否擅长吗？”他们的答案将揭示你自己看不到的盲点。
</ThinkAboutIt>
