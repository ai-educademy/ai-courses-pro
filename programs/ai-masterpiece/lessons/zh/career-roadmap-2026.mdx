# 2026 年职业路线图

人工智能就业市场的变化速度比任何其他科技领域都要快。三年前几乎不存在的职位现在薪水最高，而一些传统职位正在悄然消失。

本课程为您提供了清晰的地图：市场走向何方、投资哪些技能以及未来 90 天内具体要做什么。

## 人工智能时代的工作格局

**增长的是什么：**
- 应用 ML 和 MLOps 角色（同比增长 34%）。
- 人工智能产品管理 - 连接业务和模型。
- 人工智能安全和一致性研究。
- 快速工程和法学硕士应用程序开发。

**缩小的是什么：**
- 手动数据标记（日益自动化）。
- 没有人工智能测试技能的传统 QA 角色。
- 法学硕士现在可以在几秒钟内处理日常分析。

结论很简单：**创建、部署和管理人工智能**的角色正在蓬勃发展。人工智能可以**取代**的角色正在萎缩。

## 首要目标角色

### 机器学习工程师
在生产中构建和部署模型。需要强大的软件工程和机器学习基础知识。英国中位工资：85,000 英镑至 130,000 英镑。

### 人工智能产品经理
将业务问题转化为人工智能解决方案。需要产品意识、数据素养和足够的技术深度来挑战工程师。工资中位数：9万英镑至14万英镑。

### 提示工程师/法学硕士应用程序开发人员
设计和优化法学硕士支持的应用程序。需要对语言模型、评估和用户体验有深入的了解。工资中位数：7万英镑至11万英镑。

### 人工智能安全研究员
致力于一致性、公平性和稳健性。需要强大的数学、研究技能和道德推理能力。工资中位数：8 万英镑至 15 万英镑（变化很大）。

</ThinkAboutIt>

## 复合技能

有些技能可以使你所知道的其他一切的价值成倍增加。投资这三项：

1. **系统设计** - 构建端到端解决方案的能力。这将高级工程师与初级工程师区分开来。
2. **机器学习基础知识** - 不仅仅是调用 API，而是理解模型为何如此运行。
3. **沟通**​​ - 清晰写作、自信地呈现并向非技术利益相关者解释技术概念。

能够设计系统、构建机器学习组件并**并向董事会解释它的工程师的价值超过三名专家的总和。

<FunFact>LinkedIn Economic Graph 的研究表明，将人工智能技术技能与强大沟通能力相结合的专业人士的平均收入比仅拥有技术技能的专业人士高出 25%。
</FunFact>

## 认证：什么重要，什么不重要

**值得您花时间：**
- **AWS 机器学习专业** 或 **Google 专业 ML 工程师** - 受人尊敬、实用且经过验证的云部署技能。
- **Coursera 上的斯坦福大学或 DeepLearning.AI 课程** - 强烈的信号，特别是对于职业转换者。

**不值得你花时间：**
- 通用“人工智能为每个人”证书，没有实践部分。
- 来自未知平台的付费证书，没有进行严格的测试。
- 收集超过两到三个认证 - 之后，项目的声音更大。

## 建立你的学习路线图

对于以机器学习工程或人工智能应用角色为目标的人来说，这是一个明智的命令：

|季度|重点领域 |结果|
|--------|------------|---------|
| **Q1** | Python + ML 基础知识（scikit-learn、PyTorch 基础知识）|可以在本地训练和评估模型 |
| **第二季度** |深度学习+NLP（变形金刚、微调）|可以构建 LLM 支持的应用程序 |
| **第三季度** | MLOps + 系统设计（Docker、CI/CD、云部署）|可以在生产中部署和监控模型 |
| **第四季度** |顶点项目+求职|作品集准备好，面试准备好 |

将时间线调整到您的起点，但保持顺序：**基础→专业化→部署→证明**。

<Callout>不要试图一次学会所有东西。深度接触一个区域胜过浅度接触十个区域。选择你的车道，深入，然后拓宽。
</Callout>

## 网络倍增器

技能让你有资格。 **人们**雇用你。

- **社区**：加入 MLOps 社区、Weights & Biases Discord 或 Hugging Face 论坛。做出贡献，而不仅仅是潜伏。
- **会议**：每年至少参加一次人工智能会议 - 甚至是虚拟会议。 NeurIPS、ICML 和本地聚会都很重要。
- **开源**：为您使用的项目做出贡献。即使是文档修复也会让您的名字出现在顶级公司的维护人员面前。
- **内容创作**：写下你学到的东西。一篇写得好的博客文章可以吸引数千个潜在的联系。

<FunFact>Jobvite 的一项研究发现，85% 的职位是通过网络而不是在线申请来填补的。在人工智能领域，供不应求，热情的介绍可以让你跳过数百名申请者。
</FunFact>

## 您的 90 天行动计划

从今天开始，这是您的具体计划：

**第 1-30 天：基础**
- 确定您的目标角色并将其写在便利贴上，以便您每天都能看到。
- 根据角色要求审核您的技能。列出三个差距。
- 通过结构化课程或项目开始缩小最大差距。

**第 31-60 天：构建**
- 启动你的顶点项目（参见上一课）。
- 加入一个人工智能社区并自我介绍。
- 撰写您的第一篇技术博客文章或 Twitter 帖子。

**第 61-90 天：启动**
- 部署您的项目并将其添加到您的投资组合中。
- 更新您的简历、LinkedIn 和 GitHub 个人资料。
- 适用于五个角色。联系您欣赏的公司的五位员工。

<ThinkAboutIt>立即打开您的日历。这个周末预留两个小时用于 90 天计划的“第一天”。如果日历上没有，就不会发生。
</ThinkAboutIt>
