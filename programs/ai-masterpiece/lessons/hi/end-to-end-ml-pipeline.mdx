# एनद-टो-एनद ML पाइपलाइन - रव डेटा से तैनात मॉडल तक

ज़्यादातर ट्यूटोरियल `model.fit()` पर रुक जाते हैं। परोदुकशन में, ये बमुश्किल 20% काम है। ये पाठ **पूरे ML लिफ़ेकयकले** को कोवेर करता है - वही पाइपलाइन जो Spotify के अनुशंसा इंजन, Stripe के धोखाधड़ी पहचान, और Google की सर्च रैंकिंग को पोवेर करता है।

## 🗺️ ML लिफ़ेकयकले एक नज़र में

<Illustration src="/images/lessons/end-to-end-ml-pipeline.svg" alt="डेटा इङेसशन से निगरानी तक ML पाइपलाइन चरणस का दिअगरम" caption="परोदुकशन ML पाइपलाइन के आठ चरणस - हर एक संभावित फ़ैलुरे बिंदु है।" />

हर प्रोडक्शन ML सिस्टम इन चरणस से गुज़रता है:

1. **डेटा कोललेकशन** - APIs, डेटाबेस, घटना सटरेअमस, वेब सकरपिङ
2. **डेटा कलेअनिङ** - नुललस संभाल करना, देदुपलिकशन, प्रकार कोएरकिओन
3. **फ़ीचर इंजीनियरिंग** - रव सिग्नल को मोदेल-रेअदय फ़ीचर में बदलना
4. **मॉडल सेलेकशन** - अपनी समस्या से मेल करने वाले आर्किटेक्चर चुनना
5. **ट्रेनिंग** - GPU/CPU ओरचेसटरशन, हयपेरपरमेटेर टुनिङ
6. **मूल्यांकन** - ऑफ़लाइन मेट्रिक्स, A/B परीक्षण, निष्पक्षता औदिटस
7. **देपलोयमेनट** - सर्विंग इन्फ़्रास्ट्रक्चर, लेटेंसी बजट
8. **मोनिटोरिङ** - दरिफ़ट पहचान, अलेरटिङ, रेटरैनिङ ट्रिगर

## 📦 डेटा कोललेकशन और वेरसिओनिङ

रव डेटा आपकी फ़ोउनदशन है। इसे स्रोत कोड की तरह टरेअट करें - **सब कुछ वर्शन करें**।

```bash
# Initialise DVC in your repo
dvc init
dvc remote add -d storage s3://my-ml-data-bucket

# Track a dataset
dvc add data/transactions.csv
git add data/transactions.csv.dvc .gitignore
git commit -m "Track raw transaction dataset v1"
dvc push
```

**DVC** (डेटा वेरसिओन कोनटरोल) आपको किसी भी हिसटोरिकल दटसेट को `git checkout` करने देता है। गिट टगस के साथ मिलाकर, आप किसी भी बिंदु in समय से कोई भी एक्सपेरिमेनट रेबनाने कर सकते हैं।

<FunFact>Netflix अपनी डेटा पाइपलाइन के ज़रिए रोज़ाना 1.5 टरिललिओन से ज़्यादा इवेंट प्रोसेस करता है - हर सेकंड लगभग 17 मिलियन इवेंट जो उनके अनुशंसा मॉडल को फ़ीड करते हैं।</FunFact>

## 🛠️ फ़ीचर इंजीनियरिंग - जहाँ कोमपेटिशनस जीती जाती हैं

फ़ीचर एल्गोरिदमस से ज़्यादा मटटेर करते हैं। शानदार फ़ीचर वाला गरदिएनट-बूसटेद ट्री ख़राब फ़ीचर वाले गहरी न्यूरल नेटवर्क को हरा देता है।

```python
import pandas as pd

df = pd.read_csv("data/transactions.csv", parse_dates=["timestamp"])

# Temporal features
df["hour"] = df["timestamp"].dt.hour
df["is_weekend"] = df["timestamp"].dt.dayofweek >= 5

# Aggregation features
user_stats = df.groupby("user_id")["amount"].agg(["mean", "std", "count"])
user_stats.columns = ["user_avg_amount", "user_std_amount", "user_txn_count"]
df = df.merge(user_stats, on="user_id")

# Ratio features
df["amount_vs_avg"] = df["amount"] / df["user_avg_amount"]
```

## 🧪 मलफ़लोव के साथ एक्सपेरिमेनट टरकिङ

कभी रिकॉर्ड मत खोइए कि आपने क्या टरय किया। मलफ़लोव पैरामीटर, मेट्रिक्स, और अरटेफ़कटस औटोमटिकललय लॉग करता है।

```python
import mlflow
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import f1_score

mlflow.set_experiment("fraud-detection-v2")

with mlflow.start_run(run_name="gbm-baseline"):
    params = {"n_estimators": 500, "max_depth": 6, "learning_rate": 0.05}
    mlflow.log_params(params)

    model = GradientBoostingClassifier(**params)
    model.fit(X_train, y_train)

    score = f1_score(y_test, model.predict(X_test))
    mlflow.log_metric("f1_score", score)
    mlflow.sklearn.log_model(model, "model")
```

मलफ़लोव UI में रुनस कोमपरे करें, फिर श्रेष्ठ मॉडल को **मॉडल रेगिसटरय** में बढ़ावा करें सटगिङ → प्रोडक्शन लिफ़ेकयकले टगस के साथ।

## 🚀 पाइपलाइन as कोड - ओरचेसटरशन

मनुअल सटेपस टूटते हैं। अपनी पाइपलाइन को ओरचेसटरशन ढाँचे से कोड में एनकोदे करें:

| टूल | किसके लिए बेस्ट | मुख्य ताक़त |
|------|-----------------|------------|
| **कुबेफ़लोव पिपेलिनेस** | कुबेरनेटेस-नटिवे ML | मौजूदा K8s कलुसटेरस पर स्केल होता है |
| **अपचे ऐरफ़लोव** | जटिल DAG सचेदुलिङ | मटुरे इकोसिस्टम, विदे अदोपशन |
| **परेफ़ेकट** | आधुनिक Python वर्कफ़्लो | पयथोनिक API, एक्सकेललेनट एररोर हनदलिङ |
| **ज़ेनमल** | MLOps अबसटरकशन | सटक-अगनोसटिक, कोई भी टूल पलुग करें |

<ThinkAboutIt>आपकी पाइपलाइन निघटलय रेटरैन होती है लेकिन डेटा होउरलय बदलता है। रेटरैनिङ फ़रेक्वेनकय देकिदे करते वक़्त आप कौन से टरदे-ओफ़फ़स वेइघ करेंगे - लागत, सटलेनेस, इन्फ़्रास्ट्रक्चर जटिलता?</ThinkAboutIt>

## 🌐 मॉडल सेरविङ और देपलोयमेनट

आपके मॉडल को एक API चाहिए। दो दोमिननट पैटर्न:

**REST API** - सरल, हटटप-बसेद, मध्यम थरोउघपुट के लिए बढ़िया:
```python
# FastAPI model server
from fastapi import FastAPI
import joblib

app = FastAPI()
model = joblib.load("model.pkl")

@app.post("/predict")
async def predict(features: dict):
    prediction = model.predict([list(features.values())])
    return {"prediction": int(prediction[0])}
```

**gRPC** - बाइनरी परोटोकोल, REST से 2-10× तेज़, इनटेरनल मिकरोसेवाएँ और उच्च-थरोउघपुट सकेनरिओस के लिए विचारल।

### कनरय देपलोयमेनटस

कभी भी 100% ट्रैफ़िक नए मॉडल पर मत भेजें। **कनरय रिलीज़स** इस्तेमाल करें: 5% → 25% → 50% → 100% रूट करें, हर चरण पर एररोर दरें मोनिटोर करें। मेट्रिक्स गिरावट हों तो इनसटनटलय रोलल बक करें।

## 📊 मोनिटोरिङ और फ़ीडबैक लूप

देपलोयमेनट समापन लिने नहीं है - ये शुरुआती गुन है। मोनिटोर करें:

- **डेटा दरिफ़ट** - इनपुट डिस्ट्रिब्यूशनस ट्रेनिंग डेटा से शिफ़ट हो रही हैं
- **कोनकेपट दरिफ़ट** - फ़ीचर और लक्षित के बीच रेलशनशिप बदल रहा है
- **पेरफ़ोरमनके गिरावट** - सटीकता/लटेनकय मेट्रिक्स गिर रहे हैं

**एविदेनटलय AI**, **वहयलबस**, और **अरिज़े** जैसे टूल्स दरिफ़ट डैशबोर्ड परोविदे करते हैं। जब दरिफ़ट थरेशोलदस से ज़्यादा हो, फ़रेश प्रोडक्शन डेटा से औटोमटिक रेटरैनिङ ट्रिगर करें - फ़ीडबैक लूप बंद करें।

## 🎯 मुख्य टकेअवयस

- **सब कुछ** वर्शन करें: कोड, डेटा, मॉडल, और पाइपलाइन कोनफ़िगस
- फ़ीचर इंजीनियरिंग आर्किटेक्चर चङेस से ज़्यादा ROI देलिवेर करती है
- पिपेलिनेस को कोड में एनकोदे करें - मनुअल सटेपस तकनीकी देबट हैं
- कनरय रिलीज़स से तैनात करें और रेलेनटलेसलय मोनिटोर करें
- फ़ीडबैक लूप (प्रोडक्शन डेटा → रेटरैनिङ) वो है जो डेमो को प्रोडक्शन सिस्टम से अलग करता है
