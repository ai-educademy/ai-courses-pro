# Kaggle Competition Guide - Kaggle पर कैसे प्रतिस्पर्धा करें और सीखें

Kaggle सिर्फ़ competition platform नहीं है, यह दुनिया की सबसे बड़ी applied ML classroom है। 15 million से अधिक data scientists इसका उपयोग कौशल निखारने, portfolios बनाने और नौकरियां पाने के लिए करते हैं। यह पाठ आपको प्रभावी रूप से प्रतिस्पर्धा करना और हर competition से अधिकतम सीख निकालना सिखाता है।

## 🎯 आपके करियर के लिए Kaggle क्यों मायने रखता है

Kaggle experience वह signal देता है जो CV नहीं दे सकता: **आप messy, real-world data पर काम करने वाले models ship कर सकते हैं**। Google, Meta और top startups के hiring managers Kaggle leaderboards से सक्रिय रूप से recruit करते हैं। जीत न भी मिले, तो भी अच्छी तरह documented notebooks वाला मजबूत profile practical competence दिखाता है।

## 🔍 EDA - आपके पहले 48 घंटे

Data समझे बिना modelling कभी शुरू न करें। Disciplined EDA workflow:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("train.csv")

# Shape and types - know what you're working with
print(f"Shape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum().sort_values(ascending=False).head(10)}")

# Target distribution - is it balanced?
df["target"].value_counts(normalize=True).plot(kind="bar")
plt.title("Target Distribution")
plt.show()

# Correlations - find quick signal
correlations = df.select_dtypes(include="number").corr()["target"].sort_values()
print(correlations.head(10))  # Strongest negative correlations
print(correlations.tail(10))  # Strongest positive correlations
```

**Leakage जांचें** - ऐसे features जो prediction time पर मौजूद नहीं होंगे। Beginners की यह number-one गलती है। अगर कोई feature target से suspiciously अच्छी तरह correlate करता है, तो celebrate करने से पहले जांच करें।

## 🛠️ जीत दिलाने वाली Feature Engineering

Top competitors अपना 70% समय features पर लगाते हैं, model tuning पर नहीं। Battle-tested techniques:

**Aggregation features** - अलग-अलग granularities पर group statistics:
```python
for col in ["category", "store_id", "day_of_week"]:
    stats = df.groupby(col)["sales"].agg(["mean", "std", "median"])
    stats.columns = [f"{col}_sales_{s}" for s in ["mean", "std", "median"]]
    df = df.merge(stats, on=col, how="left")
```

**Target encoding** - categories को smoothed target means से replace करें (leakage रोकने के लिए fold-based encoding इस्तेमाल करें)।

**Lag features** - time series में previous values सोना हैं:
```python
for lag in [1, 7, 14, 28]:
    df[f"sales_lag_{lag}"] = df.groupby("store_id")["sales"].shift(lag)
```

## ✅ Cross-Validation - अपने Local Score पर भरोसा करें

आपका local CV score public leaderboard से ज़्यादा मायने रखता है। Robust validation strategy:

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_predictions = np.zeros(len(X))

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

    model = lgb.LGBMClassifier(n_estimators=1000, learning_rate=0.05)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
              callbacks=[lgb.early_stopping(50)])
    oof_predictions[val_idx] = model.predict_proba(X_val)[:, 1]

print(f"OOF AUC: {roc_auc_score(y, oof_predictions):.5f}")
```

**Golden rule**: अगर आपका local CV और public LB असहमत हों, तो अपने CV पर भरोसा करें। Public leaderboard test data के केवल fraction का उपयोग करता है, उस पर ओवरफ़िट करना trap है।

<ThinkAboutIt>आप public leaderboard पर 15th हैं, लेकिन आपका local CV बताता है कि आपका model overfit है। Final submission के लिए आप अपना best LB score submit करेंगे या best CV score? क्यों?</ThinkAboutIt>

## 🎭 Ensemble Methods - अंतिम धक्का

लगभग हर winning solution ensembles इस्तेमाल करता है। तीन प्रमुख techniques:

**Bagging** - same model को अलग data subsets पर train करें, predictions average करें। Variance घटता है।

**Stacking** - diverse base models की out-of-fold predictions पर meta-model को ट्रेन करें:
```python
# Level 1: diverse base models produce OOF predictions
base_preds = np.column_stack([lgbm_oof, xgb_oof, catboost_oof, nn_oof])

# Level 2: logistic regression learns optimal combination
from sklearn.linear_model import LogisticRegression
meta = LogisticRegression()
meta.fit(base_preds, y_train)
```

**Blending** - model predictions का weighted average. Stacking से सरल लेकिन प्रभावी:
```python
final = 0.4 * lgbm_pred + 0.35 * xgb_pred + 0.25 * catboost_pred
```

## 📓 बेहतरीन Kaggle Notebooks लिखना

Public notebooks आपकी reputation बनाते हैं। Medal-worthy notebook में ये बातें होती हैं:

1. **Clear narrative** - केवल code नहीं, अपना reasoning समझाएँ
2. **Reproducibility** - random seeds set करें, library versions दस्तावेज़ित करें
3. **Visualisations** - ऐसी plots जो insights दिखाएँ, सिर्फ़ सजावट न करें
4. **Honest results** - जो काम नहीं किया उसे भी साझा करें, सिर्फ़ सफल चीज़ें नहीं
