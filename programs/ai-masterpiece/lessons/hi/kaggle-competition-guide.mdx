# Kaggle प्रतियोगिता गुइदे - Kaggle पर कैसे प्रतिस्पर्धा करें (और सीखें)

Kaggle सिर्फ एक प्रतियोगिता प्लैटफ़ॉर्म नहीं - यह दुनिया की सबसे बड़ी अपपलिएद ML कलसरूम है। 15 मिलियन से ज़्यादा डेटा सकिएनटिसटस इसे कौशल शरपेन करने, पोर्टफ़ोलियो बनाने, और जॉब पाने के लिए उपयोग करते हैं। यह पाठ आपको सिखाएगा कि एफ़फ़ेकटिवेलय प्रतिस्पर्धा कैसे करें और हर प्रतियोगिता से मक्सिमुम लर्निंग कैसे निकालें।

## 🎯 Kaggle आपके करियर के लिए क्यों मायने रखता है

Kaggle अनुभव एक ऐसा सिग्नल देता है जो CVs नहीं दे सकते: **आप messy, वास्तविक दुनिया डेटा पर काम करने वाले मॉडल भेज कर सकते हैं**। Google, Meta, और शीर्ष startup के भर्ती मैनेजर Kaggle leaderboards से सक्रिय रूप से recruit करते हैं। जीतने के बिना भी, well-documented notebookस वाला एक मज़बूत प्रोफ़ाइल व्यावहारिक प्रतिस्पर्धात्मक क्षमता दिखाता है।

## 🔍 EDA - आपके पहले 48 घंटे

डेटा समझे बिना कभी मॉडलिंग शुरू न करें। एक disciplineद EDA वर्कफ़्लो:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("train.csv")

# Shape और types - जानें कि आप किसके साथ काम कर रहे हैं
print(f"Shape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum().sort_values(ascending=False).head(10)}")

# Target distribution - क्या यह balanced है?
df["target"].value_counts(normalize=True).plot(kind="bar")
plt.title("Target Distribution")
plt.show()

# Correlations - quick signal खोजें
correlations = df.select_dtypes(include="number").corr()["target"].sort_values()
print(correlations.head(10))  # Strongest negative correlations
print(correlations.tail(10))  # Strongest positive correlations
```

**लेअकगे जाँच करें** - ऐसे फ़ीचर जो परेदिकशन समय पर मौजूद नहीं करेंगे। यह बेगिननेरस की नंबर एक गलती है। अगर कोई फ़ीचर लक्षित के साथ सुसचुनतािओउस तरीके से कोररेलटे करता है, तो खुशी मनाने से पहले जाँच करें।

## 🛠️ फ़ीचर इंजीनियरिंग जो जिताती है

शीर्ष प्रतिस्पर्धी अपना 70% समय फ़ीचर पर लगाते हैं, मॉडल टुनिङ पर नहीं। आज़माई हुई तकनीकें:

**अगगरेगशन फ़ीचर** - अलग-अलग गरनुलरिटिएस पर गरोउप सांख्यिकी:
```python
for col in ["category", "store_id", "day_of_week"]:
    stats = df.groupby(col)["sales"].agg(["mean", "std", "median"])
    stats.columns = [f"{col}_sales_{s}" for s in ["mean", "std", "median"]]
    df = df.merge(stats, on=col, how="left")
```

**लक्षित एनCoding** - कटेगोरिएस को समूथेद लक्षित मेअनस से रेपलके करें (लेअकगे रोकने के लिए फ़ोलद-बसेद एनCoding इस्तेमाल करें)।

**लग फ़ीचर** - समय सेरिएस के लिए, पिछले वलुएस सोने जैसे हैं:
```python
for lag in [1, 7, 14, 28]:
    df[f"sales_lag_{lag}"] = df.groupby("store_id")["sales"].shift(lag)
```

## ✅ करोस-वैलिडेशन - अपने स्थानीय स्कोर पर भरोसा करें

आपका स्थानीय CV स्कोर public leaderboard से ज़्यादा मायने रखता है। एक robust वैलिडेशन रणनीति:

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_predictions = np.zeros(len(X))

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

    model = lgb.LGBMClassifier(n_estimators=1000, learning_rate=0.05)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
              callbacks=[lgb.early_stopping(50)])
    oof_predictions[val_idx] = model.predict_proba(X_val)[:, 1]

print(f"OOF AUC: {roc_auc_score(y, oof_predictions):.5f}")
```

**goldेन रुले**: अगर स्थानीय CV और public LB दिसगरी करें, तो CV पर भरोसा करें। public leaderboard टेस्ट डेटा का सिर्फ एक हिस्सा उपयोग करता है - इस पर ओवेरफ़िट होना एक जाल है।

<ThinkAboutIt>आप public leaderboard पर 15वें हैं लेकिन स्थानीय CV बता रहा है कि मॉडल ओवेरफ़िट है। फ़िनल submission के लिए श्रेष्ठ LB स्कोर submit करेंगे या श्रेष्ठ CV स्कोर? क्यों?</ThinkAboutIt>

## 🎭 ensemble methods - आखिरी पुश

लगभग हर winning solution ensembles उपयोग करती है। तीन की तकनीकें:

**बगगिङ** - समान मॉडल को अलग-अलग डेटा सुबसेटस पर ट्रेन करें, भविष्यवाणियाँ औसत करें। वरिअनके कम करता है।

**Stacking** - diverse बेस मॉडल के out-of-fold भविष्यवाणियाँ पर एक meta-model ट्रेन करें:
```python
# Level 1: diverse base models OOF predictions बनाते हैं
base_preds = np.column_stack([lgbm_oof, xgb_oof, catboost_oof, nn_oof])

# Level 2: logistic regression optimal combination सीखता है
from sklearn.linear_model import LogisticRegression
meta = LogisticRegression()
meta.fit(base_preds, y_train)
```

**बलेनदिङ** - मॉडल भविष्यवाणियाँ का भारित औसत। Stacking से सरल लेकिन प्रभावी:
```python
final = 0.4 * lgbm_pred + 0.35 * xgb_pred + 0.25 * catboost_pred
```
