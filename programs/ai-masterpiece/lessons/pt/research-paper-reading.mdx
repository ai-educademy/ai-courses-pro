# Lendo artigos de pesquisa - Como compreender e implementar artigos de IA

A lacuna entre “Eu uso IA” e “Eu construo IA” é preenchida pela leitura de artigos de pesquisa. Cada avanço – transformadores, modelos de difusão, RLHF – começou como um artigo. Os engenheiros que leem artigos não seguem apenas tendências; eles os **antecipam**.

## 🤔 Por que ler artigos?

- **Mantenha-se atualizado** - as postagens do blog ficam meses atrás dos artigos
- **Entenda os fundamentos** - os tutoriais simplificam; artigos explicam *por que*
- **Depure melhor** - quando seu modelo falha, o artigo revela casos extremos
- **Alavancagem na carreira** - engenheiros com conhecimento de papel são raros e valorizados

## 📐 Anatomia de um artigo de ML

Cada artigo de ML segue uma estrutura previsível. Conhecer o projeto acelera a leitura:

| Seção | Finalidade | Hora de gastar |
|---------|---------|-------------|
| **Resumo** | Resumo de 200 palavras de toda a contribuição | 2 minutos |
| **Introdução** | Motivação do problema, porque as soluções existentes falham | 5 minutos |
| **Trabalho Relacionado** | O que veio antes, como este artigo difere | Skim na primeira passagem |
| **Método** | A principal contribuição - arquitetura, algoritmo, matemática | 60% do seu tempo |
| **Experiências** | Prova de que funciona – conjuntos de dados, linhas de base, ablações | 20% do seu tempo |
| **Conclusão** | Resumo e direções futuras | 2 minutos |

<FunFact>O artigo original "Attention Is All You Need" (2017) foi citado mais de 130.000 vezes, tornando-o um dos artigos de ciência da computação mais influentes já escritos. Seu título gerou inúmeras paródias em títulos de jornais subsequentes.</FunFact>

## 📖 A abordagem de três passagens

### Passe 1: Skim (15 minutos)

Leia o **resumo**, **introdução**, **títulos de seção**, **figuras** e **conclusão**. Após esta passagem, você deverá ser capaz de responder:

- Que problema este artigo resolve?
- Qual é a ideia chave em uma frase?
- Este artigo é relevante para o meu trabalho?

Se a resposta à terceira pergunta for não, pare por aqui. Nem todo artigo merece uma leitura profunda.

### Passo 2: Compreender (1–2 horas)

Leia o artigo completo, ignorando provas densas no primeiro encontro. Focar em:

- **Figuras e tabelas** - os autores transformam suas melhores ideias em recursos visuais
- **Seção de método** - rastreia o fluxo de dados da entrada à saída
- **Estudos de ablação** - revelam quais componentes realmente importam

Marque as seções que você não entende. Siga em frente e retorne a eles depois de ler os experimentos – os resultados geralmente esclarecem o método.

### Passo 3: Crítica (1–2 horas)

Agora leia como um revisor. Perguntar:

- Que suposições este artigo faz? Eles são razoáveis?
- O que está faltando nos experimentos? Quais linhas de base estão ausentes?
- Como essa abordagem falharia? Quais são suas limitações?
- Posso reproduzir estes resultados com as informações fornecidas?

## 🔢 Lendo notação matemática

A notação matemática é uma linguagem. Aqui está o seu livro de frases para artigos de ML:

```
θ (theta)      - model parameters (weights)
∇ (nabla)      - gradient operator
𝔼 (E)          - expected value (average over a distribution)
argmax          - the input that maximises a function
∑ (sigma)      - summation
∏ (pi)         - product
‖x‖            - norm (magnitude) of vector x
softmax(z_i)   - e^(z_i) / Σ e^(z_j) - converts logits to probabilities
```

**Dica profissional**: ao ver uma equação complexa, substitua os números reais. Se o papel disser `L = -Σ y_i log(ŷ_i)`, insira `y = [1, 0]` e `ŷ = [0.9, 0.1]` e calcule manualmente. A abstração torna-se concreta instantaneamente.

## 💻 Do papel ao código

O teste final de compreensão: implemente-o. Um fluxo de trabalho prático:

```python
# Step 1: Implement the core mechanism in isolation
import torch
import torch.nn as nn

class SelfAttention(nn.Module):
    """Scaled dot-product attention from 'Attention Is All You Need'"""
    def __init__(self, d_model: int, n_heads: int):
        super().__init__()
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, T, C = x.shape
        q = self.W_q(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        k = self.W_k(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        v = self.W_v(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)

        # Scaled dot-product attention (Equation 1 in the paper)
        attn = (q @ k.transpose(-2, -1)) / (self.d_k ** 0.5)
        attn = torch.softmax(attn, dim=-1)
        return (attn @ v).transpose(1, 2).contiguous().view(B, T, C)
```

**Verifique no papel**: verifique as formas do tensor em cada etapa. Se o artigo disser que a saída é `(batch, seq_len, d_model)`, afirme isso.
