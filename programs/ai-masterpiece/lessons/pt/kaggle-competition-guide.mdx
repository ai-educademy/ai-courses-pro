## 🔍 EDA - Suas primeiras 48 horas

Nunca comece a modelar antes de compreender seus dados. Um fluxo de trabalho EDA disciplinado:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("train.csv")

# Shape and types - know what you're working with
print(f"Shape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum().sort_values(ascending=False).head(10)}")

# Target distribution - is it balanced?
df["target"].value_counts(normalize=True).plot(kind="bar")
plt.title("Target Distribution")
plt.show()

# Correlations - find quick signal
correlations = df.select_dtypes(include="number").corr()["target"].sort_values()
print(correlations.head(10))  # Strongest negative correlations
print(correlations.tail(10))  # Strongest positive correlations
```

**Verifique se há vazamentos** - recursos que não existiriam no momento da previsão. Este é o erro número um que os iniciantes cometem. Se uma característica se correlacionar de forma suspeita com o alvo, investigue antes de comemorar.

## 🛠️ Engenharia de recursos que vence

Os principais concorrentes gastam 70% de seu tempo em recursos, não em ajustes de modelos. Técnicas testadas em batalha:

**Recursos de agregação** - estatísticas de grupo em diferentes granularidades:
```python
for col in ["category", "store_id", "day_of_week"]:
    stats = df.groupby(col)["sales"].agg(["mean", "std", "median"])
    stats.columns = [f"{col}_sales_{s}" for s in ["mean", "std", "median"]]
    df = df.merge(stats, on=col, how="left")
```

**Codificação de destino** - substitua categorias por meios de destino suavizados (use codificação baseada em dobras para evitar vazamentos).

**Recursos de atraso** - para séries temporais, os valores anteriores são ouro:
```python
for lag in [1, 7, 14, 28]:
    df[f"sales_lag_{lag}"] = df.groupby("store_id")["sales"].shift(lag)
```

## ✅ Validação cruzada - Confie na sua pontuação local

A pontuação do seu currículo local é mais importante do que a tabela de classificação pública. Uma estratégia de validação robusta:

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_predictions = np.zeros(len(X))

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

    model = lgb.LGBMClassifier(n_estimators=1000, learning_rate=0.05)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
              callbacks=[lgb.early_stopping(50)])
    oof_predictions[val_idx] = model.predict_proba(X_val)[:, 1]

print(f"OOF AUC: {roc_auc_score(y, oof_predictions):.5f}")
```

**Regra de ouro**: se o seu currículo local e o LB público discordam, confie no seu currículo. A tabela de classificação pública usa apenas uma fração dos dados de teste – o ajuste excessivo a ela é uma armadilha.

## 🎭 Métodos Ensemble - O empurrão final

Quase todas as soluções vencedoras utilizam conjuntos. Três técnicas principais:

**Bagging** - treine o mesmo modelo em diferentes subconjuntos de dados, previsões médias. Reduz a variação.

**Stacking** - treine um metamodelo em previsões fora do padrão de diversos modelos básicos:
```python
# Level 1: diverse base models produce OOF predictions
base_preds = np.column_stack([lgbm_oof, xgb_oof, catboost_oof, nn_oof])

# Level 2: logistic regression learns optimal combination
from sklearn.linear_model import LogisticRegression
meta = LogisticRegression()
meta.fit(base_preds, y_train)
```

**Combinação** – média ponderada das previsões do modelo. Mais simples que empilhar, mas eficaz:
```python
final = 0.4 * lgbm_pred + 0.35 * xgb_pred + 0.25 * catboost_pred
```

Quando calculada a média, os erros individuais são anulados enquanto os sinais corretos se reforçam mutuamente – reduzindo a variância geral sem aumentar o viés." />

## 📓 Escrevendo ótimos cadernos Kaggle

Cadernos públicos constroem sua reputação. Um caderno digno de medalha inclui:

1. **Narrativa clara** – explique seu raciocínio, não apenas seu código
2. **Reprodutibilidade** - definir sementes aleatórias, versões da biblioteca de documentos
3. **Visualizações**: gráficos que revelam insights, não apenas decoram
4. **Resultados honestos** – compartilhe o que não funcionou junto com o que funcionou

## 🎯 Principais vantagens

- EDA primeiro, modelagem depois - sempre verifique se há vazamento de dados
- A engenharia de recursos oferece mais aumento do que o ajuste de hiperparâmetros
- Confie no seu currículo local em vez do placar público
- Monte diversos modelos para o empurrão final
- Documente seu trabalho em cadernos públicos - é o seu portfólio
