# Pipeline de ML ponta a ponta - dos dados brutos ao modelo implantado

A maioria dos tutoriais termina em `model.fit()`. Na produção, isso representa apenas 20% do trabalho. Esta lição aborda **todo o ciclo de vida do ML**: o mesmo pipeline que alimenta os mecanismos de recomendação no Spotify, a detecção de fraudes no Stripe e a classificação de pesquisa no Google.

## 🗺️ Visão geral do ciclo de vida do ML

<Illustration src="/images/lessons/end-to-end-ml-pipeline.svg" alt="Diagrama dos estágios do pipeline de ML, desde a ingestão de dados até o monitoramento" caption="Os oito estágios de um pipeline de ML de produção – cada um é um ponto de falha potencial." />

Cada sistema de ML de produção passa por estes estágios:

1. **Coleta de dados** - APIs, bancos de dados, fluxos de eventos, web scraping
2. **Limpeza de dados** - tratamento de nulos, desduplicação, coerção de tipo
3. **Engenharia de recursos** - transformação de sinais brutos em recursos prontos para modelo
4. **Seleção de modelo** - escolha de arquiteturas que correspondam ao seu problema
5. **Treinamento** - Orquestração de GPU/CPU, ajuste de hiperparâmetros
6. **Avaliação** – métricas off-line, testes A/B, auditorias de imparcialidade
7. **Implantação** – atendendo orçamentos de infraestrutura e latência
8. **Monitoramento** - detecção de desvio, alerta, gatilho de retreinamento

## 📦 Coleta de dados e controle de versão

Os dados brutos são a sua base. Trate-o como código-fonte - **versão de tudo**.

```bash
# Initialise DVC in your repo
dvc init
dvc remote add -d storage s3://my-ml-data-bucket

# Track a dataset
dvc add data/transactions.csv
git add data/transactions.csv.dvc .gitignore
git commit -m "Track raw transaction dataset v1"
dvc push
```

**DVC** (Controle de versão de dados) permite `git checkout` qualquer conjunto de dados histórico. Combinado com tags Git, você pode reproduzir qualquer experimento a partir de qualquer momento.

<FunFact>A Netflix processa mais de 1,5 trilhão de eventos por dia por meio de seus pipelines de dados – aproximadamente 17 milhões de eventos por segundo alimentando seus modelos de recomendação.</FunFact>

## 🛠️ Engenharia de recursos - onde as competições são vencidas

Os recursos são mais importantes do que os algoritmos. Uma árvore com gradiente aprimorado e recursos brilhantes supera uma rede neural profunda com recursos ruins.

```python
import pandas as pd

df = pd.read_csv("data/transactions.csv", parse_dates=["timestamp"])

# Temporal features
df["hour"] = df["timestamp"].dt.hour
df["is_weekend"] = df["timestamp"].dt.dayofweek >= 5

# Aggregation features
user_stats = df.groupby("user_id")["amount"].agg(["mean", "std", "count"])
user_stats.columns = ["user_avg_amount", "user_std_amount", "user_txn_count"]
df = df.merge(user_stats, on="user_id")

# Ratio features
df["amount_vs_avg"] = df["amount"] / df["user_avg_amount"]
```

## 🧪 Acompanhamento de experimentos com MLflow

Nunca perca o controle do que você tentou. O MLflow registra parâmetros, métricas e artefatos automaticamente.

```python
import mlflow
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import f1_score

mlflow.set_experiment("fraud-detection-v2")

with mlflow.start_run(run_name="gbm-baseline"):
    params = {"n_estimators": 500, "max_depth": 6, "learning_rate": 0.05}
    mlflow.log_params(params)
```

## 🚀 Pipeline como Código - Orquestração

As etapas manuais são interrompidas. Codifique seu pipeline em código usando estruturas de orquestração:

| Ferramenta | Melhor para | Força-chave |
|------|----------|------------|
| **Pipelines do Kubeflow** | ML nativo do Kubernetes | Escalável em clusters K8s existentes |
| **Fluxo de ar Apache** | Agendamento complexo de DAG | Ecossistema maduro, ampla adoção |
| **Prefeito** | Fluxos de trabalho Python modernos | API Pythonic, excelente tratamento de erros |
| **ZenML** | Abstração MLOps | Independente de pilha, conecte qualquer ferramenta |

## 🌐 Exibição e implantação de modelo

Seu modelo precisa de uma API. Dois padrões dominantes:

**API REST** – simples, baseada em HTTP, ótima para taxa de transferência moderada:
```python
# FastAPI model server
from fastapi import FastAPI
import joblib

app = FastAPI()
model = joblib.load("model.pkl")

@app.post("/predict")
async def predict(features: dict):
    prediction = model.predict([list(features.values())])
    return {"prediction": int(prediction[0])}
```

**gRPC** – protocolo binário, 2–10× mais rápido que REST, ideal para microsserviços internos e cenários de alto rendimento.

### Implantações Canário

Nunca envie 100% do tráfego para um novo modelo. Use **lançamentos canário**: rota 5% → 25% → 50% → 100%, monitorando as taxas de erro em cada etapa. Reverta instantaneamente se as métricas piorarem.

## 📊 Monitoramento e ciclo de feedback

A implantação não é a linha de chegada – é o ponto de partida. Monitore para:

- **Desvio de dados** – distribuições de entrada mudando dos dados de treinamento
- **Desvio de conceito** - a relação entre recursos e mudança de objetivo
- **Degradação de desempenho** - diminuição das métricas de precisão/latência

Ferramentas como **Evidently AI**, **WhyLabs** e **Arize** fornecem painéis de desvio. Quando o desvio exceder os limites, acione o retreinamento automático com novos dados de produção – fechando o ciclo de feedback.

## 🎯 Principais vantagens

- Versão **tudo**: código, dados, modelos e configurações de pipeline
- A engenharia de recursos oferece mais ROI do que mudanças de arquitetura
- Codifique pipelines como código - etapas manuais são dívidas técnicas
- Implante com versões canário e monitore incansavelmente
- O ciclo de feedback (dados de produção → reciclagem) é o que separa as demonstrações dos sistemas de produção
