# ప్రారంభం నుంచి ముగింపు వరకు ML పైప్‌లైన్ - ముడి డేటా నుండి డిప్లాయ్ చేసిన మోడల్ వరకు

చాలా ట్యుటోరియల్‌లు `model.fit()` వద్ద ఆగిపోతాయి. ప్రొడక్షన్ లో అది పని లో 20% మాత్రమే. ఈ పాఠం **మొత్తం ML జీవనచక్రం** ద్వారా నడిపిస్తుంది - **Spotify** లో సిఫార్సు ఇంజిన్‌లు, Stripe లో మోసం గుర్తింపు, **Google** లో సెర్చ్ ర్యాంకింగ్ ని శక్తి చేసే అదే పైప్‌లైన్.

## 🗺️ ML జీవనచక్రం ఒక చూపులో

ప్రతి ప్రొడక్షన్ ML సిస్టమ్ ఈ దశల ద్వారా వెళ్తుంది:

1. **డేటా సేకరణ** - **APIs**, డేటాబేస్‌లు, ఈవెంట్ స్ట్ర్ీమ్స్, వెబ్ స్క్ర్అప్ింగ్
2. **డేటా Cleaning** - న్ుల్ల్స్ నిర్వహణ, డీడూప్లికేషన్, రకం క్ోర్క్ిోన్
3. **ఫీచర్ ఇంజినీరింగ్** - ముడి సంకేతాలు ని మోడల్-సిద్ధం ఫీచర్లు గా మార్చడం
4. **మోడల్ Selection** - మీ సమస్యకు సరిపోల్చండి అయ్యే ఆర్కిటెక్చర్లు ఎంచుకోవడం
5. **శిక్షణ** - **GPU**/**CPU** ఆర్కెస్ట్రేషన్, హ్య్ప్ర్ప్ార్అమ్ెట్ర్ ట్ున్ింగ్
6. **మూల్యాంకనం** - ఆఫ్‌లైన్ మెట్రిక్స్, A/B పరీక్షలు, న్యాయం ాడ్ిట్స్
7. **డిప్లాయ్‌మెంట్** - సర్వింగ్ మౌలిక సదుపాయాలు, లేటెన్సీ బడ్జెట్‌లు
8. **పర్యవేక్షణ** - డ్రిఫ్ట్ గుర్తింపు, అలర్టింగ్, మళ్లీ శిక్షణ ప్రేరేపణ

## 📦 డేటా సేకరణ మరియు వెర్షనింగ్

ముడి డేటా మీ పునాది. దీన్ని సోర్స్ కోడ్ లాగా చూడండి - **అంతా వెర్షన్ చేయండి**.

```bash
# Initialise DVC in your repo
dvc init
dvc remote add -d storage s3://my-ml-data-bucket

# Track a dataset
dvc add data/transactions.csv
git add data/transactions.csv.dvc .gitignore
git commit -m "Track raw transaction dataset v1"
dvc push
```

**DVC** (డేటా వెర్షన్ నియంత్రణ) ద్వారా మీరు ఏ చారిత్రక డేటాసెట్ నైనా `git checkout` చేయవచ్చు. **Git** ట్అగ్స్ తో కలిపి, ఏ సమయం నుండైనా ఏ ప్రయోగం నైనా ర్ెప్ర్ోడ్ుక్ె చేయవచ్చు.

<FunFact>*Netflix* రోజుకు 1.5 ట్రిలియన్ ఈవెంట్లు ని తమ డేటా పైప్‌లైన్‌లు ద్వారా ప్రక్రియ చేస్తుంది - ప్రతి సెకను సుమారు 17 మిలియన్ ఈవెంట్లు వారి సిఫార్సు మోడళ్లు కి ఫీడ్ అవుతాయి.</FunFact>

## 🛠️ ఫీచర్ ఇంజినీరింగ్ - పోటీలు గెలిచే చోటు

అల్గారిథమ్‌లు కంటే ఫీచర్లు ఎక్కువ ముఖ్యం. అద్భుతమైన ఫీచర్లు ఉన్న గ్ర్అడ్ిెన్ట్-బ్ూస్ట్ెడ్ వృక్షం, పేలవమైన ఫీచర్లు ఉన్న లోతైన న్యూరల్ నెట్‌వర్క్ ని ఓడిస్తుంది.

```python
import pandas as pd

df = pd.read_csv("data/transactions.csv", parse_dates=["timestamp"])

# Temporal features
df["hour"] = df["timestamp"].dt.hour
df["is_weekend"] = df["timestamp"].dt.dayofweek >= 5

# Aggregation features
user_stats = df.groupby("user_id")["amount"].agg(["mean", "std", "count"])
user_stats.columns = ["user_avg_amount", "user_std_amount", "user_txn_count"]
df = df.merge(user_stats, on="user_id")

# Ratio features
df["amount_vs_avg"] = df["amount"] / df["user_avg_amount"]
```

## 🧪 *MLflow* తో ప్రయోగం ట్రాకింగ్

మీరు ఏమి ప్రయత్నించండి చేశారో ఎప్పుడూ ట్రాక్ కోల్పోకండి. *MLflow* పరామీటర్లు, మెట్రిక్స్, ార్ట్ెఫ్అక్ట్స్ ని స్వయంచాలకంగా లాగ్ చేస్తుంది.

```python
import mlflow
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import f1_score

mlflow.set_experiment("fraud-detection-v2")

with mlflow.start_run(run_name="gbm-baseline"):
    params = {"n_estimators": 500, "max_depth": 6, "learning_rate": 0.05}
    mlflow.log_params(params)

    model = GradientBoostingClassifier(**params)
    model.fit(X_train, y_train)

    score = f1_score(y_test, model.predict(X_test))
    mlflow.log_metric("f1_score", score)
    mlflow.sklearn.log_model(model, "model")
```

*MLflow* UI లో నడుస్తుంది పోల్చండి చేసి, ఉత్తమ మోడల్ ని స్ట్అగ్ింగ్ → ప్రొడక్షన్ జీవనచక్రం ట్అగ్స్ తో **మోడల్ రిజిస్ట్రీ** కి ప్ర్ోమ్ోట్ె చేయండి.

## 🚀 పైప్‌లైన్ గా కోడ్ - ఆర్కెస్ట్రేషన్

## 🌐 మోడల్ సర్వింగ్ మరియు డిప్లాయ్‌మెంట్

మీ మోడల్ కి *API* అవసరం. రెండు ప్రధాన నమూనాలు:

**REST API** - సరళం, *HTTP-*ఆధారిత, మ్ోడ్ర్అట్ె థ్రూపుట్ కి గొప్పది:
```python
# FastAPI model server
from fastapi import FastAPI
import joblib

app = FastAPI()
model = joblib.load("model.pkl")

@app.post("/predict")
async def predict(features: dict):
    prediction = model.predict([list(features.values())])
    return {"prediction": int(prediction[0])}
```

**gRPC** - ద్విమీయ ప్ర్ోట్ోక్ోల్, **REST** కంటే 2–10× వేగం, అంతర్గత మైక్రోసర్వీసులు మరియు అధిక-థ్రూపుట్ సన్నివేశాలు కి సరైన.

### కెనరీ డిప్లాయ్‌మెంట్‌లు

కొత్త మోడల్ కి 100% ట్రాఫిక్ ఎప్పుడూ పంపకండి. **Canary ర్ెల్అస్ెస్** వాడండి: 5% → 25% → 50% → 100%, ప్రతి దశ లో లోపం రేట్లు పర్యవేక్షించండి చేస్తూ. మెట్రిక్స్ తగ్గిపోవడం అయితే ిన్స్ట్అన్ట్ల్య్ రోల్‌బ్యాక్ చేయండి.

## 📊 పర్యవేక్షణ మరియు ఫీడ్‌బ్యాక్ లూప్

డిప్లాయ్‌మెంట్ పూర్తి చేయడం లైన్ కాదు - ప్రారంభ గ్ున్. ఇవి పర్యవేక్షించండి చేయండి:

- **డేటా డ్రిఫ్ట్** - శిక్షణ డేటా నుండి ఇన్‌పుట్ డ్ిస్ట్ర్ిబ్ుషన్స్ మార్పు అవడం
- **భావన డ్రిఫ్ట్** - ఫీచర్లు మరియు లక్ష్య మధ్య సంబంధం మారడం
- **పనితీరు తగ్గుదల** - ఖచ్చితత్వం/లేటెన్సీ మెట్రిక్స్ డ్ెక్ల్ిన్ె అవడం

**Evidently AI**, **WhyLabs**, **Arize** లాంటి టూల్స్ డ్రిఫ్ట్ డ్యాష్‌బోర్డ్‌లు అందిస్తాయి. డ్రిఫ్ట్ త్ర్ెష్ోల్డ్స్ దాటినప్పుడు, ఫ్ర్ెష్ ప్రొడక్షన్ డేటా తో ఆటోమేటిక్ మళ్లీ శిక్షణ ప్రేరేపణ చేయండి - ఫీడ్‌బ్యాక్ లూప్ క్ల్ోస్ె చేస్తూ.

## 🎯 కీలక విషయాలు

- **అంతా** వెర్షన్ చేయండి: కోడ్, డేటా, మోడళ్లు, పైప్‌లైన్ క్ోన్ఫ్ిగ్స్
- ఆర్కిటెక్చర్ మార్పులు కంటే ఫీచర్ ఇంజినీరింగ్ ఎక్కువ *ROI* ఇస్తుంది
- పైప్‌లైన్‌లు ని కోడ్ లో ఎన్‌కోడ్ చేయండి చేయండి - మ్అన్ుల్ దశలు సాంకేతిక డ్ెబ్ట్
- కెనరీ ర్ెల్అస్ెస్ తో డిప్లాయ్ చేయండి చేసి ర్ెల్న్ట్ల్స్స్ల్య్ పర్యవేక్షించండి చేయండి
- ఫీడ్‌బ్యాక్ లూప్ (ప్రొడక్షన్ డేటా → మళ్లీ శిక్షణ) డెమోలు ని ప్రొడక్షన్ సిస్టమ్‌లు నుండి వేరు చేసేది
