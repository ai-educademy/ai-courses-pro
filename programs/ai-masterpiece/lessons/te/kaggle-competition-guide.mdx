# Kaggle పోటీ గైడ్ - Kaggle లో ఎలా పోటీ పడాలి (మరియు నేర్చుకోవాలి)

Kaggle కేవలం పోటీ ప్లాట్‌ఫారమ్ మాత్రమే కాదు - ఇది ప్రపంచంలోనే అతిపెద్ద applied ML తరగతి గది. 15 మిలియన్లకు పైగా డేటా scientists నైపుణ్యాలు మెరుగుపరచడానికి, పోర్ట్‌ఫోలియోలు నిర్మించడానికి, మరియు ఉద్యోగాలు పొందడానికి దీన్ని ఉపయోగిస్తారు. ఈ పాఠం సమర్థవంతంగా పోటీ పడడం మరియు ప్రతి పోటీ నుండి గరిష్ట అభ్యసనాన్ని పొందడం నేర్పిస్తుంది.

## 🎯 మీ కెరీర్‌కు Kaggle ఎందుకు ముఖ్యం

Kaggle అనుభవం CVs చెప్పలేని విషయాన్ని సంకేతిస్తుంది: **మీరు గందరగోళమైన, వాస్తవ-ప్రపంచ డేటాపై పనిచేసే మోడళ్లు ను షిప్ చేయగలరు**. Google, Meta, మరియు టాప్ స్టార్టప్‌లు లోని నియామకం మేనేజర్లు Kaggle leaderboards నుండి చురుగ్గా నియమిస్తారు. గెలవకపోయినా, బాగా డాక్యుమెంట్ చేసిన notebooks తో బలమైన ప్రొఫైల్ ఆచరణాత్మక సామర్థ్యాన్ని ప్రదర్శిస్తుంది.

## 📊 పోటీ రకాలు మరియు విజయ వ్యూహాలు

## 🔍 EDA - మీ మొదటి 48 గంటలు

డేటాను అర్థం చేసుకోకుండా ఎప్పుడూ మోడలింగ్ మొదలుపెట్టకండి. క్రమశిక్షణతో కూడిన EDA వర్క్‌ఫ్లో:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("train.csv")

# Shape మరియు types - మీరు ఏమి పనిచేస్తున్నారో తెలుసుకోండి
print(f"Shape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum().sort_values(ascending=False).head(10)}")

# Target distribution - ఇది balanced గా ఉందా?
df["target"].value_counts(normalize=True).plot(kind="bar")
plt.title("Target Distribution")
plt.show()

# Correlations - త్వరిత signal కనుగొనండి
correlations = df.select_dtypes(include="number").corr()["target"].sort_values()
print(correlations.head(10))  # Strongest negative correlations
print(correlations.tail(10))  # Strongest positive correlations
```

**Leakage కోసం తనిఖీ చేయండి** - అంచనా సమయంలో ఉండని ఫీచర్లు. బిగినర్లు చేసే నంబర్ వన్ తప్పు ఇదే. ఒక ఫీచర్ లక్ష్య తో అనుమానాస్పదంగా బాగా correlate అయితే, సెలబ్రేట్ చేయడానికి ముందు విచారణ చేయండి.

## 🛠️ గెలిపించే ఫీచర్ ఇంజినీరింగ్

టాప్ పోటీదారులు 70% సమయాన్ని ఫీచర్లు పై ఖర్చు చేస్తారు, మోడల్ tuning పై కాదు. యుద్ధ-పరీక్షిత టెక్నిక్‌లు:

**Aggregation ఫీచర్లు** - వివిధ స్థాయిల్లో గుంపు గణాంకాలు:
```python
for col in ["category", "store_id", "day_of_week"]:
    stats = df.groupby(col)["sales"].agg(["mean", "std", "median"])
    stats.columns = [f"{col}_sales_{s}" for s in ["mean", "std", "median"]]
    df = df.merge(stats, on=col, how="left")
```

**లక్ష్య ఎన్‌కోడింగ్** - categories ను smoothed లక్ష్య means తో భర్తీ చేయండి (leakage నివారించడానికి fold-ఆధారిత ఎన్‌కోడింగ్ ఉపయోగించండి).

**Lag ఫీచర్లు** - సమయం series కోసం, మునుపటి విలువలు బంగారం:
```python
for lag in [1, 7, 14, 28]:
    df[f"sales_lag_{lag}"] = df.groupby("store_id")["sales"].shift(lag)
```

## ✅ Cross-ధృవీకరణ - మీ స్థానిక స్కోర్ ను నమ్మండి

మీ స్థానిక CV స్కోర్ పబ్లిక్ leaderboard కంటే ఎక్కువ ముఖ్యం. బలమైన ధృవీకరణ వ్యూహం:

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_predictions = np.zeros(len(X))

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

    model = lgb.LGBMClassifier(n_estimators=1000, learning_rate=0.05)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
              callbacks=[lgb.early_stopping(50)])
    oof_predictions[val_idx] = model.predict_proba(X_val)[:, 1]

print(f"OOF AUC: {roc_auc_score(y, oof_predictions):.5f}")
```

**బంగారు నియమం**: మీ స్థానిక CV మరియు పబ్లిక్ LB భిన్నాభిప్రాయం చెబితే, మీ CV ను నమ్మండి. పబ్లిక్ leaderboard పరీక్ష డేటా లో కొంత భాగం మాత్రమే ఉపయోగిస్తుంది - దానికి overfit అవడం ఉచ్చు.

<ThinkAboutIt>మీరు పబ్లిక్ leaderboard లో 15వ స్థానంలో ఉన్నారు కానీ మీ స్థానిక CV ప్రకారం మీ మోడల్ overfit అయింది. చివరి సబ్మిషన్ కోసం మీ అత్యుత్తమ LB స్కోర్ సబ్మిట్ చేస్తారా లేదా అత్యుత్తమ CV స్కోర్? ఎందుకు?</ThinkAboutIt>

## 🎭 Ensemble పద్ధతులు - చివరి పుష్

దాదాపు ప్రతి విజయవంతమైన పరిష్కారం ensembles ఉపయోగిస్తుంది. మూడు కీలక టెక్నిక్‌లు:

**Bagging** - ఒకే మోడల్ ను వేర్వేరు డేటా ఉపసెట్లు పై శిక్షణ ఇవ్వండి చేసి, అంచనాలు ను సగటు చేయండి. Variance తగ్గిస్తుంది.

**Stacking** - వైవిధ్యమైన బేస్ మోడళ్లు నుండి out-of-fold అంచనాలు పై meta-మోడల్ శిక్షణ ఇవ్వండి చేయండి:
```python
# Level 1: వైవిధ్యమైన base models OOF predictions ఉత్పత్తి చేస్తాయి
base_preds = np.column_stack([lgbm_oof, xgb_oof, catboost_oof, nn_oof])

# Level 2: logistic regression సరైన combination నేర్చుకుంటుంది
from sklearn.linear_model import LogisticRegression
meta = LogisticRegression()
meta.fit(base_preds, y_train)
```

**Blending** - మోడల్ అంచనాలు యొక్క బరువులు ఇచ్చిన సగటు. Stacking కంటే సరళం కానీ ప్రభావవంతం:
```python
final = 0.4 * lgbm_pred + 0.35 * xgb_pred + 0.25 * catboost_pred
```

| **Grandmaster** | 5 gold medals (1 ఒంటరి) | 3–5+ సంవత్సరాలు |

<ThinkAboutIt>ర్యాంకింగ్‌లు కు అతీతంగా, ML పాత్రలు కోసం apply చేసేటప్పుడు మీ Kaggle ప్రొఫైల్ ను పోర్ట్‌ఫోలియో గా ఎలా ఉపయోగిస్తారు? నియామకం మేనేజర్ మీ పోటీ చరిత్ర లో ఏమి వెతుకుతారు?</ThinkAboutIt>
