# *Kaggle* పోటీ గైడ్ - *Kaggle* లో ఎలా పోటీ పడాలి (మరియు నేర్చుకోవాలి)

*Kaggle* కేవలం పోటీ ప్లాట్‌ఫారమ్ మాత్రమే కాదు - ఇది ప్రపంచంలోనే అతిపెద్ద అప్ప్ల్ిెడ్ ML తరగతి గది. 15 మిలియన్లకు పైగా డేటా స్క్ిెన్ట్ిస్ట్స్ నైపుణ్యాలు మెరుగుపరచడానికి, పోర్ట్‌ఫోలియోలు నిర్మించడానికి, మరియు ఉద్యోగాలు పొందడానికి దీన్ని ఉపయోగిస్తారు. ఈ పాఠం సమర్థవంతంగా పోటీ పడడం మరియు ప్రతి పోటీ నుండి గరిష్ట అభ్యసనాన్ని పొందడం నేర్పిస్తుంది.

## 🎯 మీ కెరీర్‌కు *Kaggle* ఎందుకు ముఖ్యం

*Kaggle* అనుభవం CVలు చెప్పలేని విషయాన్ని సంకేతిస్తుంది: **మీరు గందరగోళమైన, వాస్తవ-ప్రపంచ డేటాపై పనిచేసే మోడళ్లు ను షిప్ చేయగలరు**. **Google**, **Meta**, మరియు టాప్ స్టార్టప్‌లు లోని నియామకం మేనేజర్లు **Kaggle** ల్అడ్ర్బ్ోార్డ్స్ నుండి చురుగ్గా నియమిస్తారు. గెలవకపోయినా, బాగా డాక్యుమెంట్ చేసిన నోట్‌బుక్‌లు తో బలమైన ప్రొఫైల్ ఆచరణాత్మక సామర్థ్యాన్ని ప్రదర్శిస్తుంది.

## 📊 పోటీ రకాలు మరియు విజయ వ్యూహాలు

| రకం | ఉదాహరణ | సాధారణ విజయ విధానం |
|------|---------|-------------------|
| **Tabular** | ఇంటి ధరలు, మోసం గుర్తింపు | **Gradient** బ్ూస్ట్ింగ్ (*XGBoost*/*LightGBM*) + భారీ ఫీచర్ ఇంజినీరింగ్ |
| **కంప్యూటర్ విజన్** | ఇమేజ్ వర్గీకరణ, సెగ్మెంటేషన్ | ముందస్తు-శిక్షణ పొందిన **CNNs** (*EfficientNet*, *ConvNeXt*) + ాగ్మెంట్అషన్ |
| **NLP** | *Sentiment*, ప్రశ్న అన్స్వ్ర్ింగ్ | ఫైన్ ట్యూన్ చేసిన *Transformers* (*DeBERTa*, *RoBERTa*) |
| **సిమ్యులేషన్** | *Game* AI, ఆప్టిమైజేషన్ | రిఇన్‌ఫోర్స్‌మెంట్ అభ్యాసం + డొమైన్ హ్ెుర్ిస్ట్ిక్స్ |

<FunFact>*Kaggle* పోటీ విజేతలలో అత్యంత ప్రజాదరణ పొందిన ఒకే అల్గారిథమ్ *LightGBM* - ఇది 60% కంటే ఎక్కువ టాప్-ప్ల్అక్ింగ్ ట్అబ్ుల్ార్ పరిష్కారాలు లో కనిపిస్తుంది, తరచుగా *CatBoost* లేదా *XGBoost* తో ెన్స్ెమ్బ్ల్స్ లో కలిపి ఉపయోగిస్తారు.</FunFact>

## 🔍 *EDA* - మీ మొదటి 48 గంటలు

డేటాను అర్థం చేసుకోకుండా ఎప్పుడూ మోడలింగ్ మొదలుపెట్టకండి. క్రమశిక్షణతో కూడిన *EDA* వర్క్‌ఫ్లో:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("train.csv")

# Shape మరియు types - మీరు ఏమి పనిచేస్తున్నారో తెలుసుకోండి
print(f"Shape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum().sort_values(ascending=False).head(10)}")

# Target distribution - ఇది balanced గా ఉందా?
df["target"].value_counts(normalize=True).plot(kind="bar")
plt.title("Target Distribution")
plt.show()

# Correlations - త్వరిత signal కనుగొనండి
correlations = df.select_dtypes(include="number").corr()["target"].sort_values()
print(correlations.head(10))  # Strongest negative correlations
print(correlations.tail(10))  # Strongest positive correlations
```

**Leakage కోసం తనిఖీ చేయండి** - అంచనా సమయంలో ఉండని ఫీచర్లు. బిగినర్లు చేసే నంబర్ వన్ తప్పు ఇదే. ఒక ఫీచర్ లక్ష్య తో అనుమానాస్పదంగా బాగా క్ర్ర్ెల్అట్ె అయితే, సెలబ్రేట్ చేయడానికి ముందు విచారణ చేయండి.

## 🛠️ గెలిపించే ఫీచర్ ఇంజినీరింగ్

టాప్ పోటీదారులు 70% సమయాన్ని ఫీచర్లు పై ఖర్చు చేస్తారు, మోడల్ ట్ున్ింగ్ పై కాదు. యుద్ధ-పరీక్షిత టెక్నిక్‌లు:

**సమీకరణ ఫీచర్లు** - వివిధ స్థాయిల్లో గుంపు గణాంకాలు:
```python
for col in ["category", "store_id", "day_of_week"]:
    stats = df.groupby(col)["sales"].agg(["mean", "std", "median"])
    stats.columns = [f"{col}_sales_{s}" for s in ["mean", "std", "median"]]
    df = df.merge(stats, on=col, how="left")
```

**లక్ష్య ఎన్‌కోడింగ్** - క్అట్ెగ్ర్ిెస్ ను స్మ్ూత్ెడ్ లక్ష్య మ్ీన్స్ తో భర్తీ చేయండి (ల్అక్అగ్ె నివారించడానికి ఫ్ోల్డ్-ఆధారిత ఎన్‌కోడింగ్ ఉపయోగించండి).

**Lag ఫీచర్లు** - సమయం స్ర్ిెస్ కోసం, మునుపటి విలువలు బంగారం:
```python
for lag in [1, 7, 14, 28]:
    df[f"sales_lag_{lag}"] = df.groupby("store_id")["sales"].shift(lag)
```

## ✅ క్రాస్-ధృవీకరణ - మీ స్థానిక స్కోర్ ను నమ్మండి

మీ స్థానిక CV స్కోర్ పబ్లిక్ లీడర్‌బోర్డ్ కంటే ఎక్కువ ముఖ్యం. బలమైన ధృవీకరణ వ్యూహం:

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_predictions = np.zeros(len(X))

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

    model = lgb.LGBMClassifier(n_estimators=1000, learning_rate=0.05)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
              callbacks=[lgb.early_stopping(50)])
    oof_predictions[val_idx] = model.predict_proba(X_val)[:, 1]

print(f"OOF AUC: {roc_auc_score(y, oof_predictions):.5f}")
```

**బంగారు నియమం**: మీ స్థానిక CV మరియు పబ్లిక్ LB భిన్నాభిప్రాయం చెబితే, మీ CV ను నమ్మండి. పబ్లిక్ లీడర్‌బోర్డ్ పరీక్ష డేటా లో కొంత భాగం మాత్రమే ఉపయోగిస్తుంది - దానికి ోవ్ర్ఫ్ిట్ అవడం ఉచ్చు.

## 🎭 ఎన్సెంబుల్ పద్ధతులు - చివరి పుష్

దాదాపు ప్రతి విజయవంతమైన పరిష్కారం ెన్స్ెమ్బ్ల్స్ ఉపయోగిస్తుంది. మూడు కీలక టెక్నిక్‌లు:

**బ్యాగింగ్** - ఒకే మోడల్ ను వేర్వేరు డేటా ఉపసెట్లు పై శిక్షణ ఇవ్వండి చేసి, అంచనాలు ను సగటు చేయండి. *Variance* తగ్గిస్తుంది.

**Stacking** - వైవిధ్యమైన బేస్ మోడళ్లు నుండి ౌట్-ోఫ్-ఫ్ోల్డ్ అంచనాలు పై మ్ెట్అ-మోడల్ శిక్షణ ఇవ్వండి చేయండి:
```python
# Level 1: వైవిధ్యమైన base models OOF predictions ఉత్పత్తి చేస్తాయి
base_preds = np.column_stack([lgbm_oof, xgb_oof, catboost_oof, nn_oof])

# Level 2: logistic regression సరైన combination నేర్చుకుంటుంది
from sklearn.linear_model import LogisticRegression
meta = LogisticRegression()
meta.fit(base_preds, y_train)
```

**Blending** - మోడల్ అంచనాలు యొక్క బరువులు ఇచ్చిన సగటు. *Stacking* కంటే సరళం కానీ ప్రభావవంతం:
```python
final = 0.4 * lgbm_pred + 0.35 * xgb_pred + 0.25 * catboost_pred
```

## 📓 గొప్ప *Kaggle* నోట్‌బుక్‌లు రాయడం

పబ్లిక్ నోట్‌బుక్‌లు మీ ప్రతిష్ఠను నిర్మిస్తాయి. మెడల్-అర్హమైన నోట్‌బుక్ లో ఉండాల్సినవి:

1. **స్పష్టమైన కథనం** - కేవలం కోడ్ కాదు, మీ ఆలోచన వివరించండి
2. **పునరుత్పాదకత** - రాండమ్ స్ీడ్స్ సెట్ చేయండి, ల్ిబ్ర్ార్య్ వెర్షన్‌లు డాక్యుమెంట్ చేయండి
