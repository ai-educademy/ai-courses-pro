## 🔍 EDA - Tus primeras 48 horas

Nunca empiece a modelar antes de comprender sus datos. Un flujo de trabajo EDA disciplinado:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("train.csv")

# Shape and types - know what you're working with
print(f"Shape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum().sort_values(ascending=False).head(10)}")

# Target distribution - is it balanced?
df["target"].value_counts(normalize=True).plot(kind="bar")
plt.title("Target Distribution")
plt.show()

# Correlations - find quick signal
correlations = df.select_dtypes(include="number").corr()["target"].sort_values()
print(correlations.head(10))  # Strongest negative correlations
print(correlations.tail(10))  # Strongest positive correlations
```

**Compruebe si hay fugas**: características que no existirían en el momento de la predicción. Este es el error número uno que cometen los principiantes. Si una característica se correlaciona sospechosamente bien con el objetivo, investigue antes de celebrar.

## 🛠️ Ingeniería de funciones que gana

Los principales competidores dedican el 70% de su tiempo a funciones, no a ajustes de modelos. Técnicas probadas en batalla:

**Funciones de agregación**: estadísticas de grupo con diferentes granularidades:
```python
for col in ["category", "store_id", "day_of_week"]:
    stats = df.groupby(col)["sales"].agg(["mean", "std", "median"])
    stats.columns = [f"{col}_sales_{s}" for s in ["mean", "std", "median"]]
    df = df.merge(stats, on=col, how="left")
```

**Codificación de destino**: reemplace las categorías con medios de destino suavizados (use codificación basada en pliegues para evitar fugas).

**Características de retraso**: para series temporales, los valores anteriores son dorados:
```python
for lag in [1, 7, 14, 28]:
    df[f"sales_lag_{lag}"] = df.groupby("store_id")["sales"].shift(lag)
```

## ✅ Validación cruzada: confíe en su puntuación local

La puntuación de su CV local es más importante que la clasificación pública. Una estrategia de validación sólida:

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_predictions = np.zeros(len(X))

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

    model = lgb.LGBMClassifier(n_estimators=1000, learning_rate=0.05)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
              callbacks=[lgb.early_stopping(50)])
    oof_predictions[val_idx] = model.predict_proba(X_val)[:, 1]

print(f"OOF AUC: {roc_auc_score(y, oof_predictions):.5f}")
```

**Regla de oro**: si tu CV local y tu LB público no están de acuerdo, confía en tu CV. La tabla de clasificación pública utiliza sólo una fracción de los datos de prueba; sobreajustarse a ella es una trampa.

## 🎭 Métodos de conjunto: el empujón final

Casi todas las soluciones ganadoras utilizan conjuntos. Tres técnicas clave:

**Embolsado**: entrene el mismo modelo en diferentes subconjuntos de datos, predicciones promedio. Reduce la variación.

**Apilamiento**: entrene un metamodelo con predicciones desplegadas de diversos modelos base:
```python
# Level 1: diverse base models produce OOF predictions
base_preds = np.column_stack([lgbm_oof, xgb_oof, catboost_oof, nn_oof])

# Level 2: logistic regression learns optimal combination
from sklearn.linear_model import LogisticRegression
meta = LogisticRegression()
meta.fit(base_preds, y_train)
```

**Combinación**: promedio ponderado de las predicciones del modelo. Más sencillo que apilar pero eficaz:
```python
final = 0.4 * lgbm_pred + 0.35 * xgb_pred + 0.25 * catboost_pred
```
