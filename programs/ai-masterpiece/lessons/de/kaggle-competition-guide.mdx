## 🎯 Warum Kaggle für Ihre Karriere wichtig ist

Kaggle-Erfahrung signalisiert etwas, was Lebensläufe nicht können: **Sie können Modelle ausliefern, die mit chaotischen, realen Daten arbeiten**. Einstellungsmanager bei Google, Meta und Top-Startups rekrutieren aktiv über die Kaggle-Bestenlisten. Auch ohne Sieg zeugt ein starkes Profil mit gut dokumentierten Notizbüchern von praktischer Kompetenz.

## 🔍EDA – Deine ersten 48 Stunden

Beginnen Sie niemals mit der Modellierung, bevor Sie Ihre Daten verstanden haben. Ein disziplinierter EDA-Workflow:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("train.csv")

# Shape and types - know what you're working with
print(f"Shape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum().sort_values(ascending=False).head(10)}")

# Target distribution - is it balanced?
df["target"].value_counts(normalize=True).plot(kind="bar")
plt.title("Target Distribution")
plt.show()

# Correlations - find quick signal
correlations = df.select_dtypes(include="number").corr()["target"].sort_values()
print(correlations.head(10))  # Strongest negative correlations
print(correlations.tail(10))  # Strongest positive correlations
```

**Auf Lecks prüfen** – Funktionen, die zum Vorhersagezeitpunkt nicht vorhanden wären. Das ist der häufigste Fehler, den Anfänger machen. Wenn ein Merkmal verdächtig gut mit dem Ziel korreliert, untersuchen Sie es, bevor Sie feiern.

## 🛠️ Feature Engineering, das gewinnt

Top-Konkurrenten verbringen 70 % ihrer Zeit mit Funktionen und nicht mit Modelltuning. Kampferprobte Techniken:

**Aggregationsfunktionen** – Gruppieren Sie Statistiken mit unterschiedlicher Granularität:
```python
for col in ["category", "store_id", "day_of_week"]:
    stats = df.groupby(col)["sales"].agg(["mean", "std", "median"])
    stats.columns = [f"{col}_sales_{s}" for s in ["mean", "std", "median"]]
    df = df.merge(stats, on=col, how="left")
```

**Zielkodierung** – Ersetzen Sie Kategorien durch geglättete Zielmittelwerte (verwenden Sie faltenbasierte Kodierung, um Lecks zu verhindern).

**Lag-Funktionen** – für Zeitreihen sind vorherige Werte Gold wert:
```python
for lag in [1, 7, 14, 28]:
    df[f"sales_lag_{lag}"] = df.groupby("store_id")["sales"].shift(lag)
```

## ✅ Kreuzvalidierung – Vertrauen Sie Ihrem lokalen Score

Ihr lokaler Lebenslauf-Score ist wichtiger als die öffentliche Bestenliste. Eine robuste Validierungsstrategie:

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
oof_predictions = np.zeros(len(X))

for fold, (train_idx, val_idx) in enumerate(skf.split(X, y)):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]

    model = lgb.LGBMClassifier(n_estimators=1000, learning_rate=0.05)
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
              callbacks=[lgb.early_stopping(50)])
    oof_predictions[val_idx] = model.predict_proba(X_val)[:, 1]

print(f"OOF AUC: {roc_auc_score(y, oof_predictions):.5f}")
```

**Goldene Regel**: Wenn Ihr lokaler Lebenslauf und Ihr öffentlicher Arbeitgeber nicht übereinstimmen, vertrauen Sie Ihrem Lebenslauf. Die öffentliche Bestenliste verwendet nur einen Bruchteil der Testdaten – eine Überanpassung daran ist eine Falle.

## 🎭 Ensemble-Methoden – Der letzte Schub

Fast jede erfolgreiche Lösung verwendet Ensembles. Drei Schlüsseltechniken:

**Bagging** – Trainieren Sie dasselbe Modell anhand verschiedener Datenteilmengen und durchschnittlicher Vorhersagen. Reduziert die Varianz.

**Stacking** – Trainieren Sie ein Metamodell auf Out-of-Fold-Vorhersagen aus verschiedenen Basismodellen:
```python
# Level 1: diverse base models produce OOF predictions
base_preds = np.column_stack([lgbm_oof, xgb_oof, catboost_oof, nn_oof])

# Level 2: logistic regression learns optimal combination
from sklearn.linear_model import LogisticRegression
meta = LogisticRegression()
meta.fit(base_preds, y_train)
```

**Blending** – gewichteter Durchschnitt der Modellvorhersagen. Einfacher als Stapeln, aber effektiv:
```python
final = 0.4 * lgbm_pred + 0.35 * xgb_pred + 0.25 * catboost_pred
```

Bei der Mittelung heben sich einzelne Fehler auf, während korrekte Signale sich gegenseitig verstärken – wodurch die Gesamtvarianz verringert wird, ohne dass die Verzerrung zunimmt." />

## 📓 Tolle Kaggle-Notizbücher schreiben

Öffentliche Notizbücher stärken Ihren Ruf. Ein medaillenwürdiges Notizbuch enthält:

## 🎯 Wichtige Erkenntnisse

- Zuerst EDA, dann Modellierung - immer auf Datenlecks prüfen
– Feature-Engineering bietet mehr Auftrieb als Hyperparameter-Tuning
- Vertrauen Sie Ihrem lokalen Lebenslauf und nicht der öffentlichen Bestenliste
- Kombiniere verschiedene Modelle für den Endspurt
- Dokumentieren Sie Ihre Arbeit in öffentlichen Notizbüchern – es ist Ihr Portfolio
