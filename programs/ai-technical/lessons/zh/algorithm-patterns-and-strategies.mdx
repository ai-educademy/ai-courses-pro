# 算法模式和策略

编码面试并不是要记住 500 个 LeetCode 解决方案。它们是关于识别大约十种模式中的哪一种适用于您面前的问题。一旦确定了模式，解决方案结构就会自行编写。本课程详细介绍了每种模式 - 何时使用它、如何识别它，以及一个具体的例子来巩固你的理解。将这些模式视为镜头：你练习观察它们的次数越多，每个新问题就越快成为焦点。

## 模式 1：两个指针

**识别时**：输入已排序（或可排序），需要找到满足某些条件的对或子数组。

两个指针的工作原理是在数组的每一端放置一个指针（或在“快/慢”变体的开头）并根据条件将它们移向彼此。

```python
# Three Sum: find all triplets that sum to zero
def three_sum(nums):
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue  # Skip duplicates
        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                left += 1
                right -= 1
    return result
```

**时间**：O(n²) - 相对于 O(n³) 暴力破解的巨大改进。

## 模式 2：滑动窗口

**识别它的时候**：你需要找到一个满足某些约束（最大和、包含所有字符等）的连续子数组或子字符串。

移动右侧指针可扩展窗口，移动左侧指针可缩小窗口。关键是知道什么时候收缩。

```python
# Longest substring without repeating characters
def length_of_longest_substring(s: str) -> int:
    char_index = {}
    max_length = 0
    left = 0
    for right, char in enumerate(s):
        if char in char_index and char_index[char] >= left:
            left = char_index[char] + 1
        char_index[char] = right
        max_length = max(max_length, right - left + 1)
    return max_length
```

<Callout>滑动窗口模式有一个固定的模板：初始化两个指针，向右扩展，违反约束时向左收缩，并跟踪您的答案。一旦你内化了这个模板，每个滑动窗口问题都感觉是可以管理的。</Callout>

## 模式 3：BFS（广度优先搜索）

**何时认识它**：您需要未加权图中的最短路径、层序遍历或逐层探索邻居。

BFS使用队列，逐级处理节点。它保证了未加权图中的最短路径。

```python
from collections import deque

# Number of islands — BFS variant
def num_islands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                queue = deque([(r, c)])
                grid[r][c] = '0'
                while queue:
                    row, col = queue.popleft()
                    for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                        nr, nc = row + dr, col + dc
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == '1':
                            grid[nr][nc] = '0'
                            queue.append((nr, nc))
    return count
```

## 模式 4：DFS（深度优先搜索）

**何时识别**：您需要探索所有路径、检查连通性、检测循环，或者问题具有递归/树结构。

DFS 先深后广。它是自然递归的，并且完美地映射到树遍历和回溯。

```python
# Path sum in a binary tree
def has_path_sum(root, target_sum):
    if not root:
        return False
    if not root.left and not root.right:
        return target_sum == root.val
    return (has_path_sum(root.left, target_sum - root.val) or
            has_path_sum(root.right, target_sum - root.val))
```

<ThinkAboutIt>什么时候你会选择 BFS 而不是 DFS，反之亦然？考虑：BFS 找到最短路径，但使用 O(宽度) 内存。 DFS 使用 O(深度) 内存，但不保证最短路径。图表的形状如何影响您的选择？</ThinkAboutIt>

## 模式 5：二分查找

**在以下情况下识别**：搜索空间是排序的或单调的（如果条件在索引 i 处为真，则对于所有索引 > i 或 < i 都为真）。

二分查找不仅仅适用于排序数组 - 它适用于任何单调条件。这种洞察力解决了“运送包裹的最小容量”或“查找峰值元素”等问题。

```python
# Binary search on answer: minimum days to make m bouquets
def min_days(bloom_day, m, k):
    if m * k > len(bloom_day):
        return -1

    def can_make(days):
        bouquets = flowers = 0
        for bloom in bloom_day:
            if bloom <= days:
                flowers += 1
                if flowers == k:
                    bouquets += 1
                    flowers = 0
            else:
                flowers = 0
        return bouquets >= m

    lo, hi = min(bloom_day), max(bloom_day)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_make(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

<FunFact>尽管二分搜索从概念上来说是最简单的算法之一，但 Jon Bentley 的一项研究发现，只有大约 10% 的专业程序员能够在第一次尝试时正确实现它。最常见的错误？边界条件中的相差一误差。</FunFact>

## 模式 6：回溯

**何时认识它**：您需要生成满足约束的所有组合、排列或子集。问题通常是“查找所有”、“生成所有”或“列出所有可能的”。

回溯 = 带剪枝的 DFS。你探索一条路径，如果它违反了约束，你就回溯并尝试下一个选项。

```python
# Generate all valid combinations of n pairs of parentheses
def generate_parenthesis(n):
    result = []
    def backtrack(current, open_count, close_count):
        if len(current) == 2 * n:
            result.append(current)
            return
        if open_count < n:
            backtrack(current + '(', open_count + 1, close_count)
        if close_count < open_count:
            backtrack(current + ')', open_count, close_count + 1)
    backtrack('', 0, 0)
    return result
```

## 模式 7：动态规划

**何时识别**：问题具有重叠的子问题和最优子结构。经典信号包括“最小成本”、“路径数量”、“最长/最短序列”或“你能到达目标吗？”

DP 配方：定义状态，编写递归，在自上而下（记忆）和自下而上（制表）之间做出决定。

```python
# Longest Increasing Subsequence — O(n²) DP
def length_of_lis(nums):
    if not nums:
        return 0
    dp = [1] * len(nums)  # dp[i] = length of LIS ending at index i
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

<Callout>当你遇到 DP 问题时，首先从暴力递归开始。然后添加记忆。转换为自下而上的制表是一个优化步骤，而不是第一步。这种方法可以防止迷失在表格尺寸中。</Callout>

## 模式 8：贪婪

**认识到这一点**：在每一步中做出局部最优选择会导致全局最优解。贪婪问题通常涉及间隔、日程安排或做出不需要重新审视的选择。

```python
# Minimum number of meeting rooms (interval scheduling)
def min_meeting_rooms(intervals):
    starts = sorted([i[0] for i in intervals])
    ends = sorted([i[1] for i in intervals])
    rooms = max_rooms = 0
    s = e = 0
    while s < len(starts):
        if starts[s] < ends[e]:
            rooms += 1
            max_rooms = max(max_rooms, rooms)
            s += 1
        else:
            rooms -= 1
            e += 1
    return max_rooms
```

## 模式 9：拓扑排序

**何时认识它**：任务之间存在依赖关系（课程先决条件、构建顺序、任务调度）。输入是有向无环图 (DAG)。

```python
from collections import deque, defaultdict

def course_order(num_courses, prerequisites):
    graph = defaultdict(list)
    in_degree = [0] * num_courses
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            in_degree[neighbour] -= 1
            if in_degree[neighbour] == 0:
                queue.append(neighbour)
    return order if len(order) == num_courses else []
```

## 模式 10：并查（不相交集）

**在以下情况下识别**：您需要对元素进行分组、检测连接的组件或确定两个元素是否属于同一集合 - 特别是在动态添加连接时。

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True
```

## 如何识别正确的模式

在你的头脑中建立一个决策树：

1. **输入是否已排序或者是否可以排序？** → 双指针或二分查找
2. **需要连续的子数组/子字符串吗？** → 滑动窗口
3. **是图/树遍历吗？** → BFS（最短路径）还是DFS（所有路径）
4. **“找到所有组合/排列”？** → 回溯
5. **“最小成本/路数”？** → 动态规划
6. **“进度/间隔”问题？** → 贪心还是排序
7. **依赖关系或顺序？** → 拓扑排序
8. **分组/连接？** → 并查

## 要点

- **学习模式，而不是问题**：10 种模式涵盖了绝大多数面试问题。
- **从暴力开始**：从暴力方法中识别模式，然后进行优化。
- **练习模式识别**：对于您解决的每个问题，标记它使用的模式。
- **组合模式**：许多中/难问题一起使用两种模式（例如，二分搜索+滑动窗口、BFS+拓扑排序）。
- **用语言表达你的推理**：在采访中，说“这看起来像一个滑动窗口问题，因为......”显示出强大的分析思维。
