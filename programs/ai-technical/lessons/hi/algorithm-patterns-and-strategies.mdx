# एल्गोरिथम पैटर्न और रणनीतियाँ

कोडिंग साक्षात्कार 500 लीटकोड समाधानों को याद रखने के बारे में नहीं हैं। वे यह पहचानने के बारे में हैं कि आपके सामने मौजूद समस्या पर लगभग दस पैटर्न में से कौन-सा पैटर्न लागू होता है। एक बार जब आप पैटर्न की पहचान कर लेते हैं, तो समाधान संरचना स्वयं लिखती है। यह पाठ प्रत्येक पैटर्न को तोड़ता है - इसका उपयोग कब करना है, इसे कैसे पहचानना है, और आपकी समझ को मजबूत करने के लिए एक ठोस उदाहरण है। इन पैटर्नों को लेंस के रूप में सोचें: जितना अधिक आप इन्हें देखने का अभ्यास करेंगे, उतनी ही तेज़ी से हर नई समस्या ध्यान में आएगी।

## पैटर्न 1: दो संकेतक

**इसे तब पहचानें जब**: इनपुट सॉर्ट किया गया है (या सॉर्ट किया जा सकता है), और आपको कुछ शर्तों को पूरा करने वाले जोड़े या उपसरणी ढूंढने की आवश्यकता है।

दो पॉइंटर्स सरणी के प्रत्येक छोर पर (या "तेज़/धीमे" संस्करण के लिए शुरुआत में) एक पॉइंटर रखकर और एक शर्त के आधार पर उन्हें एक-दूसरे की ओर ले जाकर काम करते हैं।

```python
# Three Sum: find all triplets that sum to zero
def three_sum(nums):
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue  # Skip duplicates
        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                left += 1
                right -= 1
    return result
```

**समय**: O(n²) - O(n³) पाशविक बल की तुलना में भारी सुधार।

## पैटर्न 2: स्लाइडिंग विंडो

**इसे तब पहचानें जब**: आपको एक सन्निहित उपसरणी या सबस्ट्रिंग ढूंढनी होगी जो कुछ बाधाओं को पूरा करती है (अधिकतम योग, सभी वर्ण शामिल हैं, आदि)।

दाएँ पॉइंटर को हिलाने से विंडो फैलती है और बाएँ पॉइंटर को हिलाने पर सिकुड़ती है। मुख्य बात यह जानना है कि कब सिकुड़ना है।

```python
# Longest substring without repeating characters
def length_of_longest_substring(s: str) -> int:
    char_index = {}
    max_length = 0
    left = 0
    for right, char in enumerate(s):
        if char in char_index and char_index[char] >= left:
            left = char_index[char] + 1
        char_index[char] = right
        max_length = max(max_length, right - left + 1)
    return max_length
```

<Callout>स्लाइडिंग विंडो पैटर्न में एक निश्चित टेम्पलेट होता है: दो पॉइंटर्स को प्रारंभ करें, दाएं का विस्तार करें, बाधा का उल्लंघन होने पर बाएं को सिकोड़ें, और अपने उत्तर को ट्रैक करें। एक बार जब आप इस टेम्पलेट को आत्मसात कर लेते हैं, तो हर स्लाइडिंग विंडो समस्या प्रबंधनीय लगती है।</Callout>

## पैटर्न 3: बीएफएस (चौड़ाई-पहली खोज)

**इसे तब पहचानें जब**: आपको बिना भारित ग्राफ़, लेवल-ऑर्डर ट्रैवर्सल, या परत दर परत पड़ोसियों का पता लगाने के लिए सबसे छोटे पथ की आवश्यकता होती है।

बीएफएस एक कतार का उपयोग करता है और नोड्स को स्तर दर स्तर संसाधित करता है। यह बिना भारित ग्राफ़ में सबसे छोटे पथ की गारंटी देता है।

```python
from collections import deque

# Number of islands — BFS variant
def num_islands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                queue = deque([(r, c)])
                grid[r][c] = '0'
                while queue:
                    row, col = queue.popleft()
                    for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                        nr, nc = row + dr, col + dc
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == '1':
                            grid[nr][nc] = '0'
                            queue.append((nr, nc))
    return count
```

## पैटर्न 4: डीएफएस (गहराई-पहली खोज)

**इसे तब पहचानें जब**: आपको सभी पथों का पता लगाने, कनेक्टिविटी की जांच करने, चक्रों का पता लगाने की आवश्यकता है, या समस्या में एक पुनरावर्ती/वृक्ष संरचना है।

डीएफएस वाइड से पहले गहराई तक जाता है। यह स्वाभाविक रूप से पुनरावर्ती है और वृक्ष ट्रैवर्सल और बैकट्रैकिंग को खूबसूरती से मैप करता है।

```python
# Path sum in a binary tree
def has_path_sum(root, target_sum):
    if not root:
        return False
    if not root.left and not root.right:
        return target_sum == root.val
    return (has_path_sum(root.left, target_sum - root.val) or
            has_path_sum(root.right, target_sum - root.val))
```

<ThinkAboutIt>आप डीएफएस के स्थान पर बीएफएस को कब चुनेंगे, और इसके विपरीत? विचार करें: बीएफएस सबसे छोटा रास्ता ढूंढता है लेकिन ओ (चौड़ाई) मेमोरी का उपयोग करता है। DFS O(गहराई) मेमोरी का उपयोग करता है लेकिन सबसे छोटे पथ की गारंटी नहीं देता है। ग्राफ़ का आकार आपकी पसंद को कैसे प्रभावित करता है?</ThinkAboutIt>

## पैटर्न 5: बाइनरी सर्च

**इसे तब पहचानें जब**: खोज स्थान क्रमबद्ध या मोनोटोनिक है (यदि सूचकांक i पर स्थिति सत्य है, तो यह सभी सूचकांकों > i या <i) के लिए सत्य है।

बाइनरी खोज केवल क्रमबद्ध सरणियों के लिए नहीं है - यह किसी भी मोनोटोनिक स्थिति पर काम करती है। यह अंतर्दृष्टि "पैकेज भेजने की कम-से-कम क्षमता" या "शीर्ष तत्व ढूंढें" जैसी समस्याओं को अनलॉक करती है।

```python
# Binary search on answer: minimum days to make m bouquets
def min_days(bloom_day, m, k):
    if m * k > len(bloom_day):
        return -1

    def can_make(days):
        bouquets = flowers = 0
        for bloom in bloom_day:
            if bloom <= days:
                flowers += 1
                if flowers == k:
                    bouquets += 1
                    flowers = 0
            else:
                flowers = 0
        return bouquets >= m

    lo, hi = min(bloom_day), max(bloom_day)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_make(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

<FunFact>बाइनरी सर्च वैचारिक रूप से सबसे सरल एल्गोरिदम में से एक होने के बावजूद, जॉन बेंटले के एक अध्ययन में पाया गया कि केवल 10% पेशेवर प्रोग्रामर ही इसे पहले प्रयास में सही ढंग से लागू कर सकते हैं। सबसे आम बग? सीमा स्थितियों में एक-एक करके त्रुटियाँ।</FunFact>

## पैटर्न 6: बैकट्रैकिंग

**इसे तब पहचानें जब**: आपको बाधाओं को पूरा करने वाले सभी संयोजन, क्रमपरिवर्तन या उपसमुच्चय उत्पन्न करने की आवश्यकता है। समस्या अक्सर कहती है "सभी ढूंढें", "सभी उत्पन्न करें", या "हर संभव सूची बनाएँ"।

बैकट्रैकिंग = प्रूनिंग के साथ डीएफएस। आप एक पथ का पता लगाते हैं, और यदि यह किसी बाधा का उल्लंघन करता है, तो आप पीछे हट जाते हैं और अगला विकल्प आज़माते हैं।

```python
# Generate all valid combinations of n pairs of parentheses
def generate_parenthesis(n):
    result = []
    def backtrack(current, open_count, close_count):
        if len(current) == 2 * n:
            result.append(current)
            return
        if open_count < n:
            backtrack(current + '(', open_count + 1, close_count)
        if close_count < open_count:
            backtrack(current + ')', open_count, close_count + 1)
    backtrack('', 0, 0)
    return result
```

## पैटर्न 7: डायनेमिक प्रोग्रामिंग

**इसे तब पहचानें जब**: समस्या में ओवरलैपिंग उपसमस्याएं और इष्टतम उपसंरचना हो। क्लासिक संकेतों में "कम-से-कम लागत", "तरीकों की संख्या", "सबसे लंबा/सबसे छोटा अनुक्रम", या "क्या आप लक्ष्य तक पहुंच सकते हैं?"

डीपी नुस्खा: स्थिति को परिभाषित करें, पुनरावृत्ति लिखें, ऊपर से नीचे (संस्मरण) और नीचे से ऊपर (सारणीबद्ध) के बीच निर्णय लें।

```python
# Longest Increasing Subsequence — O(n²) DP
def length_of_lis(nums):
    if not nums:
        return 0
    dp = [1] * len(nums)  # dp[i] = length of LIS ending at index i
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

<Callout>जब आप डीपी समस्या में फंस जाएं, तो पहले ब्रूट-फोर्स रिकर्सन से शुरुआत करें। फिर संस्मरण जोड़ें. नीचे से ऊपर सारणीकरण में कनवर्ट करना एक अनुकूलन कदम है, पहला कदम नहीं। यह दृष्टिकोण तालिका आयामों में खो जाने से बचाता है।</Callout>

## पैटर्न 8: लालची

**इसे तब पहचानें जब**: प्रत्येक चरण पर स्थानीय रूप से इष्टतम विकल्प चुनने से वैश्विक स्तर पर इष्टतम समाधान प्राप्त होता है। लालची समस्याओं में अक्सर अंतराल, शेड्यूलिंग या ऐसे विकल्प चुनना शामिल होता है जिन पर दोबारा विचार करने की आवश्यकता नहीं होती है।

```python
# Minimum number of meeting rooms (interval scheduling)
def min_meeting_rooms(intervals):
    starts = sorted([i[0] for i in intervals])
    ends = sorted([i[1] for i in intervals])
    rooms = max_rooms = 0
    s = e = 0
    while s < len(starts):
        if starts[s] < ends[e]:
            rooms += 1
            max_rooms = max(max_rooms, rooms)
            s += 1
        else:
            rooms -= 1
            e += 1
    return max_rooms
```

## पैटर्न 9: टोपोलॉजिकल सॉर्ट

**इसे तब पहचानें जब**: कार्यों के बीच निर्भरताएं हों (पाठ्यक्रम पूर्वापेक्षाएँ, निर्माण क्रम, कार्य शेड्यूलिंग)। इनपुट एक निर्देशित एसाइक्लिक ग्राफ (डीएजी) है।

```python
from collections import deque, defaultdict

def course_order(num_courses, prerequisites):
    graph = defaultdict(list)
    in_degree = [0] * num_courses
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            in_degree[neighbour] -= 1
            if in_degree[neighbour] == 0:
                queue.append(neighbour)
    return order if len(order) == num_courses else []
```

## पैटर्न 10: यूनियन-फाइंड (डिसजॉइंट सेट)

**इसे तब पहचानें जब**: आपको तत्वों को समूहित करने, जुड़े हुए घटकों का पता लगाने, या यह निर्धारित करने की आवश्यकता है कि क्या दो तत्व एक ही सेट से संबंधित हैं - खासकर जब कनेक्शन गतिशील रूप से जोड़े जाते हैं।

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True
```

## सही पैटर्न को कैसे पहचानें

अपने दिमाग में एक निर्णय वृक्ष बनाएँ:

1. **क्या इनपुट सॉर्ट किया गया है या इसे सॉर्ट किया जा सकता है?** → दो पॉइंटर्स या बाइनरी सर्च
2. **क्या आपको एक सन्निहित उपसरणी/सबस्ट्रिंग की आवश्यकता है?** → स्लाइडिंग विंडो
3. **क्या यह एक ग्राफ/ट्री ट्रैवर्सल है?** → बीएफएस (सबसे छोटा पथ) या डीएफएस (सभी पथ)
4. **"सभी संयोजन/क्रमपरिवर्तन खोजें"?** → बैकट्रैकिंग
5. **"कम-से-कम लागत/तरीकों की संख्या"?** → गतिशील प्रोग्रामिंग
6. **"अनुसूची/अंतराल" समस्या?** → लालची या छँटाई
7. **निर्भरताएं या ऑर्डरिंग?** → टोपोलॉजिकल सॉर्ट
8. **ग्रुपिंग/कनेक्टिविटी?** → यूनियन-फाइंड

- **पैटर्न पहचान का अभ्यास करें**: आपके द्वारा हल की जाने वाली प्रत्येक समस्या के लिए, यह लेबल करें कि वह किस पैटर्न का उपयोग करता है।
- **पैटर्न को संयोजित करें**: कई मध्यम/कठिन समस्याएं एक साथ दो पैटर्न का उपयोग करती हैं (उदाहरण के लिए, बाइनरी सर्च + स्लाइडिंग विंडो, बीएफएस + टोपोलॉजिकल सॉर्ट)।
- **अपने तर्क को मौखिक रूप से बताएं**: साक्षात्कारों में, यह कहना कि "यह एक स्लाइडिंग विंडो समस्या की तरह दिखती है क्योंकि..." मजबूत विश्लेषणात्मक सोच को दर्शाता है।
