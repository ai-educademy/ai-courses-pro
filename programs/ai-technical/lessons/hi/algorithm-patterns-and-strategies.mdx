# एल्गोरिदम पैटर्न और रणनीतियाँ

कोडिंग इंटरव्यू 500 LeetCode समाधान याद करने के बारे में नहीं होते। असली कौशल यह पहचानना है कि सामने आई समस्या पर लगभग दस पैटर्न में से कौन सा लागू होता है। पैटर्न पहचानते ही समाधान की बनावट साफ़ होने लगती है। यह पाठ हर पैटर्न को खोलकर समझाता है: कब इस्तेमाल करें, कैसे पहचानें, और आपकी समझ को पक्का करने वाला ठोस उदाहरण। इन पैटर्न को लेंस की तरह सोचें। जितना ज़्यादा आप इनके माध्यम से देखना सीखेंगे, हर नई समस्या उतनी जल्दी स्पष्ट होगी।

## पैटर्न 1: दो पॉइंटर

**इसे तब पहचानें जब**: इनपुट सॉर्टेड हो या सॉर्ट किया जा सकता हो, और आपको कोई शर्त पूरी करने वाले जोड़े या subarray खोजने हों।

दो पॉइंटर ऐरे के दोनों सिरों पर एक-एक पॉइंटर रखकर काम करते हैं (या "fast/slow" रूप में शुरुआत पर) और शर्त के आधार पर उन्हें एक-दूसरे की ओर बढ़ाते हैं।

```python
# Three Sum: find all triplets that sum to zero
def three_sum(nums):
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue  # Skip duplicates
        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                left += 1
                right -= 1
    return result
```

**समय**: O(n²), जो O(n³) ब्रूट फ़ोर्स की तुलना में बहुत बड़ा सुधार है।

## पैटर्न 2: स्लाइडिंग विंडो

**इसे तब पहचानें जब**: आपको ऐसी contiguous subarray या substring खोजनी हो जो कोई constraint पूरा करे (maximum sum, सभी characters शामिल हों, आदि)।

विंडो right pointer बढ़ाकर फैलती है और left pointer बढ़ाकर सिकुड़ती है। मुख्य बात यह जानना है कि कब shrink करना है।

```python
# Longest substring without repeating characters
def length_of_longest_substring(s: str) -> int:
    char_index = {}
    max_length = 0
    left = 0
    for right, char in enumerate(s):
        if char in char_index and char_index[char] >= left:
            left = char_index[char] + 1
        char_index[char] = right
        max_length = max(max_length, right - left + 1)
    return max_length
```

<Callout>स्लाइडिंग विंडो पैटर्न का एक तय टेम्पलेट है: दो पॉइंटर initialise करें, right फैलाएँ, constraint टूटे तो left सिकोड़ें, और अपना उत्तर track करें। यह टेम्पलेट भीतर बैठ जाए तो हर sliding window समस्या संभालने लायक लगती है।</Callout>

## पैटर्न 3: BFS (Breadth-First Search)

**इसे तब पहचानें जब**: आपको unweighted graph में shortest path, level-order traversal, या neighbours को layer by layer explore करना हो।

BFS queue का उपयोग करता है और nodes को level by level process करता है। यह unweighted graphs में shortest path की guarantee देता है।

```python
from collections import deque

# Number of islands — BFS variant
def num_islands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                queue = deque([(r, c)])
                grid[r][c] = '0'
                while queue:
                    row, col = queue.popleft()
                    for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                        nr, nc = row + dr, col + dc
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == '1':
                            grid[nr][nc] = '0'
                            queue.append((nr, nc))
    return count
```

## पैटर्न 4: DFS (Depth-First Search)

**इसे तब पहचानें जब**: आपको सभी paths explore करने हों, connectivity जाँचनी हो, cycles detect करनी हों, या समस्या में recursive/tree structure हो।

DFS चौड़ाई से पहले गहराई में जाता है। यह स्वाभाविक रूप से recursive है और tree traversal तथा backtracking से बहुत अच्छी तरह मेल खाता है।

```python
# Path sum in a binary tree
def has_path_sum(root, target_sum):
    if not root:
        return False
    if not root.left and not root.right:
        return target_sum == root.val
    return (has_path_sum(root.left, target_sum - root.val) or
            has_path_sum(root.right, target_sum - root.val))
```

<ThinkAboutIt>आप DFS के बजाय BFS कब चुनेंगे, और उल्टा कब? सोचें: BFS shortest paths खोजता है लेकिन O(width) memory लेता है। DFS O(depth) memory लेता है लेकिन shortest path की guarantee नहीं देता। graph का shape आपकी choice को कैसे प्रभावित करता है?</ThinkAboutIt>

## पैटर्न 5: बाइनरी सर्च

**इसे तब पहचानें जब**: search space सॉर्टेड या monotonic हो (अगर condition index i पर true है, तो वह सभी indices > i या < i के लिए true रहती है)।

बाइनरी सर्च सिर्फ सॉर्टेड ऐरे के लिए नहीं है। यह किसी भी monotonic condition पर काम करता है। यही समझ "minimum capacity to ship packages" या "find peak element" जैसी समस्याएँ खोलती है।

```python
# Binary search on answer: minimum days to make m bouquets
def min_days(bloom_day, m, k):
    if m * k > len(bloom_day):
        return -1

    def can_make(days):
        bouquets = flowers = 0
        for bloom in bloom_day:
            if bloom <= days:
                flowers += 1
                if flowers == k:
                    bouquets += 1
                    flowers = 0
            else:
                flowers = 0
        return bouquets >= m

    lo, hi = min(bloom_day), max(bloom_day)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_make(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

<FunFact>बाइनरी सर्च अवधारणा में सबसे सरल एल्गोरिदम में से एक है, फिर भी Jon Bentley के एक अध्ययन में पाया गया कि केवल लगभग 10% पेशेवर programmers इसे पहली कोशिश में सही implement कर पाए। सबसे आम bug? boundary conditions में off-by-one त्रुटियाँ।</FunFact>

## पैटर्न 6: बैकट्रैकिंग

**इसे तब पहचानें जब**: आपको constraints पूरी करने वाले सभी combinations, permutations या subsets generate करने हों। समस्या अक्सर "find all", "generate all" या "list every possible" कहती है।

Backtracking = pruning के साथ DFS. आप एक path explore करते हैं, और अगर वह constraint तोड़ता है तो वापस लौटकर अगला option आज़माते हैं। आप एक path explore करते हैं, और अगर वह constraint तोड़ता है तो वापस लौटकर अगला option आज़माते हैं।

```python
# Generate all valid combinations of n pairs of parentheses
def generate_parenthesis(n):
    result = []
    def backtrack(current, open_count, close_count):
        if len(current) == 2 * n:
            result.append(current)
            return
        if open_count < n:
            backtrack(current + '(', open_count + 1, close_count)
        if close_count < open_count:
            backtrack(current + ')', open_count, close_count + 1)
    backtrack('', 0, 0)
    return result
```

## पैटर्न 7: डायनेमिक प्रोग्रामिंग

**इसे तब पहचानें जब**: समस्या में overlapping subproblems और optimal substructure हों। Classic संकेत हैं "minimum cost", "number of ways", "longest/shortest sequence" या "क्या target तक पहुँच सकते हैं?"

DP की recipe: state define करें, recurrence लिखें, और top-down (memoisation) या bottom-up (tabulation) में से चुनें।

```python
# Longest Increasing Subsequence — O(n²) DP
def length_of_lis(nums):
    if not nums:
        return 0
    dp = [1] * len(nums)  # dp[i] = length of LIS ending at index i
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

<Callout>जब आप DP समस्या में अटकें, तो पहले brute-force recursion से शुरू करें। फिर memoisation जोड़ें। Bottom-up tabulation में बदलना optimisation step है, पहला step नहीं। यह तरीका table dimensions में खोने से बचाता है।</Callout>

## पैटर्न 8: ग्रीडी

**इसे तब पहचानें जब**: हर step पर locally optimal choice करने से globally optimal solution मिलता हो। Greedy समस्याओं में अक्सर intervals, scheduling, या ऐसी choices होती हैं जिन्हें revisit करने की ज़रूरत नहीं पड़ती।

```python
# Minimum number of meeting rooms (interval scheduling)
def min_meeting_rooms(intervals):
    starts = sorted([i[0] for i in intervals])
    ends = sorted([i[1] for i in intervals])
    rooms = max_rooms = 0
    s = e = 0
    while s < len(starts):
        if starts[s] < ends[e]:
            rooms += 1
            max_rooms = max(max_rooms, rooms)
            s += 1
        else:
            rooms -= 1
            e += 1
    return max_rooms
```

## पैटर्न 9: टोपोलॉजिकल सॉर्ट

**इसे तब पहचानें जब**: tasks के बीच dependencies हों (course prerequisites, build order, task scheduling)। इनपुट directed acyclic graph (DAG) होता है।

```python
from collections import deque, defaultdict

def course_order(num_courses, prerequisites):
    graph = defaultdict(list)
    in_degree = [0] * num_courses
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            in_degree[neighbour] -= 1
            if in_degree[neighbour] == 0:
                queue.append(neighbour)
    return order if len(order) == num_courses else []
```

## पैटर्न 10: Union-Find (Disjoint Set)

**इसे तब पहचानें जब**: आपको elements group करने हों, connected components detect करने हों, या तय करना हो कि दो elements एक ही set में हैं या नहीं, खासकर जब connections dynamically add होते हों।

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True
```

## सही पैटर्न कैसे पहचानें

अपने दिमाग में decision tree बनाएँ:

1. **क्या input sorted है या sorted किया जा सकता है?** → दो पॉइंटर या बाइनरी सर्च
2. **क्या आपको contiguous subarray/substring चाहिए?** → स्लाइडिंग विंडो
3. **क्या यह graph/tree traversal है?** → BFS (shortest path) या DFS (all paths)
4. **"सभी combinations/permutations खोजें"?** → बैकट्रैकिंग
5. **"Minimum cost / number of ways"?** → डायनेमिक प्रोग्रामिंग
6. **"Schedule / interval" समस्या?** → ग्रीडी या सॉर्टिंग
7. **Dependencies या ordering?** → टोपोलॉजिकल सॉर्ट
8. **Grouping / connectivity?** → Union-Find

- **Patterns combine करें**: कई medium/hard समस्याएँ दो patterns साथ उपयोग करती हैं, जैसे binary search + sliding window, BFS + topological सॉर्ट।
- **अपनी reasoning बोलकर समझाएँ**: इंटरव्यू में "यह sliding window problem लगती है क्योंकि..." कहना मजबूत analytical thinking दिखाता है।
