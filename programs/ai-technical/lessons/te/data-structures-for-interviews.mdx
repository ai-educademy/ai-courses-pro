# ఇంటర్వ్యూల కోసం డేటా నిర్మాణాలు

అగ్ర ఇంటర్వ్యూ కోచ్‌లు తెలుసుకోవడానికి మీకు $500 వసూలు చేయరనే రహస్యం ఇక్కడ ఉంది: దాదాపు 90% కోడింగ్ ఇంటర్వ్యూ సమస్యలు కేవలం ఏడు డేటా స్ట్రక్చర్‌ల చుట్టూ తిరుగుతాయి. ప్రతి ఒక్కటి ఎప్పుడు మరియు ఎందుకు చేరుకోవాలో మీరు లోతుగా అర్థం చేసుకుంటే, మీరు ఇప్పటికే సగం యుద్ధంలో గెలిచారు. మిగిలిన సగం అభ్యాసం - కానీ సరైన మానసిక నమూనాలు లేకుండా, అభ్యాసం కేవలం కంఠస్థం. ఈ పాఠం మీకు మ్యాప్‌ని అందిస్తుంది కాబట్టి మీరు ఎదుర్కొనే ప్రతి సమస్య తెలిసిన ప్రాంతంగా అనిపిస్తుంది.

## శ్రేణులు మరియు తీగలు — మీ పునాది

దాదాపు ప్రతి ఇంటర్వ్యూ సమస్యకు శ్రేణులు ప్రారంభ స్థానం. ప్రధాన అంతర్దృష్టి ఏమిటంటే, చాలా శ్రేణి సమస్యలు నిజంగా శ్రేణుల గురించి కాదు - అవి రెండు పాయింటర్‌లు, స్లైడింగ్ విండో లేదా ప్రిఫిక్స్ మొత్తాల వంటి నమూనాలను గుర్తించడం.

```python
# Two Sum — the most classic interview problem
# "Given an array and target, find two numbers that add to target"
def two_sum(nums, target):
    seen = {}  # Hash map to store complement
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []

# Time: O(n), Space: O(n) — trading space for time
```

ఈ "అరే" సమస్య కూడా నిజంగా హాష్ మ్యాప్ సమస్యగా ఎలా ఉందో గమనించండి. ఆ నమూనా నిరంతరం పునరావృతమవుతుంది: బ్రూట్ ఫోర్స్ శ్రేణిపై సమూహ లూప్‌లను ఉపయోగిస్తుంది మరియు సరైన పరిష్కారం హాష్ మ్యాప్‌ను పరిచయం చేస్తుంది.

## హాష్ మ్యాప్స్ — ఇంటర్వ్యూ స్విస్ ఆర్మీ నైఫ్

మీరు ఏదైనా సమస్యలో చిక్కుకుపోయి, బ్రూట్ ఫోర్స్ O(n²) అయితే, మిమ్మల్ని మీరు ఇలా ప్రశ్నించుకోండి: "హాష్ మ్యాప్ దీన్ని O(n)కి తగ్గించగలదా?" సమాధానం ఆశ్చర్యకరంగా తరచుగా అవును.

మీకు అవసరమైనప్పుడు హాష్ మ్యాప్‌లు మెరుస్తాయి:
- **కౌంట్ ఫ్రీక్వెన్సీలు** — అక్షర గణనలు, పద గణనలు, మూలకం పౌనఃపున్యాలు
- **చూసిన ఎలిమెంట్‌లను ట్రాక్ చేయండి** — నకిలీ గుర్తింపు, రెండు-మొత్తం శైలి సమస్యలు
- **గ్రూప్ అంశాలు** — అనగ్రామ్ గ్రూపింగ్, వర్గీకరణ
- **కాష్ గణనలు** — డైనమిక్ ప్రోగ్రామింగ్‌లో మెమోయిజేషన్

```java
// Group Anagrams — a classic hash map problem
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);
        String key = new String(chars);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

## లింక్డ్ లిస్ట్‌లు — పాయింటర్ మాస్టరీ

లింక్డ్ జాబితా సమస్యలు నోడ్‌ల ట్రాక్‌ను కోల్పోకుండా పాయింటర్‌లను మార్చగల మీ సామర్థ్యాన్ని పరీక్షిస్తాయి. మీకు అవసరమైన మూడు సాంకేతికతలు:

1. **టూ-పాయింటర్ (ఫాస్ట్/స్లో)** — సైకిల్ డిటెక్షన్, మిడిల్ నోడ్‌ను కనుగొనడం
2. **డమ్మీ హెడ్ నోడ్** - తల మారినప్పుడు అంచు కేసులను సులభతరం చేస్తుంది
3. **రివర్సల్** — పునరావృత రివర్సల్ అనేది అనేక సమస్యలకు బిల్డింగ్ బ్లాక్

```python
# Detect a cycle in a linked list (Floyd's Algorithm)
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

## స్టాక్‌లు మరియు క్యూలు — ఆర్డర్ విషయాలు

స్టాక్‌లు (LIFO) మరియు క్యూలు (FIFO) సరళమైన నిర్మాణాలు, కానీ అవి మొత్తం సమస్యల వర్గాలను అన్‌లాక్ చేస్తాయి:

- ** స్టాక్‌లు**: చెల్లుబాటు అయ్యే కుండలీకరణాలు, వ్యక్తీకరణ మూల్యాంకనం, మోనోటోనిక్ స్టాక్ సమస్యలు, అన్‌డు/పునరావృతం
- **క్యూలు**: BFS ట్రావెర్సల్, స్లైడింగ్ విండో గరిష్టం (డీక్యూతో), టాస్క్ షెడ్యూలింగ్

```python
# Valid Parentheses — classic stack problem
def is_valid(s: str) -> bool:
    stack = []
    matching = {')': '(', '}': '{', ']': '['}
    for char in s:
        if char in matching:
            if not stack or stack[-1] != matching[char]:
                return False
            stack.pop()
        else:
            stack.append(char)
    return len(stack) == 0
```

## చెట్లు — క్రమానుగత ఆలోచన

చెట్ల సమస్యలు సాధారణంగా పునరావృతం మరియు మూడు ట్రావెర్సల్ ఆర్డర్‌లలో ఒకటి (ఇన్-ఆర్డర్, ప్రీ-ఆర్డర్, పోస్ట్-ఆర్డర్) కలిగి ఉంటాయి. అభివృద్ధి చేయవలసిన మానసిక నమూనా: "ఎడమ సబ్‌ట్రీ, కుడి సబ్‌ట్రీ నుండి నాకు ఏమి కావాలి మరియు ప్రస్తుత నోడ్‌లో వాటిని ఎలా కలపాలి?"

```python
# Maximum depth of a binary tree — the template for tree recursion
def max_depth(root):
    if not root:
        return 0
    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)
    return 1 + max(left_depth, right_depth)
```

BST (బైనరీ సెర్చ్ ట్రీ) సమస్యలు ఒక కీలకమైన ప్రాపర్టీని జోడిస్తాయి: ఇన్-ఆర్డర్ ట్రావెర్సల్ క్రమబద్ధీకరించబడిన మూలకాలను అందిస్తుంది. మీకు ఒకే సమస్యలో "క్రమబద్ధీకరించబడినది" మరియు "చెట్టు" కనిపిస్తే, వెంటనే BSTని ఆలోచించండి.

## గ్రాఫ్‌లు — మోడలింగ్ సంబంధాలు

గ్రాఫ్ సమస్యలు బెదిరింపుగా అనిపిస్తాయి కానీ మీరు ప్రక్కనే ఉన్న జాబితాను రూపొందించిన తర్వాత చాలా వరకు BFS లేదా DFSకి తగ్గుతాయి. ప్రధాన నైపుణ్యాలు:

- **గ్రాఫ్‌ను రూపొందించడం** అంచు జాబితాలు లేదా మాత్రికల నుండి
- వెయిట్ చేయని గ్రాఫ్‌లలో చిన్నదైన మార్గం కోసం **BFS**
- **DFS** కనెక్టివిటీ, సైకిల్ డిటెక్షన్, టోపోలాజికల్ సార్ట్ కోసం

```python
# BFS shortest path in an unweighted graph
from collections import deque

def shortest_path(graph, start, end):
    queue = deque([(start, 0)])
    visited = {start}
    while queue:
        node, distance = queue.popleft()
        if node == end:
            return distance
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append((neighbour, distance + 1))
    return -1  # Not reachable
```

## హీప్స్ — "టాప్ K" సిగ్నల్

"K అతిపెద్దది కనుగొనండి", "K దగ్గరగా" లేదా "K క్రమబద్ధీకరించబడిన జాబితాలను విలీనం చేయండి" అని ఏదైనా సమస్య చెప్పినప్పుడు, ఒక కుప్ప (ప్రాధాన్యత క్యూ) దాదాపుగా సమాధానం అవుతుంది. పైథాన్‌లో, `heapq` నిమి-హీప్ని అందిస్తుంది; గరిష్ట-కుప్ప కోసం, విలువలను తిరస్కరించండి.

```python
import heapq

# Find the K largest elements in an array
def k_largest(nums, k):
    return heapq.nlargest(k, nums)  # Uses a min-heap of size k internally
```

## నమూనా గుర్తింపు — సరైన నిర్మాణాన్ని ఎంచుకోవడం

సమస్యను చదివేటప్పుడు ఈ మానసిక తనిఖీ జాబితాను అభివృద్ధి చేయండి:

- **వేగవంతమైన శోధన కావాలా?** → హాష్ మ్యాప్
- **క్రమబద్ధీకరించబడిన క్రమం కావాలా?** → BST లేదా క్రమబద్ధీకరించబడిన శ్రేణి + బైనరీ శోధన
- **FIFO ప్రాసెసింగ్ కావాలా?** → క్యూ (BFS)
- **LIFO / బ్యాక్‌ట్రాకింగ్ కావాలా?** → స్టాక్ (DFS)
- **టాప్-కె లేదా ప్రాధాన్యత కావాలా?** → హీప్
- **కనెక్షన్‌లను మోడల్ చేయాలా?** → గ్రాఫ్
- ** ఇండెక్స్ ద్వారా O(1) యాక్సెస్ కావాలా?** → అర్రే

## కీలక టేకావేలు

- **ఏడు నిర్మాణాలు 90% ఇంటర్వ్యూలను కవర్ చేస్తాయి**: శ్రేణులు, హాష్ మ్యాప్‌లు, లింక్ చేసిన జాబితాలు, స్టాక్‌లు/క్యూలు, చెట్లు, గ్రాఫ్‌లు మరియు కుప్పలు.
- **హాష్ మ్యాప్‌లు మీ బెస్ట్ ఫ్రెండ్**: అనుమానం వచ్చినప్పుడు, హాష్ మ్యాప్ సహాయపడవచ్చు.
- **మీ సంక్లిష్టతలను తెలుసుకోండి**: ఇంటర్వ్యూ చేసేవారు "సమయ సంక్లిష్టత ఏమిటి?" ప్రతి పరిష్కారం తర్వాత.
- **నమూనా గుర్తింపు మెమోరిజేషన్‌ను కొట్టేస్తుంది**: సమస్య సంకేతాలను ("టాప్ K" → హీప్, "చిన్న మార్గం" → BFS) సరైన ఆకృతికి మ్యాప్ చేయడం నేర్చుకోండి.
- **ఉద్దేశపూర్వకంగా ప్రాక్టీస్ చేయండి**: ప్రతి డేటా స్ట్రక్చర్‌కు 3-5 సమస్యలను పరిష్కరించండి, వేగం కంటే అర్థం చేసుకోవడంపై దృష్టి పెట్టండి. అర్థం చేసుకోవడం వల్ల వేగం వస్తుంది.
