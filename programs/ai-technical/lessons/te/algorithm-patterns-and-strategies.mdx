# అల్గోరిథం నమూనాలు మరియు వ్యూహాలు

కోడింగ్ ఇంటర్వ్యూలు 500 లీట్‌కోడ్ సొల్యూషన్‌లను గుర్తుంచుకోవడం గురించి కాదు. వారు మీ ముందున్న సమస్యకు దాదాపు పది నమూనాల్లో ఏది వర్తిస్తుందో గుర్తించడం. మీరు నమూనాను గుర్తించిన తర్వాత, పరిష్కార నిర్మాణం స్వయంగా వ్రాయబడుతుంది. ఈ పాఠం ప్రతి నమూనాను విచ్ఛిన్నం చేస్తుంది - దానిని ఎప్పుడు ఉపయోగించాలి, ఎలా గుర్తించాలి మరియు మీ అవగాహనను ఎంకరేజ్ చేయడానికి ఒక నిర్దిష్ట ఉదాహరణ. ఈ నమూనాలను లెన్స్‌లుగా భావించండి: మీరు వాటిని చూడటం ఎంత ఎక్కువగా ప్రాక్టీస్ చేస్తే, ప్రతి కొత్త సమస్య వేగంగా దృష్టిలోకి వస్తుంది.

## నమూనా 1: రెండు పాయింటర్లు

**దానిని ఎప్పుడు గుర్తించండి**: ఇన్‌పుట్ క్రమబద్ధీకరించబడింది (లేదా క్రమబద్ధీకరించబడుతుంది), మరియు మీరు కొన్ని షరతులకు అనుగుణంగా జతలను లేదా సబ్‌రేలను కనుగొనవలసి ఉంటుంది.

రెండు పాయింటర్‌లు శ్రేణి యొక్క ప్రతి చివర ఒక పాయింటర్‌ను ఉంచడం ద్వారా (లేదా "ఫాస్ట్/స్లో" వేరియంట్ కోసం ప్రారంభంలో) మరియు వాటిని ఒక షరతు ఆధారంగా ఒకదానికొకటి తరలించడం ద్వారా పని చేస్తాయి.

```python
# Three Sum: find all triplets that sum to zero
def three_sum(nums):
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue  # Skip duplicates
        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                left += 1
                right -= 1
    return result
```

**సమయం**: O(n²) — O(n³) బ్రూట్ ఫోర్స్ కంటే భారీ మెరుగుదల.

## నమూనా 2: స్లైడింగ్ విండో

** దీన్ని ఎప్పుడు గుర్తించండి**: మీరు కొంత పరిమితిని (గరిష్ట మొత్తం, అన్ని అక్షరాలను కలిగి ఉంటుంది, మొదలైనవి) సంతృప్తిపరిచే ప్రక్కనే ఉన్న సబ్‌రే లేదా సబ్‌స్ట్రింగ్‌ను కనుగొనాలి.

విండో కుడి పాయింటర్‌ను తరలించడం ద్వారా విస్తరిస్తుంది మరియు ఎడమ పాయింటర్‌ను తరలించడం ద్వారా కుదించబడుతుంది. ఎప్పుడు కుదించాలో తెలుసుకోవడం కీలకం.

```python
# Longest substring without repeating characters
def length_of_longest_substring(s: str) -> int:
    char_index = {}
    max_length = 0
    left = 0
    for right, char in enumerate(s):
        if char in char_index and char_index[char] >= left:
            left = char_index[char] + 1
        char_index[char] = right
        max_length = max(max_length, right - left + 1)
    return max_length
```

<Callout>స్లైడింగ్ విండో నమూనా స్థిరమైన టెంప్లేట్‌ను కలిగి ఉంది: రెండు పాయింటర్‌లను ప్రారంభించండి, కుడివైపు విస్తరించండి, అడ్డంకిని ఉల్లంఘించినప్పుడు ఎడమవైపుకు కుదించండి మరియు మీ సమాధానాన్ని ట్రాక్ చేయండి. మీరు ఈ టెంప్లేట్‌ని అంతర్గతీకరించిన తర్వాత, ప్రతి స్లయిడింగ్ విండో సమస్యనుర్వహించదగినదిగా అనిపిస్తుంది.</Callout>

## నమూనా 3: *BFS* (వెడల్పు-మొదటి శోధన)

**దీనిని ఎప్పుడు గుర్తించండి**: వెయిట్ చేయని గ్రాఫ్, లెవెల్-ఆర్డర్ ట్రావర్సల్ లేదా పొరల వారీగా పొరుగువారిని అన్వేషించడానికి మీకు చిన్నదైన మార్గం అవసరం.

*BFS* క్యూను ఉపయోగిస్తుంది మరియు లెవెల్ వారీగా నోడ్‌లను ప్రాసెస్ చేస్తుంది. ఇది వెయిట్ చేయని గ్రాఫ్‌లలో చిన్నదైన మార్గానికి హామీ ఇస్తుంది.

```python
from collections import deque

# Number of islands — BFS variant
def num_islands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                queue = deque([(r, c)])
                grid[r][c] = '0'
                while queue:
                    row, col = queue.popleft()
                    for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                        nr, nc = row + dr, col + dc
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == '1':
                            grid[nr][nc] = '0'
                            queue.append((nr, nc))
    return count
```

## నమూనా 4: *DFS* (డెప్త్-ఫస్ట్ సెర్చ్)

** ఎప్పుడు గుర్తించండి**: మీరు అన్ని మార్గాలను అన్వేషించాలి, కనెక్టివిటీని తనిఖీ చేయాలి, చక్రాలను గుర్తించాలి లేదా సమస్య పునరావృత/చెట్టు నిర్మాణాన్ని కలిగి ఉండాలి.

*DFS* వెడల్పు కంటే లోతుగా ఉంటుంది. ఇది సహజంగా పునరావృతమవుతుంది మరియు ట్రీ ట్రావర్సల్స్ మరియు బ్యాక్‌ట్రాకింగ్‌కు అందంగా మ్యాప్ చేస్తుంది.

```python
# Path sum in a binary tree
def has_path_sum(root, target_sum):
    if not root:
        return False
    if not root.left and not root.right:
        return target_sum == root.val
    return (has_path_sum(root.left, target_sum - root.val) or
            has_path_sum(root.right, target_sum - root.val))
```

<ThinkAboutIt>మీరు *DFS* కంటే *BFS*ని ఎప్పుడు ఎంచుకుంటారు మరియు వైస్ వెర్సా? పరిగణించండి: *BFS* అతి తక్కువ మార్గాలను కనుగొంటుంది కానీ O(వెడల్పు) మెమరీని ఉపయోగిస్తుంది. *DFS* O(డెప్త్) మెమరీని ఉపయోగిస్తుంది కానీ తక్కువ మార్గాలకు హామీ ఇవ్వదు. గ్రాఫ్ ఆకారం మీ ఎంపికను ఎలా ప్రభావితం చేస్తుంది?</ThinkAboutIt>

## నమూనా 5: బైనరీ శోధన

** ఎప్పుడు గుర్తించండి**: శోధన స్థలం క్రమబద్ధీకరించబడింది లేదా మోనోటోనిక్ (ఇండెక్స్ i వద్ద షరతు నిజమైతే, ఇది అన్ని సూచికలు > i లేదా < i).

బైనరీ శోధన అనేది క్రమబద్ధీకరించబడిన శ్రేణుల కోసం మాత్రమే కాదు - ఇది ఏదైనా మోనోటోనిక్ స్థితిలో పని చేస్తుంది. ఈ అంతర్దృష్టి "ప్యాకేజీలను రవాణా చేయడానికి కనీస సామర్థ్యం" లేదా "పీక్ ఎలిమెంట్‌ను కనుగొనడం" వంటి సమస్యలను అన్‌లాక్ చేస్తుంది.

```python
# Binary search on answer: minimum days to make m bouquets
def min_days(bloom_day, m, k):
    if m * k > len(bloom_day):
        return -1

    def can_make(days):
        bouquets = flowers = 0
        for bloom in bloom_day:
            if bloom <= days:
                flowers += 1
                if flowers == k:
                    bouquets += 1
                    flowers = 0
            else:
                flowers = 0
        return bouquets >= m

    lo, hi = min(bloom_day), max(bloom_day)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_make(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

<FunFact>బైనరీ శోధన సంభావితంగా సరళమైన అల్గారిథమ్‌లలో ఒకటి అయినప్పటికీ, జోన్ బెంట్లీ చేసిన అధ్యయనంలో కేవలం 10% మంది ప్రొఫెషనల్ ప్రోగ్రామర్లు మాత్రమే మొదటి ప్రయత్నంలోనే దీన్ని సరిగ్గా అమలు చేయగలరని కనుగొన్నారు. అత్యంత సాధారణ బగ్? సరిహద్దు పరిస్థితులలో ఆఫ్-బై-వన్ లోపాలు.</FunFact>

## నమూనా 6: బ్యాక్‌ట్రాకింగ్

**ఎప్పుడు గుర్తించండి**: మీరు పరిమితులను సంతృప్తిపరిచే అన్ని కలయికలు, ప్రస్తారణలు లేదా ఉపసమితులను రూపొందించాలి. సమస్య తరచుగా "అన్నింటినీ కనుగొనండి", "అన్నింటినీ రూపొందించండి" లేదా "సాధ్యమైన ప్రతిదాన్ని జాబితా చేయండి" అని చెబుతుంది.

*Backtracking* = కత్తిరింపుతో *DFS*. మీరు మార్గాన్ని అన్వేషించండి మరియు అది పరిమితిని ఉల్లంఘిస్తే, మీరు వెనుకకు వెళ్లి తదుపరి ఎంపికను ప్రయత్నించండి.

```python
# Generate all valid combinations of n pairs of parentheses
def generate_parenthesis(n):
    result = []
    def backtrack(current, open_count, close_count):
        if len(current) == 2 * n:
            result.append(current)
            return
        if open_count < n:
            backtrack(current + '(', open_count + 1, close_count)
        if close_count < open_count:
            backtrack(current + ')', open_count, close_count + 1)
    backtrack('', 0, 0)
    return result
```

## నమూనా 7: డైనమిక్ ప్రోగ్రామింగ్

**ఎప్పుడు గుర్తించండి**: సమస్య అతివ్యాప్తి చెందుతున్న ఉపసమస్యలు మరియు సరైన సబ్‌స్ట్రక్చర్‌ను కలిగి ఉంది. క్లాసిక్ సిగ్నల్‌లలో "కనీస ధర", "మార్గాల సంఖ్య", "పొడవైన/చిన్న వరుస క్రమం" లేదా "మీరు లక్ష్యాన్ని చేరుకోగలరా?"

DP వంటకం: స్థితిని నిర్వచించండి, పునరావృతాన్ని వ్రాయండి, టాప్-డౌన్ (మెమోయిజేషన్) మరియు బాటమ్-అప్ (టాబులేషన్) మధ్య నిర్ణయించండి.

```python
# Longest Increasing Subsequence — O(n²) DP
def length_of_lis(nums):
    if not nums:
        return 0
    dp = [1] * len(nums)  # dp[i] = length of LIS ending at index i
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

<Callout>మీరు DP సమస్యలో చిక్కుకున్నప్పుడు, ముందుగా బ్రూట్-ఫోర్స్ రికర్షన్‌తో ప్రారంభించండి. అప్పుడు మెమోయిజేషన్ జోడించండి. బాటమ్-అప్ ట్యాబులేషన్‌కి మార్చడం అనేది ఆప్టిమైజేషన్ దశ, మొదటి దశ కాదు. ఈ విధానం పట్టిక కొలతలు కోల్పోకుండా నిరోధిస్తుంది.</Callout>

## సరళి 8: అత్యాశ

** ఎప్పుడు గుర్తించండి**: ప్రతి దశలోనూ స్థానికంగా సరైన ఎంపిక చేసుకోవడం ప్రపంచవ్యాప్తంగా సరైన పరిష్కారానికి దారి తీస్తుంది. అత్యాశతో కూడిన సమస్యలలో తరచుగా విరామాలు, షెడ్యూల్ చేయడం లేదా మళ్లీ సందర్శించాల్సిన అవసరం లేని ఎంపికలు ఉంటాయి.

```python
# Minimum number of meeting rooms (interval scheduling)
def min_meeting_rooms(intervals):
    starts = sorted([i[0] for i in intervals])
    ends = sorted([i[1] for i in intervals])
    rooms = max_rooms = 0
    s = e = 0
    while s < len(starts):
        if starts[s] < ends[e]:
            rooms += 1
            max_rooms = max(max_rooms, rooms)
            s += 1
        else:
            rooms -= 1
            e += 1
    return max_rooms
```

## నమూనా 9: టోపోలాజికల్ క్రమబద్ధీకరణ

** ఎప్పుడు గుర్తించండి**: టాస్క్‌ల మధ్య డిపెండెన్సీలు ఉన్నాయి (కోర్సు ముందస్తు అవసరాలు, బిల్డ్ ఆర్డర్, టాస్క్ షెడ్యూలింగ్). ఇన్‌పుట్ డైరెక్ట్ ఎసిక్లిక్ గ్రాఫ్ (*DAG*).

```python
from collections import deque, defaultdict

def course_order(num_courses, prerequisites):
    graph = defaultdict(list)
    in_degree = [0] * num_courses
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            in_degree[neighbour] -= 1
            if in_degree[neighbour] == 0:
                queue.append(neighbour)
    return order if len(order) == num_courses else []
```

## సరళి 10: యూనియన్-ఫైండ్ (విభజన సెట్)

**దీనిని ఎప్పుడు గుర్తించండి**: మీరు ఎలిమెంట్‌లను సమూహపరచాలి, కనెక్ట్ చేయబడిన భాగాలను గుర్తించాలి లేదా రెండు మూలకాలు ఒకే సెట్‌కు చెందినవా అని నిర్ధారించాలి — ప్రత్యేకించి కనెక్షన్‌లు డైనమిక్‌గా జోడించబడినప్పుడు.

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # Path compression
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True
```

## సరైన నమూనాను ఎలా గుర్తించాలి

మీ తలపై నిర్ణయం చెట్టును నిర్మించండి:

1. **ఇన్‌పుట్ క్రమబద్ధీకరించబడిందా లేదా క్రమబద్ధీకరించబడుతుందా?** → రెండు పాయింటర్లు లేదా బైనరీ శోధన
2. **మీకు ప్రక్కనే ఉన్న సబ్‌అరే/సబ్‌స్ట్రింగ్ కావాలా?** → స్లైడింగ్ విండో
3. **ఇది గ్రాఫ్/ట్రీ ట్రావెర్సాలా?** → *BFS* (చిన్న మార్గం) లేదా *DFS* (అన్ని మార్గాలు)
4. **"అన్ని కలయికలు/ప్రస్తారణలను కనుగొనండి"?** → బ్యాక్‌ట్రాకింగ్
5. **"కనీస ధర / మార్గాల సంఖ్య"?** → డైనమిక్ ప్రోగ్రామింగ్
6. **"షెడ్యూల్ / ఇంటర్వెల్" సమస్య?** → అత్యాశ లేదా క్రమబద్ధీకరణ
7. **డిపెండెన్సీలు లేదా ఆర్డర్ చేయడం?** → టోపోలాజికల్ క్రమబద్ధీకరణ
8. **గ్రూపింగ్ / కనెక్టివిటీ?** → యూనియన్-ఫైండ్
