# 计算机视觉 - 人工智能如何学会看世界

你看一眼照片，立刻就知道照片上有一只狗在海滩上。对于计算机来说，同一张图像只不过是一个巨大的数字网格。 **计算机视觉**是人工智能的一个分支，它教会机器从这些数字中提取含义 - 它已经在重塑您周围的行业。

## 计算机如何“看”

当你看照片时，你的大脑会立即识别形状、颜色和深度。一台电脑
没有那种直觉。相反，它使用原始数字。

数字图像是**像素**的网格。每个像素存储颜色值 - 通常为三个
**通道**：红、绿、蓝 (RGB)。 1920×1080高清图像包含超过200万像素，
每个都有 0 到 255 之间的三个值。将它们相乘，甚至是一个帧
包含数百万个数字。

<Illustration src="/images/lessons/computer-vision.svg" alt="显示分解为具有 RGB 通道的像素网格的图像的图表" caption="每个图像只是一个跨越红色、绿色和蓝色通道的数字网格。" />

**分辨率**决定网格捕获多少细节。更高的分辨率意味着更多的像素
以及更丰富的细节 - 而且还有更多的数据可供人工智能处理。 4K 图像的四倍
高清像素，这意味着四倍的计算成本。

灰度图像只有一个通道（亮度），而一些特殊格式 - 例如
卫星图像或医学扫描 - 可能有数十个通道捕获不可见的波长
对人眼来说。

<FunFact>人眼可以辨别大约 1000 万种颜色。标准 8 位 RGB 图像可以代表超过 1670 万种独特的颜色组合 - 比我们实际感知的还要多！
</FunFact>

## 卷积神经网络 (CNN)

计算机视觉的早期尝试依赖于手工制定的规则 - “在这里寻找边缘，匹配这个
那里有模板。”当场景发生变化时，这些脆弱的方法就会失败。现代系统使用
**卷积神经网络 (CNN)**，它从数千个标记中学习自己的规则
例子。

将 CNN 视为模式检测器的装配线，每一层都建立在前一层之上：

1. **卷积层** 在图像上滑动小过滤器，检测简单的模式，例如
  边缘、角落和纹理。
2. **池化层**缩小数据，仅保留最重要的信号并丢弃
  多余的细节。
3. **更深的卷积层**将这些简单的模式组合成更复杂的特征 - 眼睛，
  轮子，字母。
4. **完全连接的层**将所有特征放在一起做出最终决定 - “这是一个
  猫”或“这是肿瘤。”

美妙之处在于没有人手动编程这些过滤器。网络在训练过程中**学习**它们，从随机噪声开始，逐渐锐化为有用的检测器。

<ThinkAboutIt>当你学习识别朋友的面孔时，你不会记住每个像素 - 你会记住眼睛形状、发型和表情等关键特征。 CNN 做的事情非常相似。您认为 CNN 会首先学习哪些特征？
</ThinkAboutIt>

## 分类、检测和分割

计算机视觉解决三个逐渐困难的任务：

|任务|提问即回答 |示例|
|------|--------------------|---------|
| **图像分类** |这张图片里有什么？ | “这张X光片显示肺炎。” |
| **物体检测** |这张图片中有什么以及在哪里？ |在街景中的每个行人周围画出方框。 |
| **语义分割** |哪些像素属于哪个对象？ |对道路、人行道、汽车和天空的每个像素进行不同的着色。 |

自动驾驶汽车同时需要这三者 - 对物体进行分类、精确定位，以及
逐个像素地了解整个场景。

每项任务都需要逐渐增加的计算能力和训练数据。分类为
到2015年基本解决；视频实时分割仍然是当今的一个活跃的研究领域。

## 实际应用

计算机视觉已经嵌入到您可能意想不到的行业中：

- **特斯拉自动驾驶仪**使用八个摄像头和基于视觉的人工智能来检测车道、交通灯和
  实时障碍物 - 每次旅程处理数百万帧。
- **医学成像** - 在发现早期乳房方面，人工智能模型现在可以与放射科医生相媲美或超过放射科医生
  乳房X光检查中的癌症有时可以发现六位人类专家错过的情况。
- **质量控制** - 工厂使用视觉系统每分钟检查数千种产品，
  对于人类检查员来说，发现缺陷太微妙或太快。
- **农业** - 具有计算机视觉的无人机可以识别大片田地里的患病作物，
  实现有针对性的治疗，可减少高达 90% 的农药使用量。
- **零售** - Amazon Go 商店使用计算机视觉来跟踪购物者挑选的产品，
  实现免结账购物。

<FunFact>谷歌的 DeepMind 开发了一种人工智能，可以通过视网膜扫描检测出 50 多种眼部疾病，与世界领先的眼科医生一样准确 - 只需几秒钟而不是几周。
</FunFact>

## 道德问题

计算机视觉很强大，但它提出了社会仍在努力解决的严重问题：

- **监控** - 面部识别可以对公民进行大规模跟踪。几个城市，
  包括旧金山和欧盟部分地区，已禁止或限制警察使用它。
- **偏见** - 麻省理工学院 Joy Buolamwini 的里程碑式研究表明，商业面部识别
  系统对于肤色较深的面孔和女性的准确度明显较低，因为训练
  从历史上看，数据过多地代表了浅肤色男性。
- **同意** - 如果您的脸部在您不知情的情况下在商店、机场或公共场所被扫描
  空格？许多国家仍在起草立法来解决这个问题。
- **Deepfakes** - 人工智能生成的虚假图像和视频可以传播错误信息和损害
  声誉，使视觉证据变得不那么可信。

## 要点

- 图像是跨颜色通道的像素值网格 - 计算机看到的是数字，而不是图片。
- CNN 通过训练学习自动提取特征，从边缘开始并构建
  直至复杂的物体。
- 分类、检测和分割代表了视觉理解水平的提高。
- 计算机视觉推动从医疗保健诊断到自动驾驶汽车的突破
  精准农业。
- 培训数据和监控方面的偏见需要谨慎、合乎道德的部署 - 技术
  如果没有负责任的治理，单靠自己是远远不够的。
