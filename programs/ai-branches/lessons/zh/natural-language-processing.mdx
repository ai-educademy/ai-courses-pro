# 自然语言处理 - 人工智能如何理解人类语言

您可能问过语音助手一个问题，使用过 Google 翻译，或者观看过实时出现的 YouTube 自动字幕。每一种体验的背后都是**自然语言处理 (NLP)** - 人工智能的一个分支，帮助机器处理人类语言。

## 为什么语言对于机器来说很难

语言对我们来说似乎毫不费力，但对计算机来说却极其混乱：

- **歧义** - “我看到她的鸭子” - 她蹲下，还是你看到她的宠物鸟？
- **上下文** - “这太恶心了！”可以表示某事令人厌恶或某事很棒，
  完全取决于谁在讲话以及何时讲话。
- **讽刺** - “哦，太棒了，又是一个星期一”与其字面意思相反，但是
  没有明确的标记来表明这一点。
- **结构** - 相同的单词重新排列可以完全改变含义：“狗咬人”与
  “人咬狗。”
- **不断发展的俚语** - 新词和新义不断出现，形成静态词典
  不足。

机器不能像人类那样依赖直觉或生活经验。 NLP系统必须学习
来自大量文本（通常是数十亿个句子）的模式。

## 核心 NLP 任务

|任务|它有什么作用 |示例|
|------|-------------|---------|
| **代币化** |将文本拆分为单词或子单词 | “我正在学习”→ [“我”，“我”，“学习”] |
| **情绪分析** |检测情绪或意见 | “这部电影太精彩了！” → 积极 |
| **命名实体识别** |查找姓名、地点、日期 | “居里夫人在巴黎工作” → 人物、地点 |
| **机器翻译** |语言之间的转换 |英语 → 法语 |
| **总结** |压缩长文本 | 10页报告→一小段|

## 将文字转化为数字

机器使用的是数字，而不是文字。那么如何体现语言的丰富性
数学上？突破性的见解是将单词表示为**向量** - 数字列表
捕捉意义和关系。

**Word2Vec** (2013) 表明，在相似上下文中使用的单词会获得相似的向量。众所周知，数学计算得出：

> *国王* − *男人* + *女人* ≈ *女王*

这证明词嵌入捕获了真正的语义关系。

**BERT**（2018）进一步将嵌入设置为**上下文** - “银行”的向量根据句子是关于河流还是金融而变化。

<FunFact>BERT 接受了整个英语维基百科和 BookCorpus 的训练 - 大约 33 亿个单词。然而，该模型本身“仅”有 3.4 亿个参数，这意味着它将庞大的人类知识库压缩成远小于原始文本的模式。
</FunFact>

## ChatGPT 的工作原理（简短版本）

ChatGPT 基于 **transformer** 架构构建 - 与 Google 背后的模型系列相同
Translate、GitHub Copilot 和许多其他 AI 工具。这是简化的管道：

1. **将您的消息标记为子词片段。
2. 使用**注意机制**来找出哪些单词与哪些单词相关 - 即使跨度很长
  带有数千个标记的段落。
3. 根据之前出现的所有内容预测下一个单词，一次一个标记。
4. 使用 **人类反馈强化学习 (RLHF)** 对该模型进行了微调 - 真实
  人们对输出进行评分，以教导模型的有用性、准确性和安全性。

“注意力”的想法是神奇的成分。它让模型专注于最相关的部分
输入的内容，无论它们在文本中出现的距离有多远。在变压器、模型之前
很难处理长文档，因为早期的单词已经从记忆中消失了。

<ThinkAboutIt>当 ChatGPT 写入段落时，它一次生成一个单词，始终预测最有可能的下一个单词。这是否意味着它真正“理解”了它所说的内容，或者它正在执行一种极其复杂的模式匹配形式？你会在哪里划清界限？
</ThinkAboutIt>

## 实际应用

- **垃圾邮件过滤器** - Gmail 使用 NLP 每分钟阻止超过 1000 万封垃圾邮件。
- **聊天机器人** - 客户服务机器人处理日常查询，使人工代理能够解决复杂的问题。
- **搜索引擎** - Google 的搜索现在可以理解完整的问题，而不仅仅是关键字匹配。
- **法律技术** - 人工智能可以在数小时内审查数千份法律文件，而这项任务曾经需要律师花费数周的时间。
- **辅助功能** - 实时字幕可帮助聋哑和听力障碍用户关注现场活动。

<FunFact>Google 翻译每天处理 133 种语言的超过 1000 亿个单词。在神经自然语言处理出现之前，它依赖于短语表并产生出了名的尴尬翻译。基于 Transformer 的现代翻译非常流畅。
</FunFact>

## 限制和挑战

尽管取得了显着的进展，但 NLP 问题还远未得到解决：

- **幻觉** - 语言模型可以生成听起来自信且真实的文本
  错了。他们没有内置的方法来验证真相。
- **偏见** - 在互联网文本上训练的模型吸收了该数据中存在的社会偏见，
  有时会产生性别歧视、种族主义或其他有害的结果。
- **低资源语言** - NLP 最适合英语；世界上 7,000 多种语言中的许多语言
  用于训练的数字文本非常少。
- **隐私** - 处理个人消息、电子邮件和文档需要严格的数据保护
  GDPR 等法规的担忧。
- **能源成本** - 训练大型语言模型需要大量的计算资源，
  提出环境可持续性问题。

<ThinkAboutIt>如果人工智能撰写的新闻文章包含事实错误，并且有成千上万的人阅读了它，谁该负责 - 人工智能公司、出版商还是没有进行事实核查的读者？
</ThinkAboutIt>

## 要点

- 人类语言充满歧义、上下文、俚语和细微差别 - 使其成为人工智能最难的语言之一
  挑战。
- 词嵌入将语言转换为捕获真实语义的数学向量
  词之间的关系。
- 变压器和注意力机制为当今最强大的语言模型提供动力，来自 ChatGPT
  到谷歌搜索。
- NLP 驱动日常工具，包括搜索引擎、垃圾邮件过滤器、聊天机器人和翻译
  服务。
- 幻觉、偏见、能源成本和数据隐私仍然是重大的悬而未决的问题
  研究人员和企业正在积极努力解决。
