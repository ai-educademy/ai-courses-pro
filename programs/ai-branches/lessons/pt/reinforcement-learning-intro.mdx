# Aprendizado por reforço: ensinando IA por meio de tentativa e erro

Como uma criança aprende a andar? Ninguém entrega a eles um conjunto de dados rotulado de exemplos de "passo bom/passo ruim". Ninguém escreve as equações físicas para o equilíbrio. Eles tentam, caem, tentam de forma diferente, melhoram gradualmente – guiados pelo feedback do mundo ao seu redor.

Essa intuição — **aprendizado por tentativa e erro, guiado por recompensas e penalidades** — é a base do **Aprendizado por Reforço (RL)**, a abordagem por trás de algumas das conquistas mais espetaculares da IA: vencer campeões mundiais no Go e no xadrez, treinar ChatGPT para ser útil e ensinar robôs a andar.

## 🎯 A Estrutura Básica: Agente, Meio Ambiente, Recompensa

Todo problema RL tem a mesma estrutura fundamental:

```
        ┌─────────────────────────────────────────┐
        │              ENVIRONMENT                 │
        │   (the world the agent operates in)      │
        └─────────────────┬───────────────────────┘
                          │
         State (s_t)      │      Reward (r_t)
         What the         │      How good was
         agent sees ◄─────┤      the last action?
                          │
        ┌─────────────────▼───────────────────────┐
        │                 AGENT                    │
        │   (the AI that takes actions)            │
        └─────────────────┬───────────────────────┘
                          │
                          │ Action (a_t)
                          ▼
              Agent acts on the environment,
              environment transitions to state s_{t+1}
```

- **Agente**: o sistema de IA que toma decisões
- **Ambiente**: tudo com o qual o agente interage (um jogo, uma simulação, o entorno físico de um robô)
- **Estado**: a observação atual do ambiente pelo agente
- **Ação**: o que o agente faz (mover para a esquerda, mover um braço do robô, escolher uma palavra)
- **Recompensa**: um sinal numérico indicando quão boa foi a ação (+1 por marcar um gol, -1 por perder uma vida, +10 por completar uma tarefa)
- **Política**: a estratégia do agente — um mapeamento dos estados para as ações

O objetivo do agente é aprender uma **política** que maximize a **recompensa** cumulativa total ao longo do tempo, e não apenas a recompensa imediata.

## 🔍 Exploração vs Exploração: O Dilema Central

Os agentes da RL enfrentam uma tensão perpétua:

**Exploração**: faça o que você já sabe que funciona bem – tome a ação que atualmente lhe parece melhor.

**Exploração**: experimente algo novo. Talvez haja uma estratégia melhor que você ainda não descobriu.

Um robô que apenas explora nunca descobrirá um caminho melhor. Um robô que apenas explora nunca chegará a lugar nenhum com segurança.

Uma estratégia simples, mas eficaz, é **ε-ganancioso**:

```python
import random

epsilon = 0.1  # 10% exploration rate

def choose_action(state, Q_table, epsilon):
    if random.random() < epsilon:
        # Explore: choose a random action
        return random.choice(available_actions)
    else:
        # Exploit: choose the action with highest expected reward
        return argmax(Q_table[state])
```

Com ε = 0,1, o agente explora aleatoriamente 10% do tempo e explora seu conhecimento aprendido 90% do tempo. Normalmente, ε começa alto (muita exploração no início) e decai durante o treinamento à medida que o agente se torna mais confiante.

<FunFact>O dilema exploração-exploração não é apenas um problema de IA – ele também aparece na tomada de decisões humanas. Você deveria ir ao seu restaurante favorito (explorar) ou tentar algum lugar novo (explorar)? A mesma estrutura matemática se aplica.</FunFact>

## 📊 Processos de decisão de Markov (MDPs)

A maioria dos problemas de RL são formalizados como **Processos de Decisão Markov (MDPs)**. A suposição principal é a **propriedade de Markov**: o estado atual contém todas as informações necessárias para escolher a melhor ação — o histórico passado não importa, apenas onde você está agora.

Um MDP é definido por:
- **S**: um conjunto de estados possíveis
- **A**: um conjunto de ações possíveis
- **P(s' | s, a)**: probabilidade de transição — dado o estado s e a ação a, probabilidade de terminar no estado s'
- **R(s, a)**: função de recompensa — recompensa imediata por tomar uma ação no estado s
- **γ (gama)**: fator de desconto — quanto valem as recompensas futuras em relação às recompensas imediatas

O **fator de desconto** é importante: recompensas em um futuro próximo valem mais do que recompensas distantes:

```python
# Cumulative discounted reward (Return)
# R = r_0 + γ·r_1 + γ²·r_2 + γ³·r_3 + ...
# With γ = 0.99: future rewards are nearly as valuable as immediate ones
# With γ = 0.5:  rewards 10 steps away are worth only 0.1% of immediate reward

gamma = 0.99
total_return = sum(gamma**t * reward for t, reward in enumerate(rewards))
```

## 🧮 Q-Learning: RL baseado em valor

**Q-learning** é um dos algoritmos RL fundamentais. Ele aprende uma **função Q**: Q(s, a) = a recompensa futura total esperada se você realizar uma ação a no estado s e depois agir de maneira otimizada para sempre.

```python
import numpy as np

# Initialise Q-table to zeros
n_states  = 16   # e.g., a 4×4 grid world
n_actions = 4    # up, down, left, right
Q = np.zeros((n_states, n_actions))

# Q-learning update rule (the Bellman equation)
def update_Q(Q, state, action, reward, next_state, alpha=0.1, gamma=0.99):
    """
    alpha: learning rate — how fast to update Q values
    gamma: discount factor — how much to value future rewards
    """
    # Current estimate
    current_Q = Q[state, action]
    
    # Target: immediate reward + discounted best future value
    target = reward + gamma * np.max(Q[next_state])
    
    # Move current estimate towards target
    Q[state, action] = current_Q + alpha * (target - current_Q)
    
    return Q
```

Ao longo de milhares de episódios, o Q-learning converge para a função Q ideal. Uma vez aprendida, a política é simplesmente: em cada estado, tome a ação com o maior valor Q.

**Deep Q-Networks (DQN)**, desenvolvidas pela DeepMind em 2013, substituíram a Q-table por uma rede neural profunda, permitindo que o Q-learning fosse dimensionado para entradas visuais complexas. DQN aprendeu a jogar 49 jogos Atari diretamente de pixels, alcançando desempenho de nível humano em muitos.

## 🚀 Métodos de gradiente de política

O Q-learning aprende indiretamente o valor das ações. Os métodos de **gradiente de política** otimizam diretamente a política — o mapeamento dos estados para as ações.

```python
# The core idea: if an action led to high reward, make it more likely
# If an action led to low reward, make it less likely

def policy_gradient_update(policy_network, states, actions, rewards):
    # Compute discounted returns for each timestep
    returns = compute_returns(rewards, gamma=0.99)
    
    # Normalise returns (reduces variance)
    returns = (returns - returns.mean()) / (returns.std() + 1e-8)
    
    # Policy loss: -log(π(a|s)) × G_t
    # Maximise log-probability of actions weighted by how good they were
    log_probs = policy_network.log_prob(states, actions)
    loss = -(log_probs * returns).mean()
    
    # Backpropagate and update
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

As variantes modernas do gradiente de política incluem:
- **PPO (Proximal Policy Optimization)**: o algoritmo mais utilizado atualmente, utilizado no treinamento RLHF do ChatGPT
- **A3C (Asynchronous Advantage Actor-Critic)**: paraleliza o treinamento em vários ambientes
- **SAC (Soft Actor-Critic)**: excelente para espaços de ação contínua (robótica)

## 💬 RLHF: como o ChatGPT foi ajustado

Uma das aplicações recentes mais impactantes de RL é **Aprendizagem por Reforço com Feedback Humano (RLHF)** — a técnica usada para tornar o ChatGPT e outros LLMs úteis, inofensivos e honestos.

O processo tem três etapas:

**Etapa 1: Pré-treinamento**
Treine um grande modelo de linguagem em texto da Internet para prever o próximo token. Isso dá ao modelo amplo conhecimento e habilidade linguística, mas nenhuma compreensão do que os humanos consideram útil.

**Etapa 2: Treinar um modelo de recompensa**
Peça aos anotadores humanos para avaliarem pares de respostas do modelo: "Qual resposta é melhor?" Use essas classificações para treinar um **modelo de recompensa** — uma rede neural que avalia a qualidade de uma resposta.

**Etapa 3: Ajuste fino de RL com PPO**
Use o modelo de recompensa como ambiente. O LLM é o agente; suas ações geram tokens; sua recompensa vem da pontuação do modelo de recompensa da resposta concluída.

```
Human prompt → LLM generates response → Reward model scores it
                                       → PPO updates LLM to generate
                                         higher-scoring responses
```

Esse loop é executado por milhares de iterações até que o LLM gere consistentemente respostas que os humanos avaliam altamente. O resultado: um modelo que não apenas tem conhecimento, mas que tenta genuinamente ser útil.

## ♟️ A história do AlphaGo

Go é um jogo de tabuleiro tão complexo – mais posições de tabuleiro possíveis do que átomos no universo observável – que foi considerado um dos desafios mais difíceis da IA. A maioria dos especialistas esperava que os campeões humanos permanecessem invictos durante décadas.

Em março de 2016, o **AlphaGo** da DeepMind derrotou o campeão mundial Lee Sedol por 4-1.

O sistema usou uma combinação de:
- Uma **rede de políticas** (treinada por meio de aprendizagem supervisionada em jogos humanos e depois refinada com RL) para sugerir movimentos promissores
- Uma **rede de valor** (treinada via RL por meio de autojogo) para avaliar posições no tabuleiro
- **Monte Carlo Tree Search** para planejar com antecedência, guiado por ambas as redes

**AlphaZero** (2017) foi além: aprendeu Go, xadrez e shogi *do zero*, sem dados humanos do jogo — apenas as regras e o autojogo via RL. Superou o AlphaGo em três dias e o melhor motor de xadrez (Stockfish) em quatro horas.

## 🤖 Aplicações de Robótica

RL é fundamental para a pesquisa em robótica moderna:

- **OpenAI's Dactyl** (2019): uma mão robótica treinada inteiramente em simulação usando RL, que poderia resolver um Cubo de Rubik usando apenas uma mão
- **Boston Dynamics**: usa RL junto com a teoria de controle tradicional para a locomoção ágil de robôs Spot e Atlas
- **Tarefas de manipulação**: robôs aprendendo a escolher, posicionar e montar objetos em ambientes não estruturados
- **Direção autônoma**: RL é usado em simulação para treinar políticas de direção antes da implantação no mundo real

Um desafio importante na robótica RL é a **lacuna entre o simulador e o real**: políticas treinadas em simulação muitas vezes falham no mundo real porque a simulação não modela perfeitamente a física, o atrito, o ruído do sensor e os objetos inesperados.

## ⚠️ Limitações do aprendizado por reforço

RL é poderoso, mas tem restrições reais:

- **Eficiência da amostra**: a RL normalmente requer milhões ou bilhões de interações para aprender o que uma criança humana aprende em horas. AlphaGo jogou o equivalente a milhares de anos de jogos humanos durante o treinamento
- **Hacking de recompensas**: os agentes às vezes encontram maneiras inteligentes de maximizar a recompensa que violam o espírito do objetivo (um robô de limpeza que aprende a *esconder* a bagunça em vez de limpá-la)
- **Recompensas escassas**: quando as recompensas são raras (apenas no final do jogo), o aprendizado é muito lento
- **Segurança**: agentes exploratórios de RL podem realizar ações perigosas no mundo real — um carro autônomo não pode explorar aleatoriamente no trânsito

## Principais conclusões

- RL é construído na estrutura **agente/ambiente/recompensa**: um agente realiza ações, recebe recompensas e aprende uma política que maximiza a recompensa cumulativa
- O dilema **exploração versus exploração** é central: estratégias ε-gananciosos e mais sofisticadas equilibram tentar coisas novas com fazer o que já funciona
- **Processos de Decisão Markov (MDPs)** formalizam problemas de RL; o fator de desconto γ controla o quanto o agente valoriza as recompensas futuras versus recompensas imediatas
- **Q-learning** (e Deep Q-Networks) aprendem funções de valor; Métodos de **gradiente de política** (PPO, A3C) otimizam diretamente a política
- **RLHF** é a técnica por trás do comportamento útil do ChatGPT: as classificações de preferência humana treinam um modelo de recompensa, que então orienta o ajuste fino do PPO do LLM
- **AlphaGo/AlphaZero** demonstrou que RL com jogo autônomo pode superar campeões mundiais humanos em jogos complexos, alcançando em dias o que os humanos levaram milênios de conhecimento acumulado
- As principais limitações da RL incluem **baixa eficiência de amostra**, **hacking de recompensas** e **lacuna entre simulação e realidade** na robótica
