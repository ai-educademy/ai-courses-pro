# ట్రాన్స్‌ఫార్మర్లు వివరించబడ్డాయి: ChatGPT వెనుక ఉన్న ఆర్కిటెక్చర్

2017లో Google బృందం *"Attention Is All You Need"* అనే పేపర్ ప్రచురించింది. అది **Transformer** ఆర్కిటెక్చర్‌ను పరిచయం చేసి AIని పూర్తిగా మార్చింది. మీరు విన్న ప్రధాన భాషా మోడళ్లు - ChatGPT, Claude, Gemini, BERT, Llama, ఆధునిక GPT మోడళ్లు - అన్నీ Transformers పై నిర్మించబడ్డాయి.

ట్రాన్స్‌ఫార్మర్‌లు ఎందుకు ముఖ్యమైనవి అని అర్థం చేసుకోవడానికి, మీరు మొదట వాటిని భర్తీ చేసిన వాటిని అర్థం చేసుకోవాలి.

## ⏱️ RNNలతో సమస్య: వచనాన్ని వరుసగా ప్రాసెస్ చేయడం

ట్రాన్స్‌ఫార్మర్‌లకు ముందు, ప్రాసెసింగ్ సీక్వెన్స్‌ల (టెక్స్ట్, ఆడియో, టైమ్ సిరీస్) ఆధిపత్య విధానం **రికరెంట్ న్యూరల్ నెట్‌వర్క్ (RNN)** మరియు దాని వైవిధ్యాలు: LSTMలు మరియు GRUలు.

RNNలు వచనాన్ని ప్రాసెస్ చేస్తాయి **ఒకసారి ఒక పదం**, సమాచారాన్ని ముందుకు తీసుకువెళ్లే "దాచిన స్థితి"ని నిర్వహిస్తుంది:

```
Input:  "The cat sat on the mat because it was comfortable"
         ↓    ↓    ↓   ↓    ↓    ↓      ↓      ↓   ↓      ↓
        h1 → h2 → h3 → h4 → h5 → h6 → h7 → h8 → h9 → h10 → output
```

ఇది పనిచేస్తుంది, కానీ రెండు ప్రధాన సమస్యలు ఉన్నాయి:

**1. లాంగ్ సీక్వెన్స్‌లలో వానిషింగ్ గ్రేడియంట్స్**
మోడల్ వర్డ్ 10ని ప్రాసెస్ చేసే సమయానికి, పదం 1 నుండి సమాచారం తొమ్మిది దాచిన స్థితి నవీకరణల ద్వారా "పలచన" చేయబడింది. వాక్యం పొడవుగా ఉన్నప్పుడు "ఇది" (పదం 8)ని తిరిగి "పిల్లి" (పదం 2)కి కనెక్ట్ చేయడానికి మోడల్ కష్టపడుతుంది.

**2. నెమ్మదిగా — సమాంతరీకరణ లేదు**
ప్రతి పదం మునుపటి దాచిన స్థితిపై ఆధారపడి ఉంటుంది కాబట్టి, మీరు పదాలను ఒక్కొక్కటిగా ప్రాసెస్ చేయాలి. మీరు క్రమం అంతటా సమాంతరంగా ఉండలేరు. పొడవైన పత్రాలపై శిక్షణ చాలా నెమ్మదిగా ఉంటుంది.

ట్రాన్స్‌ఫార్మర్ ఒకే సొగసైన మెకానిజంతో రెండు సమస్యలను పరిష్కరిస్తుంది: **శ్రద్ధ**.

## 👀 స్వీయ-అటెన్షన్ మెకానిజం

ట్రాన్స్‌ఫార్మర్ యొక్క కేంద్ర ఆవిష్కరణ **స్వీయ-శ్రద్ధ**: ఒక క్రమంలో ఉన్న ప్రతి పదానికి అవి ఎంత దూరంలో ఉన్నా, అదే సమయంలో ప్రతి ఇతర పదానికి నేరుగా హాజరయ్యే సామర్థ్యం.

సమాచారాన్ని క్రమానుగతంగా పంపే బదులు, స్వీయ-శ్రద్ధ గణిస్తుంది **క్రమంలోని ప్రతి పదానికి ప్రతి పదం ఎంత సందర్భోచితంగా ఉందో** — ఒకేసారి.

### ప్రశ్న, కీ మరియు విలువ — సాదా ఆంగ్లంలో

ప్రతి పదానికి (లేదా టోకెన్), ట్రాన్స్‌ఫార్మర్ మూడు వెక్టర్‌లను సృష్టిస్తుంది:

- **ప్రశ్న (ప్ర)**: *"నేను దేని కోసం వెతుకుతున్నాను?"* — ఈ పదం అడుగుతున్న ప్రశ్న
- **కీ (K)**: *"నేను ఏమి కలిగి ఉండాలి?"* — ప్రతి పదం దాని గురించి ప్రసారం చేసే ప్రకటన
- **విలువ (V)**: *"నేను ఏ సమాచారాన్ని అందిస్తాను?"* — తిరిగి పొందవలసిన వాస్తవ కంటెంట్

ఒక పదం యొక్క ప్రశ్న యొక్క డాట్ ఉత్పత్తిని మరొక పదం యొక్క కీతో తీసుకోవడం ద్వారా రెండు పదాల మధ్య శ్రద్ధ స్కోర్ గణించబడుతుంది. అధిక స్కోర్ అంటే "ఈ రెండు పదాలు ఒకదానికొకటి అత్యంత సంబంధితంగా ఉంటాయి."

```python
import torch
import torch.nn.functional as F

def self_attention(Q, K, V):
    d_k = Q.shape[-1]  # dimension of key vectors
    
    # Compute raw attention scores: how relevant is each word to each other
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    
    # Convert scores to probabilities (weights that sum to 1)
    attention_weights = F.softmax(scores, dim=-1)
    
    # Weighted sum of Value vectors
    output = torch.matmul(attention_weights, V)
    
    return output, attention_weights

# For the sentence "The cat sat on the mat because it was comfortable",
# "it" will have a high attention score with "cat" (the antecedent)
# regardless of how many words separate them
```

ఫలితం: ** ప్రతి టోకెన్‌కు ప్రతి ఇతర టోకెన్‌కు ప్రత్యక్ష రేఖ ఉంటుంది**. ఎక్కువ సమాచార అడ్డంకి లేదు, సుదీర్ఘమైన సీక్వెన్స్‌లలో వానిషింగ్ గ్రేడియంట్లు లేవు.

### స్క్వేర్ రూట్ స్కేలింగ్ ఎందుకు?

ఎగువ కోడ్‌లోని `/ (d_k ** 0.5)` డాట్ ఉత్పత్తులు చాలా పెద్ద సంఖ్యలుగా మారకుండా నిరోధిస్తుంది, ఇది సాఫ్ట్‌మాక్స్‌ను చాలా చిన్న గ్రేడియంట్స్ ఉన్న ప్రాంతాలలోకి నెట్టివేస్తుంది. ఇది స్థిరీకరణ ట్రిక్.

## 🧠 మల్టీ-హెడ్ అటెన్షన్

దృష్టిని ఒక్కసారి గణించడానికి బదులుగా, ట్రాన్స్‌ఫార్మర్లు దానిని **పలుసార్లు సమాంతరంగా** విభిన్న నేర్చుకున్న అంచనాలతో గణిస్తారు. దీనిని **మల్టీ-హెడ్ అటెన్షన్** అంటారు:

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=512, num_heads=8):
        super().__init__()
        self.num_heads = num_heads
        self.d_k = d_model // num_heads  # 64 per head
        
        # Separate linear projections for each head
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def forward(self, x):
        # Each head learns to attend to different aspects:
        # Head 1 might focus on syntactic relationships
        # Head 2 might focus on semantic similarity
        # Head 3 might focus on co-reference (it → cat)
        # ... and so on for all 8 heads
        pass
```

ప్రతి అటెన్షన్ హెడ్ వేరే రకమైన సంబంధంలో నైపుణ్యం పొందవచ్చు. ఒక తల సింటాక్టిక్ డిపెండెన్సీలను ట్రాక్ చేయవచ్చు (విషయం-క్రియ ఒప్పందం), మరొకటి కోర్ఫరెన్స్ (సర్వనామాలు మరియు వాటి పూర్వజన్మలు)పై దృష్టి పెట్టవచ్చు, మరొకటి అర్థ సారూప్యతను సంగ్రహించవచ్చు.

<FunFact>GPT కుటుంబంలోని పెద్ద మోడళ్లు చాలా అటెన్షన్ హెడ్‌లను వాడుతాయి. ప్రతి హెడ్ సందర్భ విండో అంతటా వేర్వేరు భాషా సంబంధాలను స్వతంత్రంగా ట్రాక్ చేయడం నేర్చుకోగలదు.</FunFact>

## 📍 స్థాన ఎన్‌కోడింగ్

స్వీయ-అటెన్షన్‌కు ఒక బ్లైండ్ స్పాట్ ఉంది: ఇది అంతర్లీనంగా **ఆర్డర్-అజ్ఞేయ**. "కుక్క మనిషిని కరుస్తుంది" మరియు "మనిషి కుక్కను కరిచింది" అదనపు సమాచారం లేకుండా ఒకే విధమైన శ్రద్ధ స్కోర్‌లను ఉత్పత్తి చేస్తుంది.

మోడల్‌కు వర్డ్ ఆర్డర్ యొక్క భావాన్ని అందించడానికి, ట్రాన్స్‌ఫార్మర్లు ఇన్‌పుట్ ఎంబెడ్డింగ్‌లకు **స్థాన ఎన్‌కోడింగ్‌లను** జోడిస్తాయి. అసలు ట్రాన్స్‌ఫార్మర్ సైనూసోయిడల్ ఫంక్షన్‌లను ఉపయోగించింది:

```python
import numpy as np

def positional_encoding(seq_len, d_model):
    PE = np.zeros((seq_len, d_model))
    for pos in range(seq_len):
        for i in range(0, d_model, 2):
            PE[pos, i]     = np.sin(pos / 10000 ** (2*i / d_model))
            PE[pos, i + 1] = np.cos(pos / 10000 ** (2*i / d_model))
    return PE

# Each position gets a unique "fingerprint" added to its embedding
# Position 0 looks different from position 1, which looks different from position 2
```

LAMA వంటి ఆధునిక నమూనాలు **రోటరీ పొజిషన్ ఎంబెడ్డింగ్‌లను (RoPE)** ఉపయోగిస్తాయి, ఇవి సాపేక్ష స్థానాన్ని మరింత ప్రభావవంతంగా ఎన్‌కోడ్ చేస్తాయి మరియు చాలా పొడవైన సందర్భాలకు మెరుగ్గా స్కేల్ చేస్తాయి.

## 🏗️ పూర్తి ట్రాన్స్‌ఫార్మర్ ఆర్కిటెక్చర్

అసలు ట్రాన్స్‌ఫార్మర్‌లో రెండు ప్రధాన భాగాలు ఉన్నాయి:

### ఎన్‌కోడర్
ఇన్‌పుట్‌ని చదువుతుంది మరియు గొప్ప సందర్భోచిత ప్రాతినిధ్యాన్ని రూపొందిస్తుంది. ప్రతి టోకెన్ యొక్క ప్రాతినిధ్యం ప్రతి ఇతర టోకెన్ ద్వారా స్వీయ-శ్రద్ధ ద్వారా తెలియజేయబడుతుంది. వాక్యాల వర్గీకరణ, పేరున్న ఎంటిటీ గుర్తింపు, ఇచ్చిన పాసేజ్‌పై ప్రశ్నలకు సమాధానమివ్వడం వంటి పనుల కోసం ఉపయోగించబడుతుంది.

### డీకోడర్
ఒక సమయంలో అవుట్‌పుట్ టోకెన్‌లను ఉత్పత్తి చేస్తుంది, ఎన్‌కోడర్ అవుట్‌పుట్ మరియు ఇప్పటికే రూపొందించిన టోకెన్‌లకు రెండింటికి హాజరవుతుంది. దీని కోసం ఉపయోగించబడుతుంది: అనువాదం, సారాంశం, వచన ఉత్పత్తి.

పూర్తి ఎన్‌కోడర్-డీకోడర్ స్టాక్:
```
Input text → Token Embeddings + Positional Encoding
           → N × [Multi-Head Self-Attention → Add & Norm → Feed-Forward → Add & Norm]
           → Encoder Output

Encoder Output + Generated tokens so far
           → N × [Masked Self-Attention → Cross-Attention → Feed-Forward]
           → Next token prediction
```

## 🆚 BERT వర్సెస్ GPT: ట్రాన్స్‌ఫార్మర్ యొక్క రెండు రుచులు

అన్ని ట్రాన్స్‌ఫార్మర్-ఆధారిత మోడల్‌లు పూర్తి ఎన్‌కోడర్-డీకోడర్ నిర్మాణాన్ని ఉపయోగించవు. రెండు ఆధిపత్య వైవిధ్యాలు:

### BERT (ఎన్‌కోడర్-మాత్రమే)
- **ఎన్‌కోడర్** స్టాక్‌ను మాత్రమే ఉపయోగిస్తుంది
- **మాస్క్డ్ లాంగ్వేజ్ మోడలింగ్**తో శిక్షణ పొందారు: కొన్ని ఇన్‌పుట్ టోకెన్‌లు దాచబడ్డాయి మరియు BERT వాటిని అంచనా వేస్తుంది.
- **అర్థం చేసుకోవడం** టెక్స్ట్‌లో అద్భుతమైనది: వర్గీకరణ, శోధన, ప్రశ్నోత్తరాలు
- మొత్తం సందర్భాన్ని ద్విముఖంగా చదువుతుంది (ప్రతి పదం ప్రతి ఇతర పదాన్ని చూస్తుంది)

### GPT (డీకోడర్-మాత్రమే)
- **డీకోడర్** స్టాక్‌ను మాత్రమే ఉపయోగిస్తుంది  
- **తదుపరి టోకెన్ ప్రిడిక్షన్**తో శిక్షణ పొందారు: మునుపటి అన్ని టోకెన్‌లను అందించి, తదుపరిది అంచనా వేయండి
- **ఉత్పత్తి** వచనంలో అద్భుతమైనది: సంభాషణ, రచన, కోడ్
- కారణ మాస్కింగ్: ప్రతి టోకెన్ మునుపటి టోకెన్‌లకు మాత్రమే హాజరు కాగలదు (భవిష్యత్తులో కాదు - అది మోసం అవుతుంది)

```
BERT training:   "The [MASK] sat on the mat"  → predict "cat"
GPT training:    "The cat sat on the"          → predict "mat"
```

<ThinkAboutIt>BERT యొక్క ద్వి దిశాత్మక శ్రద్ధ అంటే అది పదం యొక్క ప్రాతినిధ్యాన్ని నిర్మించేటప్పుడు భవిష్యత్తు పదాలను చూడగలదు. GPT సాధ్యం కాదు. ఇది తరానికి GPTని మెరుగ్గా చేస్తుంది కానీ వర్గీకరణ పనులకు BERTని ఎందుకు మెరుగ్గా చేస్తుంది?</ThinkAboutIt>

## 📈 స్కేల్ ఎందుకు ముఖ్యం

ట్రాన్స్‌ఫార్మర్ ఆర్కిటెక్చర్ అద్భుతంగా స్కేల్‌గా మారింది. ఎక్కువ పారామీటర్‌లతో కూడిన పెద్ద మోడల్‌లు, ఎక్కువ డేటాపై శిక్షణ పొంది, మరింత కంప్యూట్‌తో, స్థిరంగా మెరుగైన పనితీరును ఉత్పత్తి చేస్తాయి — ఇది **స్కేలింగ్ చట్టాలు** (కప్లాన్ మరియు ఇతరులు, 2020) ద్వారా వివరించబడిన దృగ్విషయం.

ఇది పురోగతికి దారితీసింది:
- GPT-1 (2018): 117M పారామితులు
- GPT-2 (2019): 1.5B పారామితులు
- GPT-3 (2020): 175B పారామితులు
- ప్రస్తుత అగ్రశ్రేణి మోడళ్లు: తరచుగా mixture-of-experts లేదా ప్రకటించని ఆర్కిటెక్చర్లు, వందల బిలియన్ల నుంచి ట్రిలియన్ల ప్రభావవంతమైన పరామీటర్లతో

ప్రతి ఎగబాటు సామర్థ్యంలో గుణాత్మక మెరుగుదలలు తెచ్చింది. GPT-2 అసలు చేయలేని పనులు (క్లిష్టమైన తర్కం, కోడ్ సృష్టి) GPT-3 స్కేల్‌లో సాధ్యమయ్యాయి మరియు తరువాతి అగ్రశ్రేణి మోడళ్లలో మెరుగుపడుతూ వచ్చాయి.

## ⚡ శిక్షణ వర్సెస్ అనుమితి

రెండు విభిన్న గణన ప్రొఫైల్‌లు:

**శిక్షణ**: చాలా ఖరీదైనది. ట్రిలియన్ల టోకెన్‌లను ప్రాసెస్ చేయడం, గ్రేడియెంట్లు లెక్కించడం, భారీ పరామీటర్ సెట్లను వేల GPUs పై వారాలు లేదా నెలలు నవీకరించడం. ప్రస్తుత అగ్రశ్రేణి మోడల్ శిక్షణ కంప్యూట్, డేటా, శక్తి, ఇంజినీరింగ్ కలిపి వందల మిలియన్లు ఖర్చు కావచ్చు.

**అనుమతి**: చాలా తక్కువ ధర. ప్రతి టోకెన్‌ను రూపొందించడానికి నెట్‌వర్క్ ద్వారా ఒకే ఫార్వర్డ్ పాస్. ఇప్పటికీ ముఖ్యమైన హార్డ్‌వేర్ (శక్తివంతమైన GPUలు లేదా ప్రత్యేక AI చిప్‌లు) అవసరం, కానీ స్కేల్‌లో నిర్వహించదగినవి.

ఈ అసమానత పరిశ్రమను రూపుదిద్దింది: కొన్ని మంచి వనరులు కలిగిన సంస్థలు ఫౌండేషన్ మోడల్‌లకు శిక్షణ ఇచ్చాయి; ప్రతి ఒక్కరూ వాటిని APIల ద్వారా యాక్సెస్ చేస్తారు.

## కీలక టేకావేలు

- **RNNs** ప్రాసెస్ చేయబడిన సీక్వెన్సులు దశలవారీగా, దీర్ఘ-శ్రేణి డిపెండెన్సీలతో పోరాడుతూ మరియు సమాంతరంగా చేయలేక - ట్రాన్స్‌ఫార్మర్లు వాటిని భర్తీ చేశాయి
- ** స్వీయ-శ్రద్ధ** ప్రతి టోకెన్‌ను ప్రశ్న, కీ, విలువ వెక్టర్‌ల ద్వారా ప్రతి ఇతర టోకెన్‌కు నేరుగా హాజరు కావడానికి అనుమతిస్తుంది — ఒకేసారి రెండు సమస్యలను పరిష్కరించడం
- **మల్టీ-హెడ్ అటెన్షన్** బహుళ అటెన్షన్ కంప్యూటేషన్‌లను సమాంతరంగా అమలు చేస్తుంది, మోడల్ వివిధ రకాల సంబంధాలను ఏకకాలంలో తెలుసుకోవడానికి అనుమతిస్తుంది
- **పొజిషనల్ ఎన్‌కోడింగ్** అంతర్గతంగా స్థానం-అజ్ఞేయ దృష్టి యంత్రాంగానికి ఆర్డర్ సమాచారాన్ని జోడిస్తుంది
- **BERT** (ఎన్‌కోడర్-మాత్రమే) వచనాన్ని ద్వి దిశాత్మకంగా అర్థం చేసుకోవడానికి ముందే శిక్షణ పొందింది; వర్గీకరణ మరియు శోధన పనులకు ఉత్తమమైనది
- **GPT** (డీకోడర్-మాత్రమే) ఎడమ నుండి కుడికి వచనాన్ని రూపొందించడానికి ముందే శిక్షణ పొందింది; తరం మరియు సంభాషణకు ఉత్తమమైనది
- **స్కేల్ చాలా ముఖ్యం**: ఎక్కువ డేటాపై శిక్షణ పొందిన పెద్ద ట్రాన్స్‌ఫార్మర్లు కొత్త సామర్థ్యాలను స్థిరంగా తెరుస్తాయి, GPT-1 నుండి GPT-3 మరియు తరువాతి అగ్రశ్రేణి వ్యవస్థల పురోగతి చూపినట్లుగా
- శిక్షణ చాలా ఖరీదైనది; అనుమితి చాలా చవకైనది - ఈ అసమానత పునాది నమూనాలు ఎలా అమర్చబడిందో ఆకారాన్ని చూపుతుంది
