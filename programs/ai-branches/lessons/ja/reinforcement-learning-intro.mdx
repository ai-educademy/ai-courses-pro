# 強化学習: 試行錯誤を通じて AI を教える

子どもはどうやって歩くことを学ぶのでしょうか？ 「良いステップ/悪いステップ」の例のラベル付きデータセットを彼らに渡す人はいません。誰もバランスのための物理方程式を書きません。彼らは、周囲の世界からのフィードバックに導かれながら、挑戦し、挫折し、違うやり方で挑戦し、徐々に改善していきます。

この直感 - **報酬とペナルティに導かれ、試行錯誤を通じて学習する** - は **強化学習 (RL)** の基礎であり、囲碁やチェスの世界チャンピオンに勝つこと、役立つように ChatGPT をトレーニングすること、ロボットに歩行を教えることなど、AI の最も素晴らしい成果の背後にあるアプローチです。

## 🎯 コアフレームワーク: エージェント、環境、報酬

すべての RL 問題は同じ基本構造を持っています。

```
        ┌─────────────────────────────────────────┐
        │              ENVIRONMENT                 │
        │   (the world the agent operates in)      │
        └─────────────────┬───────────────────────┘
                          │
         State (s_t)      │      Reward (r_t)
         What the         │      How good was
         agent sees ◄─────┤      the last action?
                          │
        ┌─────────────────▼───────────────────────┐
        │                 AGENT                    │
        │   (the AI that takes actions)            │
        └─────────────────┬───────────────────────┘
                          │
                          │ Action (a_t)
                          ▼
              Agent acts on the environment,
              environment transitions to state s_{t+1}
```

- **エージェント**: 意思決定を行う AI システム
- **環境**: エージェントが対話するすべてのもの (ゲーム、シミュレーション、物理的なロボットの環境)
- **状態**: エージェントによる環境の現在の観察
- **アクション**: エージェントが行うこと (左に移動、ロボットアームを移動、単語を選択)
- **報酬**: アクションがどれほど良かったかを示す数値シグナル (ゴールを決めた場合は +1、ライフを失った場合は -1、タスクを完了した場合は +10)
- **ポリシー**: エージェントの戦略 - 状態からアクションへのマッピング

エージェントの目標は、一時的な報酬だけでなく、時間の経過とともに合計**累積報酬**を最大化する**ポリシー**を学習することです。

## 🔍 探索 vs 搾取: 中心的なジレンマ

RL エージェントは絶え間ない緊張に直面しています。

**悪用**: うまくいくとすでにわかっていることを実行します。現時点で最善と思われるアクションを実行します。

**探索**: 何か新しいことを試してください。まだ発見していないより良い戦略があるかもしれません。

搾取するだけのロボットでは、より良いルートを発見することはできません。探索するだけのロボットでは、確実にどこにもたどり着くことはできません。

シンプルだが効果的な戦略は **ε-greedy** です。

```python
import random

epsilon = 0.1  # 10% exploration rate

def choose_action(state, Q_table, epsilon):
    if random.random() < epsilon:
        # Explore: choose a random action
        return random.choice(available_actions)
    else:
        # Exploit: choose the action with highest expected reward
        return argmax(Q_table[state])
```

ε = 0.1 の場合、エージェントは 10% の確率でランダムに探索を行い、90% の確率で学習した知識を活用します。通常、ε は高く始まり (早い段階で多くの探索が行われます)、エージェントがより自信を持つようになるにつれて、トレーニングが進むにつれて減衰します。

<FunFact>探索と活用のジレンマは AI だけの問題ではなく、人間の意思決定にも現れます。お気に入りのレストランに行くべきですか (Exploit)、それとも新しい場所に挑戦するべきですか (Exploit)?同じ数学的枠組みが適用されます。</FunFact>

## 📊 マルコフ意思決定プロセス (MDP)

ほとんどの RL 問題は **マルコフ決定プロセス (MDP)** として形式化されます。重要な前提は **マルコフ特性** です。つまり、現在の状態には、最適なアクションを選択するために必要なすべての情報が含まれています。過去の履歴は重要ではなく、現在いる場所だけが重要です。

MDP は次のように定義されます。
- **S**: 可能な状態のセット
- **A**: 可能なアクションのセット
- **P(s' | s, a)**: 遷移確率 - 与えられた状態 s とアクション a、最終的に状態 s' になる確率
- **R(s, a)**: 報酬関数 - 状態 s でアクション a を実行することに対する即時報酬
- **γ (ガンマ)**: 割引係数 - 当面の報酬と比較して、将来の報酬がどのくらいの価値があるか

**割引要素**は重要です。近い将来の報酬は、遠く離れた報酬よ​​りも価値があります。

```python
# Cumulative discounted reward (Return)
# R = r_0 + γ·r_1 + γ²·r_2 + γ³·r_3 + ...
# With γ = 0.99: future rewards are nearly as valuable as immediate ones
# With γ = 0.5:  rewards 10 steps away are worth only 0.1% of immediate reward

gamma = 0.99
total_return = sum(gamma**t * reward for t, reward in enumerate(rewards))
```

## 🧮 Q ラーニング: 価値ベースの RL

**Q ラーニング** は、基本的な RL アルゴリズムの 1 つです。 **Q 関数**: Q(s, a) = 状態 s でアクション a を実行し、その後永久に最適に動作した場合に期待される将来の総報酬を学習します。

```python
import numpy as np

# Initialise Q-table to zeros
n_states  = 16   # e.g., a 4×4 grid world
n_actions = 4    # up, down, left, right
Q = np.zeros((n_states, n_actions))

# Q-learning update rule (the Bellman equation)
def update_Q(Q, state, action, reward, next_state, alpha=0.1, gamma=0.99):
    """
    alpha: learning rate — how fast to update Q values
    gamma: discount factor — how much to value future rewards
    """
    # Current estimate
    current_Q = Q[state, action]
    
    # Target: immediate reward + discounted best future value
    target = reward + gamma * np.max(Q[next_state])
    
    # Move current estimate towards target
    Q[state, action] = current_Q + alpha * (target - current_Q)
    
    return Q
```

何千ものエピソードを経て、Q 学習は最適な Q 関数に収束します。学習したら、ポリシーは単純です。各状態で、最も高い Q 値を持つアクションを実行します。

2013 年に DeepMind によって開発された **Deep Q-Networks (DQN)** は、Q テーブルをディープ ニューラル ネットワークに置き換え、Q ラーニングを複雑な視覚入力に合わせて拡張できるようにしました。 DQN は 49 の Atari ゲームをピクセルから直接プレイすることを学び、多くのゲームで人間レベルのパフォーマンスに達したことは有名です。

## 🚀 ポリシー勾配メソッド

Q ラーニングはアクションの価値を間接的に学習します。 **ポリシー勾配** メソッドは、ポリシー (状態からアクションへのマッピング) を直接最適化します。

```python
# The core idea: if an action led to high reward, make it more likely
# If an action led to low reward, make it less likely

def policy_gradient_update(policy_network, states, actions, rewards):
    # Compute discounted returns for each timestep
    returns = compute_returns(rewards, gamma=0.99)
    
    # Normalise returns (reduces variance)
    returns = (returns - returns.mean()) / (returns.std() + 1e-8)
    
    # Policy loss: -log(π(a|s)) × G_t
    # Maximise log-probability of actions weighted by how good they were
    log_probs = policy_network.log_prob(states, actions)
    loss = -(log_probs * returns).mean()
    
    # Backpropagate and update
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

最新のポリシーの勾配バリアントには次のものがあります。
- **PPO (近接ポリシー最適化)**: 現在最も広く使用されているアルゴリズムで、ChatGPT の RLHF トレーニングで使用されています。
- **A3C (Asynchronous Advantage Actor-Critic)**: 複数の環境間でトレーニングを並列化します。
- **SAC (Soft Actor-Critic)**: 連続アクション スペース (ロボット工学) に最適

## 💬 RLHF: ChatGPT の調整方法

RL の最近の最も影響力のあるアプリケーションの 1 つは、**ヒューマン フィードバックからの強化学習 (RLHF)** です。これは、ChatGPT やその他の LLM を有益、無害、誠実なものにするために使用される技術です。

このプロセスには 3 つの段階があります。

**ステージ 1: 事前トレーニング**
インターネット テキストで大規模な言語モデルをトレーニングし、次のトークンを予測します。これによりモデルは幅広い知識と言語能力を得ることができますが、人間が何を役に立つと考えるかについては理解できません。

**ステージ 2: 報酬モデルをトレーニングする**
ヒューマン アノテーターにモデル応答のペアを評価してもらいます。「どの応答が優れていますか?」これらの評価を使用して、**報酬モデル** (応答の良さをスコアするニューラル ネットワーク) をトレーニングします。

**ステージ 3: PPO を使用した RL 微調整**
報酬モデルを環境として使用します。 LLM はエージェントです。そのアクションはトークンを生成します。その報酬は、完了した応答の報酬モデルのスコアから得られます。

```
Human prompt → LLM generates response → Reward model scores it
                                       → PPO updates LLM to generate
                                         higher-scoring responses
```

このループは、人間が高く評価する応答を LLM が一貫して生成するまで、何千回も繰り返し実行されます。その結果、単に知識があるだけでなく、真に役に立とうとするモデルが誕生しました。

<ThinkAboutIt>RLHF は、人間のアノテーターが高く評価する応答を生成するように ChatGPT をトレーニングします。ヒューマン・アノテーターに偏見がある場合、または「どのアノテーターが高く評価するか」が「実際に何が真実で役立つか」と同じでない場合、どのような潜在的な問題が発生する可能性がありますか?</ThinkAboutIt>

## ♟️ AlphaGo ストーリー

囲碁は非常に複雑なボード ゲームであり、観測可能な宇宙の原子よりも多くの可能な盤上の位置があるため、AI における最も困難な課題の 1 つと考えられていました。ほとんどの専門家は、人類のチャンピオンは数十年間無敗を維持すると予想していた。

2016 年 3 月、DeepMind の **AlphaGo** は世界チャンピオンのイ セドルを 4-1 で破りました。

このシステムでは次の組み合わせが使用されました。
- 有望な動きを提案する **ポリシー ネットワーク** (人間のゲームで教師あり学習を通じてトレーニングされ、その後 RL で洗練された)
- ボードのポジションを評価するための **バリュー ネットワーク** (セルフ プレイを通じて RL 経由でトレーニング)
- **モンテカルロ ツリー検索** により、両方のネットワークに基づいて事前に計画を立てることができます

**AlphaZero** (2017) はさらに進んでおり、囲碁、チェス、将棋を *ゼロから* 学習し、人間のゲーム データは使用せず、ルールと RL を介したセルフプレイのみを学習しました。 AlphaGo を 3 日で上回り、最高のチェス エンジン (Stockfish) を 4 時間で上回りました。

## 🤖 ロボット工学の応用

RL は現代のロボット研究の中心です。

- **OpenAI の Dactyl** (2019): RL を使用したシミュレーションで完全に訓練されたロボットハンド。片手だけでルービック キューブを解くことができます。
- **ボストン ダイナミクス**: スポット ロボットとアトラス ロボットの機敏な移動のために、従来の制御理論と並行して RL を使用します。
- **操作タスク**: ロボットは、構造化されていない環境で物体を拾い、配置し、組み立てることを学習します。
- **自動運転**: RL は、実際の展開前に運転ポリシーをトレーニングするためのシミュレーションで使用されます。

ロボティクス RL の主な課題は **シミュレーションと現実のギャップ** です。シミュレーションでトレーニングされたポリシーは、現実世界では失敗することがよくあります。これは、シミュレーションが物理学、摩擦、センサー ノイズ、予期しないオブジェクトを完全にモデル化していないためです。

## ⚠️ 強化学習の限界

RL は強力ですが、実際には制約があります。

- **サンプル効率**: 通常、RL では人間の子供が数時間で学習する内容を学習するために、数百万または数十億のインタラクションが必要です。 AlphaGoはトレーニング中に人間の数千年分のゲームに相当するプレイをした
- **報酬ハッキング**: エージェントは、目標の精神に反する報酬を最大化する賢い方法を見つけることがあります (汚れを掃除するのではなく *隠す* ことを学習する掃除ロボット)
- **報酬が少ない**: 報酬が少ない場合 (ゲーム終了時のみ)、学習は非常に遅くなります。
- **安全性**: 探索的な RL エージェントは現実世界でも危険な行動をとる可能性があります。自動運転車は渋滞の中をランダムに探索することはできません。

## 重要なポイント

- RL は **エージェント/環境/報酬** フレームワークに基づいて構築されています。エージェントはアクションを実行し、報酬を受け取り、累積報酬を最大化するポリシーを学習します。
- **探索 vs 搾取** のジレンマが中心です。貪欲でより洗練された戦略は、新しいことを試すことと、すでに機能していることを行うことのバランスをとることです。
- **マルコフ決定プロセス (MDP)** は RL 問題を形式化します。割引係数 γ は、エージェントが将来の報酬と当面の報酬をどの程度評価するかを制御します。
- **Q ラーニング** (およびディープ Q ネットワーク) 学習値関数。 **ポリシー勾配** メソッド (PPO、A3C) はポリシーを直接最適化します。
- **RLHF** は、ChatGPT の有益な動作の背後にある技術です。人間の好みの評価によって報酬モデルがトレーニングされ、それが PPO による LLM の微調整に役立ちます。
- **AlphaGo/AlphaZero** は、セルフプレイによる RL が複雑なゲームで人間の世界チャンピオンを上回ることができ、人間が何千年もかけて蓄積した知識を数日で達成できることを実証しました
- RL の主な制限には、**低いサンプル効率**、**報酬ハッキング**、ロボット工学における**シミュレーションと実際のギャップ**が含まれます
