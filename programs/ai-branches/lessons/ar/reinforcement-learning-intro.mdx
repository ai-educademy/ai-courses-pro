# تعزيز التعلم: تدريس الذكاء الاصطناعي من خلال التجربة والخطأ

كيف يتعلم الطفل المشي؟ لا أحد يسلمهم مجموعة بيانات مصنفة لأمثلة "الخطوة الجيدة/الخطوة السيئة". لا أحد يكتب المعادلات الفيزيائية لتحقيق التوازن. إنهم يحاولون، ويفشلون، ويحاولون بشكل مختلف، ويتحسنون تدريجيًا - مسترشدين بتعليقات العالم من حولهم.

هذا الحدس - **التعلم من خلال التجربة والخطأ، مسترشدًا بالمكافآت والعقوبات** - هو أساس **التعلم المعزز (RL)**، وهو النهج الذي يقف وراء بعض إنجازات الذكاء الاصطناعي الأكثر إثارة: التغلب على أبطال العالم في لعبة Go والشطرنج، وتدريب ChatGPT ليكون مفيدًا، وتعليم الروبوتات المشي.

## 🎯 الإطار الأساسي: الوكيل، البيئة، المكافأة

كل مشكلة RL لها نفس البنية الأساسية:

```
        ┌─────────────────────────────────────────┐
        │              ENVIRONMENT                 │
        │   (the world the agent operates in)      │
        └─────────────────┬───────────────────────┘
                          │
         State (s_t)      │      Reward (r_t)
         What the         │      How good was
         agent sees ◄─────┤      the last action?
                          │
        ┌─────────────────▼───────────────────────┐
        │                 AGENT                    │
        │   (the AI that takes actions)            │
        └─────────────────┬───────────────────────┘
                          │
                          │ Action (a_t)
                          ▼
              Agent acts on the environment,
              environment transitions to state s_{t+1}
```

- **الوكيل**: يتخذ نظام الذكاء الاصطناعي القرارات
- **البيئة**: كل ما يتفاعل معه العميل (لعبة، محاكاة، البيئة المادية المحيطة بالروبوت)
- **الحالة**: الملاحظة الحالية للوكيل للبيئة
- **الإجراء**: ما يفعله العميل (تحرك لليسار، حرك ذراع الروبوت، اختر كلمة)
- **المكافأة**: إشارة رقمية تشير إلى مدى جودة الإجراء (+1 لتسجيل هدف، -1 لخسارة حياة، +10 لإكمال مهمة)
- **السياسة**: استراتيجية الوكيل - رسم خريطة من الحالات إلى الإجراءات

هدف الوكيل هو تعلم **سياسة** تعمل على زيادة إجمالي **المكافأة التراكمية** بمرور الوقت، وليس فقط المكافأة الفورية.

## 🔍 الاستكشاف مقابل الاستغلال: المعضلة المركزية

يواجه عملاء RL توترًا دائمًا:

**الاستغلال**: افعل ما تعلم أنه يعمل بشكل جيد - اتخذ الإجراء الذي يبدو الأفضل حاليًا.

**الاستكشاف**: جرّب شيئًا جديدًا - ربما تكون هناك استراتيجية أفضل لم تكتشفها بعد.

الروبوت الذي يستغل فقط لن يكتشف أبدًا طريقًا أفضل. إن الروبوت الذي يستكشف فقط لن يتمكن أبدًا من الوصول إلى أي مكان بشكل موثوق.

هناك استراتيجية بسيطة ولكنها فعالة وهي **ε-greedy**:

```python
import random

epsilon = 0.1  # 10% exploration rate

def choose_action(state, Q_table, epsilon):
    if random.random() < epsilon:
        # Explore: choose a random action
        return random.choice(available_actions)
    else:
        # Exploit: choose the action with highest expected reward
        return argmax(Q_table[state])
```

باستخدام ε = 0.1، يستكشف الوكيل بشكل عشوائي 10% من الوقت ويستغل المعرفة المكتسبة في 90% من الوقت. عادةً، يبدأ ε مرتفعًا (الكثير من الاستكشاف في وقت مبكر) ويضعف مع التدريب عندما يصبح العميل أكثر ثقة.

<FunFact>إن معضلة الاستكشاف والاستغلال ليست مجرد مشكلة تتعلق بالذكاء الاصطناعي، بل إنها تظهر في عملية صنع القرار البشرية أيضًا. هل يجب عليك الذهاب إلى مطعمك المفضل (استغلال) أم تجربة مكان جديد (استكشاف)؟ وينطبق نفس الإطار الرياضي.</FunFact>

## 📊 عمليات اتخاذ القرار ماركوف (MDPs)

يتم إضفاء الطابع الرسمي على معظم مشكلات RL على أنها **عمليات قرار ماركوف (MDPs)**. الافتراض الرئيسي هو **خاصية ماركوف**: تحتوي الحالة الحالية على جميع المعلومات اللازمة لاختيار الإجراء الأفضل - لا يهم التاريخ الماضي، بل يهم فقط مكانك الآن.

يتم تعريف MDP بواسطة:
- **S**: مجموعة من الحالات الممكنة
- **أ**: مجموعة من الإجراءات الممكنة
- **P(s' | s, a)**: احتمالية الانتقال - في حالة الحالة s والإجراء a، احتمال الانتهاء في الحالة s'
- **R(s, a)**: وظيفة المكافأة - مكافأة فورية مقابل اتخاذ الإجراء أ في الحالة
- **γ (جاما)**: عامل الخصم - مقدار قيمة المكافآت المستقبلية مقارنة بالمكافآت الفورية

**عامل الخصم** مهم: المكافآت في المستقبل القريب تستحق أكثر من المكافآت البعيدة:

```python
# Cumulative discounted reward (Return)
# R = r_0 + γ·r_1 + γ²·r_2 + γ³·r_3 + ...
# With γ = 0.99: future rewards are nearly as valuable as immediate ones
# With γ = 0.5:  rewards 10 steps away are worth only 0.1% of immediate reward

gamma = 0.99
total_return = sum(gamma**t * reward for t, reward in enumerate(rewards))
```

## 🧮 Q-Learning: RL القائم على القيمة

**تعلم Q** هي إحدى خوارزميات RL الأساسية. يتعلم **وظيفة Q**: Q(s, a) = إجمالي المكافأة المستقبلية المتوقعة إذا اتخذت إجراءً في الحالة ثم تصرفت على النحو الأمثل إلى الأبد بعد ذلك.

```python
import numpy as np

# Initialise Q-table to zeros
n_states  = 16   # e.g., a 4×4 grid world
n_actions = 4    # up, down, left, right
Q = np.zeros((n_states, n_actions))

# Q-learning update rule (the Bellman equation)
def update_Q(Q, state, action, reward, next_state, alpha=0.1, gamma=0.99):
    """
    alpha: learning rate — how fast to update Q values
    gamma: discount factor — how much to value future rewards
    """
    # Current estimate
    current_Q = Q[state, action]
    
    # Target: immediate reward + discounted best future value
    target = reward + gamma * np.max(Q[next_state])
    
    # Move current estimate towards target
    Q[state, action] = current_Q + alpha * (target - current_Q)
    
    return Q
```

عبر آلاف الحلقات، يتقارب تعلم Q مع وظيفة Q المثالية. بمجرد تعلمها، تكون السياسة ببساطة: في كل ولاية، اتخذ الإجراء بأعلى قيمة Q.

**شبكات Q العميقة (DQN)**، التي طورتها DeepMind في عام 2013، استبدلت جدول Q بشبكة عصبية عميقة، مما يسمح لـ تعلم Q بالتوسع إلى المدخلات المرئية المعقدة. من المعروف أن DQN تعلمت لعب 49 لعبة من ألعاب Atari مباشرة من وحدات البكسل، حيث وصلت إلى مستوى الأداء البشري في الكثير منها.

## 🚀 أساليب تدرج السياسة

يتعلم تعلم Q قيمة الإجراءات بشكل غير مباشر. تعمل أساليب **تدرج السياسة** على تحسين السياسة بشكل مباشر - التعيين من الحالات إلى الإجراءات.

```python
# The core idea: if an action led to high reward, make it more likely
# If an action led to low reward, make it less likely

def policy_gradient_update(policy_network, states, actions, rewards):
    # Compute discounted returns for each timestep
    returns = compute_returns(rewards, gamma=0.99)
    
    # Normalise returns (reduces variance)
    returns = (returns - returns.mean()) / (returns.std() + 1e-8)
    
    # Policy loss: -log(π(a|s)) × G_t
    # Maximise log-probability of actions weighted by how good they were
    log_probs = policy_network.log_prob(states, actions)
    loss = -(log_probs * returns).mean()
    
    # Backpropagate and update
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

تتضمن المتغيرات الحديثة لتدرج السياسة ما يلي:
- **PPO (تحسين السياسة القريبة)**: الخوارزمية الأكثر استخدامًا اليوم، والمستخدمة في تدريب RLHF الخاص بـ ChatGPT
- **A3C (الممثل والناقد ذو الميزة غير المتزامنة)**: يوازي التدريب عبر بيئات متعددة
- **SAC (الممثل والناقد الناعم)**: ممتاز لمساحات العمل المستمر (الروبوتات)

## 💬 RLHF: كيف تم ضبط ChatGPT

أحد أكثر التطبيقات الحديثة تأثيرًا في RL هو **التعلم المعزز من التعليقات البشرية (RLHF)** - وهي التقنية المستخدمة لجعل ChatGPT وغيره من برامج LLM مفيدة وغير ضارة وصادقة.

تتكون العملية من ثلاث مراحل:

**المرحلة الأولى: التدريب المسبق**
تدريب نموذج لغة كبير على نص الإنترنت للتنبؤ بالرمز التالي. وهذا يمنح النموذج معرفة واسعة وقدرة لغوية، ولكن لا يفهم ما يجده البشر مفيدًا.

**المرحلة الثانية: تدريب نموذج المكافأة**
اطلب من المعلقين البشريين تقييم أزواج من الاستجابات النموذجية: "أي استجابة أفضل؟" استخدم هذه التقييمات لتدريب **نموذج المكافأة** - وهو عبارة عن شبكة عصبية تسجل مدى جودة الاستجابة.

**المرحلة 3: ضبط RL باستخدام PPO**
استخدم نموذج المكافأة كبيئة. LLM هو الوكيل. أفعالها تولد الرموز. تأتي مكافأتها من درجة نموذج المكافأة للاستجابة المكتملة.

```
Human prompt → LLM generates response → Reward model scores it
                                       → PPO updates LLM to generate
                                         higher-scoring responses
```

يتم تشغيل هذه الحلقة لآلاف التكرارات حتى تقوم LLM باستمرار بإنشاء استجابات يقدرها البشر بدرجة عالية. والنتيجة: نموذج لا يتمتع بالمعرفة فحسب، بل يحاول بصدق أن يكون مفيدًا.

<ThinkAboutIt>يقوم RLHF بتدريب ChatGPT لتوليد استجابات يقدرها المفسرون البشريون بدرجة عالية. ما هي المشاكل المحتملة التي يمكن أن تنشأ إذا كان لدى المفسرين البشريين تحيزات، أو إذا كان "ما يصنفه المفسرون بدرجة عالية" ليس هو نفسه "ما هو حقيقي ومفيد بالفعل"؟ </ThinkAboutIt>

## ♟️ قصة AlphaGo

Go هي لعبة لوحية معقدة للغاية - مواقع اللوحة أكثر احتمالاً من الذرات في الكون المرئي - لدرجة أنها تعتبر واحدة من أصعب التحديات في الذكاء الاصطناعي. توقع معظم الخبراء أن يظل أبطال البشر دون هزيمة لعقود من الزمن.

في مارس 2016، هزمت شركة **AlphaGo** التابعة لشركة DeepMind بطل العالم Lee Sedol بنتيجة 4-1.

استخدم النظام مزيجًا من:
- **شبكة سياسات** (يتم تدريبها من خلال التعلم الخاضع للإشراف على الألعاب البشرية، ثم تحسينها باستخدام التعلم العميق) لاقتراح خطوات واعدة
- **شبكة قيمة** (يتم تدريبها عبر RL من خلال اللعب الذاتي) لتقييم مراكز اللوحة
- **Monte Carlo Tree Search** للتخطيط للمستقبل، مع الاسترشاد بكلا الشبكتين

ذهب **AlphaZero** (2017) إلى أبعد من ذلك: فقد تعلم لعبة Go، والشطرنج، وshogi *من الصفر*، بدون بيانات بشرية عن اللعبة - فقط القواعد واللعب الذاتي عبر RL. لقد تجاوز AlphaGo في ثلاثة أيام وأفضل محرك شطرنج (Stockfish) في أربع ساعات.

## 🤖 تطبيقات الروبوتات

يعتبر RL أمرًا أساسيًا في أبحاث الروبوتات الحديثة:

- **OpenAI's Dactyl** (2019): يد آلية مدربة بالكامل على المحاكاة باستخدام RL، والتي يمكنها حل مكعب روبيك باستخدام يد واحدة فقط
- **Boston Dynamics**: تستخدم RL جنبًا إلى جنب مع نظرية التحكم التقليدية للتحرك السريع لروبوتات Spot وAtlas
- **مهام التلاعب**: تتعلم الروبوتات كيفية انتقاء الأشياء ووضعها وتجميعها في بيئات غير منظمة
- **القيادة الذاتية**: يتم استخدام RL في المحاكاة لتدريب سياسات القيادة قبل نشرها في العالم الحقيقي

أحد التحديات الرئيسية في مجال الروبوتات RL هو **فجوة المحاكاة إلى الواقع**: غالبًا ما تفشل السياسات المدربة على المحاكاة في العالم الحقيقي لأن المحاكاة لا تمثل نموذجًا مثاليًا للفيزياء والاحتكاك وضوضاء أجهزة الاستشعار والأشياء غير المتوقعة.

## ⚠️ حدود التعلم المعزز

RL قوي ولكن لديه قيود حقيقية:

- **كفاءة العينة**: يتطلب التعلم العميق عادةً ملايين أو مليارات التفاعلات لمعرفة ما يتعلمه الطفل البشري في ساعات. لقد لعب AlphaGo ما يعادل آلاف السنين من الألعاب البشرية أثناء التدريب
- **اختراق المكافآت**: يجد العملاء أحيانًا طرقًا ذكية لتعظيم المكافأة بما ينتهك روح الهدف (روبوت تنظيف يتعلم *إخفاء* الفوضى بدلاً من تنظيفها)
- **المكافآت المتفرقة**: عندما تكون المكافآت نادرة (في نهاية اللعبة فقط)، يكون التعلم بطيئًا للغاية
- **السلامة**: يمكن لعملاء RL الاستكشافيين اتخاذ إجراءات خطيرة في العالم الحقيقي - لا يمكن للسيارة ذاتية القيادة الاستكشاف بشكل عشوائي في حركة المرور

## الوجبات السريعة الرئيسية

- تم بناء RL على إطار عمل **الوكيل/البيئة/المكافأة**: يتخذ الوكيل الإجراءات، ويتلقى المكافآت، ويتعلم سياسة تزيد من المكافأة التراكمية إلى الحد الأقصى
- تعد معضلة **الاستكشاف مقابل الاستغلال** أمرًا مركزيًا: إذ تعمل الاستراتيجيات الجشعة والأكثر تطورًا على الموازنة بين تجربة أشياء جديدة والقيام بما ينجح بالفعل
- **عمليات قرار ماركوف (MDPs)** تضفي الطابع الرسمي على مشاكل RL؛ يتحكم عامل الخصم γ في مقدار تقدير الوكيل للمكافآت المستقبلية مقابل المكافآت الفورية
- **تعلم Q** (و شبكات Q العميقة) تعلم وظائف القيمة؛ تعمل أساليب **تدرج السياسة** (PPO، A3C) على تحسين السياسة بشكل مباشر
- **RLHF** هي التقنية الكامنة وراء السلوك المفيد لـ ChatGPT: تعمل تقييمات التفضيل البشري على تدريب نموذج المكافأة، والذي يوجه بعد ذلك PPO لضبط LLM
- أظهر **AlphaGo/AlphaZero** أن RL من خلال اللعب الذاتي يمكن أن يتفوق على أبطال العالم من البشر في الألعاب المعقدة، ويحقق في أيام ما استغرق البشر آلاف السنين من المعرفة المتراكمة
- تشمل القيود الرئيسية لـ RL **ضعف كفاءة العينة**، و**اختراق المكافآت**، و**الفجوة بين محاكاة الواقع** في الروبوتات
