## Was macht einen Stapel monoton?

Ein **monotoner Stapel** verwaltet Elemente in streng aufsteigender oder absteigender Reihenfolge von unten nach oben. Bevor Sie ein neues Element verschieben, entfernen Sie alles, was die Invariante verletzt. Diese einzige Idee erschließt O(n)-Lösungen für Probleme, die O(n²) zu erfordern scheinen.

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## Nächstes größeres Element

Suchen Sie für jedes Element das erste größere Element rechts davon. Brute-Force-Scans nach rechts für jede Position – O(n²). Ein monoton abnehmender Stapel erledigt dies in einem Durchgang.

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

Wenn wir den Index `j` öffnen, ist das aktuelle Element das nächstgrößere – garantiert, weil alles dazwischen kleiner war (sie wurden früher entfernt oder nie blockiert `j`).

## Tagestemperaturen (LeetCode 739)

*Ermitteln Sie bei gegebenen Tagestemperaturen, wie viele Tage bis zu einem wärmeren Tag verbleiben.* Dies ist das nächstgrößere Element mit Indizes – die Antwort für Index `j` lautet `i − j`, wenn `j` durch Index `i` ersetzt wird.

## Größtes Rechteck im Histogramm

LeetCodes **Größtes Rechteck im Histogramm** ist das Kronjuwel monotoner Stapelprobleme.

**Wichtige Erkenntnis:** Finden Sie für jeden Balken heraus, wie weit er sich als kürzester Balken nach links und rechts erstrecken kann. Verwenden Sie einen zunehmenden Stapel – wenn ein Balken platzt, definiert der platzende Balken seine rechte Grenze und die neue Stapeloberseite definiert seine linke Grenze.

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

Der Sentinel `[0]` am Ende erzwingt die Verarbeitung aller verbleibenden Balken.

## Regenwasser einfangen – Stack-Ansatz

Anstelle der klassischen Zwei-Zeiger-Methode berechnet ein monoton abnehmender Stapel das eingeschlossene Wasser Schicht für Schicht. Wenn ein höherer Balken erscheint, platzen Sie kürzere Balken und berechnen Sie das Wasser, das zwischen dem platzenden Balken, dem aktuellen Balken und der neuen Stapeloberseite eingeschlossen ist.

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>Das Einfangen von Regenwasser verfügt über mindestens vier verschiedene O(n)-Lösungen: Zwei-Zeiger-, monotoner Stapel, Präfix-Max-Arrays und einen für einen Durchgang optimierten Ansatz. Interviewer lieben es, mehrere Strategien zu sehen.</FunFact>

## Monotone Warteschlange – Maximum des gleitenden Fensters

Eine **monotone Deque** (Warteschlange mit zwei Enden) behält die absteigende Reihenfolge bei und unterstützt eine effiziente Entfernung von beiden Enden. Für **Sliding Window Maximum** (LeetCode 239):

1. Bevor Sie den Index `i` hinzufügen, entfernen Sie alle Elemente, die kleiner als `nums[i]` sind.
2. `i` nach hinten schieben
3. Die Vorderseite ist immer das Maximum des aktuellen Fensters
4. Entfernen Sie die Vorderseite, wenn sie aus dem Fenster fällt

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

Jedes Element betritt und verlässt die Deque höchstens einmal – insgesamt **O(n)**.

## Das Muster – Invariante während der Verarbeitung beibehalten

Jedes monotone Stapel-/Warteschlangenproblem folgt einer Vorlage:

1. **Definieren Sie die Invariante** (steigend oder fallend)
2. **Pop-Verstöße** – und extrahieren Sie nützliche Informationen aus jedem Pop
3. **Aktuelles Element verschieben**
4. Beim *Pop-Ereignis* wird die Antwort berechnet
