## अंतराल निरूपण

एक अंतराल एक जोड़ा होता है `[start, end]`। ज़्यादातर अंतराल समस्याएँ एक महत्वपूर्ण चरण से शुरू होती हैं: **आरम्भ समय से सॉर्ट करें**। इससे अव्यवस्थित सूची ऐसी क्रमबद्ध शृंखला बन जाती है जिसे आप बाएँ से दाएँ सरल तुलनाओं से प्रोसेस कर सकते हैं।

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## ओवरलैप होते अंतराल मर्ज करना

यह बुनियादी अंतराल समस्या है (LeetCode 56)। सॉर्ट करने के बाद, दो लगातार अंतराल ओवरलैप करते हैं अगर वर्तमान आरम्भ ≤ पिछला अंत हो।

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

`[1,4] [2,5] [3,6] [8,10]` पर चलते हैं:
- `[2,5]` `[1,4]` से ओवरलैप करता है → मर्ज करें `[1,5]` में
- `[3,6]` `[1,5]` से ओवरलैप करता है → मर्ज करें `[1,6]` में
- `[8,10]` कोई ओवरलैप नहीं → नया अंतराल

नतीजा: `[1,6] [8,10]`

## इन्सर्ट अंतराल

क्रमबद्ध गैर-ओवरलैप अंतराल और एक नया अंतराल दिया गया है, इसे डालें और ज़रूरत हो तो मर्ज करें (LeetCode 57)। तीन चरणों में बाँटें:

1. वे सभी अंतराल जोड़ें जो नए वाले के शुरू होने से पहले खत्म हो जाते हैं
2. सभी ओवरलैप होते अंतराल को नए वाले के साथ मर्ज करें
3. बचे हुए अंतराल को बिना बदले जोड़ें

<ThinkAboutIt>इन्सर्ट अंतराल अक्सर इस तरह टर्म किया जाता है कि मर्ज चरण साफ़ नहीं होता। इंटरव्यू में आप इसे मर्ज समस्या के रूप में कैसे पहचानेंगे?</ThinkAboutIt>

## मीटिंग कमरे I - क्या सब टर्म कर सकते हैं?

आरम्भ समय से सॉर्ट करें। अगर किसी अंतराल का आरम्भ पिछले अंतराल के अंत से पहले है, तो टकराव है।

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## मीटिंग कमरे II - न्यूनतम कितने कमरे चाहिए

यहाँ **इवेंट-आधारित तरीका** सबसे उपयोगी है। आरम्भ और अंत को दो क्रमबद्ध सूचियों में अलग करें, फिर स्वीप करें:

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

हीप सबसे जल्दी खत्म होने वाली मीटिंग रिकॉर्ड करता है। अगर वो अगली मीटिंग शुरू होने से पहले खत्म हो जाती है, तो हम कमरा टर्म कर लेते हैं। हीप का अधिकतम आकार ही उत्तर है।

## गैर-ओवरलैप अंतराल - न्यूनतम हटाव

अंतराल दिए गए हैं, न्यूनतम कितने हटाने होंगे ताकि कोई ओवरलैप न हो (LeetCode 435)। टर्म: **अंत समय** से सॉर्ट करें, हमेशा वह अंतराल रखें जो सबसे पहले खत्म होता है - इससे भविष्य के अंतराल के लिए सबसे ज़्यादा जगह बचती है।

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## अंतराल सूची इंटरसेक्शन

दो क्रमबद्ध अंतराल सूचियाँ दी गई हैं, सभी इंटरसेक्शन ढूँढें (LeetCode 986)। दो पॉइंटर इस्तेमाल करें - हर सूची के लिए एक। `[a1, a2]` और `[b1, b2]` का इंटरसेक्शन `[max(a1, b1), min(a2, b2)]` है अगर यह मान्य है (टर्म ≤ end)। जिस पॉइंटर का अंतराल पहले खत्म हो, उसे आगे बढ़ाएँ।

## स्वीप लाइन तकनीक

अंतराल को जोड़ीवार तुलना करने की जगह, हर अंतराल को इवेंट में बाँटें:

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

टर्म को समय से सॉर्ट करें। बाएँ से दाएँ स्वीप करें, चलती गिनती बनाए रखते हुए। पीक गिनती "अधिकतम ओवरलैप" वाले सवालों का उत्तर देता है। यह टर्म टर्म II को मनमानी इवेंट प्रोसेसिंग समस्याओं तक सामान्यीकृत करता है।
