## Interval representation

एक interval एक pair होता है `[start, end]`। ज़्यादातर interval समस्याएँ एक महत्वपूर्ण चरण से शुरू होती हैं: **start time से sort करो**। इससे अव्यवस्थित list ऐसी sequence बन जाती है जिसे आप left से right सरल comparisons से process कर सकते हैं।

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## Overlapping intervals को merge करना

यह बुनियादी interval समस्या है (LeetCode 56)। sort करने के बाद, दो consecutive intervals overlap करते हैं अगर current start ≤ previous end हो।

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

`[1,4] [2,5] [3,6] [8,10]` पर चलते हैं:
- `[2,5]` `[1,4]` से ओवेरलप करता है → मर्ज करो `[1,5]` में
- `[3,6]` `[1,5]` से ओवेरलप करता है → मर्ज करो `[1,6]` में
- `[8,10]` कोई overlap नहीं → नया interval

नतीजा: `[1,6] [8,10]`

## इनसेरट इनटेरवल

sorted non-overlapping intervals और एक नया interval दिया गया है, इसे insert करो और ज़रूरत हो तो merge करो (LeetCode 57)। तीन phases में बाँटो:

1. वे सभी intervals जोड़ो जो नए वाले के शुरू होने से पहले खत्म हो जाते हैं
2. सभी overlapping intervals को नए वाले के साथ merge करो
3. बचे हुए intervals को बिना बदले जोड़ो

## मीटिङ रूमस I - क्या सब अटटेनद कर सकते हैं?

start time से sort करो। अगर किसी interval का start पिछले interval के end से पहले है, तो conflict है।

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## मीटिङ रूमस II - न्यूनतम कितने रूमस चाहिए

यहाँ **event-based approach** सबसे उपयोगी है। starts और ends को दो sorted lists में अलग करो, फिर sweep करो:

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

हेअप सबसे जल्दी खत्म होने वाली मीटिङ रिकॉर्ड करता है। अगर वो अगली मीटिङ शुरू होने से पहले खत्म हो जाती है, तो हम रूम रेउसे कर लेते हैं। हेअप का मक्सिमुम आकार ही उत्तर है।

## Non-overlapping intervals - न्यूनतम removals

Intervals दिए गए हैं, न्यूनतम कितने हटाने होंगे ताकि कोई overlap न हो (LeetCode 435)। Greedy: **end time** से sort करो, हमेशा वह interval रखो जो सबसे पहले खत्म होता है - इससे future intervals के लिए सबसे ज़्यादा जगह बचती है।

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## Interval list intersections

दो sorted interval lists दी गई हैं, सभी intersections ढूँढो (LeetCode 986)। दो pointers इस्तेमाल करो - हर list के लिए एक। `[a1, a2]` और `[b1, b2]` का intersection `[max(a1, b1), min(a2, b2)]` है अगर यह valid है (start ≤ end)। जिस pointer का interval पहले खत्म हो, उसे आगे बढ़ाओ।

## सवीप लिने टेचनिक्वे

Intervals को pairwise compare करने की जगह, हर interval को events में decompose करो:

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

Events को समय से sort करो। left से right sweep करो, running count बनाए रखते हुए। peak count "maximum overlap" वाले सवालों का उत्तर देता है। यह Meeting Rooms II को arbitrary event-processing समस्याओं तक generalise करता है।
