## इनटेरवल रेपरेसेनटशन

एक इंटरवल एक पैर होता है `[start, end]`। ज़्यादातर इंटरवल समस्याएँ एक करिटिकल चरण से शुरू होती हैं: **सटरट समय से सॉर्ट करो**। इससे एक अव्यवस्थित लिस्ट एक ऐसी सेक्वेनके बन जाती है जिसे आप लेफ़ट से रिघट सरल कोमपरिसोनस से प्रोसेस कर सकते हैं।

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## ओवेरलपपिङ इनटेरवलस को मेरगे करना

यह फ़ोउनदशनल इंटरवल समस्या है (LeetCode 56)। सोरट करने के बाद, दो कोनसेकुटिवे इनटेरवलस ओवेरलप करते हैं अगर वर्तमान सटरट ≤ पिछली एनद हो।

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

`[1,4] [2,5] [3,6] [8,10]` पर चलते हैं:
- `[2,5]` `[1,4]` से ओवेरलप करता है → मर्ज करो `[1,5]` में
- `[3,6]` `[1,5]` से ओवेरलप करता है → मर्ज करो `[1,6]` में
- `[8,10]` कोई ओवेरलप नहीं → नया इंटरवल

नतीजा: `[1,6] [8,10]`

## इनसेरट इनटेरवल

सोरटेद नोन-ओवेरलपपिङ इनटेरवलस और एक नया इंटरवल दिया गया है, इसे इन्सर्ट करो और ज़रूरत हो तो मर्ज करो (LeetCode 57)। तीन फसेस में बाँटो:

1. वो सब इनटेरवलस जोड़ें करो जो नए वाले के शुरू होने से पहले खत्म हो जाते हैं
2. सब ओवेरलपपिङ इनटेरवलस को नए वाले के साथ मर्ज करो
3. बचे हुए इनटेरवलस को उनचङेद जोड़ें करो

<ThinkAboutIt>इनसेरट इनटेरवल अक्सर इस तरह परेसेनट किया जाता है कि मर्ज चरण ओबविओउस नहीं होता। इंटरव्यू में आप इसे मर्ज समस्या के रूप में कैसे पहचानेंगे?</ThinkAboutIt>

## मीटिङ रूमस I - क्या सब अटटेनद कर सकते हैं?

सटरट समय से सॉर्ट करो। अगर किसी इंटरवल का सटरट पिछले इंटरवल के एनद से पहले है, तो कोनफ़लिकट है।

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## मीटिङ रूमस II - मिनिमुम कितने रूमस चाहिए

यहाँ **एवेनट-बसेद तरीका** चमकता है। सटरटस और एनदस को दो सॉर्टेड लिस्ट में अलग करो, फिर सवीप करो:

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

हेअप सबसे जल्दी खत्म होने वाली मीटिङ रिकॉर्ड करता है। अगर वो अगली मीटिङ शुरू होने से पहले खत्म हो जाती है, तो हम रूम रेउसे कर लेते हैं। हेअप का मक्सिमुम आकार ही answer है।

## नोन-ओवेरलपपिङ इनटेरवलस - मिनिमुम कितने रेमोवे करें

इनटेरवलस दिए गए हैं, मिनिमुम कितने रेमोवे करने होंगे ताकि कोई ओवेरलप न हो (LeetCode 435)। गरीदय: **एनद समय** से सॉर्ट करो, हमेशा वो इंटरवल रखो जो सबसे पहले खत्म होता है - इससे फ़ुटुरे इनटेरवलस के लिए सबसे ज़्यादा जगह बचती है।

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## इनटेरवल लिसट इनटेरसेकशनस

दो सॉर्टेड इंटरवल लिस्ट दी गई हैं, सब इनटेरसेकशनस ढूँढो (LeetCode 986)। दो पॉइंटर उपयोग करो - हर लिस्ट के लिए एक। `[a1, a2]` और `[b1, b2]` का इनटेरसेकशन `[max(a1, b1), min(a2, b2)]` है अगर यह वलिद है (सटरट ≤ एनद)। जिस पॉइंटर का इंटरवल पहले खत्म हो, उसे आगे बढ़ाओ।

## सवीप लिने टेचनिक्वे

इनटेरवलस को पैरविसे कोमपरे करने की जगह, हर इंटरवल को इवेंट में देकोमपोसे करो:

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

इवेंट को समय से सॉर्ट करो। लेफ़ट से रिघट सवीप करो, एक रुननिङ गणना मैनटैन करते हुए। पीक गणना "मक्सिमुम ओवेरलप" प्रश्न का answer देता है। यह मीटिङ रूमस II को अरबिटररय एवेनट-परोकेसिङ समस्याएँ तक गेनेरलिसे करता है।

## कलेनदर बूकिङ

**My कलेनदर I** (LeetCode 729): बूकेद इनटेरवलस मैनटैन करो और ओवेरलपस रेजेकट करो। **My कलेनदर II**: एकल ओवेरलपस अललोव करो लेकिन टरिपले-बूकिङस रेजेकट करो। सवीप लिने मुलटि-लयेर ओवेरलप पहचान को सटरैघटफ़ोरवरद बनाता है।
