## इंटरवल निरूपण

इंटरवल एक जोड़ा है: `[start, end]`। अधिकतर इंटरवल समस्याएँ एक महत्वपूर्ण कदम से शुरू होती हैं: **start time से sort करें**। इससे अस्त-व्यस्त सूची ऐसे क्रम में बदल जाती है जिसे आप सरल तुलना से बाएँ से दाएँ प्रोसेस कर सकते हैं।

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## ओवरलैप होते इंटरवल मिलाना

यह बुनियादी इंटरवल समस्या है (LeetCode 56)। सॉर्ट करने के बाद, दो लगातार इंटरवल तब ओवरलैप करते हैं जब current start ≤ previous end हो।

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

`[1,4] [2,5] [3,6] [8,10]` पर चलकर देखें:
- `[2,5]`, `[1,4]` से ओवरलैप करता है → `[1,5]` में merge
- `[3,6]`, `[1,5]` से ओवरलैप करता है → `[1,6]` में merge
- `[8,10]` में overlap नहीं → नया इंटरवल

नतीजा: `[1,6] [8,10]`

## Insert Interval

क्रमबद्ध और non-overlapping intervals दिए हैं, और एक नया interval है। उसे डालें और ज़रूरत के अनुसार merge करें (LeetCode 57)। इसे तीन चरणों में बाँटें:

1. वे सभी intervals जोड़ें जो नए interval के शुरू होने से पहले समाप्त हो जाते हैं
2. नए interval से overlap करने वाले सभी intervals merge करें
3. बचे हुए intervals बिना बदलाव जोड़ें

<ThinkAboutIt>Insert Interval अक्सर इस तरह पूछा जाता है कि merge step तुरंत स्पष्ट नहीं होता। इंटरव्यू में आप इसे merge problem के रूप में कैसे पहचानेंगे?</ThinkAboutIt>

## Meeting Rooms I - क्या सभी बैठकों में जा सकते हैं?

start time से sort करें। अगर किसी interval का start पिछले interval के end से पहले है, तो conflict है।

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## Meeting Rooms II - न्यूनतम कमरों की संख्या

यहीं **event-based approach** चमकती है। starts और ends को दो sorted सूचियों में बाँटें, फिर sweep करें:

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

हीप सबसे पहले समाप्त होने वाली meeting को ट्रैक करता है। अगर वह अगली meeting शुरू होने से पहले समाप्त हो जाती है, तो हम वही कमरा फिर इस्तेमाल करते हैं। हीप का अधिकतम आकार ही उत्तर है।

## Non-Overlapping Intervals - न्यूनतम हटाना

intervals दिए हैं। न्यूनतम कितने हटाएँ ताकि कोई overlap न रहे (LeetCode 435)। Greedy तरीका: **end time** से sort करें और हमेशा वह interval रखें जो सबसे पहले समाप्त होता है। इससे आगे के intervals के लिए सबसे ज़्यादा जगह बचती है।

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## Interval List Intersections

दो sorted interval lists दी हैं। सभी intersections खोजें (LeetCode 986)। दो pointers इस्तेमाल करें, हर list के लिए एक। `[a1, a2]` और `[b1, b2]` का intersection `[max(a1, b1), min(a2, b2)]` है, अगर वह मान्य हो (start ≤ end)। जिस pointer का interval पहले समाप्त होता है, उसे आगे बढ़ाएँ।

## Sweep Line तकनीक

intervals की जोड़े-जोड़ तुलना करने के बजाय, हर interval को events में तोड़ें:

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

events को time से sort करें। बाएँ से दाएँ sweep करते हुए running count रखें। peak count "maximum overlap" वाले प्रश्नों का उत्तर देता है। यह Meeting Rooms II को मनमाने event-processing problems तक सामान्य करता है।

## Calendar Booking

**My Calendar I** (LeetCode 729): booked intervals रखें और overlaps अस्वीकार करें। **My Calendar II**: single overlap की अनुमति दें, लेकिन triple-bookings अस्वीकार करें। sweep line multi-layer overlap detection को सीधा बना देता है।
