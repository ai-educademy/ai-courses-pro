## अंतराल निरूपण

अंतराल एक जोड़ा है: `[start, end]`। अधिकतर अंतराल समस्याएँ एक महत्वपूर्ण कदम से शुरू होती हैं: **शुरुआती समय से सॉर्ट करें**। इससे अस्त-व्यस्त सूची ऐसे क्रम में बदल जाती है जिसे आप सरल तुलना से बाएँ से दाएँ प्रोसेस कर सकते हैं।

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## ओवरलैप होते अंतराल मिलाना

यह बुनियादी अंतराल समस्या है (LeetCode 56)। सॉर्ट करने के बाद, दो लगातार अंतराल तब ओवरलैप करते हैं जब वर्तमान शुरुआत ≤ पिछला अंत हो।

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

`[1,4] [2,5] [3,6] [8,10]` पर चलकर देखें:
- `[2,5]`, `[1,4]` से ओवरलैप करता है → `[1,5]` में मर्ज
- `[3,6]`, `[1,5]` से ओवरलैप करता है → `[1,6]` में मर्ज
- `[8,10]` में ओवरलैप नहीं → नया अंतराल

नतीजा: `[1,6] [8,10]`

## इंसर्ट अंतराल

क्रमबद्ध और non-ओवरलैपिंग अंतराल दिए हैं, और एक नया अंतराल है। उसे डालें और ज़रूरत के अनुसार मर्ज करें (LeetCode 57)। इसे तीन चरणों में बाँटें:

1. वे सभी अंतराल जोड़ें जो नए अंतराल के शुरू होने से पहले समाप्त हो जाते हैं
2. नए अंतराल से ओवरलैप करने वाले सभी अंतराल मर्ज करें
3. बचे हुए अंतराल बिना बदलाव जोड़ें

<ThinkAboutIt>इंसर्ट अंतराल अक्सर इस तरह पूछा जाता है कि मर्ज चरण तुरंत स्पष्ट नहीं होता। इंटरव्यू में आप इसे मर्ज समस्या के रूप में कैसे पहचानेंगे?</ThinkAboutIt>

## बैठक कमरे I - क्या सभी बैठकों में जा सकते हैं?

शुरुआती समय से सॉर्ट करें। अगर किसी अंतराल का शुरुआत पिछले अंतराल के अंत से पहले है, तो टकराव है।

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## बैठक कमरे II - न्यूनतम कमरों की संख्या

यहीं **इवेंट-आधारित तरीका** चमकती है। शुरुआतों और अंतों को दो क्रमबद्ध सूचियों में बाँटें, फिर स्वीप करें:

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

हीप सबसे पहले समाप्त होने वाली बैठक को ट्रैक करता है। अगर वह अगली बैठक शुरू होने से पहले समाप्त हो जाती है, तो हम वही कमरा फिर इस्तेमाल करते हैं। हीप का अधिकतम आकार ही उत्तर है।

## Non-Overlapping अंतराल - न्यूनतम हटाना

अंतराल दिए हैं। न्यूनतम कितने हटाएँ ताकि कोई ओवरलैप न रहे (LeetCode 435)। Greedy तरीका: **समाप्ति समय** से सॉर्ट करें और हमेशा वह अंतराल रखें जो सबसे पहले समाप्त होता है। इससे आगे के अंतराल के लिए सबसे ज़्यादा जगह बचती है।

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## अंतराल List Intersections

दो क्रमबद्ध अंतराल सूचियाँ दी हैं। सभी प्रतिच्छेदन खोजें (LeetCode 986)। दो पॉइंटर इस्तेमाल करें, हर सूची के लिए एक। `[a1, a2]` और `[b1, b2]` का प्रतिच्छेदन `[max(a1, b1), min(a2, b2)]` है, अगर वह मान्य हो (शुरुआत ≤ अंत)। जिस पॉइंटर का अंतराल पहले समाप्त होता है, उसे आगे बढ़ाएँ।

## Sweep Line तकनीक

अंतराल की जोड़े-जोड़ तुलना करने के बजाय, हर अंतराल को इवेंट में तोड़ें:

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

इवेंट को समय से सॉर्ट करें। बाएँ से दाएँ स्वीप करते हुए चलती गिनती रखें। चरम गिनती "अधिकतम ओवरलैप" वाले प्रश्नों का उत्तर देता है। यह बैठक कमरे II को मनमाने इवेंट-प्रोसेसिंग समस्याएँ तक सामान्य करता है।

## Calendar Booking

**My Calendar I** (LeetCode 729): बुक किए गए अंतराल रखें और ओवरलैप अस्वीकार करें। **My Calendar II**: एकल ओवरलैप की अनुमति दें, लेकिन तीनहरी बुकिंग अस्वीकार करें। स्वीप लाइन बहु-स्तरीय ओवरलैप पहचान को सीधा बना देता है।
