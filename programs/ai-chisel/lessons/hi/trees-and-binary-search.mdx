## AI में टरीस हर जगह हैं

जब भी कोई स्पैम फ़िल्टर किसी एमैल को कलसिफ़य करता है या कोई डेटाबेस मिलीसेकंड में आपका order लाता करता है, तो पीछे एक ट्री डेटा संरचना काम कर रही होती है। टरीस **हिएररचिकल फ़ैसले** को मॉडल करते हैं - हर नोड सर्च स्पेस को छोटा करता है जब तक आप answer तक नहीं पहुँच जाते।

## बिनरय सर्च टरीस (बसटस)

BST एलिमेंट को इस तरह सटोरे करता है कि किसी भी नोड के लिए, उसके **लेफ़ट** सुबटरी की सभी वलुएस छोटी होती हैं और **रिघट** सुबटरी की सभी वलुएस बड़ी होती हैं।

### सर्च

```
function search(node, target):
    if node is null: return null
    if target == node.value: return node
    if target < node.value: return search(node.left, target)
    return search(node.right, target)
```

हर कोमपरिसोन लगभग आधे बचे हुए नोड को एलिमिनटे कर देता है - संतुलित ट्री पर O(लॉग n)।

### इनसेरशन

```
function insert(node, value):
    if node is null: return new Node(value)
    if value < node.value:
        node.left = insert(node.left, value)
    else:
        node.right = insert(node.right, value)
    return node
```

### देलेशन

देलेशन सबसे पेचीदा ऑपरेशन है। तीन मामले बनते हैं:

1. **लेअफ़ नोड** - बस हटा दो।
2. **एक चिलद** - नोड को उसके चिलद से रेपलके कर दो।
3. **दो चिलदरेन** - नोड की वैल्यू को उसके इन-ओरदेर सुककेसोर (रिघट सुबटरी की सबसे छोटी वैल्यू) से सवप करो, फिर उस सुककेसोर को डिलीट करो।

## बलनकेद vs उनबलनकेद

अगर आप सॉर्टेड डेटा को एक पलैन BST में इन्सर्ट करो, तो वो एक लिंक्ड लिस्ट बन जाता है - हर ऑपरेशन O(n)। **सेलफ़-बलनकिङ** ट्री इसे फ़िक्स करते हैं:

| टरी | बलनके रुले | टयपिकल उपयोग |
|------|-------------|-------------|
| AVL | सुबटरीस के बीच ऊँचाई दिफ़फ़ेरेनके ≤ 1 | इन-मेमोरय लूकुपस |
| रेद-बलक | कोलोउर-बसेद रोटशन रुलेस | भाषा सटनदरद लिबररिएस (जैसे जव टरीमप) |
| ब-टरी | हर नोड में कई की, सभी लेअवेस एक ही गहराई पर | दटबसेस और फ़ाइल सिस्टम |

<FunFact>PostgreSQL और मयसकल दोनों अपने देफ़ौलट इंडेक्स संरचना के लिए ब-टरी वरिअनटस उपयोग करते हैं। बरनचिङ फ़कटोर 100 वाला ब-टरी सिर्फ पाँच लेवेलस में एक बिललिओन रोवस को इंडेक्स कर सकता है।</FunFact>

## टरी टरवेरसलस

टरवेरसलस हर नोड को ठीक एक बार विसिट करते हैं। तीन क्लासिक ओरदेरस में फ़र्क सिर्फ इतना है कि वर्तमान नोड को उसके चिलदरेन के रेलटिवे **कब** प्रोसेस किया जाता है।

| टरवेरसल | ओरदेर | उपयोग कसे |
|-----------|-------|----------|
| **इन-ओरदेर** | लेफ़ट → Node → रिघट | BST से सॉर्टेड आउटपुट निकालना |
| **परे-ओरदेर** | Node → लेफ़ट → रिघट | टरी को सेरिअलिसे / क्लोन करना |
| **पोसट-ओरदेर** | लेफ़ट → रिघट → Node | टरी को सफ़ेलय डिलीट करना; एक्सपरेसिओन ट्री एवलुअटे करना |

```
function inOrder(node):
    if node is null: return
    inOrder(node.left)
    process(node)
    inOrder(node.right)
```

<ThinkAboutIt>एक कोमपिलेर आपके कोड को अबसटरकट सयनटक्स टरी (AST) में PRsे करता है। एक्सपरेसिओन `(3 + 5) * 2` को ट्री में सटोरे करने पर एवलुअटे करने के लिए कौन सा टरवेरसल order उपयोग करोगे? क्यों?</ThinkAboutIt>

## हेअपस और परिओरिटय क्वेउएस

**हेअप** एक पूरा बाइनरी ट्री है जहाँ हर परेनट अपने चिलदरेन से बड़ा (मक्स-हेअप) या छोटा (मिन-हेअप) होता है। यह सपोर्ट करता है:

- **इनसेरट** - एनद में जोड़ें करो, बुबबले up करो। O(लॉग n)।
- **एक्सटरकट मिन/मक्स** - रूट हटाओ, लसट एलिमेंट को रूट पर लाओ, सिफ़ट दोवन करो। O(लॉग n)।

परिओरिटय क्यू जो हेअपस पर बनी हैं, ये चीज़ें पोवेर करती हैं:
- **दिजकसटर's अलगोरिथम** (अगला पाठ!) - हमेशा नेअरेसट उनविसिटेद नोड को एक्सपनद करो।
- **काम सचेदुलिङ** - OS सचेदुलेरस हिघेसट-परिओरिटय प्रोसेस को पिक करते हैं।
- **बेअम सर्च in NLP** - टोप-क सबसे परोमिसिङ सेनटेनके कोमपलेशनस रखो।

```
function siftUp(heap, index):
    while index > 0:
        parent = (index - 1) / 2
        if heap[index] < heap[parent]:
            swap(heap, index, parent)
            index = parent
        else: break
```

## वास्तविक AI अपपलिकशनस

- **देकिसिओन ट्री** मशीन लर्निंग में हर नोड पर डेटा को उस फ़ीचर से सपलिट करते हैं जो कलसेस को सबसे अच्छे से सेपरटे करता है - ट्री संरचना का दिरेकट अपपलिकशन।
- **सयनटक्स ट्री** NLP में गरममटिकल संरचना रेपरेसेनट करते हैं, जो सेनटिमेनट विश्लेषण और मचिने टरनसलशन जैसे टसकस एनबले करते हैं।
- **मोनटे करलो टरी सर्च (MCTS)** अलफगो जैसी गमे-पलयिङ AI को पोवेर करता है, पोसिबले मोवेस को गमे सटटेस के ट्री के रूप में एक्सपलोरे करता है।
- **हुफ़फ़मन ट्री** फ़रेक्वेनट सयमबोलस को शोरटेर कोदेस असाइन करके डेटा कोमपरेस करते हैं - मॉडल वज़न कोमपरेसिओन में उपयोग होते हैं।

<FunFact>scikit-learn निर्णय ट्री कलसिफ़िएर एक ऐसा ट्री बनाता है जहाँ हर इनटेरनल नोड एक फ़ीचर थरेशोलद टेस्ट करता है। देपथ 20 वाला टरैनेद मॉडल दस लाख से ज़्यादा दिसटिनकट निर्णय रास्ते रेपरेसेनट कर सकता है।</FunFact>

<ThinkAboutIt>अगर आप एक औटोकोमपलेटे सयसटेम बना रहे हो, तो BST, हीप, या कोई और ट्री संरचना (जैसे ट्राइ) - कौन सा उपयोग करोगे? सोचो कि कौन से ऑपरेशन तेज़ होने चाहिए।</ThinkAboutIt>

## मुख्य बातें

1. बसटस O(लॉग n) सर्च, इन्सर्ट, और डिलीट देते हैं - लेकिन तभी जब संतुलित हों।
2. टरवेरसल order तय करता है कि ट्री से कौन सी जानकारी निकलेगी।
3. हेअपस एक्सटरेमे वैल्यू तक O(1) एक्सेस और O(लॉग n) इन्सर्शन देते हैं - परिओरिटय-बसेद AI अलगोरिथमस के लिए इदेअल।
4. टरीस ML, दटबसेस, कोमपिलेरस, और गमे AI में देकिसिओन-मकिङ की नींव हैं।
