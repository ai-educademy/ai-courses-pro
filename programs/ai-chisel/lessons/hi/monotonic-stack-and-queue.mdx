## स्टैक को मोनोटोनिक क्या बनाता है?

एक **मोनोटोनिक स्टैक** एलिमेंट को नीचे से शीर्ष तक सख्ती से बढ़ते या घटते क्रम में बनाए रखता है। नया एलिमेंट पुश करने से पहले, आप उन सभी एलिमेंट को पॉप कर देते हैं जो इनवेरिएंट को तोड़ते हैं। यह एक सरल विचार O(n²) लगने वाली समस्याएँ को O(n) में हल कर देता है।

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## Next Greater Element

हर एलिमेंट के लिए, उसके दाईं ओर पहला बड़ा एलिमेंट ढूँढना है। ब्रूट फोर्स हर स्थिति से दाएँ की तरफ स्कैन करता है - O(n²)। एक मोनोटोनिक घटते स्टैक यह काम एक ही पास में कर देता है।

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

जब हम इंडेक्स `j` को पॉप करते हैं, तो वर्तमान एलिमेंट उसका नेक्स्ट ग्रेटर है - यह गारंटी है क्योंकि बीच के सारे एलिमेंट छोटे थे (वे पहले पॉप हो गए थे या `j` को कभी ब्लॉक नहीं किया)।

## दैनिक तापमान (LeetCode 739)

*दैनिक तापमान दी गई हैं, पता करें कि गर्म दिन आने में कितने दिन लगेंगे।* यह नेक्स्ट ग्रेटर एलिमेंट है इंडेक्स के साथ - इंडेक्स `j` का उत्तर `i − j` होता है जब `j` को इंडेक्स `i` पॉप करता है।

## स्टॉक स्पैन समस्या

*हर दिन के लिए, कितने लगातार दिनों (आज सहित) की कीमत आज की कीमत से ≤ थी?* एक मोनोटोनिक घटते स्टैक इस्तेमाल करें जिसमें `(price, index)` स्टोर हो। जब आप पॉप करते हैं, वर्तमान इंडेक्स और नए स्टैक शीर्ष के बीच का gap स्पैन देता है।

## सबसे-बड़ा रेक्टैंगल in हिस्टोग्राम

LeetCode का **सबसे-बड़ा रेक्टैंगल in हिस्टोग्राम** मोनोटोनिक स्टैक समस्याएँ का सबसे शानदार समस्याओं में से एक है।

**मुख्य समझ:** हर बार के लिए पता करें कि वह सबसे छोटी बार होते हुए बाएँ और दाएँ कितनी दूर तक फैल सकती है। बढ़ता स्टैक इस्तेमाल करें - जब कोई बार pop होती है, वही निकली हुई बार उसकी दाईं सीमा तय करती है, और नया स्टैक शीर्ष बाईं सीमा तय करता है।

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

अंत में टर्म `[0]` बाकी सभी बार को प्रोसेस करने के लिए फोर्स करता है।

## ट्रैपिंग रेन वॉटर - स्टैक तरीका

क्लासिक two-pointer विधि की जगह, एक मोनोटोनिक घटते स्टैक ट्रैप्ड वॉटर को परत by परत गणना करता है। जब एक ऊँची बार आती है, छोटी बार को पॉप करें और टर्म बर, वर्तमान बर, और नए स्टैक शीर्ष के बीच ट्रैप्ड वॉटर गणना करें।

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>ट्रैपिंग रेन वॉटर के कम से कम चार अलग-अलग O(n) समाधान हैं - two-pointer, मोनोटोनिक स्टैक, प्रीफ़िक्स max ऐरे, और एक एकल-pass ओपटिमिसेद तरीका। इंटरव्यूअर को कई रणनीतियाँ देखना बहुत पासंद है।</FunFact>

## मोनोटोनिक क्यू - स्लाइडिंग विंडो अधिकतम

एक **मोनोटोनिक डेक** (डबल-एंडेड क्यू) घटता क्रम बनाए रखता है और दोनों छोरों से कुशलता से हटा सकता है। **स्लाइडिंग विंडो अधिकतम** (LeetCode 239) के लिए:

1. इंडेक्स `i` जोड़ें करने से पहले, बैक के सभी एलिमेंट जो `nums[i]` से छोटे हैं उन्हें पॉप करें
2. `i` को बैक में पुश करें
3. फ़्रंट हमेशा वर्तमान विंडो का अधिकतम होता है
4. अगर फ़्रंट विंडो के बाहर चला गया है तो उसे हटा करें

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

हर एलिमेंट डेक में ज़्यादा से ज़्यादा एक बार टर्म और टर्म करता है - कुल **O(n)**।

## पैटर्न - टर्म करते समय इनवेरिएंट बनाए करें

हर मोनोटोनिक स्टैक/क्यू समस्या एक ही टर्म फ़ॉलो करती है:

1. **इनवेरिएंट परिभाषित करें** (बढ़ते या घटते)
2. **टर्म को पॉप करें** - और हर पॉप से उपयोगी जानकारी निकालें
3. **वर्तमान एलिमेंट पुश करें**
4. *पॉप घटना* वह जगह है जहाँ उत्तर कम्प्यूट होता है
