## सटक को मोनोटोनिक क्या बनाता है?

एक **मोनोटोनिक स्टैक** एलिमेंट को नीचे से शीर्ष तक सख्ती से बढ़ते या घटते क्रम में बनाए करता है। नया एलिमेंट पुश करने से पहले, आप उन सभी एलिमेंट को पॉप कर देते हैं जो इनवेरिएंट को उल्लंघन करते हैं। यह एक सरल विचार O(n²) लगने वाली समस्याएँ को O(n) में हल कर देता है।

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## नेक्सट गरेअटेर एलेमेनट

हर एलिमेंट के लिए, उसके दाईं ओर पहला बड़ा एलिमेंट ढूंढना है। बरुटे फ़ोर्स हर स्थिति से अधिकार की तरफ सकन करता है - O(n²)। एक मोनोटोनिक घटते स्टैक यह काम एक ही पस में कर देता है।

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

जब हम इंडेक्स `j` को पॉप करते हैं, तो वर्तमान एलिमेंट उसका नेक्सट गरेअटेर है - यह गारंटी है क्योंकि बीच के सारे एलिमेंट छोटे थे (वे पहले पॉप हो गए थे या `j` को कभी ब्लॉक नहीं किया)।

## दैनिक तापमानस (LeetCode 739)

*दैनिक तापमानस दी गई हैं, पता करें कि गर्म दिन आने में कितने दिन लगेंगे।* यह नेक्सट-गरेअटेर-एलेमेनट है इंडेक्स के साथ - इंडेक्स `j` का उत्तर `i − j` होता है जब `j` को इंडेक्स `i` पॉप करता है।

## सटोक सपन समस्या

*हर दिन के लिए, कितने लगातार दिनों (आज सहित) की कीमत आज की कीमत से ≤ थी?* एक मोनोटोनिक घटते स्टैक इस्तेमाल करें जिसमें `(price, index)` स्टोर हो। जब आप पॉप करते हैं, वर्तमान इंडेक्स और नए स्टैक शीर्ष के बीच का गप सपन देता है।

## बड़ेसट रेकटङले in हिसटोगरम

LeetCode का **बड़ेसट रेकटङले in हिसटोगरम** मोनोटोनिक स्टैक समस्याएँ का सबसे शानदार समस्या है।

**मुख्य insight:** हर bar के लिए पता करें कि वह सबसे छोटी bar होते हुए left और right कितनी दूर तक extend कर सकती है। increasing stack इस्तेमाल करें - जब कोई bar pop होती है, वही popping bar उसकी right boundary तय करती है, और नया stack top left boundary तय करता है।

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

अंत में सेनटिनेल `[0]` बाकी सभी बरस को प्रोसेस करने के लिए फ़ोर्स करता है।

## टरपपिङ रैन वटेर - सटक तरीका

कलसिक टवो-पोइनटेर विधि की जगह, एक मोनोटोनिक घटते स्टैक टरपपेद वटेर को परत by परत कलकुलटे करता है। जब एक ऊँची बर आती है, छोटी बरस को पॉप करें और पॉपपेद बर, वर्तमान बर, और नए स्टैक शीर्ष के बीच टरपपेद वटेर कलकुलटे करें।

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>टरपपिङ रैन वटेर के कम से कम चार अलग-अलग O(n) समाधान हैं - टवो-पोइनटेर, मोनोटोनिक स्टैक, प्रीफ़िक्स मक्स ऐरे, और एक एकल-पस ओपटिमिसेद तरीका। इनटेरविएवेरस को कई रणनीतियाँ देखना बहुत पसंद है।</FunFact>

## मोनोटोनिक क्यू - स्लाइडिंग विंडो अधिकतम

एक **मोनोटोनिक डेक** (डबल-एंडेड क्यू) घटता क्रम बनाए करता है और दोनों छोरों से कुशलता से हटा कर सकता है। **स्लाइडिंग विंडो अधिकतम** (LeetCode 239) के लिए:

1. इनदेक्स `i` जोड़ें करने से पहले, बक के सभी एलिमेंट जो `nums[i]` से छोटे हैं उन्हें पॉप करें
2. `i` को बक में पुश करें
3. फ़रोनट हमेशा वर्तमान विंडो का मक्सिमुम होता है
4. अगर फ़रोनट विंडो के बाहर चला गया है तो उसे हटा करें

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

हर एलिमेंट डेक में ज़्यादा से ज़्यादा एक बार एनटेर और लेअवे करता है - कुल **O(n)**।

## पटटेरन - परोकेस करते समय इनवेरिएंट बनाए करें

हर मोनोटोनिक सटक/क्यू समस्या एक ही टेमपलटे फ़ॉलो करती है:

1. **इनवेरिएंट परिभाषित करें** (बढ़ते या घटते)
2. **विओलटोरस को पॉप करें** - और हर पॉप से उपयोगी जानकारी निकालें
3. **वर्तमान एलिमेंट पुश करें**
