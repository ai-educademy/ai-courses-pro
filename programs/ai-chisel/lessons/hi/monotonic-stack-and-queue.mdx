## स्टैक को मोनोटोनिक क्या बनाता है?

**मोनोटोनिक स्टैक** नीचे से ऊपर तक एलिमेंट को सख़्ती से बढ़ते या घटते क्रम में रखता है। नया एलिमेंट डालने से पहले आप invariant तोड़ने वाली हर चीज़ pop करते हैं। यही एक विचार उन समस्याओं के लिए O(n) समाधान खोलता है जो O(n²) माँगती हुई लगती हैं।

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## Next Greater Element

हर एलिमेंट के लिए उसके दाईं ओर पहला बड़ा एलिमेंट खोजें। बलपूर्वक तरीका हर स्थिति के लिए दाईं ओर स्कैन करता है। O(n²)। मोनोटोनिक घटता स्टैक इसे एक पास में करता है।

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

जब हम index `j` pop करते हैं, तो वर्तमान एलिमेंट उसका next greater होता है। यह गारंटी है, क्योंकि बीच के सभी एलिमेंट छोटे थे। वे पहले pop हो चुके थे या `j` को रोक ही नहीं पाए।

## Largest Rectangle in Histogram

LeetCode की **Largest Rectangle in Histogram** मोनोटोनिक स्टैक समस्याओं का शिखर है।

**मुख्य समझ:** हर bar के लिए खोजें कि वह सबसे छोटी bar रहते हुए कितनी दूर बाएँ और दाएँ फैल सकती है। बढ़ता स्टैक इस्तेमाल करें। जब कोई bar pop होती है, तो pop कराने वाली bar उसकी दाईं सीमा तय करती है और नया stack top उसकी बाईं सीमा तय करता है।

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

अंत में sentinel `[0]` बची हुई सभी bars को प्रोसेस करवाता है।

## Trapping Rain Water - स्टैक तरीका

क्लासिक दो-पॉइंटर तरीके के बजाय, मोनोटोनिक घटता स्टैक फँसे पानी को परत दर परत निकालता है। जब ऊँची bar आती है, तो छोटी bars pop करें और popped bar, वर्तमान bar और नए stack top के बीच फँसा पानी निकालें।

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>Trapping Rain Water के कम से कम चार अलग O(n) समाधान हैं: दो-पॉइंटर, मोनोटोनिक स्टैक, prefix max arrays और single-pass optimised approach। इंटरव्यूअर कई रणनीतियाँ देखना पसंद करते हैं।</FunFact>

## मोनोटोनिक क्यू - Sliding Window Maximum

**मोनोटोनिक deque** (double-ended queue) घटता क्रम बनाए रखता है और दोनों सिरों से कुशल हटाने का समर्थन करता है। **Sliding Window Maximum** (LeetCode 239) के लिए:

1. index `i` जोड़ने से पहले, पीछे के वे सभी एलिमेंट pop करें जो `nums[i]` से छोटे हैं
2. `i` को पीछे जोड़ें
3. सामने वाला एलिमेंट हमेशा वर्तमान विंडो का maximum है
4. अगर सामने वाला index विंडो से बाहर चला गया है, तो उसे हटाएँ

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

हर एलिमेंट deque में अधिकतम एक बार आता है और अधिकतम एक बार निकलता है। कुल **O(n)**।

## पैटर्न - प्रोसेस करते समय invariant बनाए रखें

हर मोनोटोनिक स्टैक/क्यू समस्या एक टेम्पलेट का पालन करती है:

1. **invariant तय करें** (बढ़ता या घटता)
2. **उल्लंघन करने वालों को pop करें** और हर pop से उपयोगी जानकारी निकालें
3. **वर्तमान एलिमेंट push करें**
4. उत्तर की गणना *pop event* पर होती है
