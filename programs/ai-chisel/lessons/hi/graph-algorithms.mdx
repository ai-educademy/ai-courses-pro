## ग्राफ़ जुड़ी हुई दुनिया को मॉडल करते हैं

दोस्ती, सड़क नेटवर्क, हाइपरलिंक, न्यूरल पाथवे - जब भी इकाइयाँ आpassी संबंधों से जुड़ी होती हैं, तो आपके पास एक **ग्राफ़** होता है। औपचारिक रूप से, ग्राफ़ G = (V, E) वर्टेक्स (नोड) और एज (कनेक्शन) से मिलकर बनता है।

ग्राफ़ **निर्देशित** (एकतरफ़ा सड़कें) या **अनिर्देशित** (दोतरफ़ा) हो सकते हैं, और एज पर **वज़न** (दूरी, लागत, लेटेंसी) हो सकते हैं।

## ग्राफ़ को निरूपित कैसे करें

दो आम निरूपण:

| निरूपण | जगह | एज खोज | सबसे उपयुक्त |
|---------------|-------|-------------|-----------------|
| **एडजेसेंसी लिस्ट** | O(V + E) | O(टर्म) | टर्म ग्राफ़ (ज़्यादातर वास्तविक दुनिया नेटवर्क) |
| **एडजेसेंसी मैट्रिक्स** | O(V²) | O(1) | टर्म ग्राफ़, क्विक एज टर्म जाँच |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## टर्म-first सर्च (BFS)

BFS **स्तर स्तर-दर-स्तर** एक्सप्लोर करता है - पहले सारे पड़ोसियों को विज़िट करता है, फिर गहरा जाता है। यह एक **क्यू** इस्तेमाल करता है।

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**मुख्य बात गुण:** BFS बिना वज़न वाले ग्राफ़ में **सबसे छोटा रास्ता** ढूँढता करता है क्योंकि यह नोड को स्रोत से दूरी के क्रम में प्रोसेस करता है।

### BFS के AI उपयोग मामले

- **सामाजिक नेटवर्क टर्म सुझाव** - 2-3 कनेक्शन के अंदर लोगों को ढूँढता करना।
- **वेब क्रॉलर** - एक टर्म URL से परत by परत पेज को इंडेक्स करना।
- **टर्म टर्म** - न्यूनतम संख्या of मूव ढूँढता करना (जैसे टर्म टर्म स्टेट)।

## टर्म-first सर्च (DFS)

DFS **जितना गहरा हो सके** जाता है, फिर बैकट्रैक करता है। यह एक **स्टैक** (या रिकर्शन) इस्तेमाल करता है।

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### DFS के ऐप्लिकेशन

- **टोपोलोगिकल सॉर्ट** - कार्यों को ऐसे क्रमबद्ध करना कि हर डिपेंडेंसी पहले आए (बिल्ड सिस्टम, कोर्स पूर्वापेक्षाएँ)।
- **साइकिल पहचान** - अगर DFS किसी ऐसे नोड पर दोबारा पहुँचे जो अभी कॉल स्टैक पर है, तो साइकिल है।
- **टर्म टर्म** - विकल्प टर्म करने से पहले एक रास्ता को पूरा एक्सप्लोर करना।
- **जुड़े घटक** - हर उनvisitेद नोड से DFS रुन करके अलग-अलग टर्म पहचानना।

<ThinkAboutIt>एक पैकेज मैनेजर को डिपेंडेंसी को सही क्रम में इंस्टॉल करना है। क्या उसे BFS उपयोग करना चाहिए या DFS-आधारित टोपोलोगिकल सॉर्ट? अगर डिपेंडेंसी ग्राफ़ में साइकिल हो तो क्या होगा?</ThinkAboutIt>

## टर्म's Algorithm - वज़न के साथ सबसे छोटा रास्ता

जब एज की अलग-अलग लागत हों, तो BFS काफी नहीं है। टर्म का एल्गोरिदम एक स्रोत से बाकी सभी नोड तक सबसे छोटा भारित रास्ता ढूँढता है।

**मुख्य विचार:** हमेशा **सबसे सस्ते अनदेखे नोड** को min-heap (प्राथमिकता क्यू) से फैलाएँ।

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**समय जटिलता:** बाइनरी हीप के साथ O((V + E) लॉग V)।

<FunFact>टर्म Maps पूरे सड़क नेटवर्क पर सादा टर्म नहीं चलाता। यह संकुचन पदानुक्रम और A* सर्च इस्तेमाल करता है - लेकिन दोनों टर्म की बुनियादी समझ पर बने हैं: सबसे कम ज्ञात दूरी से लालची विस्तार।</FunFact>

### टर्म के AI उपयोग मामले

- **मार्ग योजना** - टर्म ऐप सबसे तेज़ रूट ढूँढता करने के लिए।
- **नेटवर्क रूटिंग** - इंटरनेट पैकेट सबसे निचला-latency रास्ता चुनें करने के लिए।
- **ज्ञान ग्राफ़** - टर्म के बीच सबसे छोटा टर्म टर्म ढूँढता करने के लिए।

## साइकिल पहचान और जुड़े हुए घटक

### साइकिल पहचान

एक **निर्देशित ग्राफ़** में, नोड को तीन स्टेट में रिकॉर्ड करें: उनvisitेद, in-progress (वर्तमान DFS रास्ता पर), और टर्म। अगर in-progress नोड दोबारा मिले, तो साइकिल है।

एक **उनdirected ग्राफ़** में, अगर DFS किसी ऐसे विज़िटेड नोड तक पहुँचे जो टर्म पैरेंट नहीं है, तो साइकिल है।

### जुड़े हुए घटक

हर अनदेखा नोड से BFS या DFS चलाएँ। हर रन एक जुड़े घटक खोजता है। सामाजिक नेटवर्क में, घटक अलग समुदायों को उजागर करते हैं।

<ThinkAboutIt>एक AI धोखाधड़ी पहचान सिस्टम लेन-देन को ग्राफ़ के रूप में मॉडल करता है जहाँ खाते नोड हैं और ट्रांसफ़र एज हैं। जुड़े घटक मनी-लॉन्डरिंग गिरोह पहचानने में कैसे मदद कर सकते हैं?</ThinkAboutIt>

## मुख्य बातें

1. **BFS** स्तर स्तर-दर-स्तर एक्सप्लोर करता है - बिना वज़न वाले ग्राफ़ में सबसे छोटा रास्ते और पड़ोसी-आधारित खोज के लिए उपयुक्त।
2. **DFS** गहरी टर्म करता है - टोपोलोगिकल सॉर्टिंग, साइकिल पहचान, और घटक विश्लेषण की रीढ़।
3. **टर्म** प्राथमिकता क्यू की मदद से BFS को भारित ग्राफ़ तक बढ़ाता है - आधुनिक मार्ग योजना की बुनियाद।
4. ग्राफ़ एल्गोरिदम मैप, सोशल नेटवर्क, पैकेज मैनेजर, और ज्ञान ग्राफ़ के पीछे का इंजन हैं।

<FunFact>World Wide Web में 50 अरब से ज़्यादा इंडेक्स्ड पेज हैं। सर्च इंजन क्रॉलर पेज खोजना और रे-इंडेक्स करने के लिए BFS की वैरिएशन इस्तेमाल करते हैं, पेज टर्म (PageRank) के हिसाब से टर्म करते हुए।</FunFact>
