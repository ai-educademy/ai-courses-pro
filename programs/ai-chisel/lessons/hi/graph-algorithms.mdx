## ग्राफ़ जुड़ी हुई दुनिया को मॉडल करते हैं

दोस्ती, सड़क नेटवर्क, हाइपरलिंक, न्यूरल पाथवे - जब भी इकाइयाँ रिश्तों से जुड़ी हों, आपके पास **ग्राफ़** होता है। औपचारिक रूप से, ग्राफ़ G = (V, E) में वर्टेक्स (नोड) और एज (कनेक्शन) होते हैं।

ग्राफ़ **दिशित** (एकतरफ़ा सड़कें) या **अदिशित** (दोतरफ़ा) हो सकते हैं, और एज पर **वेट** (दूरी, लागत, लेटेंसी) हो सकता है।

## ग्राफ़ को दर्शाना

दो आम निरूपण:

| निरूपण | स्पेस | एज लुकअप | सबसे अच्छा उपयोग |
|---------------|-------|-------------|----------|
| **ऐडजेसेंसी लिस्ट** | O(V + E) | O(degree) | विरल ग्राफ़ (अधिकतर वास्तविक नेटवर्क) |
| **ऐडजेसेंसी मैट्रिक्स** | O(V²) | O(1) | घने ग्राफ़, एज मौजूद है या नहीं इसकी तेज़ जाँच |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## Breadth-First Search (BFS)

BFS **स्तर दर स्तर** खोजता है। गहराई में जाने से पहले वह सभी पड़ोसियों को देखता है। यह **क्यू** इस्तेमाल करता है।

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**मुख्य गुण:** BFS बिना वेट वाले ग्राफ़ में **सबसे छोटा रास्ता** खोजता है, क्योंकि वह स्रोत से दूरी के क्रम में नोड प्रोसेस करता है।

### BFS के AI उपयोग

- **सोशल नेटवर्क में मित्र सुझाव** - 2-3 कनेक्शन के भीतर लोगों को ढूँढना।
- **वेब क्रॉलर** - किसी seed URL से पेजों को परत दर परत इंडेक्स करना।
- **पहेली हल करने वाले सिस्टम** - चालों की न्यूनतम संख्या ढूँढना, जैसे Rubik's cube अवस्थाएँ।

## Depth-First Search (DFS)

DFS बैकट्रैक करने से पहले **जितना सम्भव हो उतना गहरा** जाता है। यह **स्टैक** या रिकर्शन इस्तेमाल करता है।

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### DFS के उपयोग

- **टोपोलॉजिकल सॉर्ट** - कामों को ऐसे क्रम में रखना कि हर निर्भरता पहले आए, जैसे बिल्ड सिस्टम और कोर्स पूर्वापेक्षाएँ।
- **चक्र पहचान** - अगर DFS कॉल स्टैक पर मौजूद नोड को फिर देखे, तो चक्र है।
- **भूलभुलैया हल करना** - विकल्प आज़माने से पहले एक रास्ते को पूरा खोजना।
- **कनेक्टेड कॉम्पोनेंट** - हर अनदेखे नोड से DFS चलाकर अलग क्लस्टर पहचानना।

<ThinkAboutIt>पैकेज मैनेजर को निर्भरताएँ सही क्रम में इंस्टॉल करनी हैं। क्या उसे BFS इस्तेमाल करना चाहिए या DFS-आधारित टोपोलॉजिकल सॉर्ट? अगर निर्भरता ग्राफ़ में चक्र हो तो क्या होगा?</ThinkAboutIt>

## Dijkstra's Algorithm - वेट के साथ सबसे छोटा रास्ता

जब एज की लागत अलग-अलग हो, तो BFS काफ़ी नहीं रहता। Dijkstra's algorithm किसी स्रोत से बाकी सभी नोड तक सबसे छोटा वेटेड रास्ता खोजता है।

**मुख्य विचार:** min-heap (प्रायोरिटी क्यू) से हमेशा **सबसे सस्ता अनदेखा नोड** फैलाएँ।

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**समय जटिलता:** बाइनरी हीप के साथ O((V + E) log V)।

<FunFact>Google Maps पूरे सड़क नेटवर्क पर साधारण Dijkstra नहीं चलाता। वह contraction hierarchies और A* search इस्तेमाल करता है, लेकिन दोनों Dijkstra की सबसे छोटी ज्ञात दूरी से लालची विस्तार वाली बुनियादी समझ पर बने हैं।</FunFact>

### Dijkstra के AI उपयोग

- **रूट प्लानिंग** - नेविगेशन ऐप सबसे तेज़ ड्राइव ढूँढते हैं।
- **नेटवर्क रूटिंग** - इंटरनेट पैकेट सबसे कम लेटेंसी वाला रास्ता चुनते हैं।
- **नॉलेज ग्राफ़** - अवधारणाओं के बीच सबसे छोटा अर्थपूर्ण संबंध ढूँढना।

## चक्र पहचान और कनेक्टेड कॉम्पोनेंट

### चक्र पहचान

**दिशित ग्राफ़** में नोड को तीन अवस्थाओं में ट्रैक करें: अनदेखा, प्रगति में (वर्तमान DFS पथ पर), और पूरा। प्रगति में मौजूद नोड फिर मिलना चक्र का संकेत है।

**अदिशित ग्राफ़** में चक्र तब है जब DFS किसी ऐसे देखे गए नोड तक पहुँचे जो तुरंत वाला पैरेंट नहीं है।

### कनेक्टेड कॉम्पोनेंट

हर अनदेखे नोड से BFS या DFS चलाएँ। हर रन एक कनेक्टेड कॉम्पोनेंट खोजता है। सोशल नेटवर्क में कॉम्पोनेंट अलग-थलग समुदाय दिखाते हैं।

<ThinkAboutIt>AI धोखाधड़ी पहचान सिस्टम लेन-देन को ग्राफ़ की तरह मॉडल करता है, जहाँ खाते नोड हैं और ट्रांसफ़र एज। कनेक्टेड कॉम्पोनेंट मनी-लॉन्डरिंग रिंग पहचानने में कैसे मदद कर सकते हैं?</ThinkAboutIt>

## मुख्य बातें

1. **BFS** स्तर दर स्तर खोजता है। यह बिना वेट वाले ग्राफ़ में सबसे छोटे रास्ते और पड़ोसी-आधारित खोज के लिए आदर्श है।
2. **DFS** गहराई में जाता है। टोपोलॉजिकल सॉर्ट, चक्र पहचान और कॉम्पोनेंट विश्लेषण की रीढ़ यही है।
3. **Dijkstra** प्रायोरिटी क्यू से BFS को वेटेड ग्राफ़ तक बढ़ाता है। आधुनिक रूट प्लानिंग की नींव यही है।
4. ग्राफ़ एल्गोरिदम मैप, सोशल नेटवर्क, पैकेज मैनेजर और नॉलेज ग्राफ़ के पीछे का इंजन हैं।

<FunFact>World Wide Web में 50 अरब से अधिक इंडेक्स किए गए पेज हैं। सर्च इंजन क्रॉलर पेज खोजने और फिर से इंडेक्स करने के लिए BFS के वैरिएशन इस्तेमाल करते हैं, और पेज के महत्व (PageRank) के आधार पर प्राथमिकता देते हैं।</FunFact>
