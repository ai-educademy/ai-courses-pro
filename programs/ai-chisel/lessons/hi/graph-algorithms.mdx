## ग्राफ़ जुड़ी हुई दुनिया को मॉडल करते हैं

दोस्ती, सड़क नेटवर्क, हाइपरलिंक, न्यूरल पाथवे - जब भी इकाइयाँ आपसी संबंधों से जुड़ी होती हैं, तो आपके पास एक **ग्राफ़** होता है। औपचारिक रूप से, ग्राफ़ G = (V, E) वर्टेक्स (नोड) और एज (कनेक्शन) से मिलकर बनता है।

ग्राफ़ **निर्देशित** (एकतरफ़ा सड़कें) या **अनिर्देशित** (दोतरफ़ा) हो सकते हैं, और एज पर **वज़न** (दूरी, लागत, लेटेंसी) हो सकते हैं।

## ग्राफ़ को निरूपित कैसे करें

दो आम निरूपण:

| निरूपण | जगह | एज खोज | सबसे उपयुक्त |
|---------------|-------|-------------|-----------------|
| **अदजकेनकय लिस्ट** | O(V + E) | O(देगरी) | सPRsे ग्राफ़ (ज़्यादातर वास्तविक दुनिया नेटवोरकस) |
| **अदजकेनकय मैट्रिक्स** | O(V²) | O(1) | देनसे ग्राफ़, क्विक एज एक्सिसटेनके चेकस |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## बरेअदथ-फ़िरसट सर्च (BFS)

BFS **स्तर by स्तर** एक्सप्लोर करता है - पहले सारे नेइघबोउरस को विसिट करता है, फिर दीपेर जाता है। यह एक **क्यू** उपयोग करता है।

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**मुख्य बात गुण:** BFS बिना वज़न वाले ग्राफ़ में **सबसे छोटा रास्ता** फ़ाइंड करता है क्योंकि यह नोड को स्रोत से दूरी के क्रम में प्रोसेस करता है।

### BFS के AI उपयोग कसेस

- **सामाजिक नेटवर्क फ़रिएनद सुझाव** - 2-3 कनेक्शन के अंदर लोगों को फ़ाइंड करना।
- **वेब करवलेरस** - एक सीद URL से परत by परत पेज को इंडेक्स करना।
- **पुज़ज़ले सोलवेरस** - न्यूनतम नुमबेर of मोवेस फ़ाइंड करना (जैसे रुबिक's कुबे सटटेस)।

## देपथ-फ़िरसट सर्च (DFS)

DFS **जितना गहरा हो सके** जाता है, फिर बैकट्रैक करता है। यह एक **स्टैक** (या रिकर्शन) इस्तेमाल करता है।

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### DFS के ऐप्लिकेशन

- **टोपोलोगिकल सॉर्ट** - कार्यों को ऐसे क्रमबद्ध करना कि हर डिपेंडेंसी पहले आए (बिल्ड सिस्टम, कोर्स पूर्वापेक्षाएँ)।
- **कयकले पहचान** - अगर DFS किसी ऐसे नोड पर दोबारा पहुँचे जो अभी कॉल स्टैक पर है, तो साइकिल है।
- **मज़े सोलविङ** - अलटेरनटिवेस टरय करने से पहले एक रास्ता को पूरा एक्सप्लोर करना।
- **कोननेकटेद कोमपोनेनटस** - हर उनविसिटेद नोड से DFS रुन करके अलग-अलग कलुसटेरस इदेनटिफ़य करना।

<ThinkAboutIt>एक पैकेज मैनेजर को डिपेंडेंसी को सही क्रम में इंस्टॉल करना है। क्या उसे BFS उपयोग करना चाहिए या DFS-आधारित टोपोलोगिकल सॉर्ट? अगर डिपेंडेंसी ग्राफ़ में साइकिल हो तो क्या होगा?</ThinkAboutIt>

## Dijkstra's Algorithm - वज़न के साथ सबसे छोटा रास्ता

जब एज की अलग-अलग लागत हों, तो BFS काफी नहीं है। Dijkstra का एल्गोरिदम एक स्रोत से बाकी सभी नोड तक सबसे छोटा भारित रास्ता ढूँढता है।

**मुख्य विचार:** हमेशा **सबसे सस्ते अनदेखे नोड** को min-heap (प्राथमिकता क्यू) से फैलाएँ।

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**समय जटिलता:** बिनरय हीप के साथ O((V + E) लॉग V)।

<FunFact>Google Maps पूरे सड़क नेटवर्क पर सादा Dijkstra नहीं चलाता। यह संकुचन पदानुक्रम और A* सर्च इस्तेमाल करता है - लेकिन दोनों Dijkstra की बुनियादी समझ पर बने हैं: सबसे कम ज्ञात दूरी से लालची विस्तार।</FunFact>

### Dijkstra के AI उपयोग मामले

- **रास्ता योजना** - नविगशन ऐप सबसे तेज़ रूट फ़ाइंड करने के लिए।
- **नेटवर्क रूटिंग** - इनटेरनेट पकेटस लोवेसट-लटेनकय रास्ता चुनें करने के लिए।
- **ज्ञान ग्राफ़** - कोनकेपटस के बीच सबसे छोटा सेमनटिक कोननेकशन फ़ाइंड करने के लिए।

## कयकले देटेकशन और जुड़े हुए घटक

### कयकले देटेकशन

एक **दिरेकटेद ग्राफ़** में, नोड को तीन सटटेस में रिकॉर्ड करें: उनविसिटेद, इन-परोगरेस (वर्तमान DFS रास्ता पर), और कोमपलेटेद। अगर इन-परोगरेस नोड दोबारा मिले, तो साइकिल है।

एक **उनदिरेकटेद ग्राफ़** में, अगर DFS किसी ऐसे विज़िटेड नोड तक पहुँचे जो इममेदिअटे परेनट नहीं है, तो साइकिल है।

### जुड़े हुए घटक

हर उनविसिटेद नोड से BFS या DFS रुन करो। हर रुन एक कोननेकटेद कोमपोनेनट खोजना करता है। सामाजिक नेटवोरकस में, कोमपोनेनटस इसोलटेद कोममुनिटिएस को उजागर करते हैं।

<ThinkAboutIt>एक AI धोखाधड़ी पहचान सिस्टम लेन-देन को ग्राफ़ के रूप में मॉडल करता है जहाँ खाते नोड हैं और ट्रांसफ़र एज हैं। जुड़े घटक मनी-लॉन्डरिंग गिरोह पहचानने में कैसे मदद कर सकते हैं?</ThinkAboutIt>

## मुख्य बातें

1. **BFS** स्तर by स्तर एक्सप्लोर करता है - बिना वज़न वाले ग्राफ़ में सबसे छोटा रास्ते और नेइघबोउर-बसेद दिसकोवेरय के लिए विचारल।
2. **DFS** गहरी दिवे करता है - टोपोलोगिकल सॉर्टिंग, साइकिल पहचान, और कोमपोनेनट विश्लेषण की बकबोने।
3. **Dijkstra** प्राथमिकता क्यू की मदद से BFS को भारित ग्राफ़ तक बढ़ाता है - आधुनिक मार्ग योजना की बुनियाद।
4. गरफ एल्गोरिदमस मपस, सोकिअल नेटवोरकस, पैकेज मैनेजर, और ज्ञान ग्राफ़ के पीछे का एङिने हैं।

<FunFact>वोरलद विदे वेब में 50 बिललिओन से ज़्यादा इनदेक्सेद पेज हैं। सर्च एङिने करवलेरस पेज खोजना और रे-इनदेक्स करने के लिए BFS की वरिअशनस उपयोग करते हैं, पगे इमपोरटनके (पगेरनक) के हिसाब से परिओरिटिसे करते हुए।</FunFact>
