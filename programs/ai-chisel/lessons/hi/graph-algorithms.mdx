## गरफस दुनिया के कोननेकशनस को मॉडल करते हैं

दोस्ती, रोअद नेटवोरकस, हयपेरलिनकस, न्यूरल पथवयस - जब भी एनटिटिएस आपस में रेलशनशिपस से जुड़ी होती हैं, तो आपके पास एक **ग्राफ़** होता है। फ़ोरमललय, एक ग्राफ़ G = (V, E) वर्टेक्स (नोड) और एदगेस (कनेक्शन) से मिलकर बनता है।

गरफस **दिरेकटेद** (ओने-वय सटरीटस) या **उनदिरेकटेद** (टवो-वय) हो सकते हैं, और एदगेस पर **वेट्स** (दिसटनकेस, कोसटस, लटेनकिएस) हो सकते हैं।

## गरफस को रेपरेसेनट कैसे करें

दो आम रेपरेसेनटशनस:

| रेपरेसेनटशन | सपके | एदगे लुकअप | किसके लिए बेस्ट |
|---------------|-------|-------------|-----------------|
| **अदजकेनकय लिस्ट** | O(V + E) | O(देगरी) | सPRsे ग्राफ़ (ज़्यादातर रेअल-वोरलद नेटवोरकस) |
| **अदजकेनकय मैट्रिक्स** | O(V²) | O(1) | देनसे ग्राफ़, क्विक बढ़त एक्सिसटेनके चेकस |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## बरेअदथ-फ़िरसट सर्च (BFS)

BFS **स्तर by स्तर** एक्सपलोरे करता है - पहले सारे नेइघबोउरस को विसिट करता है, फिर दीपेर जाता है। यह एक **क्यू** उपयोग करता है।

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**मुख्य बात परोपेरटय:** BFS उनवेइघटेद ग्राफ़ में **सबसे छोटा रास्ता** फ़ाइंड करता है क्योंकि यह नोड को सोउरके से दिसटनके के order में प्रोसेस करता है।

### BFS के AI उपयोग कसेस

- **सामाजिक नेटवर्क फ़रिएनद सुझाव** - 2-3 कनेक्शन के अंदर लोगों को फ़ाइंड करना।
- **वेब करवलेरस** - एक सीद URL से परत by परत पेज को इंडेक्स करना।
- **पुज़ज़ले सोलवेरस** - मिनिमुम नुमबेर of मोवेस फ़ाइंड करना (जैसे रुबिक's कुबे सटटेस)।

## देपथ-फ़िरसट सर्च (DFS)

DFS **जितना गहरी हो सके** जाता है, फिर बकटरक करता है। यह एक **स्टैक** (या रिकर्शन) उपयोग करता है।

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### DFS के अपपलिकशनस

- **टोपोलोगिकल सॉर्ट** - टसकस को ऐसे order करना कि हर देपेनदेनकय पहले आए (बनाना सिस्टम, कोर्स परेरेक्विसिटेस)।
- **कयकले पहचान** - अगर DFS किसी ऐसे नोड पर दोबारा पहुँचे जो अभी कॉल स्टैक पर है, तो साइकिल है।
- **मज़े सोलविङ** - अलटेरनटिवेस टरय करने से पहले एक रास्ता को पूरा एक्सपलोरे करना।
- **कोननेकटेद कोमपोनेनटस** - हर उनविसिटेद नोड से DFS रुन करके अलग-अलग कलुसटेरस इदेनटिफ़य करना।

<ThinkAboutIt>एक पकगे मैनेजर को देपेनदेनकिएस को सही order में इनसटलल करना है। क्या उसे BFS उपयोग करना चाहिए या दफ़स-बसेद टोपोलोगिकल सॉर्ट? अगर देपेनदेनकय ग्राफ़ में साइकिल हो तो क्या होगा?</ThinkAboutIt>

## दिजकसटर's अलगोरिथम - वेट्स के साथ शोरटेसट रास्ता

जब एदगेस की अलग-अलग कोसटस हों, तो BFS काफी नहीं है। दिजकसटर's अलगोरिथम एक सोउरके से बाकी सभी नोड तक सबसे छोटा भारित रास्ता फ़ाइंड करता है।

**कोरे इदेअ:** हमेशा **सबसे सस्ते उनविसिटेद नोड** को मिन-हेअप (प्राथमिकता क्यू) से एक्सपनद करो।

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**समय जटिलता:** बिनरय हीप के साथ O((V + E) लॉग V)।

<FunFact>Google मपस पूरे रोअद नेटवर्क पर पलैन दिजकसटर नहीं चलाता। यह कोनटरकशन हिएररचिएस और A* सर्च उपयोग करता है - लेकिन दोनों दिजकसटर की फ़ोउनदशनल इनसिघट पर बने हैं: सबसे छोटा ज्ञात दिसटनके से ग्रीडी एक्सपनसिओन।</FunFact>

### दिजकसटर के AI उपयोग कसेस

- **रास्ता योजना** - नविगशन ऐप सबसे तेज़ रूट फ़ाइंड करने के लिए।
- **नेटवर्क रूटिंग** - इनटेरनेट पकेटस लोवेसट-लटेनकय रास्ता चुनें करने के लिए।
- **ज्ञान ग्राफ़** - कोनकेपटस के बीच सबसे छोटा सेमनटिक कोननेकशन फ़ाइंड करने के लिए।

## कयकले देटेकशन और जुड़े हुए घटक

### कयकले देटेकशन

एक **दिरेकटेद ग्राफ़** में, नोड को तीन सटटेस में रिकॉर्ड करें: उनविसिटेद, इन-परोगरेस (वर्तमान DFS रास्ता पर), और कोमपलेटेद। अगर इन-परोगरेस नोड दोबारा मिले, तो साइकिल है।

एक **उनदिरेकटेद ग्राफ़** में, अगर DFS किसी ऐसे विज़िटेड नोड तक पहुँचे जो इममेदिअटे परेनट नहीं है, तो साइकिल है।

### जुड़े हुए घटक

हर उनविसिटेद नोड से BFS या DFS रुन करो। हर रुन एक कोननेकटेद कोमपोनेनट खोजना करता है। सामाजिक नेटवोरकस में, कोमपोनेनटस इसोलटेद कोममुनिटिएस को उजागर करते हैं।

<ThinkAboutIt>एक AI धोखाधड़ी पहचान सयसटेम टरनसकशनस को ग्राफ़ के रूप में मॉडल करता है जहाँ अकाउंट नोड हैं और टरनसफ़ेरस एदगेस हैं। कोननेकटेद कोमपोनेनटस मोनेय-लौनदेरिङ रिङस इदेनटिफ़य करने में कैसे मदद कर सकते हैं?</ThinkAboutIt>

## मुख्य बातें

1. **BFS** स्तर by स्तर एक्सपलोरे करता है - उनवेइघटेद ग्राफ़ में सबसे छोटा रास्ते और नेइघबोउर-बसेद दिसकोवेरय के लिए इदेअल।
2. **DFS** गहरी दिवे करता है - टोपोलोगिकल सॉर्टिंग, साइकिल पहचान, और कोमपोनेनट विश्लेषण की बकबोने।
3. **दिजकसटर** BFS को प्राथमिकता क्यू से भारित ग्राफ़ तक एक्सटेनद करता है - आधुनिक रूट योजना की फ़ोउनदशन।
4. गरफ अलगोरिथमस मपस, सोकिअल नेटवोरकस, पकगे मैनेजर, और ज्ञान ग्राफ़ के पीछे का एङिने हैं।

<FunFact>वोरलद विदे वेब में 50 बिललिओन से ज़्यादा इनदेक्सेद पेज हैं। सर्च एङिने करवलेरस पेज खोजना और रे-इनदेक्स करने के लिए BFS की वरिअशनस उपयोग करते हैं, पगे इमपोरटनके (पगेरनक) के हिसाब से परिओरिटिसे करते हुए।</FunFact>
