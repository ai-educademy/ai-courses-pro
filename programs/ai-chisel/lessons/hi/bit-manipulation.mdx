## बाइनरी संख्या की समीक्षा

हर पूर्णांक बिटों की एक श्रृंखला है। 13 को बाइनरी में `1101` लिखा जाता है:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

बिट मैनिपुलेशन इन बिटों पर बिटवाइज़ ऑपरेटर से सीधे काम करता है। अक्सर लूप की जगह एक ही ऑपरेशन ले लेता है।

## मुख्य बिटवाइज़ ऑपरेशन

| Operator | Symbol | Example (5 = 101, 3 = 011) | Result |
|----------|--------|----------------------------|--------|
| AND      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| XOR      | `^`    | `101 ^ 011`                | `110` (6) |
| NOT      | `~`    | `~101`                     | `...010` |
| बायाँ शिफ़्ट  | `<<` | `101 << 1`              | `1010` (10) |
| दायाँ शिफ़्ट | `>>` | `101 >> 1`              | `10` (2) |

## ज़रूरी बिट ट्रिक्स

### दो की घात जाँचना

2 की घात में ठीक एक सेट बिट होता है: `n & (n - 1) == 0`।

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### Set Bits गिनना (Brian Kernighan's एल्गोरिदम)

हर `n & (n - 1)` सबसे निचला सेट बिट हटा देता है। n = 0 होने तक दोहराव गिनें।

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

यह O(k) में चलता है, जहाँ k सेट बिट की संख्या है। यह O(32) नहीं है।

### अस्थायी वैरिएबल के बिना बदलना

```python
a ^= b
b ^= a
a ^= b
```

यह इसलिए काम करता है क्योंकि XOR स्वयं का प्रतिलोम है: `a ^ b ^ b = a`।

## Single संख्या - XOR Cancellation

हर एलिमेंट दो बार आता है, सिर्फ़ एक को छोड़कर। उसे खोजें। क्योंकि `a ^ a = 0` और `a ^ 0 = a`, सभी एलिमेंट को XOR करें। जोड़े निरस्त हो जाते हैं और अद्वितीय संख्या बचता है।

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

समय O(n), स्पेस O(1)। हैश मैप की ज़रूरत नहीं।

## Single संख्या III - दो Unique Numbers

जब *दो* संख्याएँ अद्वितीय हों, तो सबको XOR करके `x = a ^ b` पाएँ। `x` में कोई भी सेट बिट खोजें (वहाँ दोनों संख्याएँ अलग हैं)। उसी बिट से सभी संख्याएँ को बाँटें और हर समूह को XOR करें। हर समूह में ठीक एक अद्वितीय संख्या होगा।

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>`xor & (-xor)` सबसे दाएँ सेट बिट को अलग क्यों करता है? सोचें कि ऋणात्मक संख्याएँ को two's कॉम्प्लिमेंट में कैसे दर्शाया जाता है।</ThinkAboutIt>

## उपसमूह के लिए बिट मास्किंग

लंबाई n का बिटमास्क, n आइटम के उपसमूह को दर्शाता है। बिट `i` सेट होने का मतलब आइटम `i` शामिल है। `0` से `2^n - 1` तक दोहराने करने से सभी उपसमूह बनते हैं।

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

यह तकनीक n ≤ 20 वाली समस्याएँ के लिए काम करती है। 2^n गणना के लिए इतना छोटा है।

<FunFact>Linux फ़ाइल अनुमतियाँ (rwxr-xr-x = 755) असल दुनिया का बिटमास्क हैं। हर अंक तीन अनुमति बिट एन्कोड करता है: पढ़ना (4), लिखना (2), चलाना (1), जिन्हें OR से मिलाया जाता है।</FunFact>

## Bits उलटना (LeetCode 190)

32-बिट अनसाइन्ड पूर्णांक को बिट से बिट उलटें। परिणाम को बाएँ शिफ़्ट करें और इनपुट का सबसे निचला बिट OR करें, फिर इनपुट को दाएँ शिफ़्ट करें।

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## Missing संख्या (LeetCode 268)

0 से n तक के n संख्याएँ का ऐरे है, जिसमें एक संख्या गुम है। सभी ऐरे एलिमेंट को इंडेक्स 0 से n के साथ XOR करें। जोड़े निरस्त हो जाते हैं और गुम संख्या बचता है। विकल्प के रूप में योग सूत्र भी इस्तेमाल कर सकते हैं, लेकिन XOR संभावित ओवरफ़्लो से बचाता है।

## Hamming Distance (LeetCode 461)

संबंधित बिट जहाँ अलग हों, उन स्थितियाँ की संख्या। दोनों संख्याएँ को XOR करें। परिणाम में सेट बिट ही अलग स्थितियाँ हैं। उन्हें Brian Kernighan's युक्ति से गिनें।

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```
