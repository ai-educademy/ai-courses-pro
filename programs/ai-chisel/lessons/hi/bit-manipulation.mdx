## बाइनरी संख्या की समीक्षा

हर पूर्णांक बिटों की एक श्रृंखला है। 13 को बाइनरी में `1101` लिखा जाता है:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

बिट मैनिपुलेशन इन बिटों पर bitwise operators से सीधे काम करता है। अक्सर loops की जगह एक ही operation ले लेता है।

## मुख्य bitwise operations

| Operator | Symbol | Example (5 = 101, 3 = 011) | Result |
|----------|--------|----------------------------|--------|
| AND      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| XOR      | `^`    | `101 ^ 011`                | `110` (6) |
| NOT      | `~`    | `~101`                     | `...010` |
| बायाँ shift  | `<<` | `101 << 1`              | `1010` (10) |
| दायाँ shift | `>>` | `101 >> 1`              | `10` (2) |

## ज़रूरी बिट ट्रिक्स

### दो की घात जाँचना

2 की घात में ठीक एक set bit होता है: `n & (n - 1) == 0`।

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### Set Bits गिनना (Brian Kernighan's Algorithm)

हर `n & (n - 1)` सबसे निचला set bit हटा देता है। n = 0 होने तक iterations गिनें।

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

यह O(k) में चलता है, जहाँ k set bits की संख्या है। यह O(32) नहीं है।

### Temp Variable के बिना Swap

```python
a ^= b
b ^= a
a ^= b
```

यह इसलिए काम करता है क्योंकि XOR स्वयं का inverse है: `a ^ b ^ b = a`।

## Single Number - XOR Cancellation

हर element दो बार आता है, सिर्फ़ एक को छोड़कर। उसे खोजें। क्योंकि `a ^ a = 0` और `a ^ 0 = a`, सभी elements को XOR करें। जोड़े cancel हो जाते हैं और unique number बचता है।

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

समय O(n), space O(1)। hash map की ज़रूरत नहीं।

## Single Number III - दो Unique Numbers

जब *दो* numbers unique हों, तो सबको XOR करके `x = a ^ b` पाएँ। `x` में कोई भी set bit खोजें (वहाँ दोनों numbers अलग हैं)। उसी bit से सभी numbers को बाँटें और हर group को XOR करें। हर group में ठीक एक unique number होगा।

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>`xor & (-xor)` सबसे दाएँ set bit को अलग क्यों करता है? सोचें कि negative numbers को two's complement में कैसे दर्शाया जाता है।</ThinkAboutIt>

## Subsets के लिए Bit Masking

लंबाई n का bitmask, n items के subset को दर्शाता है। bit `i` set होने का मतलब item `i` शामिल है। `0` से `2^n - 1` तक iterate करने से सभी subsets बनते हैं।

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

यह तकनीक n ≤ 20 वाली problems के लिए काम करती है। 2^n enumeration के लिए इतना छोटा है।

<FunFact>Linux file permissions (rwxr-xr-x = 755) असल दुनिया का bitmask हैं। हर digit तीन permission bits encode करता है: read (4), write (2), execute (1), जिन्हें OR से मिलाया जाता है।</FunFact>

## Bits उलटना (LeetCode 190)

32-bit unsigned integer को bit by bit उलटें। result को बाएँ shift करें और input का सबसे निचला bit OR करें, फिर input को दाएँ shift करें।

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## Missing Number (LeetCode 268)

0 से n तक के n numbers का array है, जिसमें एक number missing है। सभी array elements को indices 0 से n के साथ XOR करें। जोड़े cancel हो जाते हैं और missing number बचता है। विकल्प के रूप में sum formula भी इस्तेमाल कर सकते हैं, लेकिन XOR संभावित overflow से बचाता है।

## Hamming Distance (LeetCode 461)

संबंधित bits जहाँ अलग हों, उन positions की संख्या। दोनों numbers को XOR करें। result में set bits ही अलग positions हैं। उन्हें Brian Kernighan's trick से गिनें।

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```
