## बिनरय नुमबेर रिव्यू

हर इनटेगेर बिटस की एक सेक्वेनके होता है। 13 को बाइनरी में लिखें तो `1101` मिलता है:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

बिट मैनिपुलेशन इन बिटस पर सीधे बिटविसे ओपेरटोरस से काम करता है - अक्सर लूपस की जगह एक ही ऑपरेशन काफ़ी होता है।

## कोरे बिटविसे ओपेरशनस

| ओपेरटोर | सयमबोल | एक्समपले (5 = 101, 3 = 011) | नतीजा |
|----------|--------|----------------------------|--------|
| AND      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| XOR      | `^`    | `101 ^ 011`                | `110` (6) |
| NOT      | `~`    | `~101`                     | `...010` |
| लेफ़ट शिफ़ट  | `<<` | `101 << 1`              | `1010` (10) |
| रिघट शिफ़ट | `>>` | `101 >> 1`              | `10` (2) |

## ज़रूरी बिट टरिकस

### पोवेर of टवो चेक करना

पोवेर of 2 में सिर्फ़ एक सेट बिट होता है: `n & (n - 1) == 0`।

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### सेट बिटस गिनना (बरिअन केरनिघन's अलगोरिथम)

हर `n & (n - 1)` सबसे नीचे वाला सेट बिट हटा देता है। जब तक n = 0 न हो, इटेरशनस गिनते रहो।

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

यह O(k) में चलता है जहाँ k सेट बिटस की संख्या है - O(32) नहीं।

### बिना टेमप वरिअबले के सवप

```python
a ^= b
b ^= a
a ^= b
```

काम करता है क्योंकि XOR अपना ही इनवेरसे है: `a ^ b ^ b = a`।

## सिङले नुमबेर - XOR कनकेललशन

हर एलिमेंट दो बार आता है सिवाय एक के। उसे ढूँढो। चूँकि `a ^ a = 0` और `a ^ 0 = a`, सभी एलिमेंट को XOR करो - पैरस कनकेल हो जाएँगे, उनिक्वे नुमबेर बचेगा।

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

समय O(n), स्पेस O(1)। कोई हैश मैप नहीं चाहिए।

## सिङले नुमबेर III - दो उनिक्वे नुमबेरस

जब *दो* नंबर उनिक्वे हों, तो सबको XOR करो - `x = a ^ b` मिलेगा। `x` में कोई भी सेट बिट ढूँढो (वहाँ दोनों नंबर अलग हैं)। उस बिट से सभी नंबर को दो गरोउपस में बाँटो और हर गरोउप को XOR करो - हर गरोउप में ठीक एक उनिक्वे नुमबेर होगा।

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>`xor & (-xor)` सबसे दाएँ सेट बिट को इसोलटे क्यों करता है? सोचो कि टवो's कोमपलेमेनट में नेगटिवे नंबर कैसे रेपरेसेनट होते हैं।</ThinkAboutIt>

## सुबसेटस के लिए बिट मसकिङ

लेङथ n का बिटमसक, n आइटम का एक उपसमूह रेपरेसेनट करता है। बिट `i` सेट होने का मतलब आइटम `i` शामिल है। `0` से `2^n - 1` तक इटेरटे करने पर सभी सुबसेटस जनरेट हो जाते हैं।

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

यह टेचनिक्वे उन समस्याएँ के लिए काम करती है जहाँ n ≤ 20 हो - 2^n एनुमेरशन के लिए काफ़ी छोटा।

<FunFact>लिनुक्स फ़ाइल पेरमिसिओनस (रवक्सर-क्सर-क्स = 755) रेअल-वोरलद बिटमसक का एक बढ़िया एक्समपले हैं। हर दिगिट तीन पेरमिसिओन बिटस एनकोदे करती है: रेअद (4), राइट (2), चलना (1), जो OR से जोड़ते होती हैं।</FunFact>

## बिटस रेवेरसे करना (LeetCode 190)

एक 32-बिट उनसिगनेद इनटेगेर को बिट by बिट रेवेरसे करो। नतीजा को लेफ़ट शिफ़ट करो और इनपुट का लोवेसट बिट OR करो, फिर इनपुट को रिघट शिफ़ट करो।

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## मिसिङ नुमबेर (LeetCode 268)

0 से n तक के n नंबर की ऐरे जिसमें एक मिसिङ है। सभी ऐरे एलिमेंट को इंडेक्स 0 से n के साथ XOR करो - पैरस कनकेल होंगे, मिसिङ नुमबेर बचेगा। सुम फ़ॉर्मूला भी चलेगा, लेकिन XOR में ओवेरफ़लोव का ख़तरा नहीं।

## हममिङ दिसटनके (LeetCode 461)

वो पोसिशनस जहाँ कोररेसपोनदिङ बिटस अलग हैं, उनकी संख्या। दोनों नंबर को XOR करो - रेसुलट में सेट बिटस ही दिफ़फ़ेरिङ पोसिशनस हैं। बरिअन केरनिघन's टरिक से गिन लो।

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```
