## बाइनरी संख्या रिव्यू

हर पूर्णांक बिट की एक क्रम होता है। 13 को बाइनरी में लिखें तो `1101` मिलता है:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

बिट मैनिपुलेशन इन बिट पर सीधे बिटवाइज़ ऑपरेटर से काम करता है - अक्सर लूप की जगह एक ही ऑपरेशन काफ़ी होता है।

## मुख्य बिटवाइज़ ऑपरेशन

| ऑपरेटर | चिह्न | उदाहरण (5 = 101, 3 = 011) | नतीजा |
|----------|--------|----------------------------|--------|
| AND      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| XOR      | `^`    | `101 ^ 011`                | `110` (6) |
| NOT      | `~`    | `~101`                     | `...010` |
| बाएँ शिफ़ट  | `<<` | `101 << 1`              | `1010` (10) |
| दाएँ शिफ़ट | `>>` | `101 >> 1`              | `10` (2) |

## ज़रूरी बिट युक्तियाँ

### दो की घात चेक करना

दो की घात में सिर्फ़ एक सेट बिट होता है: `n & (n - 1) == 0`।

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### सेट बिट गिनना (Brian Kernighan's एल्गोरिदम)

हर `n & (n - 1)` सबसे नीचे वाला सेट बिट हटा देता है। जब तक n = 0 न हो, दोहराव गिनें।

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

यह O(k) में चलता है जहाँ k सेट बिट की संख्या है - O(32) नहीं।

### बिना अस्थायी बदलती के स्वैप

```python
a ^= b
b ^= a
a ^= b
```

काम करता है क्योंकि XOR अपना ही इनवर्स है: `a ^ b ^ b = a`।

## एकल संख्या - XOR निरस्तीकरण

हर एलिमेंट दो बार आता है सिवाय एक के। उसे ढूँढें। चूँकि `a ^ a = 0` और `a ^ 0 = a`, सभी एलिमेंट को XOR करें - जोड़े निरस्त हो जाएँगे, अलग संख्या बचेगा।

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

समय O(n), स्पेस O(1)। कोई हैश मैप नहीं चाहिए।

## एकल संख्या III - दो अलग संख्यास

जब *दो* नंबार अलग हों, तो सbackो XOR करें - `x = a ^ b` मिलेगा। `x` में कोई भी सेट बिट ढूँढें (वहाँ दोनों नंबार अलग हैं)। उस बिट से सभी नंबार को दो समूह में बाँटो और हर समूह को XOR करें - हर समूह में ठीक एक अलग संख्या होगा।

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>`xor & (-xor)` सबसे दाएँ सेट बिट को अलग क्यों करता है? सोचें कि two's टर्म में नेगेटिव नंबार कैसे दर्शाते होते हैं।</ThinkAboutIt>

## उpassमूह के लिए बिट मास्किंग

लंबाई n का बिटमास्क, n आइटम के एक उpassमूह को दर्शाता है। बिट `i` सेट होने का मतलब आइटम `i` शामिल है। `0` से `2^n - 1` तक दोहराने पर सभी उpassमूह बन जाते हैं।

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

यह तकनीक उन समस्याएँ के लिए काम करती है जहाँ n ≤ 20 हो - 2^n टर्म के लिए काफ़ी छोटा।

<FunFact>Linux फ़ाइल अनुमतियाँ (rwx-r-x-r-x = 755) वास्तविक दुनिया के बिटमास्क का बढ़िया उदाहरण हैं। हर अंक तीन अनुमति बिट एन्कोड करता है: पढ़ना (4), लिखना (2), चलाना (1), जिन्हें OR से जोड़ा जाता है।</FunFact>

## बिट वापास करना करना (LeetCode 190)

एक 32-बिट टर्म पूर्णांक को बिट-दर-बिट टर्म करें। नतीजे को बाएँ शिफ़ट करें और इनपुट का सबसे निचला बिट OR करें, फिर इनपुट को दाएँ शिफ़ट करें।

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## मिसिंग संख्या (LeetCode 268)

0 से n तक के n नंबार की ऐरे जिसमें एक मिसिंग है। सभी ऐरे एलिमेंट को इंडेक्स 0 से n के साथ XOR करें - जोड़े निरस्त होंगे, मिसिंग संख्या बचेगा। टर्म फ़ॉर्मूला भी चलेगा, लेकिन XOR में ओवरफ़्लो का ख़तरा नहीं।

## Hamming दूरी (LeetCode 461)

वो स्थितियाँ जहाँ टर्म बिट अलग हैं, उनकी संख्या। दोनों नंबार को XOR करें - नतीजा में सेट बिट ही टर्म स्थितियाँ हैं। Brian Kernighan's युक्ति से गिनें।

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```
