## टरिए क्या है?

**टरिए** (उच्चारण "टरय") एक ट्री जैसी संरचना है जहाँ हर नोड एक एकल चरकटेर रेपरेसेनट करता है। रूट से मरकेद नोड तक के रास्ते स्टोरद वोरदस सपेलल करते हैं। हश मपस के विपरीत, ट्राइ आपको *एक प्रीफ़िक्स साझा करने वाले सभी वोरदस* क्वेरी करने देते हैं बिना हर की सकन किए।

```
        root
       / | \
      a   b   c
     /     \
    p       a
   / \       \
  p   e      t
  |
  l
  e
```

हर रास्ता एक वोरद एनकोदे करता है: **अपपले**, **अपे**, **बट**, **कट**।

## टरिएनोदे कलस

हर नोड में चिलदरेन का एक मैप और वोरद कोमपलेशन इनदिकटे करने वाला फ़्लैग होता है।

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False
```

एक पूरा टरिए इसे इन्सर्ट, सर्च, और प्रीफ़िक्स ऑपरेशन के साथ वरप करता है।

## Core operations

### इनसेरट - O(m) जहाँ m = वोरद की लेङथ

चरकटेर by चरकटेर चलें, ज़रूरत पड़ने पर नोड बनाएं, फिर लसट नोड को मरक करें।

```python
def insert(self, word):
    node = self.root
    for ch in word:
        if ch not in node.children:
            node.children[ch] = TrieNode()
        node = node.children[ch]
    node.is_end = True
```

### Search और startsWith

**Search** रास्ता follow करता है और `is_end` जाँचता है। **startsWith** सिर्फ़ जाँचता है कि रास्ता मौजूद है या नहीं - इसे `is_end = True` की ज़रूरत नहीं।

## DFS के साथ औटोकोमपलेटे

किसी प्रीफ़िक्स के लिए सुझाव देने के लिए, प्रीफ़िक्स नोड तक नविगटे करें, फिर DFS रुन करें और नीचे के सभी वोरदस कोललेकट करें।

```python
def autocomplete(self, prefix):
    node = self._find(prefix)
    if not node:
        return []
    results = []
    self._dfs(node, prefix, results)
    return results
```

`_dfs` हेलपेर चिलदरेन में रेकुरसे करता है और जब भी `is_end` `True` होता है तो नतीजे में अपपेनद करता है।

<ThinkAboutIt>आप औटोकोमपलेटे को टोप-क सबसे फ़रेक्वेनट सुझाव तक कैसे लिमिट करेंगे? हर नोड को कौनसा एक्सटर डेटा चाहिए होगा?</ThinkAboutIt>

## Wildcard search - Word Dictionary

LeetCode की **Design Add and Search Words Data Structure** समस्या में `.` को wildcard के रूप में संभालना होता है, जो किसी भी single character से match करता है।

Search के दौरान, जब `.` मिले तो *हर* child में branch करें और recursively continue करें। यह simple traversal को bounded backtracking search में बदल देता है।

```python
def search_wild(self, node, word, i):
    if i == len(word):
        return node.is_end
    if word[i] == '.':
        return any(
            self.search_wild(c, word, i + 1)
            for c in node.children.values()
        )
    if word[i] not in node.children:
        return False
    return self.search_wild(
        node.children[word[i]], word, i + 1
    )
```

## टरिएस के साथ IP रोउटिङ

Routers IP prefixes को **binary trie** में store करते हैं - हर bit (0 या 1) एक branch बनाता है। Longest prefix match सबसे specific route ढूँढता है। इसी तरह आपके packets internet पर अपना रास्ता खोजते हैं।

<FunFact>Internet backbone routers हर सेकंड अरबों longest-prefix-match lookups करते हैं, hardware-optimised tries की मदद से जो TCAMs नाम के specialised chips में बने होते हैं।</FunFact>

## कोमपरेसेद टरिएस (रदिक्स ट्री)

Standard tries single-child chains पर space waste करते हैं। एक **radix tree** इन chains को merge करके single edges बनाता है जिनमें multi-character labels store होते हैं।

```
Standard:  r → u → n → n → i → n → g
Radix:     r → "unning"
```

इससे नोड गणना काफ़ी कम हो जाता है और इसे लिनुक्स केरनेल रूटिंग टेबल और HTTP रोउटेरस जैसे Go के `httprouter` में उपयोग किया जाता है।

## समय और सपके जटिलता

| ओपेरशन    | टरिए   | हश मैप |
|--------------|--------|----------|
| इनसेरट       | O(m)   | O(m)     |
| सर्च       | O(m)   | O(m)     |
| परेफ़िक्स क्वेरी | O(m+k) | O(n·m)   |

यहाँ *m* वोरद की लेङथ है, *k* नतीजे की गणना है, और *n* कुल की हैं। परेफ़िक्स-हेअवय वोरकलोविज्ञापन में ट्राइ का दबदबा है।
