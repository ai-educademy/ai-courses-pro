## ट्राइ क्या है?

**टर्म** (उच्चारण "टर्म") एक ट्री जैसी संरचना है जहाँ हर नोड एक अक्षर दर्शाता है। रूट से टर्म नोड तक के रास्ते संग्रहित शब्द बनाते हैं। हैश मैप के विपरीत, ट्राइ आपको *एक प्रीफ़िक्स साझा करने वाले सभी शब्द* क्वेरी करने देते हैं बिना हर key स्कैन किए।

```
        root
       / | \
      a   b   c
     /     \
    p       a
   / \       \
  p   e      t
  |
  l
  e
```

हर रास्ता एक शब्द एन्कोड करता है: **अपपले**, **अपे**, **बट**, **कट**।

## ट्राइनोदे कलस

हर नोड में बच्चे का एक मैप और शब्द कोमपलेशन इनदिकटे करने वाला फ़्लैग होता है।

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False
```

एक पूरा ट्राइ इसे इन्सर्ट, सर्च, और प्रीफ़िक्स ऑपरेशन के साथ टर्म करता है।

## मुख्य ऑपरेशन

### इन्सर्ट - O(m) जहाँ m = शब्द की लंबाई

अक्षर by अक्षर चलें, ज़रूरत पड़ने पर नोड बनाएं, फिर लसट नोड को मरक करें।

```python
def insert(self, word):
    node = self.root
    for ch in word:
        if ch not in node.children:
            node.children[ch] = TrieNode()
        node = node.children[ch]
    node.is_end = True
```

### Search और startsWith

**Search** रास्ते का अनुसरण करता है और `is_end` जाँचता है। **startsWith** सिर्फ़ जाँचता है कि रास्ता मौजूद है या नहीं - इसे `is_end = True` की ज़रूरत नहीं।

## DFS के साथ औटोकोमपलेटे

किसी प्रीफ़िक्स के लिए सुझाव देने के लिए, प्रीफ़िक्स नोड तक नेविगेट करें, फिर DFS चलाएँ और नीचे के सभी शब्द इकट्ठा करें।

```python
def autocomplete(self, prefix):
    node = self._find(prefix)
    if not node:
        return []
    results = []
    self._dfs(node, prefix, results)
    return results
```

`_dfs` टर्म बच्चे में रिकर्स करता है और जब भी `is_end` `True` होता है तो नतीजे में अपेंड करता है।

<ThinkAboutIt>आप औटोकोमपलेटे को टोप-क सबसे फ़रेक्वेनट सुझाव तक कैसे लिमिट करेंगे? हर नोड को कौनसा अतिरिक्त डेटा चाहिए होगा?</ThinkAboutIt>

## Wildcard सर्च - Word Dictionary

LeetCode की **Design Add and Search Words Data Structure** समस्या में `.` को वाइल्डकार्ड के रूप में संभालना होता है, जो किसी भी एक अक्षर से मेल खाता है।

Search के दौरान, जब `.` मिले तो *हर* चाइल्ड में ब्रांच करें और रिकर्सिव रूप से आगे बढ़ें। यह सरल ट्रैवर्सल को सीमित बैकट्रैकिंग सर्च में बदल देता है।

```python
def search_wild(self, node, word, i):
    if i == len(word):
        return node.is_end
    if word[i] == '.':
        return any(
            self.search_wild(c, word, i + 1)
            for c in node.children.values()
        )
    if word[i] not in node.children:
        return False
    return self.search_wild(
        node.children[word[i]], word, i + 1
    )
```

## ट्राइस के साथ IP टर्म

Routers IP प्रीफ़िक्स को **बाइनरी ट्राइ** में स्टोर करते हैं - हर bit (0 या 1) एक ब्रांच बनाता है। टर्म प्रीफ़िक्स मेल सबसे विशिष्ट रूट ढूँढता है। इसी तरह आपके पैकेट इंटरनेट पर अपना रास्ता खोजते हैं।

<FunFact>Internet बैकबोन राउटर हर सेकंड अरबों सबसे-लंबे-प्रीफ़िक्स-मिलान खोज करते हैं, हार्डवेयर-अनुकूलित ट्राइ की मदद से जो TCAMs नाम के विशेष चिप में बने होते हैं।</FunFact>

## compareसेद ट्राइस (रदिक्स ट्री)

मानक ट्राइ एकल-child चेन पर जगह बर्बाद करते हैं। एक **रैडिक्स ट्री** इन चेन को मर्ज करके एकल एज बनाता है जिनमें मल्टी-character लेबल स्टोर होते हैं।

```
Standard:  r → u → n → n → i → n → g
Radix:     r → "unning"
```

इससे नोड गणना काफ़ी कम हो जाता है और इसे लिनुक्स केरनेल रूटिंग टेबल और HTTP टर्म जैसे Go के `httprouter` में उपयोग किया जाता है।

## समय और स्पेस जटिलता

| टर्म    | ट्राइ   | हैश मैप |
|--------------|--------|----------|
| इन्सर्ट       | O(m)   | O(m)     |
| सर्च       | O(m)   | O(m)     |
| प्रीफ़िक्स क्वेरी | O(m+k) | O(n·m)   |

यहाँ *m* शब्द की लंबाई है, *k* नतीजे की गणना है, और *n* कुल की हैं। प्रीफ़िक्स-हेअवय वोरकलोविज्ञापन में ट्राइ का टर्म है।
