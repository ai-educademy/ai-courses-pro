## Smart scanning क्यों ज़रूरी है

सोचिए कि एक AI किसी लाइव वीडियो फ़ीड पर संदिग्ध गतिविधि मोनिटोर कर रहा है। वो हर सेकंड पूरी रेकोरदिङ दोबारा नहीं देख सकता - उसे सटरेअम पर एक ध्यान की विंडो सलिदे करनी होती है, बस उतना संदर्भ रखते हुए जितना ज़रूरी है। **टवो पॉइंटर** और **स्लाइडिंग विंडो** पैटर्न सेक्वेनटिअल डेटा के साथ बिल्कुल यही करते हैं।

दोनों तकनीकें brute-force O(n²) scans को elegant O(n) passes में बदल देती हैं।

## टवो पोइनटेर टेचनिक्वे

किसी सेक्वेनके में दो रेफ़ेरेनकेस रखो और उन्हें एक रुले के हिसाब से मोवे करो। इसके दो मुख्य तरीके हैं।

### कोनवेरगिङ पोइनटेरस

एक पॉइंटर शुरू में और एक अंत में रखो, फिर अंदर की तरफ़ मोवे करो। **सोरटेद** डेटा के लिए बेहतरीन है।

**कलसिक समस्या - पैर सुम:** एक सॉर्टेड ऐरे दिया है, दो नंबर ढूँढो जिनका सुम लक्षित के बराबर हो।

```
function pairSum(arr, target):
    left = 0
    right = arr.length - 1
    while left < right:
        sum = arr[left] + arr[right]
        if sum == target: return (left, right)
        if sum < target: left += 1
        else: right -= 1
    return null
```

क्योंकि ऐरे सॉर्टेड है, `left` को अधिकार मोवे करने से सुम एजा है, और `right` को लेफ़ट मोवे करने से सुम घटता है - इससे कोई भी वलिद पैर मिस नहीं होती।

### समे-दिरेकशन पोइनटेरस

दोनों पॉइंटर आगे की तरफ़ मोवे करते हैं, लेकिन अलग-अलग स्पीड से। **परटिशनिङ** या **साइकिल पहचान** के लिए उपयोगी है।

**एक्सैंपल - दुपलिकटेस इन-पलके हटा करो:** एक धीमे पॉइंटर राइट स्थिति मरक करता है; एक तेज़ पॉइंटर आगे सकन करता है।

```
function removeDuplicates(arr):
    slow = 0
    for fast in 1..arr.length - 1:
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1
```

## स्लाइडिंग विंडो पटटेरन

Sliding window contiguous sub-sequence बनाए रखती है जिसका size _k_ (fixed) या variable length हो सकता है, और aggregates को scratch से recalculate करने की बजाय incrementally update करती है।

### फ़िक्सेद-सिज़े विनदोव

बिल्कुल _k_ एलिमेंट की विंडो को ऐरे पर सलिदे करो।

**एक्सैंपल - किन्हीं k कोनसेकुटिवे एलिमेंट का मक्सिमुम सुम:**

```
function maxSubarraySum(arr, k):
    windowSum = sum(arr[0..k-1])
    best = windowSum
    for i in k..arr.length - 1:
        windowSum += arr[i] - arr[i - k]
        best = max(best, windowSum)
    return best
```

हर step में window में आने वाला नया element add होता है और बाहर जाने वाला subtract होता है - O(1) प्रति move।

### वरिअबले-सिज़े विनदोव

ज़्यादा data शामिल करने के लिए window expand करो, फिर constraint टूटे तो उसे shrink करो।

**एक्सैंपल - लोङेसट सब-स्ट्रिंग बिना रेपेअटिङ चरकटेरस:**

```
function longestUnique(s):
    seen = {}
    left = 0
    best = 0
    for right in 0..s.length - 1:
        if s[right] in seen and seen[s[right]] >= left:
            left = seen[s[right]] + 1
        seen[s[right]] = right
        best = max(best, right - left + 1)
    return best
```

<FunFact>अपचे फ़लिनक जैसे स्ट्रीमिंग एनालिटिक्स पलटफ़ोरमस स्लाइडिंग और टुमबलिङ विनदोवस को फ़िरसट-कलस परिमिटिवेस की तरह उपयोग करते हैं - यही कोनकेपट मिलियन of इवेंट प्रति सेकंड पर स्केल होता है।</FunFact>

## वास्तविक AI ऐप्लिकेशन

| पटटेरन | AI उपयोग कसे |
|---------|------------|
| फ़िक्सेद विंडो | पिछली _k_ सेनसोर रेअदिङस पर अनोमलय पहचान |
| वरिअबले विंडो | सभी क्वेरी केयवोरदस वाला सबसे छोटा टेक्स्ट सपन ढूँढना (सर्च इंजन) |
| कोनवेरगिङ पॉइंटर | सोरटेद एमबेददिङ दिमेनसिओनस में कुशल नेअरेसट-नेइघबोउर चेकस |
| समे-दिरेकशन पॉइंटर | मुलटिपले प्राप्ति मॉडल से सॉर्टेड रेसुलट लिस्ट को मर्ज करना |

## कौन सा पटटेरन कब इस्तेमाल करें

- **टवो पॉइंटर (कोनवेरगिङ):** सॉर्टेड इनपुट, पैर/टरिपलेट सर्च, पैलिंड्रोम चेकस।
- **Two pointers (same-direction):** in-place modifications, fast/slow runner problems.
- **फ़िक्सेद स्लाइडिंग विंडो:** एक ज्ञात विंडो आकार पर अगगरेगटे।
- **वरिअबले स्लाइडिंग विंडो:** किसी शर्त को सटिसफ़य करने वाली सबसे छोटी या सबसे बड़ी विंडो ढूँढो।
