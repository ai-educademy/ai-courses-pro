## समझदारी से स्कैन करना क्यों ज़रूरी है

सोचिए कि एक AI किसी लाइव वीडियो फ़ीड पर संदिग्ध गतिविधि टर्म कर रहा है। वो हर सेकंड पूरी रेकोरदिङ दोबारा नहीं देख सकता - उसे सटरेअम पर एक ध्यान की विंडो सलिदे करनी होती है, बस उतना संदर्भ रखते हुए जितना ज़रूरी है। **two-pointer** और **स्लाइडिंग विंडो** पैटर्न टर्म डेटा के साथ बिल्कुल यही करते हैं।

दोनों तकनीकें ब्रूट-force O(n²) स्कैन को सुंदर O(n) पास में बदल देती हैं।

## टवो पोइनटेर तकनीक

किसी क्रम में दो रेफ़ेरेनकेस रखो और उन्हें एक रुले के हिसाब से मूव करें। इसके दो मुख्य तरीके हैं।

### कोनवेरगिङ पॉइंटर

एक पॉइंटर शुरू में और एक अंत में रखो, फिर अंदर की तरफ़ मूव करें। **सोरटेद** डेटा के लिए बेहतरीन है।

**क्लासिक समस्या - पैर टर्म:** एक सॉर्टेड ऐरे दिया है, दो नंबार ढूँढें जिनका टर्म लक्षित के बराबार हो।

```
function pairSum(arr, target):
    left = 0
    right = arr.length - 1
    while left < right:
        sum = arr[left] + arr[right]
        if sum == target: return (left, right)
        if sum < target: left += 1
        else: right -= 1
    return null
```

क्योंकि ऐरे सॉर्टेड है, `left` को दाएँ मूव करने से टर्म बढ़ता है, और `right` को बाएँ मूव करने से टर्म घटता है - इससे कोई भी मान्य पैर मिस नहीं होती।

### समे-direction पॉइंटर

दोनों पॉइंटर आगे की तरफ़ मूव करते हैं, लेकिन अलग-अलग स्पीड से। **टर्म** या **साइकिल पहचान** के लिए उपयोगी है।

**उदाहरण - टर्म in-place हटा करें:** एक धीमे पॉइंटर टर्म स्थिति टर्म करता है; एक तेज़ पॉइंटर आगे स्कैन करता है।

```
function removeDuplicates(arr):
    slow = 0
    for fast in 1..arr.length - 1:
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1
```

## स्लाइडिंग विंडो पैटर्न

Sliding विंडो लगातार sub-sequence बनाए रखती है जिसका आकार _k_ (स्थिर) या बदलती लंबाई हो सकता है, और समुच्चय को शुरुआत से दोबारा गणना करने की बजाय क्रमिक रूप से अपडेट करती है।

### स्थिर-size विंडो

बिल्कुल _k_ एलिमेंट की विंडो को ऐरे पर सलिदे करें।

**उदाहरण - किन्हीं k कोनसेकुटिवे एलिमेंट का अधिकतम टर्म:**

```
function maxSubarraySum(arr, k):
    windowSum = sum(arr[0..k-1])
    best = windowSum
    for i in k..arr.length - 1:
        windowSum += arr[i] - arr[i - k]
        best = max(best, windowSum)
    return best
```

हर चरण में विंडो में आने वाला नया एलिमेंट जोड़ा जाता है और बाहर जाने वाला घटाया जाता है - O(1) प्रति चाल।

### बदलती-size विंडो

ज़्यादा डेटा शामिल करने के लिए विंडो फैलाएँ, फिर शर्त टूटे तो उसे छोटा करें।

**उदाहरण - लोङेसट सब-स्ट्रिंग बिना दोहराई जाने वाली अक्षर:**

```
function longestUnique(s):
    seen = {}
    left = 0
    best = 0
    for right in 0..s.length - 1:
        if s[right] in seen and seen[s[right]] >= left:
            left = seen[s[right]] + 1
        seen[s[right]] = right
        best = max(best, right - left + 1)
    return best
```

<FunFact>Apache Flink जैसे स्ट्रीमिंग एनालिटिक्स टर्म स्लाइडिंग और टर्म टर्म को टर्म-class टर्म की तरह इस्तेमाल करते हैं - यही अवधारणा प्रति सेकंड लाखों इवेंट पर स्केल होती है।</FunFact>

## वास्तविक AI ऐप्लिकेशन

| पैटर्न | AI उपयोग मामला |
|---------|------------|
| स्थिर विंडो | पिछली _k_ सेनसोर टर्म पर टर्म पहचान |
| बदलती विंडो | सभी क्वेरी टर्म वाला सबसे छोटा टेक्स्ट सपन ढूँढना (सर्च इंजन) |
| कोनवेरगिङ पॉइंटर | सोरटेद एमबेददिङ टर्म में कुशल नेअरेसट-पड़ोसी जाँच |
| समे-direction पॉइंटर | मुलटिपले प्राप्ति मॉडल से सॉर्टेड नतीजा लिस्ट को मर्ज करना |

## कौन सा पैटर्न कब इस्तेमाल करें

- **two-pointer (कोनवेरगिङ):** सॉर्टेड इनपुट, पैर/टरिपलेट सर्च, पैलिंड्रोम जाँच।
- **Two पॉइंटर (एक ही दिशा):** in-place बदलाव, तेज़/slow रनर समस्याएँ।
- **स्थिर स्लाइडिंग विंडो:** एक ज्ञात विंडो आकार पर अगगरेगटे।
- **बदलती स्लाइडिंग विंडो:** किसी शर्त को टर्म करने वाली सबसे छोटी या सबसे बड़ी विंडो ढूँढें।
