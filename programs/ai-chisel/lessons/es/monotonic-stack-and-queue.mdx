## ¿Qué hace que una pila sea monótona?

Una **pila monótona** mantiene los elementos en orden estrictamente creciente o decreciente de abajo hacia arriba. Antes de insertar un nuevo elemento, elimina todo lo que viole el invariante. Esta única idea desbloquea soluciones O(n) para problemas que parecen requerir O(n²).

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## Siguiente elemento mayor

Para cada elemento, busque el primer elemento más grande a su derecha. La fuerza bruta escanea hacia la derecha para cada posición: O(n²). Una pila monótona decreciente lo hace de una sola vez.

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

Cuando sacamos el índice `j`, el elemento actual es el siguiente mayor, garantizado porque todo lo que hay entre ellos era más pequeño (se abrieron antes o nunca se bloquearon `j`).

## Rectángulo más grande en histograma

El **Rectángulo más grande en histograma** de LeetCode es la joya de la corona de los problemas de pila monótona.

**Información clave:** para cada barra, encuentre hasta qué punto puede extenderse hacia la izquierda y hacia la derecha como la barra más corta. Utilice una pila creciente: cuando una barra aparece, la barra emergente define su límite derecho y la nueva parte superior de la pila define su límite izquierdo.

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

El centinela `[0]` al final obliga a procesar todas las barras restantes.

## Atrapamiento de agua de lluvia: enfoque de pila

En lugar del método clásico de dos punteros, una pila decreciente monótona calcula el agua atrapada capa por capa. Cuando aparezca una barra más alta, haga estallar las barras más cortas y calcule el agua atrapada entre la barra sacada, la barra actual y la nueva parte superior de la pila.

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>Trapping Rain Water tiene al menos cuatro soluciones O(n) distintas: dos punteros, pila monótona, matrices de prefijo máximo y un enfoque optimizado de un solo paso. A los entrevistadores les encanta ver múltiples estrategias.</FunFact>

## Cola monótona - Máximo de ventana deslizante

Una **deque monótona** (cola de dos extremos) mantiene un orden decreciente y admite una eliminación eficiente desde ambos extremos. Para **Ventana deslizante máxima** (LeetCode 239):

1. Antes de agregar el índice `i`, extraiga todos los elementos posteriores más pequeños que `nums[i]`
2. Empuje `i` hacia atrás
3. El frente es siempre el máximo de la ventana actual.
4. Retire el frente si cae fuera de la ventana.

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

Cada elemento entra y sale del deque como máximo una vez: **O(n)** en total.

## El patrón: mantener invariante durante el procesamiento

Cada problema monótono de pila/cola sigue una plantilla:

1. **Defina la invariante** (creciente o decreciente)
2. **Infractores del pop** - y extrae información útil de cada pop
3. **Empujar el elemento actual**
4. El *evento pop* es donde se calcula la respuesta.
