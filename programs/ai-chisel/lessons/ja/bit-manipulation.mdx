## 2 進数のレビュー

すべての整数はビットのシーケンスです。 2 進数の 13 は `1101` です。

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

ビット操作は、ビットごとの演算子を使用してこれらのビットに直接作用します。多くの場合、ループは単一の演算に置き換えられます。

## コアのビット演算

|オペレーター |記号 |例 (5 = 101、3 = 011) |結果 |
|----------|----------|----------------------------|----------|
|そして | `&` | `101 & 011` | `001` (1) |
|または | `\|` | `101 \| 011` | `111` (7) |
| XOR | `^` | `101 ^ 011` | `110` (6) |
|いいえ | `~` | `~101` | `...010` |
|左シフト | `<<` | `101 << 1` | `1010` (10) |
|右シフト | `>>` | `101 >> 1` | `10` (2) |

## 重要なビット トリック

### 2 の累乗かどうかを確認する

2 のべき乗には、設定ビットが 1 つだけあります: `n & (n - 1) == 0`。

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### Count Set Bits (Brian Kernighan のアルゴリズム)

各 `n & (n - 1)` は、設定された最下位ビットを削除します。 n = 0 になるまで反復をカウントします。

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

これは O(k) で実行されます。ここで、k は設定されたビットの数であり、O(32) ではありません。

### 温度変数を使用しないスワップ

```python
a ^= b
b ^= a
a ^= b
```

XOR がそれ自身の逆数であるため、機能します: `a ^ b ^ b = a`。

## 単一の数値 - XOR キャンセル

すべての要素は 1 つを除いて 2 回出現します。見つけてください。 `a ^ a = 0` と `a ^ 0 = a` なので、すべての要素の XOR - ペアがキャンセルされ、一意の番号が残ります。

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

時間 O(n)、空間 O(1)。ハッシュマップは必要ありません。

## 単一の数字 III - 2 つの固有の数字

*2* の数値が一意である場合、すべてを XOR して `x = a ^ b` を取得します。 `x` で設定されたビットを見つけます (数字はそこで異なります)。すべての数値をそのビットで分割し、各グループに XOR します。各グループには、一意の数値が 1 つだけ含まれます。

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

## 1 ビットの数 (LeetCode 191)

これは、上記のブライアン・カーニハンのアルゴリズム、つまり直接のインタビューの質問です。フォローアップでは、入力が署名されている場合はどうなるかを尋ねます。 Python では、整数の精度は任意ですが、Java/C++ では 32 ビット境界を処理する必要があります。

## サブセットのビット マスキング

長さ n のビットマスクは、n 個の項目のサブセットを表します。ビット `i` が設定されているということは、項目 `i` が含まれていることを意味します。 `0` から `2^n - 1` までを反復すると、すべてのサブセットが生成されます。

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

この手法は、n ≤ 20 (2^n の列挙には十分小さい) の問題の解決策を強化します。

<FunFact>Linux ファイルのアクセス許可 (rwxr-xr-x = 755) は実際のビットマスクです。各桁は、読み取り (4)、書き込み (2)、実行 (1) の 3 つの許可ビットをエンコードし、OR と組み合わせます。</FunFact>

## ビットを反転する (LeetCode 190)

32 ビットの符号なし整数をビットごとに反転します。結果を左にシフトし、入力の最下位ビットで OR を計算してから、入力を右にシフトします。

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## 欠落番号 (LeetCode 268)

0 から n までの n 個の数値 (1 つが欠けている) の配列。すべての配列要素とすべてのインデックス 0 ～ n の XOR (ペア) がキャンセルされ、欠落した数値が残ります。あるいは、合計の式を使用しますが、XOR により潜在的なオーバーフローが回避されます。

## ハミング距離 (LeetCode 461)

対応するビットが異なる位置の数。 2 つの数値の XOR を計算します。結果のセット ビットは異なる位置になります。ブライアン・カーニハンのトリックでそれらを数えてください。

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```

## 実際の応用例

ビット操作は随所に現れます。Unix ファイルのアクセス許可では OR/AND マスクが使用され、機能フラグではトグルが個別のビットとして保存され、ネットワーク サブネット マスクではルーティングに AND が使用され、エラー検出は XOR チェックサムに依存します。
