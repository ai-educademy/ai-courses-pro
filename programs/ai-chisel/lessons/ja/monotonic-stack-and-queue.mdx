## スタックが単調になる理由は何ですか?

**単調スタック** は、要素を下から上へ厳密に増加または減少する順序で維持します。新しい要素をプッシュする前に、不変条件に違反するすべてのものをポップします。この 1 つのアイデアにより、O(n²) が必要と思われる問題に対して O(n) 個の解決策が得られます。

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## 次のより優れた要素

各要素について、その右側にある最初の大きな要素を見つけます。各位置 - O(n²) に対して右方向にブルート フォース スキャンを実行します。単調減少スタックはこれを 1 パスで実行します。

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

インデックス `j` をポップすると、現在の要素はその次に大きくなります。これは、間にある要素がすべて小さいため (以前にポップされたか、ブロックされなかった `j`) ため、保証されます。

## ヒストグラム内の最大の長方形

LeetCode の **ヒストグラム内の最大の長方形** は、単調スタック問題の最高の宝石です。

**重要な洞察:** 各バーについて、最短のバーとして左右にどれだけ伸びることができるかを調べます。増加するスタックを使用します。バーがポップされると、ポップするバーがその右側の境界を定義し、新しいスタックの上部がその左側の境界を定義します。

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

最後のセンチネル `[0]` は、残りのすべてのバーを強制的に処理します。

## 雨水をトラップする - スタックアプローチ

古典的な 2 ポインタ法の代わりに、単調減少スタックがトラップされた水を層ごとに計算します。より高いバーが表示されたら、より短いバーをポップし、ポップされたバー、現在のバー、および新しいスタックの最上部の間に閉じ込められた水を計算します。

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>Trapping Rain Water には、少なくとも 4 つの異なる O(n) ソリューション (2 ポインター、単調スタック、プレフィックス最大配列、およびシングルパス最適化アプローチ) があります。面接官は複数の戦略を見るのが大好きです。</FunFact>

## モノトニックキュー - スライディングウィンドウの最大値

**単調デキュー** (両端キュー) は降順を維持し、両端からの効率的な削除をサポートします。 **スライディング ウィンドウの最大値** (LeetCode 239) の場合:

1. インデックス`i`を追加する前に、`nums[i]`より小さいすべての後方要素をポップします。
2.`i`を奥に押します
3. フロントは常に現在のウィンドウの最大値です
4. フロントが窓の外に落ちた場合は取り外します。

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

各要素は、両端キューに出入りするのは最大 1 回です (合計 **O(n)**)。

## パターン - 処理中に不変を維持する

すべての単調なスタック/キューの問題は 1 つのテンプレートに従います。

1. **不変式を定義** (増加または減少)
2. **違反者をポップ** - 各ポップから有用な情報を抽出します
3. **現在の要素をプッシュ**
4. *ポップイベント*は答えが計算される場所です
