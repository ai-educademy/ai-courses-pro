## グラフはつながった世界をモデル化する

友人関係、道路網、ハイパーリンク、神経経路など、エンティティが関係によってリンクされている場合は常に、**グラフ**が作成されます。正式には、グラフ G = (V, E) は頂点 (ノード) とエッジ (接続) で構成されます。

グラフは **有向** (一方通行) または **無向** (双方向) にすることができ、エッジには **重み** (距離、コスト、待ち時間) が含まれる場合があります。

## グラフの表現

2 つの一般的な表現:

|代表 |スペース |エッジルックアップ |こんな方に最適 |
|------|----------|---------------|----------|
| **隣接リスト** | O(V + E) | O(度) |スパース グラフ (ほとんどの現実世界のネットワーク) |
| **隣接行列** | O(V²) |お(1) |密なグラフ、素早いエッジの存在チェック |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## 幅優先検索 (BFS)

BFS は**レベルごと**に探索し、深く進む前にすべての近隣を訪問します。 **キュー**を使用します。

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**重要なプロパティ:** BFS はソースからの距離の順にノードを処理するため、重み付けされていないグラフで **最短パス** を見つけます。

### BFS の AI ユースケース

- **ソーシャル ネットワークの友達の提案** - 2 ～ 3 つのつながり内の人々を見つけます。
- **Web クローラー** - シード URL からレイヤーごとにページにインデックスを付けます。
- **パズルソルバー** - 最小の移動数を見つけます (ルービックキューブの状態など)。

## 深さ優先検索 (DFS)

DFS はバックトラックする前に**可能な限り深く**進みます。 **スタック** (または再帰) を使用します。

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### DFS のアプリケーション

- **トポロジカルソート** - すべての依存関係が最初に来るようにタスクを順序付けします (システムの構築、コースの前提条件)。
- **サイクル検出** - DFS が現在コール スタック上にあるノードを再訪問する場合、サイクルが存在します。
- **迷路解決** - 別の道を試す前に、1 つの道を徹底的に探索します。
- **接続されたコンポーネント** - 未訪問のすべてのノードから DFS を実行して、個別のクラスターを識別します。

## ダイクストラのアルゴリズム - 重み付きの最短経路

エッジのコストが異なる場合、BFS では十分ではなくなります。ダイクストラのアルゴリズムは、ソースから他のすべてのノードまでの最短の加重パスを見つけます。

**中心的なアイデア:** 最小ヒープ (優先キュー) を使用して、**最も安価な未訪問ノード** を常に拡張します。

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**時間計算量:** バイナリ ヒープの場合 O((V + E) log V)。

<FunFact>Google マップは、道路網全体で単純なダイクストラを実行するわけではありません。これは短縮階層と A* 検索を使用しますが、どちらも既知の最短距離による貪欲な拡張に関するダイクストラの基本的な洞察に基づいています。</FunFact>

### ダイクストラの AI ユースケース

- **ルート計画** - 最速のドライブを見つけるナビゲーション アプリ。
- **ネットワーク ルーティング** - インターネット パケットは最も遅延の少ないパスを選択します。
- **ナレッジ グラフ** - 概念間の最短の意味的つながりを見つけます。

## サイクル検出と接続コンポーネント

### サイクル検出

**有向グラフ**では、未訪問、進行中 (現在の DFS パス上)、完了の 3 つの状態にあるノードを追跡します。進行中のノードに遭遇すると、サイクルが存在することを意味します。

**無向グラフ**では、DFS が直接の親ではない訪問ノードに到達すると、サイクルが存在します。

### 接続されたコンポーネント

未訪問の各ノードから BFS または DFS を実行します。実行ごとに 1 つの接続コンポーネントが検出されます。ソーシャル ネットワークでは、コンポーネントによって孤立したコミュニティが明らかになります。

<ThinkAboutIt>AI 不正検出システムは、アカウントがノード、転送がエッジであるグラフとしてトランザクションをモデル化します。接続されたコンポーネントはマネーロンダリング組織の特定にどのように役立つでしょうか?</ThinkAboutIt>

## 重要なポイント

1. **BFS*​​ はレベルごとに探索します。重み付けされていないグラフの最短パスや近傍ベースの検出に最適です。
2. **DFS** は、トポロジカル ソート、サイクル検出、およびコンポーネント分析のバックボーンを深く掘り下げます。
3. **ダイクストラ** は、現代のルート計画の基礎である優先キューを使用して、BFS を重み付きグラフに拡張します。
4. グラフ アルゴリズムは、マップ、ソーシャル ネットワーク、パッケージ マネージャー、ナレッジ グラフの背後にあるエンジンです。

<FunFact>World Wide Web には、500 億を超えるインデックス付きページが含まれています。検索エンジン クローラーは、BFS のバリエーションを使用してページを検出し、インデックスを再作成し、ページの重要性 (PageRank) に基づいて優先順位を付けます。</FunFact>
