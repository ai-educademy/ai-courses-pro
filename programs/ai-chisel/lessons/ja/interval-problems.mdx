## 間隔表現

間隔は`[start, end]`のペアです。ほとんどの間隔の問題は、**開始時刻による並べ替え**という 1 つの重要なステップから始まります。これにより、混沌としたリストが、単純な比較で左から右に処理できるシーケンスに変換されます。

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## 重複する間隔を結合する

基本的な区間問題 (LeetCode 56)。並べ替え後、現在の開始位置 ≤ 前の終了位置の場合、2 つの連続する間隔が重複します。

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

`[1,4] [2,5] [3,6] [8,10]` を歩きます:
- `[2,5]`が`[1,4]`と重なる → `[1,5]`に結合
- `[3,6]`が`[1,5]`と重なる → `[1,6]`に結合
- `[8,10]` 重複なし → 新しい間隔

結果: `[1,6] [8,10]`

## 間隔を挿入

ソートされた重複しない間隔と新しい間隔を指定して、それを挿入し、必要に応じてマージします (LeetCode 57)。 3 つのフェーズに分かれています。

1. 新しい間隔が開始される前に終了するすべての間隔を追加します。
2. 重複するすべての間隔を新しい間隔とマージします。
3. 残りの間隔を変更せずに追加します。

<ThinkAboutIt>挿入間隔は、マージ ステップが明確に示されないことがよくあります。面接中にそれがマージの問題であるとどのように認識しますか?</ThinkAboutIt>

## 会議室 I - 全員に出席できますか?

開始時間順に並べ替えます。間隔の開始が前の間隔の終了より前にある場合、競合が発生します。

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## 会議室 II - 最小部屋数

ここで、**イベントベースのアプローチ**が威力を発揮します。開始と終了を 2 つのソートされたリストに分離し、スイープします。

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

ヒープは、最も早く終了した会議を追跡します。次のイベントが始まる前に終了した場合は、部屋を再利用します。ヒープの最大サイズが答えです。

## 重複しない間隔 - 最小削除数

指定された間隔で、重複しないように削除する最小数を見つけます (LeetCode 435)。貪欲: **終了時刻**で並べ替え、常に最も早く終了する間隔を維持します。これにより、将来の間隔に最大限の余地が残ります。

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## 間隔リストの交差

2 つのソートされた間隔リストを指定して、すべての交差を見つけます (LeetCode 986)。リストごとに 1 つずつ、2 つのポインターを使用します。 `[a1, a2]` と `[b1, b2]` の交点は、有効 (開始 ≤ 終了) の場合、`[max(a1, b1), min(a2, b2)]` になります。区間が最初に終了するポインタを進めます。

## スイープ ライン テクニック

間隔をペアごとに比較する代わりに、それぞれをイベントに分解します。

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

イベントを時間ごとに並べ替えます。ランニングカウントを維持しながら、左から右にスイープします。ピーク数は、「最大重複」の質問に答えます。これは、Meeting Rooms II を任意のイベント処理問題に一般化します。

## カレンダーの予約

**My Calendar I** (LeetCode 729): 予約された間隔を維持し、重複を拒否します。 **My Calendar II**: 単一の重複は許可しますが、トリプル予約は拒否します。スイープ ラインにより、多層の重なりの検出が簡単になります。
