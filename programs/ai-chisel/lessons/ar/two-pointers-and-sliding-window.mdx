## ما أهمية إجراء المسح الضوئي بذكاء؟

تخيل أن الذكاء الاصطناعي يراقب بث الفيديو المباشر بحثًا عن أي نشاط مشبوه. لا يمكنه إعادة مشاهدة التسجيل بأكمله كل ثانية - فهو يحتاج إلى تمرير نافذة الانتباه عبر الدفق، وتتبع السياق الكافي فقط. هذا هو بالضبط ما يفعله نمطا **المؤشران** و**النافذة المنزلقة** للبيانات المتسلسلة.

تعمل كلتا الطريقتين على تحويل عمليات المسح بالقوة الغاشمة O(n²) إلى تمريرات O(n) أنيقة.

## تقنية المؤشرين

ضع مرجعين في تسلسل وحركهما وفقًا للقاعدة. هناك نوعان من النكهات الرئيسية.

### المؤشرات المتقاربة

ابدأ بمؤشر واحد عند كل طرف وحركه إلى الداخل. مثالي للبيانات **المرتبة**.

**مشكلة كلاسيكية - مجموع الزوج:** في حالة وجود مصفوفة مرتبة، ابحث عن رقمين يضافان إلى الهدف.

```
function pairSum(arr, target):
    left = 0
    right = arr.length - 1
    while left < right:
        sum = arr[left] + arr[right]
        if sum == target: return (left, right)
        if sum < target: left += 1
        else: right -= 1
    return null
```

نظرًا لأن المصفوفة مرتبة، فإن تحريك `left` لليمين يزيد المجموع، والتحرك `right` لليسار يقلله - مما يضمن عدم تفويت زوج صالح أبدًا.

### مؤشرات نفس الاتجاه

يتحرك كلا المؤشرين للأمام، ولكن بسرعات مختلفة. مفيد في **التقسيم** أو **الكشف عن الدورة**.

**مثال - إزالة التكرارات في مكانها:** يشير المؤشر البطيء إلى موضع الكتابة؛ يقوم مؤشر سريع بالمسح للأمام.

```
function removeDuplicates(arr):
    slow = 0
    for fast in 1..arr.length - 1:
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1
```

## نمط النافذة المنزلقة

تحافظ النافذة المنزلقة على تسلسل فرعي متجاور بحجم _k_ (ثابت) أو طول متغير، وتحديث المجاميع بشكل متزايد بدلاً من إعادة الحساب من البداية.

### نافذة ذات حجم ثابت

قم بتمرير نافذة تحتوي على عناصر _k_ بالضبط عبر المصفوفة.

**مثال - الحد الأقصى لمجموع أي عناصر متتالية:**

```
function maxSubarraySum(arr, k):
    windowSum = sum(arr[0..k-1])
    best = windowSum
    for i in k..arr.length - 1:
        windowSum += arr[i] - arr[i - k]
        best = max(best, windowSum)
    return best
```

تضيف كل خطوة العنصر الجديد الذي يدخل إلى النافذة وتطرح العنصر المغادر - O(1) لكل حركة.

### نافذة متغيرة الحجم

قم بتوسيع النافذة لتشمل المزيد من البيانات، ثم قم بتقليصها عند انتهاك أحد القيود.

**مثال - أطول سلسلة فرعية بدون أحرف متكررة:**

```
function longestUnique(s):
    seen = {}
    left = 0
    best = 0
    for right in 0..s.length - 1:
        if s[right] in seen and seen[s[right]] >= left:
            left = seen[s[right]] + 1
        seen[s[right]] = right
        best = max(best, right - left + 1)
    return best
```

<FunFact>تستخدم منصات التحليلات المتدفقة مثل Apache Flink النوافذ المنزلقة والمتداعية كأوليات من الدرجة الأولى - وهو نفس المفهوم الذي تم قياسه ليشمل ملايين الأحداث في الثانية.</FunFact>

## تطبيقات الذكاء الاصطناعي الحقيقية

| نمط | حالة استخدام الذكاء الاصطناعي |
|---------|-----------|
| نافذة ثابتة | اكتشاف الشذوذ خلال قراءات مستشعر _k_ الأخيرة |
| نافذة متغيرة | البحث عن أقصر امتداد نصي يحتوي على جميع كلمات الاستعلام (محركات البحث) |
| المؤشرات المتقاربة | عمليات فحص فعالة لأقرب جار في أبعاد التضمين المصنفة |
| مؤشرات نفس الاتجاه | دمج قوائم النتائج المصنفة من نماذج استرجاع متعددة |

<ThinkAboutIt>يقوم المساعد الصوتي بتخزين آخر 3 ثوانٍ من الصوت لاكتشاف كلمة التنبيه. ما هو هذا النمط - نافذة ثابتة أم نافذة متغيرة؟ ماذا يحدث إذا كانت كلمة التنبيه أطول من المخزن المؤقت؟ </ThinkAboutIt>

## متى تستخدم أي

- **مؤشران (متقاربان):** المدخلات المصنفة، البحث الزوجي/الثلاثي، فحص المتناظر.
- **مؤشران (نفس الاتجاه):** تعديلات موضعية، مشاكل في العداء السريع/البطيء.
- **نافذة منزلقة ثابتة:** مجمعة على حجم نافذة معروف.
- **نافذة منزلقة متغيرة:** ابحث عن أصغر أو أكبر نافذة تستوفي الشرط.

## الوجبات السريعة الرئيسية

1. يقوم المؤشران بإزالة الحلقات المتداخلة من خلال الاستفادة من الترتيب أو التقسيم.
2. تحافظ النوافذ المنزلقة على حالة التشغيل بحيث تتم معالجة كل عنصر مرتين على الأكثر.
3. يعد كلا النمطين أساسيين في مسارات الذكاء الاصطناعي في الوقت الفعلي - بدءًا من الكشف عن الحالات الشاذة وحتى تصنيف البحث.
