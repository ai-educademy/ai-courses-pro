## ما الذي يجعل المكدس رتيبًا؟

**المكدس الرتيب** يحافظ على العناصر بترتيب متزايد أو متناقص بشكل صارم من الأسفل إلى الأعلى. قبل دفع عنصر جديد، عليك أن تفرقع كل ما ينتهك الثوابت. هذه الفكرة الفردية تفتح حلول O(n) للمشكلات التي يبدو أنها تتطلب O(n²).

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## العنصر الأعظم التالي

لكل عنصر، ابحث عن أول عنصر أكبر على يمينه. تقوم القوة الغاشمة بمسح اليمين لكل موضع - O(n²). كومة متناقصة رتيبة تفعل ذلك في تمريرة واحدة.

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

عندما نفرقع الفهرس `j`، فإن العنصر الحالي هو العنصر التالي الأكبر - وهذا مضمون لأن كل شيء بينهما كان أصغر (تم ظهورهما مسبقًا أو لم يتم حظرهما مطلقًا `j`).

## درجات الحرارة اليومية (LeetCode 739)

*بالنظر إلى درجات الحرارة اليومية، ابحث عن عدد الأيام المتبقية حتى يوم أكثر دفئًا.* هذا هو العنصر الأكبر التالي مع المؤشرات - إجابة المؤشر `j` هي `i − j` عندما يتم ظهور `j` بواسطة المؤشر `i`.

## مشكلة امتداد المخزون

*لكل يوم، كم عدد الأيام المتتالية (بما في ذلك اليوم) التي كان سعرها ≥ سعر اليوم؟ * استخدم تخزين المكدس المتناقص الرتيب `(price, index)`. عندما تنبثق، فإن الفجوة بين الفهرس الحالي وأعلى المكدس الجديد تعطي الامتداد.

## أكبر مستطيل في الرسم البياني

يعد **أكبر مستطيل في الرسم البياني** من LeetCode جوهرة التاج لمشاكل المكدس الرتيبة.

**الرؤية الأساسية:** بالنسبة لكل شريط، يمكنك العثور على المدى الذي يمكن أن يمتد به إلى اليسار واليمين كأقصر شريط. استخدم مكدسًا متزايدًا - عندما ينفجر شريط، يحدد الشريط المنبثق حدوده اليمنى، ويحدد الجزء العلوي الجديد للمكدس حده الأيسر.

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

الحارس `[0]` في النهاية يفرض معالجة جميع القضبان المتبقية.

## محاصرة مياه الأمطار - نهج المكدس

بدلاً من الطريقة الكلاسيكية ذات المؤشرين، تقوم المكدس المتناقص الرتيب بحساب طبقة المياه المحاصرة طبقة تلو الأخرى. عندما يظهر شريط أطول، قم بإخراج القضبان الأقصر واحسب الماء المحصور بين الشريط المنبثق والشريط الحالي والجزء العلوي الجديد من المكدس.

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>يحتوي محاصرة مياه الأمطار على أربعة حلول O(n) مميزة على الأقل - مؤشران، ومكدس رتيب، ومصفوفات الحد الأقصى للبادئة، ونهج محسّن بتمريرة واحدة. يحب القائمون على المقابلات رؤية استراتيجيات متعددة.</FunFact>

## قائمة الانتظار الرتيبة - الحد الأقصى للنافذة المنزلقة

تحافظ **deque الرتيبة** (قائمة الانتظار ذات النهاية المزدوجة) على الترتيب التنازلي وتدعم الإزالة الفعالة من كلا الطرفين. بالنسبة لـ **الحد الأقصى للنافذة المنزلقة** (LeetCode 239):

1. قبل إضافة الفهرس `i`، قم بإزاحة جميع العناصر الأصغر من `nums[i]`
2. ادفع `i` إلى الخلف
3. الجزء الأمامي هو دائمًا الحد الأقصى للنافذة الحالية
4. قم بإزالة الجزء الأمامي إذا سقط خارج النافذة

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

يدخل كل عنصر إلى المجموعة ويخرج منها مرة واحدة على الأكثر - إجمالي **O(n)**.

## النمط - الحفاظ على الثبات أثناء المعالجة

تتبع كل مشكلة مكدس/قائمة انتظار رتيبة قالبًا واحدًا:

1. **تعريف الثابت** (زيادة أو نقصان)
2. **مخالفو البوب** - واستخراج المعلومات المفيدة من كل فرقعة
3. **ادفع العنصر الحالي**
4. حدث *البوب* هو المكان الذي يتم فيه حساب الإجابة
