## الأشجار في كل مكان في الذكاء الاصطناعي

في كل مرة يقوم فيها مرشح البريد العشوائي بتصنيف بريد إلكتروني أو تقوم قاعدة بيانات باسترداد طلبك بالمللي ثانية، فإن بنية البيانات الشجرية تقوم بالمهمة الثقيلة. نموذج الأشجار **القرارات الهرمية** - كل عقدة تضيق مساحة البحث حتى تصل إلى إجابة.

## أشجار البحث الثنائية (BSTs)

تقوم BST بتخزين العناصر بحيث تكون جميع القيم في الشجرة الفرعية **اليسرى** الخاصة بها أصغر وكل القيم في الشجرة الفرعية **اليمنى** الخاصة بها أكبر.

### يبحث

```
function search(node, target):
    if node is null: return null
    if target == node.value: return node
    if target < node.value: return search(node.left, target)
    return search(node.right, target)
```

تقوم كل مقارنة بإزالة ما يقرب من نصف العقد المتبقية - O(log n) على شجرة متوازنة.

### الإدراج

```
function insert(node, value):
    if node is null: return new Node(value)
    if value < node.value:
        node.left = insert(node.left, value)
    else:
        node.right = insert(node.right, value)
    return node
```

### الحذف

الحذف هو أصعب عملية. تنشأ ثلاث حالات:

1. **العقدة الورقية** - قم بإزالتها ببساطة.
2. **طفل واحد** - استبدل العقدة بطفلها.
3. **طفلان** - قم بتبديل قيمة العقدة مع خليفتها بالترتيب (أصغر قيمة في الشجرة الفرعية اليمنى)، ثم احذف تلك اللاحقة.

## متوازن مقابل غير متوازن

إذا قمت بإدراج البيانات التي تم فرزها في BST عادي، فإنها تتحول إلى قائمة مرتبطة - O(n) لكل عملية. تعمل أشجار **التوازن الذاتي** على إصلاح هذا الأمر:

| شجرة | قاعدة التوازن | الاستخدام النموذجي |
|------|------------|-------------|
| أفل | فرق الارتفاع ≥ 1 بين الأشجار الفرعية | عمليات البحث في الذاكرة |
| أحمر-أسود | قواعد التناوب على أساس اللون | مكتبات اللغة القياسية (مثل Java TreeMap) |
| ب-شجرة | مفاتيح متعددة لكل عقدة، جميعها تترك بنفس العمق | قواعد البيانات وأنظمة الملفات |

<FunFact>يستخدم كل من PostgreSQL وMySQL متغيرات B-tree كبنية الفهرس الافتراضية الخاصة بهما. يمكن لشجرة B ذات عامل التفرع 100 فهرسة مليار صف في خمسة مستويات فقط.</FunFact>

## اجتياز الشجرة

تزور عمليات الاجتياز كل عقدة مرة واحدة بالضبط. تختلف الأوامر الكلاسيكية الثلاثة فقط في **متى** تقوم بمعالجة العقدة الحالية بالنسبة إلى أبنائها.

| اجتياز | اطلب | حالة الاستخدام |
|-----------|------|----------|
| **بالترتيب** | اليسار → العقدة → اليمين | ينتج مخرجات مرتبة من BST |
| **الطلب المسبق** | العقدة → اليسار → اليمين | تسلسل / استنساخ شجرة |
| **طلب ما بعد** | اليسار → اليمين → العقدة | حذف شجرة بأمان؛ تقييم أشجار التعبير |

```
function inOrder(node):
    if node is null: return
    inOrder(node.left)
    process(node)
    inOrder(node.right)
```

<ThinkAboutIt>يقوم المترجم بتوزيع التعليمات البرمجية الخاصة بك إلى شجرة بناء جملة مجردة (AST). ما ترتيب الاجتياز الذي ستستخدمه لتقييم التعبير `(3 + 5) * 2` المخزن كشجرة؟ لماذا؟</ThinkAboutIt>

## الكومة وقوائم الانتظار ذات الأولوية

** الكومة ** هي شجرة ثنائية كاملة حيث يكون كل والد أكبر (أقصى كومة) أو أصغر (أدنى كومة) من أبنائه. وهو يدعم:

- **إدراج** - أضف في النهاية، ثم ارفع الفقاعة. يا (سجل ن).
- **استخرج الحد الأدنى/الحد الأقصى** - قم بإزالة الجذر، وانقل العنصر الأخير إلى الجذر، ثم قم بالغربلة. يا (سجل ن).

قوائم الانتظار ذات الأولوية المبنية على أكوام الطاقة:
- **خوارزمية ديكسترا** (الدرس التالي!) - قم دائمًا بتوسيع أقرب عقدة لم تتم زيارتها.
- **جدولة المهام** - يقوم برنامج جدولة نظام التشغيل باختيار العملية ذات الأولوية القصوى.
- **بحث الشعاع في البرمجة اللغوية العصبية** - احتفظ بإكمالات الجمل الواعدة.

```
function siftUp(heap, index):
    while index > 0:
        parent = (index - 1) / 2
        if heap[index] < heap[parent]:
            swap(heap, index, parent)
            index = parent
        else: break
```

## تطبيقات الذكاء الاصطناعي الحقيقية

- **أشجار القرار** في التعلم الآلي تقوم بتقسيم البيانات في كل عقدة باستخدام الميزة التي تفصل بين الفئات بشكل أفضل - وهو تطبيق مباشر لبنية الشجرة.
- **تمثل أشجار بناء الجملة** في البرمجة اللغوية العصبية البنية النحوية، مما يتيح تنفيذ مهام مثل تحليل المشاعر والترجمة الآلية.
- **Monte Carlo Tree Search (MCTS)** يعمل على تشغيل الذكاء الاصطناعي أثناء اللعب مثل AlphaGo، واستكشاف التحركات المحتملة كشجرة لحالات اللعبة.
- **أشجار هوفمان** تقوم بضغط البيانات عن طريق تعيين رموز أقصر للرموز المتكررة - المستخدمة في ضغط وزن النموذج.

<FunFact>يقوم مُصنف شجرة القرار scikit-Learn ببناء شجرة حيث تختبر كل عقدة داخلية عتبة الميزة. يمكن للنموذج المُدرب بعمق 20 أن يمثل أكثر من مليون مسار قرار مختلف.</FunFact>

<ThinkAboutIt>إذا كنت تقوم ببناء نظام الإكمال التلقائي، فهل ستستخدم BST، أو الكومة، أو بنية شجرة مختلفة (مثل محاولة)؟ فكر في العمليات التي تحتاجها لتكون سريعًا.</ThinkAboutIt>

## الوجبات السريعة الرئيسية

1. توفر BSTs بحثًا وإدراجًا وحذفًا لـ O(log n) - ولكن فقط عندما تكون متوازنة.
2. يحدد ترتيب الاجتياز المعلومات التي تستخرجها من الشجرة.
3. تمنح الأكوام O(1) إمكانية الوصول إلى القيمة القصوى وإدراج O(log n) - وهي مثالية لخوارزميات الذكاء الاصطناعي القائمة على الأولوية.
4. تدعم الأشجار عملية اتخاذ القرار عبر تعلم الآلة وقواعد البيانات والمترجمين والذكاء الاصطناعي للألعاب.
