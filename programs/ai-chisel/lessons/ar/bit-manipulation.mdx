## مراجعة الرقم الثنائي

كل عدد صحيح هو سلسلة من البتات. الرقم 13 في النظام الثنائي هو `1101`:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

تعمل معالجة البتات مباشرة على هذه البتات باستخدام معاملات البت - وغالبًا ما يتم استبدال الحلقات بعمليات فردية.

## العمليات الأساسية المتعلقة بالبت

| Operator | Symbol | Example (5 = 101, 3 = 011) | Result |
|----------|--------|----------------------------|--------|
| AND      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| XOR      | `^`    | `101 ^ 011`                | `110` (6) |
| NOT      | `~`    | `~101`                     | `...010` |
| Left shift  | `<<` | `101 << 1`              | `1010` (10) |
| Right shift | `>>` | `101 >> 1`              | `10` (2) |

## حيل البت الأساسية

### تحقق مما إذا كانت قوة اثنين

تحتوي القوة 2 على بتة واحدة بالضبط: `n & (n - 1) == 0`.

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### عدد البتات المحددة (خوارزمية بريان كيرنيغان)

كل `n & (n - 1)` يزيل أقل بتة محددة. عد التكرارات حتى ن = 0.

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

يتم تشغيل هذا في O(k) حيث k هو عدد البتات المحددة - وليس O(32).

### التبديل بدون متغير درجة الحرارة

```python
a ^= b
b ^= a
a ^= b
```

يعمل لأن XOR هو معكوسه: `a ^ b ^ b = a`.

## الرقم الفردي - إلغاء XOR

كل عنصر يظهر مرتين ماعدا عنصر واحد. العثور عليه. منذ `a ^ a = 0` و`a ^ 0 = a`، XOR جميع العناصر - يتم إلغاء الأزواج، مع ترك الرقم الفريد.

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

الوقت O(n)، الفضاء O(1). لا حاجة لخريطة التجزئة.

## الرقم الفردي III - رقمان فريدان

عندما يكون *رقمان* فريدين، XOR كل شيء لتحصل على `x = a ^ b`. ابحث عن أي بتة محددة في `x` (تختلف الأرقام هناك). قم بتقسيم جميع الأرقام حسب ذلك البت وXOR لكل مجموعة - تحتوي كل مجموعة على رقم فريد واحد بالضبط.

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>لماذا يقوم `xor & (-xor)` بعزل البت الموجود في أقصى اليمين؟ فكر في كيفية تمثيل الأرقام السالبة في تكملة الاثنين.</ThinkAboutIt>

## إخفاء البت للمجموعات الفرعية

يمثل قناع البت ذو الطول n مجموعة فرعية من n من العناصر. تعيين البت `i` يعني تضمين العنصر `i`. التكرار من `0` إلى `2^n - 1` يُنشئ جميع المجموعات الفرعية.

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

توفر هذه التقنية حلولاً للمشكلات ذات n ≥ 20 - وهي صغيرة بما يكفي لتعداد 2^n.

<FunFact>أذونات ملفات Linux (rwxr-xr-x = 755) هي قناع نقطي حقيقي. يقوم كل رقم بتشفير ثلاث بتات إذن: القراءة (4)، الكتابة (2)، التنفيذ (1)، بالإضافة إلى OR.</FunFact>

## عكس البتات (LeetCode 190)

عكس عدد صحيح غير موقّع 32 بت شيئًا فشيئًا. قم بإزاحة النتيجة إلى اليسار وOR في أدنى جزء من الإدخال، ثم قم بتحويل الإدخال إلى اليمين.

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## الرقم المفقود (LeetCode 268)

مصفوفة من الأرقام n من 0 إلى n مع فقدان رقم واحد. XOR جميع عناصر المصفوفة التي تحتوي على جميع المؤشرات من 0 إلى n - يتم إلغاء الأزواج، مما يترك الرقم المفقود. وبدلاً من ذلك، استخدم صيغة المجموع، ولكن XOR يتجنب التجاوز المحتمل.

## مسافة هامينغ (LeetCode 461)

عدد المواضع التي تختلف فيها البتات المقابلة. XOR الرقمان - البتات المحددة في النتيجة هي المواضع المختلفة. عدهم بحيلة بريان كيرنيغان.

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```
