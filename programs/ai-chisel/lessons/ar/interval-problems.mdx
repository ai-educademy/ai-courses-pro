## التمثيل الفاصل

الفاصل الزمني هو زوج `[start, end]`. تبدأ معظم مشكلات الفترات بخطوة واحدة مهمة: **الفرز حسب وقت البدء**. يؤدي هذا إلى تحويل القائمة الفوضوية إلى تسلسل يمكنك معالجته من اليسار إلى اليمين من خلال مقارنات بسيطة.

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## دمج الفترات المتداخلة

مشكلة الفاصل التأسيسي (LeetCode 56). بعد الفرز، تتداخل فترتان متتاليتان إذا كانت البداية الحالية ≥ النهاية السابقة.

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

المشي عبر `[1,4] [2,5] [3,6] [8,10]`:
- `[2,5]` يتداخل `[1,4]` → دمج إلى `[1,5]`
- `[3,6]` يتداخل `[1,5]` → دمج إلى `[1,6]`
- `[8,10]` لا يوجد تداخل → فاصل زمني جديد

النتيجة: `[1,6] [8,10]`

## أدخل الفاصل الزمني

بالنظر إلى الفواصل الزمنية غير المتداخلة التي تم فرزها والفاصل الزمني الجديد، قم بإدراجها ودمجها حسب الحاجة (LeetCode 57). تنقسم إلى ثلاث مراحل:

1. قم بإضافة جميع الفواصل الزمنية التي تنتهي قبل أن تبدأ الفترة الجديدة
2. دمج كافة الفواصل الزمنية المتداخلة مع الفترة الجديدة
3. أضف الفواصل الزمنية المتبقية دون تغيير

<ThinkAboutIt>غالبًا ما يتم تقديم الفاصل الزمني للإدراج دون أن تكون خطوة الدمج واضحة. كيف يمكنك التعرف عليها كمشكلة دمج أثناء المقابلة؟ </ThinkAboutIt>

## قاعات الاجتماعات التي يمكنني حضورها - هل يمكنني حضور الجميع؟

الترتيب حسب وقت البدء. إذا كانت بداية أي فاصل زمني قبل نهاية الفاصل الزمني السابق، فهذا يعني وجود تعارض.

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## غرف الاجتماعات II - الحد الأدنى من الغرف

هذا هو المكان الذي يتألق فيه **النهج القائم على الحدث**. افصل البدايات والنهايات في قائمتين مرتبتين، ثم امسح:

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

الكومة تتعقب أول اجتماع نهائي. إذا انتهى قبل أن يبدأ التالي، فإننا نعيد استخدام الغرفة. الحد الأقصى لحجم الكومة هو الجواب.

## الفترات غير المتداخلة - الحد الأدنى من عمليات الإزالة

مع فترات زمنية معينة، ابحث عن الحد الأدنى للعدد المطلوب إزالته حتى لا يتداخل أي شيء (LeetCode 435). الجشع: قم بالفرز حسب **وقت الانتهاء**، واحتفظ دائمًا بالفاصل الزمني الذي ينتهي في أقرب وقت ممكن - وهذا يترك مساحة أكبر للفترات الزمنية المستقبلية.

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## تقاطعات القائمة الفاصلة

بالنظر إلى قائمتين للفواصل الزمنية المصنفة، ابحث عن جميع التقاطعات (LeetCode 986). استخدم مؤشرين - واحد لكل قائمة. تقاطع `[a1, a2]` و `[b1, b2]` هو `[max(a1, b1), min(a2, b2)]` إذا كان صحيحا (البداية ≥ النهاية). قم بتقديم المؤشر الذي ينتهي الفاصل الزمني له أولاً.

## تقنية خط الاجتياح

بدلاً من مقارنة الفترات الزوجية، قم بتحليل كل منها إلى أحداث:

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

فرز الأحداث حسب الوقت. اكتساح اليسار إلى اليمين، والحفاظ على العد الجاري. يجيب عدد الذروة على أسئلة "الحد الأقصى للتداخل". يؤدي ذلك إلى تعميم غرف الاجتماعات II على مشكلات معالجة الأحداث العشوائية.

## حجز التقويم

**تقويمي الأول** (LeetCode 729): الحفاظ على الفواصل الزمنية المحجوزة ورفض التداخلات. **تقويمي II**: يسمح بالتداخلات الفردية ولكن يرفض الحجوزات الثلاثية. يجعل خط المسح اكتشاف التداخل متعدد الطبقات أمرًا سهلاً.
