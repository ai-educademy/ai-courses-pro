## ما هي المحاولة؟

**trie** (تنطق "try") هي بنية تشبه الشجرة حيث تمثل كل عقدة حرفًا واحدًا. توضح المسارات من الجذر إلى العقد المحددة الكلمات المخزنة. على عكس خرائط التجزئة، تتيح لك المحاولات الاستعلام عن *جميع الكلمات التي تتشارك في بادئة* دون مسح كل مفتاح.

```
        root
       / | \
      a   b   c
     /     \
    p       a
   / \       \
  p   e      t
  |
  l
  e
```

يشفر كل مسار كلمة: **apple**، **ape**، **bat**، **cat**.

## فئة TrieNode

تحتوي كل عقدة على خريطة للأطفال وعلم يشير إلى اكتمال الكلمة.

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False
```

يقوم Trie الكامل بتغليف هذا من خلال عمليات الإدراج والبحث والبادئة.

## العمليات الأساسية

### أدخل - O(m) حيث m = طول الكلمة

انتقل حرفًا تلو الآخر، وأنشئ العقد حسب الحاجة، ثم حدد العقدة الأخيرة.

```python
def insert(self, word):
    node = self.root
    for ch in word:
        if ch not in node.children:
            node.children[ch] = TrieNode()
        node = node.children[ch]
    node.is_end = True
```

### البحث والبدء بـ

**بحث** يتبع المسار ويتحقق `is_end`. **startsWith** يتحقق فقط من وجود المسار - فهو لا يتطلب `is_end = True`.

## الإكمال التلقائي باستخدام DFS

لاقتراح إكمالات لبادئة، انتقل إلى عقدة البادئة، ثم قم بتشغيل DFS لتجميع كل الكلمات الموجودة أسفلها.

```python
def autocomplete(self, prefix):
    node = self._find(prefix)
    if not node:
        return []
    results = []
    self._dfs(node, prefix, results)
    return results
```

يتكرر المساعد `_dfs` من خلال الأطفال، ويلحق بالنتائج عندما يكون `is_end` هو `True`.

<ThinkAboutIt>كيف يمكنك قصر الإكمال التلقائي على الاقتراحات الأكثر شيوعًا؟ ما هي البيانات الإضافية التي تحتاجها كل عقدة؟ </ThinkAboutIt>

## بحث البدل - قاموس الكلمات

يطلب منك **تصميم إضافة وبنية بيانات كلمات البحث** من LeetCode التعامل مع `.` كحرف بدل يطابق أي حرف واحد.

أثناء البحث، عندما تضغط على `.`، تفرع إلى *كل* طفل واستمر بشكل متكرر. يؤدي هذا إلى تحويل اجتياز بسيط إلى بحث تراجعي محدود.

```python
def search_wild(self, node, word, i):
    if i == len(word):
        return node.is_end
    if word[i] == '.':
        return any(
            self.search_wild(c, word, i + 1)
            for c in node.children.values()
        )
    if word[i] not in node.children:
        return False
    return self.search_wild(
        node.children[word[i]], word, i + 1
    )
```

## توجيه IP مع المحاولات

تقوم أجهزة التوجيه بتخزين بادئات IP في **محاولة ثنائية** - كل بت (0 أو 1) يشكل فرعًا. تعمل أطول مطابقة للبادئة على العثور على المسار الأكثر تحديدًا. هذه هي الطريقة التي تجد بها حزمك طريقها عبر الإنترنت.

<FunFact>تقوم أجهزة التوجيه الأساسية للإنترنت بإجراء مليارات عمليات البحث عن تطابق البادئة الأطول في الثانية باستخدام محاولات محسنة للأجهزة مدمجة في شرائح متخصصة تسمى TCAMs.</FunFact>

## المحاولات المضغوطة (أشجار الجذر)

يحاول المعيار إضاعة المساحة على سلاسل الطفل الواحد. تقوم **شجرة الجذر** بدمج هذه السلاسل في حواف مفردة لتخزين التسميات متعددة الأحرف.

```
Standard:  r → u → n → n → i → n → g
Radix:     r → "unning"
```

يؤدي هذا إلى تقليل عدد العقد بشكل كبير ويتم استخدامه بواسطة جداول توجيه Linux kernel وأجهزة توجيه HTTP مثل Go's `httprouter`.

## تعقيد الزمان والمكان

| عملية | حاول | خريطة التجزئة |
|-------------|--------|----------|
| أدخل | يا(م) | يا(م) |
| بحث | يا(م) | يا(م) |
| استعلام البادئة| يا(م+ك) | يا(ن·م) |

هنا *m* هو طول الكلمة، *k* هو عدد النتائج، و*n* هو إجمالي المفاتيح. المحاولات تهيمن على أعباء العمل ذات البادئات الثقيلة.
