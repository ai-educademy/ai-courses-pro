## 大创意

有些问题看起来极其复杂，直到您注意到它们是由**更小的、重复的子问题**组成的。动态编程 (DP) 解决每个子问题**一次**，存储结果并重用它 - 用一点内存换取显着的加速。

有两个条件表明有 DP 机会：

1. **重叠子问题** - 相同的计算重复多次。
2. **最优子结构** - 整个问题的最佳解决方案可以由其各个部分的最佳解决方案构建。

## 斐波那契：经典示例

### 朴素递归 - O(2ⁿ)

```
function fib(n):
    if n <= 1: return n
    return fib(n - 1) + fib(n - 2)
```

调用 `fib(5)` 会触发 **15** 函数调用，其中许多是多余的。 `fib(40)` 需要几秒钟；在`fib(100)`时，它将比宇宙更长久。

### 记忆（自上而下）- O(n)

将结果存储在缓存中。如果您已经解决了子问题，则返回缓存的答案。

```
memo = {}
function fib(n):
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = fib(n - 1) + fib(n - 2)
    return memo[n]
```

### 制表（自下而上）- O(n)

从基本案例向上迭代构建答案。

```
function fib(n):
    table = [0, 1]
    for i in 2..n:
        table[i] = table[i - 1] + table[i - 2]
    return table[n]
```

## 经典DP问题

### 爬楼梯

您可以一次走 1 或 2 步。有多少种不同的方法可以到达步骤 _n_？

```
function climbStairs(n):
    if n <= 2: return n
    a = 1, b = 2
    for i in 3..n:
        a, b = b, a + b
    return b
```

这是变相的斐波那契 - 步骤 _n_ 的答案是到达步骤 _n−1_ 和 _n−2_ 的方法之和。

### 硬币找零

给定硬币面额，找到**最少的硬币**来达到目标​​金额。

```
function coinChange(coins, amount):
    dp = array of size (amount + 1), filled with INF
    dp[0] = 0
    for i in 1..amount:
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != INF else -1
```

### 最长公共子序列（LCS）

查找两个字符串（不一定是连续的）共有的最长字符序列。

```
function lcs(s1, s2):
    m = s1.length, n = s2.length
    dp = 2D array of size (m+1) x (n+1), filled with 0
    for i in 1..m:
        for j in 1..n:
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

## 自上而下与自下而上

|方面|自上而下（记忆）|自下而上（制表）|
|--------|----------------------------------|----------------------|
|风格|递归+缓存|迭代+表格|
|子问题已解决 |只提供那些需要的 |所有子问题最多 _n_ |
|堆栈溢出风险|是的，对于深度递归 |没有 |
|易于优化 |减少空间更难 |更容易（通常只保留最后一行）|

**经验法则：** 从记忆开始以了解重复情况，然后如果需要优化空间或避免堆栈限制，则转换为表格。

<ThinkAboutIt>硬币找零台的大小为O（金额）。 LCS 表的大小为 O(m × n)。你能通过一次只保留两行将 LCS 空间减少到 O(min(m, n)) 吗？您会丢失哪些信息？</ThinkAboutIt>

## 要点

1. DP通过**缓存重复工作**将指数暴力转换为多项式时间。
2. 在达到 DP 之前确定重叠的子问题和最佳子结构。
3. 记忆直观；制表是高效的——两者都学习。
4. 编辑距离、维特比和序列比对显示 DP 是现代人工智能的核心。
