## 区间表示

一个音程是一对`[start, end]`。大多数间隔问题都始于一个关键步骤：**按开始时间排序**。这会将混乱的列表转换为可以通过简单比较从左到右处理的序列。

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## 合并重叠区间

基础区间问题（LeetCode 56）。排序后，如果当前开始≤前一个结束，则两个连续区间重叠。

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

遍历`[1,4] [2,5] [3,6] [8,10]`：
- `[2,5]` 重叠 `[1,4]` → 合并到 `[1,5]`
- `[3,6]` 重叠 `[1,5]` → 合并到 `[1,6]`
- `[8,10]` 无重叠 → 新区间

结果：`[1,6] [8,10]`

## 插入间隔

给定排序的非重叠间隔和新间隔，将其插入并根据需要合并（LeetCode 57）。分为三个阶段：

1. 添加新间隔开始之前结束的所有间隔
2. 将所有重叠的间隔与新的间隔合并
3.添加剩余间隔不变

## 会议室 I - 可以参加全部吗？

按开始时间排序。如果任何间隔的开始早于前一个间隔的结束，则存在冲突。

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## 会议室 II - 最低房间数

这就是**基于事件的方法**的闪光点。将开始和结束分成两个排序列表，然后扫描：

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

堆跟踪最早结束的会议。如果它在下一个房间开始之前结束，我们会重复使用该房间。堆的最大大小就是答案。

## 非重叠间隔 - 最小移除量

给定间隔，找到要删除的最小数量，这样就不会重叠（LeetCode 435）。贪婪：按**结束时间**排序，始终保留最早结束的间隔 - 这为未来的间隔留下了最大的空间。

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## 扫线技术

不要逐对比较间隔，而是将每个间隔分解为事件：

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

按时间对事件进行排序。从左向右扫动，保持连续计数。峰值计数回答了“最大重叠”问题。这将会议室 II 概括为任意事件处理问题。
