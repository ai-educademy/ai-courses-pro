## గ్రాఫ్‌లు అనుసంధానిత ప్రపంచాన్ని మోడల్ చేస్తాయి

స్నేహాలు, రోడ్ నెట్‌వర్క్‌లు, హైపర్‌లింక్‌లు, నాడీ మార్గాలు - ఎంటిటీలు సంబంధాల ద్వారా అనుసంధానమైనప్పుడల్లా, మీకు ఒక **గ్రాఫ్** ఉంటుంది. అధికారికంగా, ఒక గ్రాఫ్ G = (V, E) శీర్షాలు (నోడ్‌లు) మరియు ఎడ్జ్‌లు (కనెక్షన్‌లు) తో కూడి ఉంటుంది.

గ్రాఫ్‌లు **దిశా ఉన్న** (ఏకదిశ వీధులు) లేదా **దిశలేని** (ద్విదిశ) కావచ్చు, మరియు ఎడ్జ్‌లు పై **బరువులు** (దూరాలు, ఖర్చులు, లేటెన్సీలు) ఉండవచ్చు.

## గ్రాఫ్‌లు ను ఎలా ప్రతినిధ్యం చేస్తుంది చేయాలి

రెండు సాధారణ representations:

| Representation | స్థలం | ముందంజ శోధన | దేనికి అనువైనది |
|---------------|-------|-------------|-----------------|
| **Adjacency జాబితా** | O(V + E) | O(డిగ్రీ) | Sparse గ్రాఫ్‌లు (చాలావరకు నిజమైన-ప్రపంచం జాలాలు) |
| **Adjacency matrix** | O(V²) | O(1) | Dense గ్రాఫ్‌లు, వేగవంతమైన ముందంజ ఉనికి తనిఖీలు |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## Breadth-మొదటి సెర్చ్ (BFS)

BFS **స్థాయి వారీగా** అన్వేషిస్తుంది - లోతుగా వెళ్ళే ముందు అన్ని పొరుగువారిని సందర్శిస్తుంది. ఇది ఒక **క్యూ** ను ఉపయోగిస్తుంది.

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**ముఖ్య లక్షణం:** BFS బరువు లేని గ్రాఫ్‌లు లో **చిన్నదైన మార్గం** కనుగొంటుంది ఎందుకంటే ఇది సోర్స్ నుండి దూరం క్రమంలో నోడ్‌లు ను ప్రాసెస్ చేస్తుంది.

### BFS యొక్క AI వాడండి సందర్భాలు

- **సోషల్ నెట్‌వర్క్ friend సూచనలు** - 2-3 కనెక్షన్‌లు లోపల వ్యక్తులను కనుగొనడం.
- **వెబ్ క్రాలర్లు** - ప్రారంభ URL నుండి పొర పొరగా పేజీలు ను ఇండెక్స్ చేయడం.
- **పజిల్ పరిష్కారకాలు** - కనీస సంఖ్యలో కదలికలు కనుగొనడం (ఉదా. రూబిక్ క్యూబ్ స్థితులు).

## లోతు-మొదటి సెర్చ్ (DFS)

DFS **సాధ్యమైనంత లోతుగా** వెళ్తుంది, తర్వాత backtrack చేస్తుంది. ఇది ఒక **స్టాక్** (లేదా రికర్షన్) ఉపయోగిస్తుంది.

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### DFS యొక్క అప్లికేషన్‌లు

- **టోపాలజికల్ క్రమబద్ధీకరణ** - ప్రతి ఆధారపడటం ముందు వచ్చేలా పనులు ను క్రమం చేయడం (బిల్డ్ సిస్టమ్‌లు, కోర్సు prerequisites).
- **Cycle గుర్తింపు** - DFS ప్రస్తుతం కాల్ స్టాక్ పై ఉన్న నోడ్ ను మళ్ళీ సందర్శిస్తే, చక్రం ఉన్నట్లు.
- **Maze solving** - ప్రత్యామ్నాయాలను ప్రయత్నించే ముందు ఒక మార్గాన్ని పూర్తిగా అన్వేషించడం.
- **Connected భాగాలు** - ప్రతి సందర్శించని నోడ్ నుండి DFS నడపడం ద్వారా వేర్వేరు clusters ను గుర్తించడం.

<ThinkAboutIt>ఒక ప్యాకేజ్ మేనేజర్ ఆధారాలను సరైన క్రమంలో ఇన్‌స్టాల్ చేయాలి. BFS ఉపయోగించాలా లేదా DFS-ఆధారిత టోపాలజికల్ క్రమబద్ధీకరణ ఉపయోగించాలా? ఆధారపడటం గ్రాఫ్ లో చక్రం ఉంటే ఏమి జరుగుతుంది?</ThinkAboutIt>

## Dijkstra's అల్గారిథమ్ - బరువులు తో చిన్నదైన మార్గం

ఎడ్జ్‌లు కు వేర్వేరు ఖర్చులు ఉన్నప్పుడు, BFS సరిపోదు. Dijkstra's అల్గారిథమ్ ఒక సోర్స్ నుండి అన్ని ఇతర నోడ్‌లు కు చిన్నదైన బరువులు ఇచ్చిన మార్గం కనుగొంటుంది.

**ప్రధాన ఆలోచన:** ఎల్లప్పుడూ నిమి-హీప్ (ప్రాధాన్యం క్యూ) ఉపయోగించి **అత్యంత చౌకైన సందర్శించని నోడ్** ను విస్తరించండి.

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**సమయం క్లిష్టత:** Binary హీప్ తో O((V + E) లాగ్ V).

<FunFact>Google మ్యాప్‌లు మొత్తం రోడ్ నెట్‌వర్క్ పై సాధారణ Dijkstra నడపదు. ఇది కాంట్రాక్షన్ హైరార్కీలు మరియు A* సెర్చ్ ఉపయోగిస్తుంది - కానీ రెండూ Dijkstra యొక్క మౌలిక అంతర్దృష్టిపై ఆధారపడి ఉన్నాయి: చిన్నదైన తెలిసిన దూరం ద్వారా లోభి విస్తరణ.</FunFact>

### Dijkstra యొక్క AI వాడండి సందర్భాలు

- **మార్గం ప్రణాళిక** - అత్యంత వేగవంతమైన మార్గాన్ని కనుగొనే నావిగేషన్ యాప్‌లు.
- **నెట్‌వర్క్ రూటింగ్** - అత్యల్ప లేటెన్సీ మార్గం ఎంచుకునే ఇంటర్నెట్ ప్యాకెట్లు.
- **జ్ఞానం గ్రాఫ్‌లు** - భావనలు మధ్య చిన్నదైన semantic కనెక్షన్ కనుగొనడం.

## చక్రం గుర్తింపు మరియు కలిసిన భాగాలు

### చక్రం గుర్తింపు

ఒక **దిశా ఉన్న గ్రాఫ్** లో, నోడ్‌లు ను మూడు స్థితులు లో ట్రాక్ చేయండి: సందర్శించని, లో-పురోగతి (ప్రస్తుత DFS మార్గం పై), మరియు పూర్తయిన. లో-పురోగతి నోడ్ ను మళ్ళీ ఎదుర్కోవడం అంటే చక్రం ఉన్నట్లు.

ఒక **దిశలేని గ్రాఫ్** లో, DFS తక్షణ తల్లి నోడ్ కాని సందర్శించిన నోడ్ ను చేరుకుంటే చక్రం ఉన్నట్లు.

### కలిసిన భాగాలు

ప్రతి సందర్శించని నోడ్ నుండి BFS లేదా DFS నడపండి. ప్రతి నడపండి ఒక కలిసిన భాగం ను కనుగొంటుంది. సోషల్ జాలాలు లో, భాగాలు ఒంటరి సముదాయాలను వెల్లడిస్తాయి.

<ThinkAboutIt>ఒక AI మోసం గుర్తింపు సిస్టమ్ లావాదేవీలు ను గ్రాఫ్ గా మోడల్ చేస్తుంది, ఇక్కడ ఖాతాలు నోడ్‌లు మరియు బదిలీలు ఎడ్జ్‌లు. కలిసిన భాగాలు డబ్బు అక్రమ చలామణి వలయాలు ను గుర్తించడంలో ఎలా సహాయపడగలవు?</ThinkAboutIt>

## ముఖ్యమైన విషయాలు

1. **BFS** స్థాయి వారీగా అన్వేషిస్తుంది - బరువు లేని గ్రాఫ్‌లు లో చిన్నదైన మార్గాలు మరియు neighbour-ఆధారిత ఆవిష్కరణ కు అనువైనది.
2. **DFS** లోతుగా వెళ్తుంది - టోపాలజికల్ క్రమబద్ధీకరణ, చక్రం గుర్తింపు, మరియు భాగం విశ్లేషణ కు వెన్నెముక.
3. **Dijkstra** ప్రాధాన్యం క్యూ ఉపయోగించి BFS ను బరువులు ఇచ్చిన గ్రాఫ్‌లు కు విస్తరిస్తుంది - ఆధునిక మార్గం ప్రణాళిక కు పునాది.
4. గ్రాఫ్ అల్గారిథమ్‌లు మ్యాప్‌లు, సోషల్ జాలాలు, ప్యాకేజ్ మేనేజర్లు, మరియు జ్ఞానం గ్రాఫ్‌లు వెనుక ఉన్న ఇంజిన్.
