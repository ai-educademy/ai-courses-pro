## గ్రాఫ్‌లు అనుసంధానిత ప్రపంచాన్ని మోడల్ చేస్తాయి

స్నేహాలు, రోడ్ నెట్‌వర్క్‌లు, హ్య్ప్ర్ల్ిన్క్స్, నాడీ మార్గాలు - ెన్ట్ిట్ిెస్ సంబంధాల ద్వారా అనుసంధానమైనప్పుడల్లా, మీకు ఒక **గ్రాఫ్** ఉంటుంది. అధికారికంగా, ఒక గ్రాఫ్ G = (V, E) వ్ర్ట్ిక్ెస్ (నోడ్‌లు) మరియు ఎడ్జ్‌లు (కనెక్షన్‌లు) తో కూడి ఉంటుంది.

గ్రాఫ్‌లు **దిశానిర్దేశిత** (ఏకదిశ వీధులు) లేదా **ున్డ్ిర్ెక్ట్ెడ్** (ద్విదిశ) కావచ్చు, మరియు ఎడ్జ్‌లు పై **బరువులు** (దూరాలు, ఖర్చులు, ల్అట్ెన్క్ిెస్) ఉండవచ్చు.

## గ్రాఫ్‌లు ను ఎలా ప్రతినిధ్యం చేస్తుంది చేయాలి

రెండు సాధారణ ర్ెప్ర్ెస్ెన్ట్అషన్స్:

| ప్రతినిధ్యం | స్థలం | ముందంజ లుక్‌అప్ | దేనికి అనువైనది |
|---------------|-------|-------------|-----------------|
| **Adjacency జాబితా** | O(V + E) | O(డిగ్రీ) | *Sparse* గ్రాఫ్‌లు (చాలావరకు నిజమైన-ప్రపంచం నెట్‌వర్క్‌లు) |
| **Adjacency మ్అట్ర్ిక్స్** | O(V²) | O(1) | *Dense* గ్రాఫ్‌లు, వేగవంతమైన ముందంజ ఉనికి తనిఖీలు |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## *Breadth-*మొదటి సెర్చ్ (*BFS*)

*BFS* **స్థాయి వారీగా** అన్వేషిస్తుంది - లోతుగా వెళ్ళే ముందు అన్ని పొరుగువారిని సందర్శిస్తుంది. ఇది ఒక **క్యూ** ను ఉపయోగిస్తుంది.

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**ముఖ్య లక్షణం:** BFS ున్వ్ెిగ్హ్ట్ెడ్ గ్రాఫ్‌లు లో **చిన్నదైన మార్గం** కనుగొంటుంది ఎందుకంటే ఇది సోర్స్ నుండి దూరం క్రమంలో నోడ్‌లు ను ప్రాసెస్ చేస్తుంది.

### *BFS* యొక్క AI వాడండి సందర్భాలు

- **సోషల్ నెట్‌వర్క్ ఫ్ర్ిెన్డ్ స్ుగ్గ్ెస్షన్స్** - 2–3 కనెక్షన్‌లు లోపల వ్యక్తులను కనుగొనడం.
- **వెబ్ క్రాలర్లు** - స్ీడ్ *URL* నుండి పొర పొరగా పేజీలు ను ఇండెక్స్ చేయడం.
- **Puzzle స్ోల్వ్ర్స్** - కనీస సంఖ్యలో కదలికలు కనుగొనడం (ఉదా. *Rubik*'s క్ుబ్ె స్థితులు).

## లోతు-మొదటి సెర్చ్ (*DFS*)

*DFS* **సాధ్యమైనంత లోతుగా** వెళ్తుంది, తర్వాత బ్అక్ట్ర్అక్ చేస్తుంది. ఇది ఒక **స్టాక్** (లేదా రికర్షన్) ఉపయోగిస్తుంది.

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### *DFS* యొక్క అప్లికేషన్‌లు

- **Topological క్రమబద్ధీకరించండి** - ప్రతి ఆధారపడటం ముందు వచ్చేలా పనులు ను క్రమం చేయడం (నిర్మించండి సిస్టమ్‌లు, కోర్సు ప్ర్ర్ెక్వ్ిస్ిట్ెస్).
- **Cycle గుర్తింపు** - *DFS* ప్రస్తుతం కాల్ స్టాక్ పై ఉన్న నోడ్ ను మళ్ళీ సందర్శిస్తే, చక్రం ఉన్నట్లు.
- **Maze స్ోల్వ్ింగ్** - ప్రత్యామ్నాయాలను ప్రయత్నించే ముందు ఒక మార్గాన్ని పూర్తిగా అన్వేషించడం.
- **Connected భాగాలు** - ప్రతి సందర్శించని నోడ్ నుండి *DFS* నడపడం ద్వారా వేర్వేరు క్లస్టర్లు ను గుర్తించడం.

<ThinkAboutIt>ఒక ప్యాకేజ్ మేనేజర్ ఆధారపడే అంశాలు ను సరైన క్రమంలో ిన్స్ట్ల్ల్ చేయాలి. *BFS* ఉపయోగించాలా లేదా *DFS-*ఆధారిత ట్ోప్ోల్ోగ్ిక్ల్ క్రమబద్ధీకరించండి ఉపయోగించాలా? ఆధారపడటం గ్రాఫ్ లో చక్రం ఉంటే ఏమి జరుగుతుంది?</ThinkAboutIt>

## *Dijkstra*'s అల్గారిథమ్ - బరువులు తో చిన్నదైన మార్గం

ఎడ్జ్‌లు కు వేర్వేరు ఖర్చులు ఉన్నప్పుడు, *BFS* సరిపోదు. *Dijkstra*'s అల్గారిథమ్ ఒక సోర్స్ నుండి అన్ని ఇతర నోడ్‌లు కు చిన్నదైన బరువులు ఇచ్చిన మార్గం కనుగొంటుంది.

**ప్రధాన ఆలోచన:** ఎల్లప్పుడూ నిమి-హీప్ (ప్రాధాన్యం క్యూ) ఉపయోగించి **అత్యంత చౌకైన సందర్శించని నోడ్** ను విస్తరించండి.

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**సమయం క్లిష్టత:** ద్విమీయ హీప్ తో O((V + E) లాగ్ V).

<FunFact>*Google* మ్యాప్‌లు మొత్తం ర్ోఅడ్ నెట్‌వర్క్ పై ప్ల్ైన్ *Dijkstra* నడపదు. ఇది క్ోన్ట్ర్అక్షన్ హ్ిర్ార్చ్ిెస్ మరియు A* సెర్చ్ ఉపయోగిస్తుంది - కానీ రెండూ **Dijkstra** యొక్క మౌలిక అంతర్దృష్టిపై ఆధారపడి ఉన్నాయి: చిన్నదైన తెలిసిన దూరం ద్వారా గ్ర్ీడ్య్ ెక్స్ప్అన్షన్.</FunFact>

### *Dijkstra* యొక్క AI వాడండి సందర్భాలు

- **మార్గం ప్రణాళిక** - అత్యంత వేగవంతమైన మార్గాన్ని కనుగొనే న్అవ్ిగ్అషన్ అప్ప్స్.
- **నెట్‌వర్క్ రూటింగ్** - అత్యల్ప లేటెన్సీ మార్గం ఎంచుకునే ిన్ట్ర్న్ెట్ ప్అక్ెట్స్.
- **జ్ఞానం గ్రాఫ్‌లు** - భావనలు మధ్య చిన్నదైన అర్థ సంబంధ కనెక్షన్ కనుగొనడం.

## చక్రం గుర్తింపు మరియు కలిసిన భాగాలు

### చక్రం గుర్తింపు

ఒక **దిశానిర్దేశిత గ్రాఫ్** లో, నోడ్‌లు ను మూడు స్థితులు లో ట్రాక్ చేయండి: సందర్శించని, లో-పురోగతి (ప్రస్తుత *DFS* మార్గం పై), మరియు పూర్తయిన. లో-పురోగతి నోడ్ ను మళ్ళీ ఎదుర్కోవడం అంటే చక్రం ఉన్నట్లు.

ఒక **ున్డ్ిర్ెక్ట్ెడ్ గ్రాఫ్** లో, *DFS* తక్షణ ప్ార్ెన్ట్ కాని వ్ిస్ిట్ెడ్ నోడ్ ను చేరుకుంటే చక్రం ఉన్నట్లు.

### కలిసిన భాగాలు

ప్రతి సందర్శించని నోడ్ నుండి *BFS* లేదా *DFS* నడపండి. ప్రతి నడపండి ఒక కలిసిన భాగం ను కనుగొంటుంది. సోషల్ నెట్‌వర్క్‌లు లో, భాగాలు ఒంటరి సముదాయాలను వెల్లడిస్తాయి.

<ThinkAboutIt>ఒక AI మోసం గుర్తింపు సిస్టమ్ ట్ర్అన్స్అక్షన్స్ ను గ్రాఫ్ గా మోడల్ చేస్తుంది, ఇక్కడ ఖాతాలు నోడ్‌లు మరియు ట్ర్అన్స్ఫ్ర్స్ ఎడ్జ్‌లు. కలిసిన భాగాలు మ్ోన్ెయ్-ల్ాన్డ్ర్ింగ్ ర్ింగ్స్ ను గుర్తించడంలో ఎలా సహాయపడగలవు?</ThinkAboutIt>

## ముఖ్యమైన విషయాలు

1. **BFS** స్థాయి వారీగా అన్వేషిస్తుంది - ున్వ్ెిగ్హ్ట్ెడ్ గ్రాఫ్‌లు లో చిన్నదైన మార్గాలు మరియు న్ెిగ్హ్బ్ౌర్-ఆధారిత ఆవిష్కరణ కు అనువైనది.
2. **DFS** లోతుగా వెళ్తుంది - ట్ోప్ోల్ోగ్ిక్ల్ క్రమబద్ధీకరణ, చక్రం గుర్తింపు, మరియు భాగం విశ్లేషణ కు వెన్నెముక.
3. **Dijkstra** ప్రాధాన్యం క్యూ ఉపయోగించి *BFS* ను బరువులు ఇచ్చిన గ్రాఫ్‌లు కు విస్తరిస్తుంది - ఆధునిక మార్గం ప్రణాళిక కు పునాది.
4. గ్రాఫ్ అల్గారిథమ్‌లు మ్యాప్‌లు, సోషల్ నెట్‌వర్క్‌లు, ప్యాకేజ్ మేనేజర్లు, మరియు జ్ఞానం గ్రాఫ్‌లు వెనుక ఉన్న ఇంజిన్.
