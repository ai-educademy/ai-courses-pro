## గ్రాఫ్‌లు అనుసంధానిత ప్రపంచాన్ని మోడల్ చేస్తాయి

స్నేహాలు, రోడ్ నెట్‌వర్క్‌లు, hyperlinks, నాడీ మార్గాలు - entities సంబంధాల ద్వారా అనుసంధానమైనప్పుడల్లా, మీకు ఒక **గ్రాఫ్** ఉంటుంది. అధికారికంగా, ఒక గ్రాఫ్ G = (V, E) vertices (నోడ్‌లు) మరియు ఎడ్జ్‌లు (కనెక్షన్‌లు) తో కూడి ఉంటుంది.

గ్రాఫ్‌లు **directed** (ఏకదిశ వీధులు) లేదా **undirected** (ద్విదిశ) కావచ్చు, మరియు ఎడ్జ్‌లు పై **బరువులు** (దూరాలు, ఖర్చులు, latencies) ఉండవచ్చు.

## గ్రాఫ్‌లు ను ఎలా ప్రతినిధ్యం చేస్తుంది చేయాలి

రెండు సాధారణ representations:

| Representation | స్థలం | ముందంజ lookup | దేనికి అనువైనది |
|---------------|-------|-------------|-----------------|
| **Adjacency జాబితా** | O(V + E) | O(డిగ్రీ) | Sparse గ్రాఫ్‌లు (చాలావరకు నిజమైన-ప్రపంచం networks) |
| **Adjacency matrix** | O(V²) | O(1) | Dense గ్రాఫ్‌లు, వేగవంతమైన ముందంజ ఉనికి తనిఖీలు |

```
// Adjacency list example
graph = {
    A: [(B, 4), (C, 1)],
    B: [(D, 1)],
    C: [(B, 2), (D, 5)],
    D: []
}
```

## Breadth-మొదటి సెర్చ్ (BFS)

BFS **స్థాయి వారీగా** అన్వేషిస్తుంది - లోతుగా వెళ్ళే ముందు అన్ని పొరుగువారిని సందర్శిస్తుంది. ఇది ఒక **క్యూ** ను ఉపయోగిస్తుంది.

```
function bfs(graph, start):
    visited = {start}
    queue = [start]
    while queue is not empty:
        node = queue.dequeue()
        process(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.enqueue(neighbour)
```

**ముఖ్య లక్షణం:** BFS unweighted గ్రాఫ్‌లు లో **చిన్నదైన మార్గం** కనుగొంటుంది ఎందుకంటే ఇది సోర్స్ నుండి దూరం క్రమంలో నోడ్‌లు ను ప్రాసెస్ చేస్తుంది.

### BFS యొక్క AI వాడండి సందర్భాలు

- **సోషల్ నెట్‌వర్క్ friend suggestions** - 2–3 కనెక్షన్‌లు లోపల వ్యక్తులను కనుగొనడం.
- **వెబ్ crawlers** - seed URL నుండి పొర పొరగా పేజీలు ను ఇండెక్స్ చేయడం.
- **Puzzle solvers** - కనీస సంఖ్యలో కదలికలు కనుగొనడం (ఉదా. Rubik's cube states).

## లోతు-మొదటి సెర్చ్ (DFS)

DFS **సాధ్యమైనంత లోతుగా** వెళ్తుంది, తర్వాత backtrack చేస్తుంది. ఇది ఒక **స్టాక్** (లేదా recursion) ఉపయోగిస్తుంది.

```
function dfs(graph, node, visited):
    visited.add(node)
    process(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### DFS యొక్క అప్లికేషన్‌లు

- **Topological క్రమబద్ధీకరించండి** - ప్రతి dependency ముందు వచ్చేలా పనులు ను క్రమం చేయడం (నిర్మించండి సిస్టమ్‌లు, కోర్సు prerequisites).
- **Cycle గుర్తింపు** - DFS ప్రస్తుతం కాల్ స్టాక్ పై ఉన్న నోడ్ ను మళ్ళీ సందర్శిస్తే, చక్రం ఉన్నట్లు.
- **Maze solving** - ప్రత్యామ్నాయాలను ప్రయత్నించే ముందు ఒక మార్గాన్ని పూర్తిగా అన్వేషించడం.
- **Connected భాగాలు** - ప్రతి సందర్శించని నోడ్ నుండి DFS నడపడం ద్వారా వేర్వేరు clusters ను గుర్తించడం.

<ThinkAboutIt>ఒక package మేనేజర్ dependencies ను సరైన క్రమంలో install చేయాలి. BFS ఉపయోగించాలా లేదా DFS-ఆధారిత topological క్రమబద్ధీకరించండి ఉపయోగించాలా? dependency గ్రాఫ్ లో చక్రం ఉంటే ఏమి జరుగుతుంది?</ThinkAboutIt>

## Dijkstra's అల్గారిథమ్ - బరువులు తో చిన్నదైన మార్గం

ఎడ్జ్‌లు కు వేర్వేరు ఖర్చులు ఉన్నప్పుడు, BFS సరిపోదు. Dijkstra's అల్గారిథమ్ ఒక సోర్స్ నుండి అన్ని ఇతర నోడ్‌లు కు చిన్నదైన బరువులు ఇచ్చిన మార్గం కనుగొంటుంది.

**ప్రధాన ఆలోచన:** ఎల్లప్పుడూ నిమి-హీప్ (ప్రాధాన్యం క్యూ) ఉపయోగించి **అత్యంత చౌకైన unvisited నోడ్** ను విస్తరించండి.

```
function dijkstra(graph, source):
    dist = {source: 0}          // all others: infinity
    pq = MinHeap([(0, source)])
    while pq is not empty:
        (cost, node) = pq.extractMin()
        if cost > dist[node]: continue
        for (neighbour, weight) in graph[node]:
            newDist = cost + weight
            if newDist < dist.getOrDefault(neighbour, INF):
                dist[neighbour] = newDist
                pq.insert((newDist, neighbour))
    return dist
```

**సమయం క్లిష్టత:** Binary హీప్ తో O((V + E) లాగ్ V).

<FunFact>Google మ్యాప్‌లు మొత్తం road నెట్‌వర్క్ పై plain Dijkstra నడపదు. ఇది contraction hierarchies మరియు A* సెర్చ్ ఉపయోగిస్తుంది - కానీ రెండూ Dijkstra యొక్క మౌలిక అంతర్దృష్టిపై ఆధారపడి ఉన్నాయి: చిన్నదైన తెలిసిన distance ద్వారా greedy expansion.</FunFact>

### Dijkstra యొక్క AI వాడండి సందర్భాలు

- **మార్గం planning** - అత్యంత వేగవంతమైన మార్గాన్ని కనుగొనే navigation apps.
- **నెట్‌వర్క్ రూటింగ్** - అత్యల్ప లేటెన్సీ మార్గం ఎంచుకునే internet packets.
- **జ్ఞానం గ్రాఫ్‌లు** - భావనలు మధ్య చిన్నదైన semantic కనెక్షన్ కనుగొనడం.

## చక్రం గుర్తింపు మరియు కలిసిన భాగాలు

### చక్రం గుర్తింపు

ఒక **directed గ్రాఫ్** లో, నోడ్‌లు ను మూడు states లో ట్రాక్ చేయండి: unvisited, లో-progress (ప్రస్తుత DFS మార్గం పై), మరియు completed. లో-progress నోడ్ ను మళ్ళీ ఎదుర్కోవడం అంటే చక్రం ఉన్నట్లు.

ఒక **undirected గ్రాఫ్** లో, DFS తక్షణ parent కాని visited నోడ్ ను చేరుకుంటే చక్రం ఉన్నట్లు.

### కలిసిన భాగాలు

ప్రతి సందర్శించని నోడ్ నుండి BFS లేదా DFS నడపండి. ప్రతి నడపండి ఒక కలిసిన భాగం ను కనుగొంటుంది. సోషల్ networks లో, భాగాలు ఒంటరి సముదాయాలను వెల్లడిస్తాయి.

<ThinkAboutIt>ఒక AI మోసం గుర్తింపు సిస్టమ్ transactions ను గ్రాఫ్ గా మోడల్ చేస్తుంది, ఇక్కడ ఖాతాలు నోడ్‌లు మరియు transfers ఎడ్జ్‌లు. కలిసిన భాగాలు money-laundering rings ను గుర్తించడంలో ఎలా సహాయపడగలవు?</ThinkAboutIt>

## ముఖ్యమైన విషయాలు

1. **BFS** స్థాయి వారీగా అన్వేషిస్తుంది - unweighted గ్రాఫ్‌లు లో చిన్నదైన మార్గాలు మరియు neighbour-ఆధారిత ఆవిష్కరణ కు అనువైనది.
2. **DFS** లోతుగా వెళ్తుంది - topological sorting, చక్రం గుర్తింపు, మరియు భాగం విశ్లేషణ కు వెన్నెముక.
3. **Dijkstra** ప్రాధాన్యం క్యూ ఉపయోగించి BFS ను బరువులు ఇచ్చిన గ్రాఫ్‌లు కు విస్తరిస్తుంది - ఆధునిక మార్గం planning కు పునాది.
4. గ్రాఫ్ అల్గారిథమ్‌లు మ్యాప్‌లు, సోషల్ networks, package మేనేజర్లు, మరియు జ్ఞానం గ్రాఫ్‌లు వెనుక ఉన్న ఇంజిన్.

<FunFact>ప్రపంచం Wide వెబ్ లో 50 బిలియన్ కంటే ఎక్కువ indexed పేజీలు ఉన్నాయి. సెర్చ్ ఇంజిన్ crawlers పేజీలు ను కనుగొని మళ్ళీ ఇండెక్స్ చేయడానికి BFS variations ఉపయోగిస్తాయి, పేజీ importance (PageRank) ఆధారంగా ప్రాధాన్యత ఇస్తూ.</FunFact>
