## పెద్ద ఆలోచన

కొన్ని సమస్యలు చూడటానికి చాలా క్లిష్టమైన గా కనిపిస్తాయి, కానీ జాగ్రత్తగా చూస్తే అవి **చిన్న, పునరావృతమయ్యే ఉప-సమస్యలు** తో తయారయ్యాయని తెలుస్తుంది. Dynamic ప్రోగ్రామింగ్ (DP) ప్రతి ఉప-సమస్య ను **ఒక్కసారి** మాత్రమే పరిష్కరించండి చేసి, ఫలితం ను నిల్వ చేసి, దాన్ని ర్ెుస్ె చేస్తుంది - కొంచెం మెమరీ ఖర్చు చేసి గొప్ప వేగం-up సాధిస్తుంది.

రెండు క్ోన్డ్ిషన్స్ DP అవకాశాన్ని సూచిస్తాయి:

1. **ఒకదానిపై ఒకటి పడే స్ుబ్-సమస్యలు** - అదే క్ల్క్ుల్అషన్స్ చాలాసార్లు పునరావృతమవుతాయి.
2. **Optimal స్ుబ్స్ట్ర్ుక్ట్ుర్ె** - మొత్తం సమస్య యొక్క ఉత్తమ పరిష్కారం దాని భాగాల ఉత్తమ పరిష్కారాలు నుండి నిర్మించవచ్చు.

## *Fibonacci*: అత్యంత సాంప్రదాయ ఉదాహరణ

### Naïve రికర్షన్ - O(2ⁿ)

```
function fib(n):
    if n <= 1: return n
    return fib(n - 1) + fib(n - 2)
```

`fib(5)` కాల్ చేస్తే **15** ఫంక్షన్ కాల్‌లు జరుగుతాయి, వాటిలో చాలా ర్ెడ్ున్డ్అన్ట్. `fib(40)` కి సెకన్లు పడుతుంది; `fib(100)` కి అయితే ున్ివ్ర్స్ె కంటే ఎక్కువ సమయం పడుతుంది.

### మెమోయైజేషన్ (ముఖ్యమైన-కిందికి) - O(n)

ఫలితాలు ను ఒక క్యాష్ లో నిల్వ చేయండి. ఒక ఉప-సమస్య ఇప్పటికే పరిష్కరించండి అయి ఉంటే, క్అచ్ెడ్ సమాధానం తిరిగి ఇవ్వండి.

```
memo = {}
function fib(n):
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = fib(n - 1) + fib(n - 2)
    return memo[n]
```

### ట్యాబ్యులేషన్ (బాటమ్-అప్) - O(n)

బేస్ సందర్భాలు నుండి ిట్ర్అట్ివ్ల్య్ సమాధానం నిర్మించండి.

```
function fib(n):
    table = [0, 1]
    for i in 2..n:
        table[i] = table[i - 1] + table[i - 2]
    return table[n]
```

## సాంప్రదాయ DP సమస్యలు

### మెట్లు ఎక్కడం

మీరు ఒకేసారి 1 లేదా 2 మెట్లు ఎక్కవచ్చు. దశ _n_ కి చేరుకోవడానికి ఎన్ని విభిన్న మార్గాలు ఉన్నాయి?

```
function climbStairs(n):
    if n <= 2: return n
    a = 1, b = 2
    for i in 3..n:
        a, b = b, a + b
    return b
```

ఇది మారువేషంలో *Fibonacci* - దశ _n_ కి సమాధానం, దశ _n−1_ మరియు _n−2_ కి చేరుకునే మార్గాల మొత్తం.

### నాణెం మార్పు

ఇచ్చిన క్ోిన్ డ్ెన్ోమ్ిన్అషన్స్ తో లక్ష్య అమ్ౌన్ట్ చేయడానికి **అత్యల్ప క్ోిన్స్** కనుగొనండి.

```
function coinChange(coins, amount):
    dp = array of size (amount + 1), filled with INF
    dp[0] = 0
    for i in 1..amount:
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != INF else -1
```

### అత్యంత పొడవైన సాధారణ ఉపక్రమం (*LCS*)

రెండు స్ట్ర్ింగ్స్ లో సాధారణ అక్షరాలు యొక్క పొడవైన క్రమం కనుగొనండి (తప్పనిసరిగా క్ోన్ట్ిగ్ుస్ కానవసరం లేదు).

```
function lcs(s1, s2):
    m = s1.length, n = s2.length
    dp = 2D array of size (m+1) x (n+1), filled with 0
    for i in 1..m:
        for j in 1..n:
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

<FunFact>ఫైల్ వెర్షన్‌లు మధ్య మార్పులు చూపించే `diff` టూల్ *LCS* పై ఆధారపడింది. మీరు `git diff` నడపండి చేసినప్పుడల్లా *Git* దాని వ్ార్ిఅన్ట్ ని వాడుతుంది.</FunFact>

<ThinkAboutIt>నాణెం మార్పు కనిష్ఠ క్ోిన్స్ సంఖ్య అడుగుతుంది. *Amount* చేయడానికి మొత్తం విభిన్న మార్గాల సంఖ్య లెక్కించాలంటే? *Recurrence* ర్ెల్అషన్ ఎలా మారుతుంది?</ThinkAboutIt>

## ముఖ్యమైన-కిందికి వర్సెస్ బాటమ్-అప్

| అంశం | ముఖ్యమైన-కిందికి (మెమోయైజేషన్) | బాటమ్-అప్ (ట్యాబ్యులేషన్) |
|------|----------------------|----------------------|
| శైలి | *Recursive* + క్యాష్ | *Iterative* + పట్టిక |
| పరిష్కరించండి అయిన ఉప-సమస్యలు | అవసరమైనవి మాత్రమే | _n_ వరకు అన్ని ఉప-సమస్యలు |
| స్టాక్ ఓవర్‌ఫ్లో రిస్క్ | అవును, లోతైన రికర్షన్ లో | కాదు |
| ఆప్టిమైజేషన్ సౌలభ్యం | స్థలం తగ్గించడం కష్టం | సులభం (తరచుగా చివరి వరుస మాత్రమే ఉంచితే చాలు) |

**సాధారణ నియమం:** ముందు మెమోయైజేషన్ తో ర్ెక్ుర్ర్ెన్క్ె అర్థం చేసుకోండి, తర్వాత స్థలం మెరుగుపరచండి చేయడానికి లేదా స్టాక్ పరిమితులు నివారించడానికి ట్యాబ్యులేషన్ కి మార్చండి చేయండి.

<ThinkAboutIt>నాణెం మార్పు పట్టిక పరిమాణం O(అమ్ౌన్ట్). *LCS* పట్టిక పరిమాణం O(m × n). ఒకేసారి రెండు వరుసలు మాత్రమే ఉంచి *LCS* స్థలం ను O(నిమి(m, n)) కి తగ్గించగలరా? ఏ సమాచారం కోల్పోతారు?</ThinkAboutIt>

## ముఖ్యమైన అంశాలు

1. DP ెక్స్ప్ోన్ెన్షల్ బ్ర్ుట్ె-బలవంతం చేయండి ను ప్ోల్య్న్ోమ్ిల్ సమయం గా మారుస్తుంది **ర్ెప్ీట్ెడ్ పని ను క్యాష్ చేయడం** ద్వారా.
2. DP వాడే ముందు ఒకదానిపై ఒకటి పడే ఉప-సమస్యలు మరియు అనుకూలమైన స్ుబ్స్ట్ర్ుక్ట్ుర్ె గుర్తించండి.
