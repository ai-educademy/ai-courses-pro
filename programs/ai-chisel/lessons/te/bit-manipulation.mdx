## ద్విమాన సంఖ్య సమీక్ష

ప్రతి పూర్ణసంఖ్య బిట్‌లు యొక్క ఒక వరుస. 13 అనే సంఖ్య ద్విమానం లో `1101`:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

బిట్ మానిప్యులేషన్ ఈ బిట్‌లు పై నేరుగా బిట్‌వైజ్ ఆపరేటర్లు ఉపయోగించి పని చేస్తుంది - తరచుగా లూపులు స్థానంలో ఒకే చర్య సరిపోతుంది.

## ప్రాథమిక బిట్‌వైజ్ ఆపరేషన్లు

| ఆపరేటర్ | గుర్తు | ఉదాహరణ (5 = 101, 3 = 011) | ఫలితం |
|----------|--------|----------------------------|--------|
| మరియు      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| XOR      | `^`    | `101 ^ 011`                | `110` (6) |
| NOT      | `~`    | `~101`                     | `...010` |
| ఎడమ షిఫ్ట్  | `<<` | `101 << 1`              | `1010` (10) |
| కుడి షిఫ్ట్ | `>>` | `101 >> 1`              | `10` (2) |

## అవసరమైన బిట్ చిట్కాలు

### రెండు ఘాతం చెక్ చేయడం

రెండు ఘాతం లో సరిగ్గా ఒక్క సెట్ బిట్ ఉంటుంది: `n & (n - 1) == 0`.

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### సెట్ బిట్‌లు లెక్కించడం (బ్రయన్ కెర్నిఘన్ అల్గారిథమ్)

ప్రతి `n & (n - 1)` అత్యంత తక్కువ సెట్ బిట్ ని తొలగిస్తుంది. n = 0 అయ్యే వరకు iterations లెక్కించండి.

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

ఇది O(k) లో నడుస్తుంది, ఇక్కడ k అనేది సెట్ బిట్‌లు సంఖ్య - O(32) కాదు.

### తాత్కాలిక చరరాశి లేకుండా Swap

```python
a ^= b
b ^= a
a ^= b
```

XOR తన స్వంత inverse కాబట్టి ఇది పని చేస్తుంది: `a ^ b ^ b = a`.

## ఒకే సంఖ్య - XOR రద్దు

ప్రతి ఎలిమెంట్ రెండు సార్లు వస్తుంది ఒక్కటి తప్ప. దాన్ని కనుగొనండి. `a ^ a = 0` మరియు `a ^ 0 = a` కాబట్టి, అన్ని ఎలిమెంట్‌లు ని XOR చేయండి - జతలు రద్దవుతాయి అవుతాయి, ప్రత్యేక సంఖ్య మిగులుతుంది.

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

సమయం O(n), స్థలం O(1). హ్యాష్ మ్యాప్ అవసరం లేదు.

## ఒకే సంఖ్య III - రెండు ప్రత్యేక సంఖ్యలు

*రెండు* సంఖ్యలు ప్రత్యేక అయినప్పుడు, అన్నింటినీ XOR చేస్తే `x = a ^ b` వస్తుంది. `x` లో ఏదైనా సెట్ బిట్ కనుగొనండి (అక్కడ రెండు సంఖ్యలు భిన్నంగా ఉంటాయి). ఆ బిట్ ఆధారంగా అన్ని సంఖ్యలను రెండు గుంపులు గా విభజించి, ప్రతి గుంపు ని XOR చేయండి - ప్రతి గుంపు లో సరిగ్గా ఒక ప్రత్యేక సంఖ్య ఉంటుంది.

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>`xor & (-xor)` అత్యంత కుడివైపు సెట్ బిట్ ని ఎందుకు వేరు చేస్తుంది? రెండు యొక్క పూరక రూపంలో ఋణ సంఖ్యలు ఎలా సూచించబడతాయో ఆలోచించండి.</ThinkAboutIt>

## 1 బిట్‌ల సంఖ్య (LeetCode 191)

ఇది పైన చూసిన బ్రయన్ కెర్నిఘన్ అల్గారిథమ్ - నేరుగా ఇంటర్వ్యూ ప్రశ్న. తదుపరి ప్రశ్న: ఇన్‌పుట్ సైన్ ఉన్న అయితే? Python లో పూర్ణసంఖ్యలకు పరిమితిలేని ఖచ్చితత్వం కలిగి ఉంటాయి, కానీ Java/C++ లో 32-బిట్ హద్దులు నిర్వహించాలి.

## ఉపసెట్లు కోసం బిట్ మాస్కింగ్

n పొడవు గల బిట్‌మాస్క్, n అంశాలు యొక్క ఒక ఉపసెట్ ని ప్రతినిధ్యం చేస్తుంది. బిట్ `i` సెట్ అయి ఉంటే అంశం `i` చేర్చబడింది. `0` నుండి `2^n - 1` వరకు పునరావృతంగా నడిపితే చేస్తే అన్ని ఉపసెట్లు సృష్టించు అవుతాయి.

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

n ≤ 20 ఉన్న సమస్యలు కోసం ఈ పద్ధతి పని చేస్తుంది - 2^n లెక్కింపు కి సరిపోయేంత చిన్నది.

<FunFact>Linux ఫైల్ అనుమతులు (rwxr-xr-x = 755) ఒక నిజమైన-ప్రపంచం బిట్‌మాస్క్ ఉదాహరణ. ప్రతి అంకె మూడు అనుమతి బిట్‌లను సంకేతీకరిస్తుంది: చదవడం (4), రాయండి (2), అమలు (1); వీటిని OR తో కలుపుతారు.</FunFact>

## బిట్‌లు తిరగబెట్టడం చేయడం (LeetCode 190)

ఒక 32-బిట్ సైన్ లేని పూర్ణసంఖ్యను బిట్ వారీగా తిరగబెట్టండి. ఫలితం ని ఎడమ షిఫ్ట్ చేసి ఇన్‌పుట్ యొక్క అత్యంత తక్కువ బిట్ ని OR చేయండి, తర్వాత ఇన్‌పుట్ ని కుడి షిఫ్ట్ చేయండి.

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## తప్పిపోయిన సంఖ్య (LeetCode 268)

0 నుండి n వరకు n సంఖ్యలు ఉన్న అరే లో ఒకటి తప్పిపోయిన. అన్ని అరే ఎలిమెంట్‌లు ని 0 నుండి n వరకు సూచికలు తో XOR చేయండి - జతలు రద్దవుతాయి అవుతాయి, తప్పిపోయిన సంఖ్య మిగులుతుంది. మొత్తం సూత్రం కూడా పని చేస్తుంది, కానీ XOR ఓవర్‌ఫ్లో ప్రమాదాన్ని నివారిస్తుంది.

## హామింగ్ దూరం (LeetCode 461)

సంబంధిత బిట్‌లు భిన్నంగా ఉన్న స్థానాలు సంఖ్య. రెండు సంఖ్యలను XOR చేయండి - ఫలితం లో సెట్ బిట్‌లు భిన్నమైన స్థానాలు. బ్రయన్ కెర్నిఘన్ చిట్కా తో లెక్కించండి.

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```

## ఆచరణాత్మక అనువర్తనాలు

బిట్ మానిప్యులేషన్ ప్రతిచోటా కనిపిస్తుంది: Unix ఫైల్ అనుమతులు OR/AND మాస్క్‌లు వాడతాయి, ఫీచర్ ఫ్లాగ్‌లు వ్యక్తిగత బిట్‌లలో ఆన్/ఆఫ్ విలువలు నిల్వ చేస్తాయి, నెట్‌వర్క్ సబ్‌నెట్ మాస్క్‌లు రూటింగ్ కోసం AND వాడతాయి, మరియు లోప గుర్తింపు XOR చెక్‌సమ్‌లపై ఆధారపడుతుంది.
