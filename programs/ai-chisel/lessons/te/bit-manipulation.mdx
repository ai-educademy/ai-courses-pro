## Binary సంఖ్య సమీక్ష

ప్రతి integer బిట్‌లు యొక్క ఒక sequence. 13 అనే సంఖ్య binary లో `1101`:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

బిట్ manipulation ఈ బిట్‌లు పై నేరుగా bitwise operators ఉపయోగించి పని చేస్తుంది - తరచుగా loops స్థానంలో ఒకే operation సరిపోతుంది.

## ప్రాథమిక Bitwise ఆపరేషన్లు

| Operator | Symbol | ఉదాహరణ (5 = 101, 3 = 011) | ఫలితం |
|----------|--------|----------------------------|--------|
| మరియు      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| XOR      | `^`    | `101 ^ 011`                | `110` (6) |
| NOT      | `~`    | `~101`                     | `...010` |
| మిగిలిన shift  | `<<` | `101 << 1`              | `1010` (10) |
| సరైన shift | `>>` | `101 >> 1`              | `10` (2) |

## అవసరమైన బిట్ Tricks

### శక్తి of రెండు చెక్ చేయడం

శక్తి of 2 లో సరిగ్గా ఒక్క సెట్ బిట్ ఉంటుంది: `n & (n - 1) == 0`.

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### సెట్ బిట్‌లు లెక్కించడం (Brian Kernighan's అల్గారిథమ్)

ప్రతి `n & (n - 1)` అత్యంత తక్కువ సెట్ బిట్ ని తొలగిస్తుంది. n = 0 అయ్యే వరకు iterations లెక్కించండి.

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

ఇది O(k) లో నడుస్తుంది, ఇక్కడ k అనేది సెట్ బిట్‌లు సంఖ్య - O(32) కాదు.

### Temp Variable లేకుండా Swap

```python
a ^= b
b ^= a
a ^= b
```

XOR తన స్వంత inverse కాబట్టి ఇది పని చేస్తుంది: `a ^ b ^ b = a`.

## ఒకే సంఖ్య - XOR Cancellation

ప్రతి ఎలిమెంట్ రెండు సార్లు వస్తుంది ఒక్కటి తప్ప. దాన్ని కనుగొనండి. `a ^ a = 0` మరియు `a ^ 0 = a` కాబట్టి, అన్ని ఎలిమెంట్‌లు ని XOR చేయండి - pairs cancel అవుతాయి, ప్రత్యేక సంఖ్య మిగులుతుంది.

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

సమయం O(n), స్థలం O(1). హ్యాష్ మ్యాప్ అవసరం లేదు.

## ఒకే సంఖ్య III - రెండు ప్రత్యేక సంఖ్యలు

*రెండు* సంఖ్యలు ప్రత్యేక అయినప్పుడు, అన్నింటినీ XOR చేస్తే `x = a ^ b` వస్తుంది. `x` లో ఏదైనా సెట్ బిట్ కనుగొనండి (అక్కడ రెండు సంఖ్యలు భిన్నంగా ఉంటాయి). ఆ బిట్ ఆధారంగా అన్ని సంఖ్యలు ని రెండు groups గా విభజించి, ప్రతి గుంపు ని XOR చేయండి - ప్రతి గుంపు లో సరిగ్గా ఒక ప్రత్యేక సంఖ్య ఉంటుంది.

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>`xor & (-xor)` అత్యంత కుడివైపు సెట్ బిట్ ని ఎందుకు isolate చేస్తుంది? రెండు's complement లో negative సంఖ్యలు ఎలా ప్రతినిధ్యం చేస్తుంది అవుతాయో ఆలోచించండి.</ThinkAboutIt>

## ఉపసెట్లు కోసం బిట్ Masking

n పొడవు గల bitmask, n అంశాలు యొక్క ఒక ఉపసెట్ ని ప్రతినిధ్యం చేస్తుంది చేస్తుంది. బిట్ `i` సెట్ అయి ఉంటే అంశం `i` చేర్చబడింది. `0` నుండి `2^n - 1` వరకు iterate చేస్తే అన్ని ఉపసెట్లు సృష్టించు అవుతాయి.

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

n ≤ 20 ఉన్న సమస్యలు కోసం ఈ technique పని చేస్తుంది - 2^n enumeration కి సరిపోయేంత చిన్నది.

<FunFact>Linux ఫైల్ permissions (rwxr-xr-x = 755) ఒక నిజమైన-ప్రపంచం bitmask ఉదాహరణ. ప్రతి digit మూడు permission బిట్‌లు ని encode చేస్తుంది: చదవడం (4), రాయండి (2), execute (1), OR తో కలపడం చేయబడతాయి.</FunFact>

## బిట్‌లు Reverse చేయడం (LeetCode 190)

ఒక 32-బిట్ unsigned integer ని బిట్ వారీగా reverse చేయండి. ఫలితం ని మిగిలిన shift చేసి ఇన్‌పుట్ యొక్క lowest బిట్ ని OR చేయండి, తర్వాత ఇన్‌పుట్ ని సరైన shift చేయండి.

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## Missing సంఖ్య (LeetCode 268)

0 నుండి n వరకు n సంఖ్యలు ఉన్న అరే లో ఒకటి missing. అన్ని అరే ఎలిమెంట్‌లు ని 0 నుండి n వరకు indices తో XOR చేయండి - pairs cancel అవుతాయి, missing సంఖ్య మిగులుతుంది. మొత్తం formula కూడా పని చేస్తుంది, కానీ XOR overflow ప్రమాదాన్ని నివారిస్తుంది.

## Hamming Distance (LeetCode 461)

సంబంధిత బిట్‌లు భిన్నంగా ఉన్న positions సంఖ్య. రెండు సంఖ్యలు ని XOR చేయండి - ఫలితం లో సెట్ బిట్‌లు భిన్నమైన positions. Brian Kernighan's trick తో లెక్కించండి.

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```
