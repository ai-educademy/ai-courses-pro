## ద్విమీయ సంఖ్య సమీక్ష

ప్రతి ిన్ట్ెగ్ర్ బిట్‌లు యొక్క ఒక క్రమం. 13 అనే సంఖ్య ద్విమీయ లో `1101`:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

బిట్ మ్అన్ిప్ుల్అషన్ ఈ బిట్‌లు పై నేరుగా బ్ిట్వ్ైజ్ ోప్ర్అట్ర్స్ ఉపయోగించి పని చేస్తుంది - తరచుగా ల్ూప్స్ స్థానంలో ఒకే ఆపరేషన్ సరిపోతుంది.

## ప్రాథమిక *Bitwise* ఆపరేషన్లు

| *Operator* | *Symbol* | ఉదాహరణ (5 = 101, 3 = 011) | ఫలితం |
|----------|--------|----------------------------|--------|
| మరియు      | `&`    | `101 & 011`                | `001` (1) |
| OR       | `\|`   | `101 \| 011`               | `111` (7) |
| *XOR*      | `^`    | `101 ^ 011`                | `110` (6) |
| *NOT*      | `~`    | `~101`                     | `...010` |
| మిగిలిన మార్పు  | `<<` | `101 << 1`              | `1010` (10) |
| సరైన మార్పు | `>>` | `101 >> 1`              | `10` (2) |

## అవసరమైన బిట్ చిట్కాలు

### శక్తి of రెండు చెక్ చేయడం

శక్తి of 2 లో సరిగ్గా ఒక్క సెట్ బిట్ ఉంటుంది: `n & (n - 1) == 0`.

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### సెట్ బిట్‌లు లెక్కించడం (*Brian Kernighan*'s అల్గారిథమ్)

ప్రతి `n & (n - 1)` అత్యంత తక్కువ సెట్ బిట్ ని తొలగిస్తుంది. n = 0 అయ్యే వరకు ిట్ర్అషన్స్ లెక్కించండి.

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

ఇది O(k) లో నడుస్తుంది, ఇక్కడ k అనేది సెట్ బిట్‌లు సంఖ్య - O(32) కాదు.

### *Temp* చరరాశి లేకుండా *Swap*

```python
a ^= b
b ^= a
a ^= b
```

*XOR* తన స్వంత ిన్వ్ర్స్ె కాబట్టి ఇది పని చేస్తుంది: `a ^ b ^ b = a`.

## ఒకే సంఖ్య - *XOR* *Cancellation*

ప్రతి ఎలిమెంట్ రెండు సార్లు వస్తుంది ఒక్కటి తప్ప. దాన్ని కనుగొనండి. `a ^ a = 0` మరియు `a ^ 0 = a` కాబట్టి, అన్ని ఎలిమెంట్‌లు ని *XOR* చేయండి - జంటలు క్అన్క్ెల్ అవుతాయి, ప్రత్యేక సంఖ్య మిగులుతుంది.

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

సమయం O(n), స్థలం O(1). హ్యాష్ మ్యాప్ అవసరం లేదు.

## ఒకే సంఖ్య *III* - రెండు ప్రత్యేక సంఖ్యలు

*రెండు* సంఖ్యలు ప్రత్యేక అయినప్పుడు, అన్నింటినీ *XOR* చేస్తే `x = a ^ b` వస్తుంది. `x` లో ఏదైనా సెట్ బిట్ కనుగొనండి (అక్కడ రెండు సంఖ్యలు భిన్నంగా ఉంటాయి). ఆ బిట్ ఆధారంగా అన్ని సంఖ్యలు ని రెండు గ్ర్ౌప్స్ గా విభజించి, ప్రతి గుంపు ని *XOR* చేయండి - ప్రతి గుంపు లో సరిగ్గా ఒక ప్రత్యేక సంఖ్య ఉంటుంది.

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

<ThinkAboutIt>`xor & (-xor)` అత్యంత కుడివైపు సెట్ బిట్ ని ఎందుకు ిస్ోల్అట్ె చేస్తుంది? రెండు's క్ోమ్ప్ల్మెంట్ లో న్ెగ్అట్ివ్ సంఖ్యలు ఎలా ప్రతినిధ్యం చేస్తుంది అవుతాయో ఆలోచించండి.</ThinkAboutIt>

## సంఖ్య of 1 బిట్‌లు (*LeetCode* 191)

ఇది పైన చూసిన *Brian Kernighan*'s అల్గారిథమ్ - నేరుగా ఇంటర్వ్యూ ప్రశ్న. అనుసరించండి-up: ఇన్‌పుట్ స్ిగ్న్ెడ్ అయితే? *Python* లో ిన్ట్ెగ్ర్స్ ార్బ్ిట్ర్ార్య్ ప్రెసిషన్ కలిగి ఉంటాయి, కానీ *Java*/C++ లో 32-బిట్ హద్దులు నిర్వహించు చేయాలి.

## ఉపసెట్లు కోసం బిట్ *Masking*

n పొడవు గల బ్ిట్మ్అస్క్, n అంశాలు యొక్క ఒక ఉపసెట్ ని ప్రతినిధ్యం చేస్తుంది చేస్తుంది. బిట్ `i` సెట్ అయి ఉంటే అంశం `i` చేర్చబడింది. `0` నుండి `2^n - 1` వరకు పునరావృతం చేయండి చేస్తే అన్ని ఉపసెట్లు సృష్టించు అవుతాయి.

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

n ≤ 20 ఉన్న సమస్యలు కోసం ఈ టెక్నిక్ పని చేస్తుంది - 2^n ెన్ుమ్ర్అషన్ కి సరిపోయేంత చిన్నది.

<FunFact>*Linux* ఫైల్ ప్ర్మ్ిస్షన్స్ (ర్వ్క్స్ర్-క్స్ర్-క్స్ = 755) ఒక నిజమైన-ప్రపంచం బ్ిట్మ్అస్క్ ఉదాహరణ. ప్రతి డ్ిగ్ిట్ మూడు అనుమతి బిట్‌లు ని ఎన్‌కోడ్ చేయండి చేస్తుంది: చదవడం (4), రాయండి (2), అమలు చేయండి (1), OR తో కలపడం చేయబడతాయి.</FunFact>

## బిట్‌లు *Reverse* చేయడం (*LeetCode* 190)

ఒక 32-బిట్ ున్స్ిగ్న్ెడ్ ిన్ట్ెగ్ర్ ని బిట్ వారీగా ర్ెవ్ర్స్ె చేయండి. ఫలితం ని మిగిలిన మార్పు చేసి ఇన్‌పుట్ యొక్క ల్ౌెస్ట్ బిట్ ని OR చేయండి, తర్వాత ఇన్‌పుట్ ని సరైన మార్పు చేయండి.

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## *Missing* సంఖ్య (*LeetCode* 268)

0 నుండి n వరకు n సంఖ్యలు ఉన్న అరే లో ఒకటి మ్ిస్స్ింగ్. అన్ని అరే ఎలిమెంట్‌లు ని 0 నుండి n వరకు సూచికలు తో *XOR* చేయండి - జంటలు క్అన్క్ెల్ అవుతాయి, మ్ిస్స్ింగ్ సంఖ్య మిగులుతుంది. మొత్తం ఫ్ర్మ్ుల్అ కూడా పని చేస్తుంది, కానీ *XOR* ఓవర్‌ఫ్లో ప్రమాదాన్ని నివారిస్తుంది.

## హామింగ్ దూరం (*LeetCode* 461)

సంబంధిత బిట్‌లు భిన్నంగా ఉన్న స్థానాలు సంఖ్య. రెండు సంఖ్యలు ని *XOR* చేయండి - ఫలితం లో సెట్ బిట్‌లు భిన్నమైన స్థానాలు. *Brian Kernighan*'s ట్ర్ిక్ తో లెక్కించండి.

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```

## ఆచరణాత్మక అనువర్తనాలు

బిట్ మ్అన్ిప్ుల్అషన్ ప్రతిచోటా కనిపిస్తుంది: *Unix* ఫైల్ ప్ర్మ్ిస్షన్స్ OR/మరియు మ్అస్క్స్ వాడతాయి, ఫీచర్ ఫ్ల్అగ్స్ వ్యక్తిగత బిట్‌లు లో ట్ోగ్గ్ల్స్ నిల్వ చేస్తాయి, నెట్‌వర్క్ స్ుబ్న్ెట్ మ్అస్క్స్ రూటింగ్ కోసం మరియు వాడతాయి, మరియు లోపం గుర్తింపు *XOR* చ్ెక్స్ుమ్స్ పై ఆధారపడుతుంది.
