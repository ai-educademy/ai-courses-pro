## స్టాక్ ను మోనోటానిక్ గా మార్చేది ఏమిటి?

ఒక **మోనోటానిక్ స్టాక్** ఎలిమెంట్‌లు ను bottom నుండి ముఖ్యమైన వరకు strictly increasing లేదా తగ్గే క్రమం లో నిర్వహించండి చేస్తుంది. కొత్త ఎలిమెంట్ పుష్ చేయడానికి ముందు, invariant ను violate చేసే అన్ని ఎలిమెంట్‌లు ను పాప్ చేస్తారు. ఈ ఒక్క ఆలోచన O(n²) అవసరమని అనిపించే సమస్యలు ను O(n) లో పరిష్కరించండి చేస్తుంది.

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## తర్వాతి Greater ఎలిమెంట్

ప్రతి ఎలిమెంట్ కి, దాని కుడి వైపు మొదటి పెద్ద ఎలిమెంట్ ను కనుగొనాలి. Brute force ప్రతి స్థానం నుండి కుడి వైపు scan చేస్తుంది - O(n²). ఒక మోనోటానిక్ తగ్గే స్టాక్ ఇది ఒక్క pass లో చేస్తుంది.

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

మనం ఇండెక్స్ `j` ను పాప్ చేసినప్పుడు, ప్రస్తుత ఎలిమెంట్ దాని తర్వాతి greater - ఇది guarantee ఎందుకంటే మధ్యలో ఉన్నవన్నీ చిన్నవి (అవి ముందే పాప్ అయ్యాయి లేదా `j` ను ఎప్పుడూ బ్లాక్ చేయలేదు).

## Stock Span సమస్య

*ప్రతి రోజుకి, ఈ రోజుతో సహా ఎన్ని వరుస రోజుల price ≤ ఈ రోజు price?* `(price, index)` నిల్వ చేసే మోనోటానిక్ తగ్గే స్టాక్ వాడండి. పాప్ చేసినప్పుడు, ప్రస్తుత ఇండెక్స్ మరియు కొత్త స్టాక్ ముఖ్యమైన మధ్య అంతరం span ఇస్తుంది.

## Largest Rectangle లో Histogram

LeetCode యొక్క **Largest Rectangle in Histogram** మోనోటానిక్ స్టాక్ సమస్యలు లో అత్యుత్తమ సమస్య.

**కీ insight:** ప్రతి bar కి, అది చిన్నదైన bar గా ఎంత మిగిలిన మరియు సరైన extend కాగలదో కనుగొనండి. ఒక increasing స్టాక్ వాడండి - ఒక bar పాప్ అయినప్పుడు, popping bar దాని సరైన boundary define చేస్తుంది, మరియు కొత్త స్టాక్ ముఖ్యమైన మిగిలిన boundary define చేస్తుంది.

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

చివరలో sentinel `[0]` మిగిలిన అన్ని bars ప్రక్రియ అయ్యేలా force చేస్తుంది.

## Trapping Rain నీరు - స్టాక్ విధానం

సాంప్రదాయ రెండు-పాయింటర్ పద్ధతి బదులు, ఒక మోనోటానిక్ తగ్గే స్టాక్ చిక్కుకున్న నీరు ను పొర ద్వారా పొర లెక్కించండి చేస్తుంది. ఒక పొడవైన bar వచ్చినప్పుడు, పొట్టి bars ను పాప్ చేసి, popped bar, ప్రస్తుత bar మరియు కొత్త స్టాక్ ముఖ్యమైన మధ్య చిక్కుకున్న నీరు లెక్కించండి చేయండి.

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>Trapping Rain నీరు కి కనీసం నాలుగు విభిన్న O(n) పరిష్కారాలు ఉన్నాయి - రెండు-పాయింటర్, మోనోటానిక్ స్టాక్, ప్రీఫిక్స్ max arrays మరియు ఒకే-pass optimised విధానం. ఇంటర్వ్యూయర్లు అనేక వ్యూహాలు చూడడం ఇష్టపడతారు.</FunFact>

## మోనోటానిక్ క్యూ - స్లైడింగ్ విండో గరిష్ట

ఒక **మోనోటానిక్ deque** (double-ended క్యూ) తగ్గే క్రమం నిర్వహించండి చేస్తుంది మరియు రెండు ends నుండి efficiently తొలగించండి చేయగలదు. **స్లైడింగ్ విండో గరిష్ట** (LeetCode 239) కోసం:

1. ఇండెక్స్ `i` జోడించు చేయడానికి ముందు, `nums[i]` కంటే చిన్న back ఎలిమెంట్‌లు అన్నింటినీ పాప్ చేయండి
2. `i` ను back కి పుష్ చేయండి
3. Front ఎల్లప్పుడూ ప్రస్తుత విండో యొక్క గరిష్ట
4. Front విండో బయటకు వెళ్ళిపోతే దాన్ని తొలగించండి చేయండి

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

ప్రతి ఎలిమెంట్ deque లో గరిష్టంగా ఒక్కసారి enter మరియు leave అవుతుంది - మొత్తం **O(n)**.

## నమూనా - ప్రక్రియ చేస్తూ Invariant నిర్వహించండి చేయండి

ప్రతి మోనోటానిక్ స్టాక్/క్యూ సమస్య ఒకే template అనుసరించండి చేస్తుంది:

1. **Invariant define చేయండి** (increasing లేదా తగ్గే)
2. **Violators ను pop చేయండి** - మరియు ప్రతి పాప్ నుండి ఉపయోగకరమైన సమాచారం extract చేయండి
3. **ప్రస్తుత ఎలిమెంట్ పుష్ చేయండి**
4. *Pop ఈవెంట్* - సమాధానం కంప్యూట్ అయ్యే చోటు అదే
