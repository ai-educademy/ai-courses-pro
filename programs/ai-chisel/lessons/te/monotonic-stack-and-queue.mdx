## స్టాక్ ను మోనోటానిక్ గా మార్చేది ఏమిటి?

ఒక **మోనోటానిక్ స్టాక్** ఎలిమెంట్‌లను కింద నుండి ముఖ్యమైన వరకు కచ్చితంగా పెరుగుతున్న లేదా తగ్గే క్రమం లో నిర్వహిస్తుంది. కొత్త ఎలిమెంట్ పుష్ చేయడానికి ముందు, నియమం ను ఉల్లంఘించే చేసే అన్ని ఎలిమెంట్‌లను పాప్ చేస్తారు. ఈ ఒక్క ఆలోచన O(n²) అవసరమని అనిపించే సమస్యలు ను O(n) లో పరిష్కరిస్తుంది.

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## తర్వాతి పెద్ద ఎలిమెంట్

ప్రతి ఎలిమెంట్ కి, దాని కుడి వైపు మొదటి పెద్ద ఎలిమెంట్ ను కనుగొనాలి. బ్రూట్ ఫోర్స్ ప్రతి స్థానం నుండి కుడి వైపు స్కాన్ చేస్తుంది - O(n²). ఒక మోనోటానిక్ తగ్గే స్టాక్ ఇది ఒక్క పాస్ లో చేస్తుంది.

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

మనం ఇండెక్స్ `j` ను పాప్ చేసినప్పుడు, ప్రస్తుత ఎలిమెంట్ దాని తర్వాతి పెద్ద - ఇది హామీ ఇస్తుంది ఎందుకంటే మధ్యలో ఉన్నవన్నీ చిన్నవి (అవి ముందే పాప్ అయ్యాయి లేదా `j` ను ఎప్పుడూ బ్లాక్ చేయలేదు).

## రోజువారీ Temperatures (LeetCode 739)

*రోజువారీ ఉష్ణోగ్రతలు ఇవ్వబడితే, వెచ్చని రోజు రావడానికి ఎన్ని రోజులు పడుతుందో కనుగొనండి.* ఇది సూచికలు తో తర్వాతి-పెద్ద-ఎలిమెంట్ - ఇండెక్స్ `j` యొక్క సమాధానం `i − j` అవుతుంది, ఇండెక్స్ `i` `j` ను పాప్ చేసినప్పుడు.

## స్టాక్ స్పాన్ సమస్య

*ప్రతి రోజుకి, ఈ రోజుతో సహా ఎన్ని వరుస రోజుల ధర ≤ ఈ రోజు ధర?* `(price, index)` నిల్వ చేసే మోనోటానిక్ తగ్గే స్టాక్ వాడండి. పాప్ చేసినప్పుడు, ప్రస్తుత ఇండెక్స్ మరియు కొత్త స్టాక్ పైభాగం మధ్య అంతరం విస్తృతి ఇస్తుంది.

<ThinkAboutIt>స్టాక్ విస్తృతి సమస్య ఎలిమెంట్‌లను ఎడమ నుంచి కుడికి ప్రాసెస్ చేస్తుంది, అయినా ఎడమ వైపు గురించి సమాచారం కనుగొంటుంది. స్టాక్ ముందుకు వెళ్తూ "వెనక్కి చూడడం" ఎలా సంకేతీకరిస్తుంది?</ThinkAboutIt>

## హిస్టోగ్రామ్‌లో అతిపెద్ద దీర్ఘచతురస్రం

LeetCode యొక్క **Largest Rectangle in Histogram** మోనోటానిక్ స్టాక్ సమస్యలు లో అత్యుత్తమ సమస్య.

**కీ అంతర్దృష్టి:** ప్రతి బార్ కి, అది చిన్నదైన బార్ గా ఎంత ఎడమ మరియు కుడి వైపులా విస్తరించగలదో కాగలదో కనుగొనండి. ఒక పెరుగుతున్న స్టాక్ వాడండి - ఒక బార్ పాప్ అయినప్పుడు, పాప్ చేసిన బార్ దాని కుడి సరిహద్దును నిర్ణయిస్తుంది, మరియు కొత్త స్టాక్ పైభాగం ఎడమ సరిహద్దును నిర్ణయిస్తుంది.

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

చివరలో సెంటినెల్ `[0]` మిగిలిన అన్ని బార్‌లు ప్రాసెస్ అయ్యేలా బలవంతం చేస్తుంది.

## వర్షపు నీరు నిల్వ - స్టాక్ విధానం

సాంప్రదాయ రెండు-పాయింటర్ పద్ధతి బదులు, ఒక మోనోటానిక్ తగ్గే స్టాక్ చిక్కుకున్న నీరు ను పొర ద్వారా పొర లెక్కిస్తుంది. ఒక పొడవైన బార్ వచ్చినప్పుడు, పొట్టి బార్‌లు ను పాప్ చేసి, పాప్ చేసిన బార్, ప్రస్తుత బార్ మరియు కొత్త స్టాక్ పైభాగం మధ్య చిక్కుకున్న నీరు లెక్కించండి.

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>వర్షపు నీరు నిల్వ కి కనీసం నాలుగు విభిన్న O(n) పరిష్కారాలు ఉన్నాయి - రెండు-పాయింటర్, మోనోటానిక్ స్టాక్, ప్రీఫిక్స్ గరిష్ఠ అరేలు మరియు ఒకే-పాస్ మెరుగుపరచిన విధానం. ఇంటర్వ్యూయర్లు అనేక వ్యూహాలు చూడడం ఇష్టపడతారు.</FunFact>

## మోనోటానిక్ క్యూ - స్లైడింగ్ విండో గరిష్ట

ఒక **మోనోటానిక్ డెక్** (రెండు వైపుల క్యూ) తగ్గే క్రమం నిర్వహిస్తుంది మరియు రెండు ముగింపులు నుండి సమర్థంగా తొలగించగలదు. **స్లైడింగ్ విండో గరిష్ట** (LeetCode 239) కోసం:

1. ఇండెక్స్ `i` జోడించడానికి ముందు, `nums[i]` కంటే చిన్న back ఎలిమెంట్‌లు అన్నింటినీ పాప్ చేయండి
2. `i` ను back కి పుష్ చేయండి
3. ముందు భాగం ఎల్లప్పుడూ ప్రస్తుత విండో యొక్క గరిష్ట
4. ముందు భాగం విండో బయటకు వెళ్ళిపోతే దాన్ని తొలగించండి

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

ప్రతి ఎలిమెంట్ డెక్ లో గరిష్టంగా ఒక్కసారి ప్రవేశించి బయటకు వస్తుంది - మొత్తం **O(n)**.

## నమూనా - ప్రాసెస్ చేస్తూ నియమం నిర్వహించండి

ప్రతి మోనోటానిక్ స్టాక్/క్యూ సమస్య ఒకే టెంప్లేట్ అనుసరిస్తుంది:

1. **నియమం define చేయండి** (పెరుగుతున్న లేదా తగ్గే)
2. **Violators ను pop చేయండి** - మరియు ప్రతి పాప్ నుండి ఉపయోగకరమైన సమాచారం తీయండి
3. **ప్రస్తుత ఎలిమెంట్ పుష్ చేయండి**
4. *Pop ఈవెంట్* - సమాధానం కంప్యూట్ అయ్యే చోటు అదే
