## స్టాక్ ను మోనోటానిక్ గా మార్చేది ఏమిటి?

ఒక **మోనోటానిక్ స్టాక్** ఎలిమెంట్‌లు ను బ్ోట్ట్ోమ్ నుండి ముఖ్యమైన వరకు స్ట్ర్ిక్ట్ల్య్ పెరుగుతున్న లేదా తగ్గే క్రమం లో నిర్వహించండి చేస్తుంది. కొత్త ఎలిమెంట్ పుష్ చేయడానికి ముందు, ిన్వ్ార్ిఅన్ట్ ను వ్ిోల్అట్ె చేసే అన్ని ఎలిమెంట్‌లు ను పాప్ చేస్తారు. ఈ ఒక్క ఆలోచన O(n²) అవసరమని అనిపించే సమస్యలు ను O(n) లో పరిష్కరించండి చేస్తుంది.

```
Decreasing stack processing [2, 1, 5, 3, 4]:

Push 2 → [2]
Push 1 → [2, 1]         (1 < 2, invariant holds)
Pop 1, Pop 2, Push 5 → [5]  (5 > both)
Push 3 → [5, 3]
Pop 3, Push 4 → [5, 4]  (4 > 3)
```

## తర్వాతి పెద్దది ఎలిమెంట్

ప్రతి ఎలిమెంట్ కి, దాని కుడి వైపు మొదటి పెద్ద ఎలిమెంట్ ను కనుగొనాలి. *Brute* బలవంతం చేయండి ప్రతి స్థానం నుండి కుడి వైపు స్కాన్ చేయండి చేస్తుంది - O(n²). ఒక మోనోటానిక్ తగ్గే స్టాక్ ఇది ఒక్క పాస్ చేయండి లో చేస్తుంది.

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []
    for i, num in enumerate(nums):
        while stack and nums[stack[-1]] < num:
            result[stack.pop()] = num
        stack.append(i)
    return result
```

మనం ఇండెక్స్ `j` ను పాప్ చేసినప్పుడు, ప్రస్తుత ఎలిమెంట్ దాని తర్వాతి గ్ర్ీట్ర్ - ఇది గ్ుార్అన్ట్ీ ఎందుకంటే మధ్యలో ఉన్నవన్నీ చిన్నవి (అవి ముందే పాప్ అయ్యాయి లేదా `j` ను ఎప్పుడూ బ్లాక్ చేయలేదు).

## రోజువారీ *Temperatures* (*LeetCode* 739)

*రోజువారీ ట్ెమ్ప్ర్అట్ుర్ెస్ ఇవ్వబడితే, వెచ్చని రోజు రావడానికి ఎన్ని రోజులు పడుతుందో కనుగొనండి.* ఇది సూచికలు తో తర్వాతి-గ్ర్ీట్ర్-ఎలిమెంట్ - ఇండెక్స్ `j` యొక్క సమాధానం `i − j` అవుతుంది, ఇండెక్స్ `i` `j` ను పాప్ చేసినప్పుడు.

## స్టాక్ వ్యాప్తి సమస్య

*ప్రతి రోజుకి, ఈ రోజుతో సహా ఎన్ని వరుస రోజుల ధర ≤ ఈ రోజు ధర?* `(price, index)` నిల్వ చేసే మోనోటానిక్ తగ్గే స్టాక్ వాడండి. పాప్ చేసినప్పుడు, ప్రస్తుత ఇండెక్స్ మరియు కొత్త స్టాక్ ముఖ్యమైన మధ్య అంతరం వ్యాప్తి ఇస్తుంది.

## *Largest* *Rectangle* లో *Histogram*

*LeetCode* యొక్క **Largest Rectangle in Histogram** మోనోటానిక్ స్టాక్ సమస్యలు లో అత్యుత్తమ సమస్య.

**కీ అంతర్దృష్టి:** ప్రతి బార్ కి, అది చిన్నదైన బార్ గా ఎంత మిగిలిన మరియు సరైన ెక్స్ట్ెన్డ్ కాగలదో కనుగొనండి. ఒక పెరుగుతున్న స్టాక్ వాడండి - ఒక బార్ పాప్ అయినప్పుడు, ప్ోప్ప్ింగ్ బార్ దాని సరైన హద్దు నిర్వచించండి చేస్తుంది, మరియు కొత్త స్టాక్ ముఖ్యమైన మిగిలిన హద్దు నిర్వచించండి చేస్తుంది.

```python
def largest_rectangle(heights):
    stack, max_area = [], 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
```

చివరలో స్ెన్ట్ిన్ెల్ `[0]` మిగిలిన అన్ని బ్ార్స్ ప్రక్రియ అయ్యేలా బలవంతం చేయండి చేస్తుంది.

## బంధించడం వర్షం నీరు - స్టాక్ విధానం

సాంప్రదాయ రెండు-పాయింటర్ పద్ధతి బదులు, ఒక మోనోటానిక్ తగ్గే స్టాక్ చిక్కుకున్న నీరు ను పొర ద్వారా పొర లెక్కించండి చేస్తుంది. ఒక పొడవైన బార్ వచ్చినప్పుడు, పొట్టి బ్ార్స్ ను పాప్ చేసి, ప్ోప్ప్ెడ్ బార్, ప్రస్తుత బార్ మరియు కొత్త స్టాక్ ముఖ్యమైన మధ్య చిక్కుకున్న నీరు లెక్కించండి చేయండి.

```
Heights:  [3, 1, 2, 1, 3]
Water:       [2, 1, 2]  → total = 5
```

<FunFact>బంధించడం వర్షం నీరు కి కనీసం నాలుగు విభిన్న O(n) పరిష్కారాలు ఉన్నాయి - రెండు-పాయింటర్, మోనోటానిక్ స్టాక్, ప్రీఫిక్స్ మ్అక్స్ ార్ర్ేస్ మరియు ఒకే-పాస్ చేయండి ోప్ట్ిమ్ైజ్డ్ విధానం. ఇంటర్వ్యూయర్లు అనేక వ్యూహాలు చూడడం ఇష్టపడతారు.</FunFact>

## మోనోటానిక్ క్యూ - స్లైడింగ్ విండో గరిష్ట

ఒక **మోనోటానిక్ డ్ెక్వ్ె** (డ్ౌబ్ల్-ెన్డ్ెడ్ క్యూ) తగ్గే క్రమం నిర్వహించండి చేస్తుంది మరియు రెండు ెన్డ్స్ నుండి ెఫ్ఫ్ిక్ిెన్ట్ల్య్ తొలగించండి చేయగలదు. **స్లైడింగ్ విండో గరిష్ట** (*LeetCode* 239) కోసం:

1. ఇండెక్స్ `i` జోడించు చేయడానికి ముందు, `nums[i]` కంటే చిన్న వెనుక ఎలిమెంట్‌లు అన్నింటినీ పాప్ చేయండి
2. `i` ను వెనుక కి పుష్ చేయండి
3. ముందు ఎల్లప్పుడూ ప్రస్తుత విండో యొక్క గరిష్ట
4. ముందు విండో బయటకు వెళ్ళిపోతే దాన్ని తొలగించండి చేయండి

```python
from collections import deque

def max_sliding_window(nums, k):
    dq, result = deque(), []
    for i, num in enumerate(nums):
        while dq and nums[dq[-1]] <= num:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

ప్రతి ఎలిమెంట్ డ్ెక్వ్ె లో గరిష్టంగా ఒక్కసారి ెన్ట్ర్ మరియు వదలండి అవుతుంది - మొత్తం **O(n)**.

## నమూనా - ప్రక్రియ చేస్తూ మారనిది నిర్వహించండి చేయండి

ప్రతి మోనోటానిక్ స్టాక్/క్యూ సమస్య ఒకే నమూనా అనుసరించండి చేస్తుంది:

1. **Invariant నిర్వచించండి చేయండి** (పెరుగుతున్న లేదా తగ్గే)
2. **Violators ను ప్ోప్ చేయండి** - మరియు ప్రతి పాప్ నుండి ఉపయోగకరమైన సమాచారం తీయండి చేయండి
3. **ప్రస్తుత ఎలిమెంట్ పుష్ చేయండి**
4. *Pop ఈవెంట్* - సమాధానం కంప్యూట్ అయ్యే చోటు అదే
