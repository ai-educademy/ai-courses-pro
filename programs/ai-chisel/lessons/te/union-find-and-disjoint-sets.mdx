## కనెక్టివిటీ సమస్య

మీ దగ్గర నోడ్‌లు తో ఒక నెట్‌వర్క్ ఉందని అనుకోండి, మీకు రెండు రకాల క్వెరీలు వస్తూ ఉంటాయి: *నోడ్ A ని నోడ్ B కి కలపండి చేయండి* మరియు *A మరియు B క్ోన్న్ెక్ట్ెడ్ గా ఉన్నాయా?* ప్రతి క్వెరీ కి *BFS*/*DFS* చేస్తే మొత్తం గ్రాఫ్ ట్ర్అవ్ర్స్ె చేయాల్సి వస్తుంది - లక్షల ఆపరేషన్లు కి ఇది చాలా నెమ్మది.

**Union-Find** రెండు క్వెరీలు ని దాదాపు క్ోన్స్ట్అన్ట్ సమయం లో సమాధానం చేస్తుంది.

## సరళమైన విధానం - త్వరిత కనుగొనండి

ప్రతి నోడ్ కి ఒక భాగం ID నిల్వ చేయండి. కనెక్టివిటీ తనిఖీ చేయడానికి *IDs* ని O(1) లో పోల్చండి చేయండి. కానీ రెండు భాగాలు మర్జ్ చేయడానికి ఒక గుంపు లోని ప్రతి మ్ెమ్బ్ర్ ని నవీకరించు చేయాలి - ప్రతి యూనియన్ కి O(n).

```
IDs:  [0, 0, 0, 3, 3]
       └─group 0─┘ └group 3┘
union(0, 3) → update all 3s to 0 → O(n)
```

మనకు ఏదైనా మెరుగైనది కావాలి.

## *Union-Find* డేటా నిర్మాణం

ప్రతి నోడ్ ఒక **ప్ార్ెన్ట్** వైపు స్థానం చేస్తుంది. ప్రతి వృక్షం యొక్క రూట్ ఆ భాగం యొక్క ర్ెప్ర్ెస్ెన్ట్అట్ివ్. రెండు నోడ్‌లు ఒకే రూట్ పంచుకోండి చేస్తే మాత్రమే అవి కలిసిన.

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
```

## కనుగొనండి తో మార్గం కంప్రెషన్

లోతైన వృక్షం లో ప్ార్ెన్ట్ పాయింటర్లు అనుసరించండి చేయడం నెమ్మది గా ఉంటుంది. **మార్గం కంప్రెషన్** వృక్షం ని ఫ్ల్అట్ చేస్తుంది - ప్రతి వ్ిస్ిట్ెడ్ నోడ్ ని నేరుగా రూట్ కి స్థానం చేయిస్తుంది.

```python
def find(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find(self.parent[x])
    return self.parent[x]
```

నోడ్ 4 ని కనుగొనండి చేయడానికి ముందు మరియు తర్వాత:

```
Before:  0←1←2←3←4     After:  0←1
                                0←2
                                0←3
                                0←4
```

## యూనియన్ ద్వారా ర్యాంక్

ఎల్లప్పుడూ చిన్న వృక్షం ని పెద్ద వృక్షం కింద అట్ట్అచ్ చేయండి. ఇది వృక్షం హ్ెిగ్హ్ట్ ని ల్ోగ్ార్ిత్మ్ిక్ గా ఉంచుతుంది మరియు డ్ెగ్ెన్ర్అట్ె చ్ైన్స్ ఏర్పడకుండా చేస్తుంది.

```python
def union(self, x, y):
    rx, ry = self.find(x), self.find(y)
    if rx == ry:
        return False
    if self.rank[rx] < self.rank[ry]:
        rx, ry = ry, rx
    self.parent[ry] = rx
    if self.rank[rx] == self.rank[ry]:
        self.rank[rx] += 1
    return True
```

## *Kruskal*'s *MST* అల్గారిథమ్

*Union-Find* **Kruskal's అల్గారిథమ్** ని శక్తి చేస్తుంది - కనిష్ఠ *Spanning* వృక్షాలు కోసం:

1. అన్ని ఎడ్జ్‌లు ని బరువు ప్రకారం క్రమబద్ధీకరించండి చేయండి
2. ప్రతి ముందంజ (u, v) కి, `find(u) ≠ find(v)` అయితే, దాన్ని జోడించు చేసి `union(u, v)` చేయండి
3. n − 1 ఎడ్జ్‌లు వచ్చినప్పుడు ఆపండి

*Union-Find* క్య్క్ల్స్ ని నిరోధించండి చేస్తుంది - ఎండ్‌పాయింట్‌లు ఇప్పటికే ఒకే రూట్ పంచుకోండి చేస్తుంటే ముందంజ తిరస్కరించండి అవుతుంది. మొత్తం సమయం: **O(E లాగ్ E)** - క్రమబద్ధీకరణ డ్ోమ్ిన్అట్ె చేస్తుంది.

<ThinkAboutIt>*Kruskal*'s అల్గారిథమ్ క్య్క్ల్స్ గుర్తించండి చేయడానికి *Union-Find* వాడండి చేస్తుంది. *DFS* తో చక్రం ఎలా గుర్తించండి చేస్తారు, మరియు ఇక్కడ *Union-Find* ఎందుకు మరింత సహజ?</ThinkAboutIt>

## సాంప్రదాయ సమస్యలు

### సంఖ్య of కలిసిన భాగాలు

*Union-Find* ని n నోడ్‌లు తో ిన్ిషల్ైజ్ చేయండి. ప్రతి ముందంజ ని `union` తో ప్రక్రియ చేయండి. చివరలో డ్ిస్ట్ిన్క్ట్ ర్ూట్స్ లెక్క చేయండి.

### ఖాతాలు మర్జ్ (*LeetCode* 721)

ప్రతి అక్క్ౌన్ట్ లో ఇమెయిల్‌లు ఉంటాయి. రెండు ఖాతాలు ఒక ఇమెయిల్ పంచుకోండి చేస్తే, అవి ఒకే వ్యక్తికి చెందినవి. పంచుకున్న ఇమెయిల్‌లు ఆధారంగా ఖాతాలు ని యూనియన్ చేసి, గుంపు మరియు క్రమబద్ధీకరించండి చేయండి.

### *Redundant* కనెక్షన్ (*LeetCode* 684)

ఒక వృక్షం ఇవ్వబడింది దానిలో ఒక ెక్స్ట్ర్అ ముందంజ ఉంది - ర్ెడ్ున్డ్అన్ట్ ముందంజ కనుగొనండి. ఎడ్జ్‌లు ని క్రమం లో ప్రక్రియ చేయండి - `union` మొదటిసారి `False` రిటర్న్ చేసే ముందంజ (ఇప్పటికే కలిసిన) అదే సమాధానం.

<FunFact>*Union-Find* రెండు మెరుగుదలలు తో O(α(n)) లో నడపండి అవుతుందని రుజువు ని *Tarjan* 1975 లో ప్రచురించండి చేశారు - ఇది కంప్యూటర్ సైన్స్ లో అత్యంత చక్కని అమార్టైజ్డ్ అన్ల్య్స్ెస్ లో ఒకటిగా పరిగణించబడుతుంది.</FunFact>

## *Union-Find* వర్సెస్ *BFS*/*DFS* - ఎప్పుడు ఏది ఎంచుకోవాలి

| సన్నివేశం | ఉత్తమ ఎంపిక |
|----------|-------------|
| మళ్ళీ మళ్ళీ క్ోన్న్ెక్ట్ివ్ిటీ క్వెరీలు | *Union-Find* |
| ఒకే ట్రావర్సల్ / చిన్నదైన మార్గం | *BFS*/*DFS* |
| *Incremental* ముందంజ అడ్డ్ిషన్స్ | *Union-Find* |
| ముందంజ ర్ెమ్ోవ్ల్స్ (డ్య్న్అమ్ిక్ గ్రాఫ్) | *BFS*/*DFS* (లేదా ఆఫ్‌లైన్ UF) |
| *Kruskal*'s *MST* | *Union-Find* |
| టోపాలజికల్ క్రమబద్ధీకరించండి / దిశానిర్దేశిత గ్రాఫ్ లో చక్రం | *DFS* |

ఎడ్జ్‌లు ని *ిన్క్ర్ెమెంట్ల్ల్య్* ప్రక్రియ చేస్తూ వేగంగా క్ోన్న్ెక్ట్ివ్ిటీ తనిఖీలు కావాలంటే *Union-Find* బాగా పని చేస్తుంది. ఒకే సారి ట్ర్అవ్ర్స్ె చేయాల్సి వస్తే లేదా మార్గం సమాచారం కావాలంటే *BFS*/*DFS* వాడండి.
