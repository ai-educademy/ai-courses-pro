## ట్రై అంటే ఏమిటి?

**ట్రై** (ఉచ్చారణ "try") అనేది ప్రతి నోడ్ ఒక్క అక్షరం ను ప్రతినిధ్యం చేసే వృక్షం లాంటి నిర్మాణం. రూట్ నుండి గుర్తించిన నోడ్‌లు వరకు ఉన్న మార్గాలు నిల్వైన పదాలను అక్షరక్రమం చేస్తాయి. హ్యాష్ మ్యాప్‌లు కి భిన్నంగా, ట్రైలు *ఒక ప్రీఫిక్స్ పంచుకునే అన్ని పదాలు* ను ప్రతి కీ స్కాన్ చేయకుండా క్వెరీ చేయగలవు.

```
        root
       / | \
      a   b   c
     /     \
    p       a
   / \       \
  p   e      t
  |
  l
  e
```

ప్రతి మార్గం ఒక పదం ను సంకేతీకరిస్తుంది: **apple**, **ape**, **bat**, **cat**.

## TrieNode Class

ప్రతి నోడ్ లో పిల్లలు మ్యాప్ మరియు పదం ముగింపును సూచించే గుర్తు ఉంటాయి.

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False
```

పూర్తి ట్రై దీనిని చేర్చండి, సెర్చ్, మరియు ప్రీఫిక్స్ ఆపరేషన్లు తో wrap చేస్తుంది.

## ప్రధాన ఆపరేషన్లు

### చేర్చండి - O(m) ఇక్కడ m = పదం యొక్క పొడవు

అక్షరం ద్వారా అక్షరం నడవండి, అవసరమైతే నోడ్‌లు సృష్టించండి, తర్వాత చివరి నోడ్ ని mark చేయండి.

```python
def insert(self, word):
    node = self.root
    for ch in word:
        if ch not in node.children:
            node.children[ch] = TrieNode()
        node = node.children[ch]
    node.is_end = True
```

### సెర్చ్ మరియు startsWith

**సెర్చ్** మార్గం ను అనుసరించి `is_end` తనిఖీ చేస్తుంది. **startsWith** మార్గం ఉందా లేదా అని మాత్రమే తనిఖీ చేస్తుంది - దీనికి `is_end = True` అవసరం లేదు.

## DFS తో ఆటోకంప్లీట్

ఒక ప్రీఫిక్స్ కోసం సూచనలు ఇవ్వడానికి, ప్రీఫిక్స్ నోడ్ కి వెళ్లి, తర్వాత DFS నడిపి దాని కింద ఉన్న అన్ని పదాలు సేకరించండి.

```python
def autocomplete(self, prefix):
    node = self._find(prefix)
    if not node:
        return []
    results = []
    self._dfs(node, prefix, results)
    return results
```

`_dfs` సహాయకం పిల్లల్లో పునరావృతంగా సంచరించి `is_end` `True` అయినప్పుడల్లా ఫలితాలు కి జోడిస్తుంది.

<ThinkAboutIt>ఆటోకంప్లీట్ ని ముఖ్యమైన k అత్యధిక తరచుగా వచ్చే సూచనలు కి ఎలా పరిమితి చేస్తారు? ప్రతి నోడ్ కి ఏ అదనపు డేటా అవసరం?</ThinkAboutIt>

## వైల్డ్‌కార్డ్ శోధన - పద నిఘంటువు

LeetCode యొక్క **డిజైన్ జోడించు మరియు సెర్చ్ Words డేటా నిర్మాణం** లో `.` ని ఏదైనా ఒకే అక్షరం కి సరిపోలే వైల్డ్‌కార్డ్ గా నిర్వహించాలి.

సెర్చ్ సమయంలో `.` వచ్చినప్పుడు, *ప్రతి* పిల్ల లోకి ప్రతి శాఖలోకి పునరావృతంగా కొనసాగండి. ఇది సులభమైన సంచారం ని పరిమిత బ్యాక్‌ట్రాకింగ్ సెర్చ్ గా మారుస్తుంది.

```python
def search_wild(self, node, word, i):
    if i == len(word):
        return node.is_end
    if word[i] == '.':
        return any(
            self.search_wild(c, word, i + 1)
            for c in node.children.values()
        )
    if word[i] not in node.children:
        return False
    return self.search_wild(
        node.children[word[i]], word, i + 1
    )
```

## పొడవైన సాధారణ ప్రీఫిక్స్

రూట్ నుండి ట్రై లో నడవండి. పొడవైన సాధారణ ప్రీఫిక్స్ మొదటి నోడ్ వద్ద ముగుస్తుంది, ఆ నోడ్ కి ఒకటి కంటే ఎక్కువ పిల్లలు ఉన్నప్పుడు లేదా `is_end` flag ఉన్నప్పుడు.

## Tries తో IP రూటింగ్

రౌటర్లు IP ప్రీఫిక్స్‌లను ను **ద్విమానం ట్రై** లో నిల్వ చేస్తారు - ప్రతి బిట్ (0 లేదా 1) ఒక శాఖ ఏర్పరుస్తుంది. పొడవైన ప్రీఫిక్స్ సరిపోలిక అత్యంత స్పష్టంగా మార్గం ని కనుగొంటుంది. మీ ప్యాకెట్లు ఇంటర్నెట్ లో తమ దారిని ఇలాగే కనుగొంటాయి.

<FunFact>ఇంటర్నెట్ బ్యాక్‌బోన్ రౌటర్లు TCAMలు అనే ప్రత్యేక చిప్‌లు లో నిర్మించిన హార్డ్‌వేర్‌కు అనుకూలీకరించిన ట్రైలు ఉపయోగించి ప్రతి సెకండ్ బిలియన్ల పొడవైన ప్రీఫిక్స్ సరిపోలిక లుక్‌అప్‌లు చేస్తాయి.</FunFact>

## కుదించిన ట్రైలు (రాడిక్స్ వృక్షాలు)

ప్రామాణిక ట్రైలు ఒకే-పిల్ల గొలుసులు పై స్థలం వృథా చేస్తాయి. **Radix వృక్షం** ఈ గొలుసులు ని మర్జ్ చేసి బహుళ-అక్షరం లేబుల్‌లు ఉన్న ఒకే ఎడ్జ్‌లు గా మారుస్తుంది.

```
Standard:  r → u → n → n → i → n → g
Radix:     r → "unning"
```

ఇది నోడ్ లెక్క ని గణనీయంగా తగ్గిస్తుంది మరియు Linux కెర్నల్ రూటింగ్ పట్టికలు మరియు Go యొక్క `httprouter` వంటి HTTP రౌటర్లు లో ఉపయోగించబడుతుంది.

## సమయం మరియు స్థలం క్లిష్టత

| Operation    | ట్రై   | హ్యాష్ మ్యాప్ |
|--------------|--------|----------|
| చేర్చండి       | O(m)   | O(m)     |
| సెర్చ్       | O(m)   | O(m)     |
| ప్రీఫిక్స్ క్వెరీ | O(m+k) | O(n·m)   |

ఇక్కడ *m* పదం పొడవు, *k* ఫలితాలు లెక్క, మరియు *n* మొత్తం కీలు. ప్రీఫిక్స్-భారీ పని భారాల్లో ట్రైలు ఆధిపత్యం చెలాయిస్తాయి.
