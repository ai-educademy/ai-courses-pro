## ట్రై అంటే ఏమిటి?

**Trie** (ఉచ్చారణ "try") అనేది ప్రతి నోడ్ ఒక్క అక్షరం ను ప్రతినిధ్యం చేస్తుంది చేసే వృక్షం లాంటి నిర్మాణం. రూట్ నుండి marked నోడ్‌లు వరకు ఉన్న మార్గాలు stored words ను spell చేస్తాయి. హ్యాష్ మ్యాప్‌లు కి భిన్నంగా, tries *ఒక ప్రీఫిక్స్ పంచుకోండి చేసే అన్ని words* ను ప్రతి కీ scan చేయకుండా క్వెరీ చేయగలవు.

```
        root
       / | \
      a   b   c
     /     \
    p       a
   / \       \
  p   e      t
  |
  l
  e
```

ప్రతి మార్గం ఒక పదం ను encode చేస్తుంది: **apple**, **ape**, **bat**, **cat**.

## TrieNode Class

ప్రతి నోడ్ లో children మ్యాప్ మరియు పదం completion ని indicate చేసే flag ఉంటాయి.

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False
```

పూర్తి ట్రై దీనిని చేర్చండి, సెర్చ్, మరియు ప్రీఫిక్స్ ఆపరేషన్లు తో wrap చేస్తుంది.

## ప్రధాన ఆపరేషన్లు

### చేర్చండి - O(m) ఇక్కడ m = పదం యొక్క length

అక్షరం ద్వారా అక్షరం నడవండి, అవసరమైతే నోడ్‌లు సృష్టించండి, తర్వాత చివరి నోడ్ ని mark చేయండి.

```python
def insert(self, word):
    node = self.root
    for ch in word:
        if ch not in node.children:
            node.children[ch] = TrieNode()
        node = node.children[ch]
    node.is_end = True
```

### సెర్చ్ మరియు startsWith

**సెర్చ్** మార్గం ను అనుసరించండి చేసి `is_end` తనిఖీ చేస్తుంది. **startsWith** మార్గం ఉందా లేదా అని మాత్రమే తనిఖీ చేస్తుంది - దీనికి `is_end = True` అవసరం లేదు.

## DFS తో ఆటోకంప్లీట్

ఒక ప్రీఫిక్స్ కోసం suggestions ఇవ్వడానికి, ప్రీఫిక్స్ నోడ్ కి navigate చేసి, తర్వాత DFS నడపండి చేసి దాని కింద ఉన్న అన్ని words collect చేయండి.

```python
def autocomplete(self, prefix):
    node = self._find(prefix)
    if not node:
        return []
    results = []
    self._dfs(node, prefix, results)
    return results
```

`_dfs` helper children లో recursively traverse చేసి `is_end` `True` అయినప్పుడల్లా ఫలితాలు కి append చేస్తుంది.

<ThinkAboutIt>ఆటోకంప్లీట్ ని ముఖ్యమైన-k అత్యధిక frequent suggestions కి ఎలా పరిమితి చేస్తారు? ప్రతి నోడ్ కి ఏ extra డేటా అవసరం?</ThinkAboutIt>

## Wildcard సెర్చ్ - పదం Dictionary

LeetCode యొక్క **డిజైన్ జోడించు మరియు సెర్చ్ Words డేటా నిర్మాణం** లో `.` ని ఏదైనా ఒకే అక్షరం కి సరిపోల్చండి అయ్యే wildcard గా నిర్వహించు చేయాలి.

సెర్చ్ సమయంలో `.` వచ్చినప్పుడు, *ప్రతి* child లోకి branch చేసి recursively continue చేయండి. ఇది సులభమైన traversal ని bounded backtracking సెర్చ్ గా మారుస్తుంది.

```python
def search_wild(self, node, word, i):
    if i == len(word):
        return node.is_end
    if word[i] == '.':
        return any(
            self.search_wild(c, word, i + 1)
            for c in node.children.values()
        )
    if word[i] not in node.children:
        return False
    return self.search_wild(
        node.children[word[i]], word, i + 1
    )
```

## Longest సాధారణ ప్రీఫిక్స్

రూట్ నుండి ట్రై లో నడవండి. Longest సాధారణ ప్రీఫిక్స్ మొదటి నోడ్ వద్ద ముగుస్తుంది, ఆ నోడ్ కి ఒకటి కంటే ఎక్కువ children ఉన్నప్పుడు లేదా `is_end` flag ఉన్నప్పుడు.

## Tries తో IP రూటింగ్

Routers IP prefixes ను **binary ట్రై** లో నిల్వ చేస్తారు - ప్రతి బిట్ (0 లేదా 1) ఒక branch ఏర్పరుస్తుంది. Longest ప్రీఫిక్స్ సరిపోల్చండి అత్యంత స్పష్టంగా మార్గం ని కనుగొంటుంది. మీ packets internet లో తమ దారిని ఇలాగే కనుగొంటాయి.

<FunFact>Internet backbone routers TCAMs అనే specialised chips లో నిర్మించిన hardware-optimised tries ఉపయోగించి ప్రతి సెకండ్ బిలియన్ల longest-ప్రీఫిక్స్-సరిపోల్చండి లుక్‌అప్‌లు చేస్తాయి.</FunFact>

## Compressed Tries (Radix వృక్షాలు)

ప్రామాణిక tries ఒకే-child chains పై స్థలం వృథా చేస్తాయి. **Radix వృక్షం** ఈ chains ని మర్జ్ చేసి బహుళ-అక్షరం labels ఉన్న ఒకే ఎడ్జ్‌లు గా మారుస్తుంది.

```
Standard:  r → u → n → n → i → n → g
Radix:     r → "unning"
```

ఇది నోడ్ లెక్క ని గణనీయంగా తగ్గిస్తుంది మరియు Linux kernel రూటింగ్ tables మరియు Go యొక్క `httprouter` వంటి HTTP routers లో ఉపయోగించబడుతుంది.

## సమయం మరియు స్థలం క్లిష్టత

| Operation    | ట్రై   | హ్యాష్ మ్యాప్ |
|--------------|--------|----------|
| చేర్చండి       | O(m)   | O(m)     |
| సెర్చ్       | O(m)   | O(m)     |
| ప్రీఫిక్స్ క్వెరీ | O(m+k) | O(n·m)   |

ఇక్కడ *m* పదం length, *k* ఫలితాలు లెక్క, మరియు *n* మొత్తం కీలు. ప్రీఫిక్స్-భారీ workloads లో tries ఆధిపత్యం చెలాయిస్తాయి.
