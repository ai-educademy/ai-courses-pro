## ట్రై అంటే ఏమిటి?

**Trie** (ఉచ్చారణ "ప్రయత్నించండి") అనేది ప్రతి నోడ్ ఒక్క అక్షరం ను ప్రతినిధ్యం చేస్తుంది చేసే వృక్షం లాంటి నిర్మాణం. రూట్ నుండి మ్ార్క్ెడ్ నోడ్‌లు వరకు ఉన్న మార్గాలు స్ట్ర్ెడ్ పదాలు ను స్ప్ెల్ల్ చేస్తాయి. హ్యాష్ మ్యాప్‌లు కి భిన్నంగా, ట్ర్ిెస్ *ఒక ప్రీఫిక్స్ పంచుకోండి చేసే అన్ని పదాలు* ను ప్రతి కీ స్కాన్ చేయండి చేయకుండా క్వెరీ చేయగలవు.

```
        root
       / | \
      a   b   c
     /     \
    p       a
   / \       \
  p   e      t
  |
  l
  e
```

ప్రతి మార్గం ఒక పదం ను ఎన్‌కోడ్ చేయండి చేస్తుంది: **ఆపిల్**, **ఏప్**, **బ్యాట్**, **క్యాట్**.

## *TrieNode* *Class*

ప్రతి నోడ్ లో చ్ిల్డ్ర్ెన్ మ్యాప్ మరియు పదం క్ోమ్ప్ల్షన్ ని ిన్డ్ిక్అట్ె చేసే ఫ్ల్అగ్ ఉంటాయి.

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False
```

పూర్తి ట్రై దీనిని చేర్చండి, సెర్చ్, మరియు ప్రీఫిక్స్ ఆపరేషన్లు తో వ్ర్అప్ చేస్తుంది.

## ప్రధాన ఆపరేషన్లు

### చేర్చండి - O(m) ఇక్కడ m = పదం యొక్క పొడవు

అక్షరం ద్వారా అక్షరం నడవండి, అవసరమైతే నోడ్‌లు సృష్టించండి, తర్వాత చివరి నోడ్ ని మ్ార్క్ చేయండి.

```python
def insert(self, word):
    node = self.root
    for ch in word:
        if ch not in node.children:
            node.children[ch] = TrieNode()
        node = node.children[ch]
    node.is_end = True
```

### సెర్చ్ మరియు స్ట్ార్ట్స్వ్ిత్

**సెర్చ్** మార్గం ను అనుసరించండి చేసి `is_end` తనిఖీ చేస్తుంది. **స్ట్ార్ట్స్వ్ిత్** మార్గం ఉందా లేదా అని మాత్రమే తనిఖీ చేస్తుంది - దీనికి `is_end = True` అవసరం లేదు.

## *DFS* తో ఆటోకంప్లీట్

ఒక ప్రీఫిక్స్ కోసం స్ుగ్గ్ెస్షన్స్ ఇవ్వడానికి, ప్రీఫిక్స్ నోడ్ కి నావిగేట్ చేయండి చేసి, తర్వాత *DFS* నడపండి చేసి దాని కింద ఉన్న అన్ని పదాలు సేకరించండి చేయండి.

```python
def autocomplete(self, prefix):
    node = self._find(prefix)
    if not node:
        return []
    results = []
    self._dfs(node, prefix, results)
    return results
```

`_dfs` హ్ెల్ప్ర్ చ్ిల్డ్ర్ెన్ లో ర్ెక్ుర్స్ివ్ల్య్ ట్ర్అవ్ర్స్ె చేసి `is_end` `True` అయినప్పుడల్లా ఫలితాలు కి అప్ప్ెన్డ్ చేస్తుంది.

<ThinkAboutIt>ఆటోకంప్లీట్ ని ముఖ్యమైన-k అత్యధిక తరచుగా స్ుగ్గ్ెస్షన్స్ కి ఎలా పరిమితి చేస్తారు? ప్రతి నోడ్ కి ఏ ెక్స్ట్ర్అ డేటా అవసరం?</ThinkAboutIt>

## *Wildcard* సెర్చ్ - పదం *Dictionary*

*LeetCode* యొక్క **డిజైన్ జోడించు మరియు సెర్చ్ పదాలు డేటా నిర్మాణం** లో `.` ని ఏదైనా ఒకే అక్షరం కి సరిపోల్చండి అయ్యే వ్ిల్డ్క్ార్డ్ గా నిర్వహించు చేయాలి.

సెర్చ్ సమయంలో `.` వచ్చినప్పుడు, *ప్రతి* చ్ిల్డ్ లోకి శాఖ చేసి ర్ెక్ుర్స్ివ్ల్య్ క్ోన్ట్ిన్ుె చేయండి. ఇది సులభమైన ట్రావర్సల్ ని బ్ౌన్డ్ెడ్ బ్అక్ట్ర్అక్ింగ్ సెర్చ్ గా మారుస్తుంది.

```python
def search_wild(self, node, word, i):
    if i == len(word):
        return node.is_end
    if word[i] == '.':
        return any(
            self.search_wild(c, word, i + 1)
            for c in node.children.values()
        )
    if word[i] not in node.children:
        return False
    return self.search_wild(
        node.children[word[i]], word, i + 1
    )
```

## అత్యంత పొడవైన సాధారణ ప్రీఫిక్స్

రూట్ నుండి ట్రై లో నడవండి. అత్యంత పొడవైన సాధారణ ప్రీఫిక్స్ మొదటి నోడ్ వద్ద ముగుస్తుంది, ఆ నోడ్ కి ఒకటి కంటే ఎక్కువ చ్ిల్డ్ర్ెన్ ఉన్నప్పుడు లేదా `is_end` ఫ్ల్అగ్ ఉన్నప్పుడు.

## ట్రైలు తో IP రూటింగ్

*Routers* IP ప్ర్ెఫ్ిక్స్ెస్ ను **ద్విమీయ ట్రై** లో నిల్వ చేస్తారు - ప్రతి బిట్ (0 లేదా 1) ఒక శాఖ ఏర్పరుస్తుంది. అత్యంత పొడవైన ప్రీఫిక్స్ సరిపోల్చండి అత్యంత స్పష్టంగా మార్గం ని కనుగొంటుంది. మీ ప్అక్ెట్స్ ిన్ట్ర్న్ెట్ లో తమ దారిని ఇలాగే కనుగొంటాయి.

<FunFact>*Internet* బ్అక్బ్ోన్ె ర్ౌట్ర్స్ *TCAMs* అనే ప్రత్యేక చ్ిప్స్ లో నిర్మించిన హ్ార్డ్వ్ార్ె-ోప్ట్ిమ్ైజ్డ్ ట్ర్ిెస్ ఉపయోగించి ప్రతి సెకండ్ బిలియన్ల ల్ోన్గ్ెస్ట్-ప్రీఫిక్స్-సరిపోల్చండి లుక్‌అప్‌లు చేస్తాయి.</FunFact>

## కంప్రెస్ చేసిన ట్రైలు (*Radix* వృక్షాలు)

ప్రామాణిక ట్ర్ిెస్ ఒకే-చ్ిల్డ్ చ్ైన్స్ పై స్థలం వృథా చేస్తాయి. **Radix వృక్షం** ఈ చ్ైన్స్ ని మర్జ్ చేసి బహుళ-అక్షరం ల్అబ్ెల్స్ ఉన్న ఒకే ఎడ్జ్‌లు గా మారుస్తుంది.

```
Standard:  r → u → n → n → i → n → g
Radix:     r → "unning"
```

ఇది నోడ్ లెక్క ని గణనీయంగా తగ్గిస్తుంది మరియు *Linux* క్ర్న్ెల్ రూటింగ్ పట్టికలు మరియు Go యొక్క `httprouter` వంటి *HTTP* ర్ౌట్ర్స్ లో ఉపయోగించబడుతుంది.

## సమయం మరియు స్థలం క్లిష్టత

| ఆపరేషన్    | ట్రై   | హ్యాష్ మ్యాప్ |
|--------------|--------|----------|
| చేర్చండి       | O(m)   | O(m)     |
| సెర్చ్       | O(m)   | O(m)     |
| ప్రీఫిక్స్ క్వెరీ | O(m+k) | O(n·m)   |

ఇక్కడ *m* పదం పొడవు, *k* ఫలితాలు లెక్క, మరియు *n* మొత్తం కీలు. ప్రీఫిక్స్-భారీ వర్క్‌లోడ్‌లు లో ట్ర్ిెస్ ఆధిపత్యం చెలాయిస్తాయి.
