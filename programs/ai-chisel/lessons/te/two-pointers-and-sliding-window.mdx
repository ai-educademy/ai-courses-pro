## తెలివైన *Scanning* ఎందుకు ముఖ్యం

ఒక AI ప్రత్యక్ష వీడియో ఫీడ్ లో అనుమానాస్పద కార్యకలాపాలను పర్యవేక్షించండి చేస్తుందని ఊహించుకోండి. ప్రతి సెకనూ మొత్తం ర్ెక్ర్డ్ింగ్ మళ్ళీ చూడటం సాధ్యం కాదు - స్ట్రీమ్ మీద ఒక అటెన్షన్ విండో స్ల్ిడ్ె చేయాలి, అవసరమైనంత సందర్భం మాత్రమే ఉంచుకుంటూ. **రెండు పాయింటర్లు** మరియు **స్లైడింగ్ విండో** నమూనాలు స్ెక్వ్ెన్షల్ డేటా తో సరిగ్గా ఇదే చేస్తాయి.

రెండు టెక్నిక్‌లు బ్ర్ుట్ె-బలవంతం చేయండి O(n²) స్క్అన్స్ ను చక్కని O(n) ప్అస్స్ెస్ గా మారుస్తాయి.

## రెండు పాయింటర్ టెక్నిక్

ఒక క్రమం లో రెండు ర్ెఫ్ర్ెన్క్ెస్ ఉంచి, ఒక ర్ుల్ ప్రకారం వాటిని మారడం చేయండి. రెండు ప్రధాన రకాలు ఉన్నాయి.

### కలుస్తున్న పాయింటర్లు

ఒక పాయింటర్ ప్రారంభంలో, మరొకటి చివరలో ఉంచి, లోపలికి మారడం చేయండి. **క్రమబద్ధమైన** డేటా కు అద్భుతం.

**Classic సమస్య - జంట మొత్తం:** ఒక క్రమబద్ధమైన అరే ఇస్తే, లక్ష్య కు జోడించు అయ్యే రెండు సంఖ్యలు కనుగొనండి.

```
function pairSum(arr, target):
    left = 0
    right = arr.length - 1
    while left < right:
        sum = arr[left] + arr[right]
        if sum == target: return (left, right)
        if sum < target: left += 1
        else: right -= 1
    return null
```

అరే క్రమబద్ధమైన కాబట్టి, `left` ను సరైన కి మారడం చేస్తే మొత్తం పెరుగుతుంది, `right` ను మిగిలిన కి మారడం చేస్తే మొత్తం తగ్గుతుంది - ఏ చెల్లుబాటు అయ్యే జంట కూడా మిస్ అవడం కాదు.

### అదే-*Direction* పాయింటర్లు

రెండు పాయింటర్లు ముందుకు మారడం అవుతాయి, కానీ వేర్వేరు స్ప్ీడ్స్ తో. **Partitioning** లేదా **చక్రం గుర్తింపు** కు ఉపయోగకరమైన.

**ఉదాహరణ - Duplicates ను లో-ప్ల్అక్ె తొలగించండి చేయడం:** నెమ్మది పాయింటర్ రాయండి స్థానం ను మ్ార్క్ చేస్తుంది; వేగంగా పాయింటర్ ముందుకు స్కాన్ చేయండి చేస్తుంది.

```
function removeDuplicates(arr):
    slow = 0
    for fast in 1..arr.length - 1:
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1
```

## స్లైడింగ్ విండో నమూనా

స్లైడింగ్ విండో ఒక క్ోన్ట్ిగ్ుస్ ఉప-క్రమం ను నిర్వహించండి చేస్తుంది, దాని పరిమాణం _k_ (స్థిర) లేదా చరరాశి, మరియు అగ్గ్ర్ెగ్అట్ెస్ ను మొదటి నుంచి నుండి ర్ెక్ల్క్ుల్అట్ె చేయకుండా ిన్క్ర్ెమెంట్ల్ల్య్ నవీకరించు చేస్తుంది.

### స్థిర-పరిమాణం విండో

సరిగ్గా _k_ ఎలిమెంట్‌లు ఉన్న విండో ను అరే మీద స్ల్ిడ్ె చేయండి.

**ఉదాహరణ - ఏదైనా k క్ోన్స్ెక్ుట్ివ్ ఎలిమెంట్‌లు యొక్క గరిష్ట మొత్తం:**

```
function maxSubarraySum(arr, k):
    windowSum = sum(arr[0..k-1])
    best = windowSum
    for i in k..arr.length - 1:
        windowSum += arr[i] - arr[i - k]
        best = max(best, windowSum)
    return best
```

ప్రతి దశ లో విండో లోకి వచ్చే కొత్త ఎలిమెంట్ జోడించు అవుతుంది, బయటికి వెళ్ళేది స్ుబ్ట్ర్అక్ట్ అవుతుంది - O(1) ప్రతి మారడం.

### చరరాశి-పరిమాణం విండో

మరింత డేటా చేర్చండి చేయడానికి విండో ను ెక్స్ప్అన్డ్ చేయండి, క్ోన్స్ట్ర్ైన్ట్ వ్ిోల్అట్ె అయినప్పుడు ష్ర్ిన్క్ చేయండి.

**ఉదాహరణ - Repeating అక్షరాలు లేని అత్యంత పొడవైన స్ుబ్స్ట్ర్ింగ్:**

```
function longestUnique(s):
    seen = {}
    left = 0
    best = 0
    for right in 0..s.length - 1:
        if s[right] in seen and seen[s[right]] >= left:
            left = seen[s[right]] + 1
        seen[s[right]] = right
        best = max(best, right - left + 1)
    return best
```

## ఏ నమూనా ఎప్పుడు వాడాలి

- **రెండు పాయింటర్లు (క్ోన్వ్ర్గ్ింగ్):** క్రమబద్ధమైన ఇన్‌పుట్, జంట/ట్ర్ిప్ల్ట్ సెర్చ్, ప్ల్ిన్డ్ర్ోమ్ె తనిఖీలు.
- **రెండు పాయింటర్లు (అదే-డ్ిర్ెక్షన్):** లో-ప్ల్అక్ె మ్ోడ్ిఫ్ిక్అషన్స్, వేగంగా/నెమ్మది ర్ున్న్ర్ సమస్యలు.
- **స్థిర స్లైడింగ్ విండో:** తెలిసిన విండో పరిమాణం మీద అగ్గ్ర్ెగ్అట్ె.
- **చరరాశి స్లైడింగ్ విండో:** ఒక క్ోన్డ్ిషన్ ను స్అట్ిస్ఫ్య్ చేసే అతి చిన్న లేదా అతి పెద్ద విండో కనుగొనడం.

## కీ ముఖ్యాంశాలు

1. రెండు పాయింటర్లు ర్డ్ర్ింగ్ లేదా ప్ార్ట్ిషన్ింగ్ ను ఉపయోగించి న్ెస్ట్ెడ్ ల్ూప్స్ ను తొలగించండి చేస్తాయి.
