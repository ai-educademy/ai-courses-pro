## తెలివైన Scanning ఎందుకు ముఖ్యం

ఒక AI ప్రత్యక్ష వీడియో ఫీడ్ లో అనుమానాస్పద కార్యకలాపాలను monitor చేస్తుందని ఊహించుకోండి. ప్రతి సెకనూ మొత్తం recording మళ్ళీ చూడటం సాధ్యం కాదు - stream మీద ఒక అటెన్షన్ విండో slide చేయాలి, అవసరమైనంత సందర్భం మాత్రమే ఉంచుకుంటూ. **రెండు పాయింటర్లు** మరియు **స్లైడింగ్ విండో** నమూనాలు sequential డేటా తో సరిగ్గా ఇదే చేస్తాయి.

రెండు techniques brute-force O(n²) scans ను elegant O(n) passes గా మారుస్తాయి.

## రెండు పాయింటర్ Technique

ఒక sequence లో రెండు references ఉంచి, ఒక rule ప్రకారం వాటిని మారడం చేయండి. రెండు ప్రధాన రకాలు ఉన్నాయి.

### Converging పాయింటర్లు

ఒక పాయింటర్ ప్రారంభంలో, మరొకటి చివరలో ఉంచి, లోపలికి మారడం చేయండి. **Sorted** డేటా కు అద్భుతం.

**Classic సమస్య - Pair మొత్తం:** ఒక sorted అరే ఇస్తే, లక్ష్య కు జోడించు అయ్యే రెండు సంఖ్యలు కనుగొనండి.

```
function pairSum(arr, target):
    left = 0
    right = arr.length - 1
    while left < right:
        sum = arr[left] + arr[right]
        if sum == target: return (left, right)
        if sum < target: left += 1
        else: right -= 1
    return null
```

అరే sorted కాబట్టి, `left` ను సరైన కి మారడం చేస్తే మొత్తం పెరుగుతుంది, `right` ను మిగిలిన కి మారడం చేస్తే మొత్తం తగ్గుతుంది - ఏ valid pair కూడా మిస్ అవడం కాదు.

### అదే-Direction పాయింటర్లు

రెండు పాయింటర్లు ముందుకు మారడం అవుతాయి, కానీ వేర్వేరు speeds తో. **Partitioning** లేదా **చక్రం గుర్తింపు** కు ఉపయోగకరమైన.

**ఉదాహరణ - Duplicates ను లో-place తొలగించండి చేయడం:** నెమ్మది పాయింటర్ రాయండి స్థానం ను mark చేస్తుంది; వేగంగా పాయింటర్ ముందుకు scan చేస్తుంది.

```
function removeDuplicates(arr):
    slow = 0
    for fast in 1..arr.length - 1:
        if arr[fast] != arr[slow]:
            slow += 1
            arr[slow] = arr[fast]
    return slow + 1
```

## స్లైడింగ్ విండో నమూనా

స్లైడింగ్ విండో ఒక contiguous ఉప-sequence ను నిర్వహించండి చేస్తుంది, దాని పరిమాణం _k_ (స్థిర) లేదా variable, మరియు aggregates ను మొదటి నుంచి నుండి recalculate చేయకుండా incrementally నవీకరించు చేస్తుంది.

### స్థిర-పరిమాణం విండో

సరిగ్గా _k_ ఎలిమెంట్‌లు ఉన్న విండో ను అరే మీద slide చేయండి.

**ఉదాహరణ - ఏదైనా k consecutive ఎలిమెంట్‌లు యొక్క గరిష్ట మొత్తం:**

```
function maxSubarraySum(arr, k):
    windowSum = sum(arr[0..k-1])
    best = windowSum
    for i in k..arr.length - 1:
        windowSum += arr[i] - arr[i - k]
        best = max(best, windowSum)
    return best
```

ప్రతి దశ లో విండో లోకి వచ్చే కొత్త ఎలిమెంట్ జోడించు అవుతుంది, బయటికి వెళ్ళేది subtract అవుతుంది - O(1) ప్రతి మారడం.

### Variable-పరిమాణం విండో

మరింత డేటా చేర్చండి చేయడానికి విండో ను expand చేయండి, constraint violate అయినప్పుడు shrink చేయండి.

**ఉదాహరణ - Repeating అక్షరాలు లేని longest substring:**

```
function longestUnique(s):
    seen = {}
    left = 0
    best = 0
    for right in 0..s.length - 1:
        if s[right] in seen and seen[s[right]] >= left:
            left = seen[s[right]] + 1
        seen[s[right]] = right
        best = max(best, right - left + 1)
    return best
```

## నిజమైన AI అప్లికేషన్‌లు

| నమూనా | AI వాడండి సందర్భం |
|---------|------------|
| స్థిర విండో | చివరి _k_ sensor readings మీద anomaly గుర్తింపు |
| Variable విండో | అన్ని క్వెరీ keywords ఉన్న అతి చిన్న టెక్స్ట్ span కనుగొనడం (సెర్చ్ ఇంజిన్‌లు) |
| Converging పాయింటర్లు | Sorted ఎంబెడ్డింగ్ dimensions లో efficient nearest-neighbour తనిఖీలు |
| అదే-direction పాయింటర్లు | అనేక రిట్రీవల్ మోడళ్లు నుండి sorted ఫలితం lists ను మర్జ్ చేయడం |

## ఏ నమూనా ఎప్పుడు వాడాలి

- **రెండు పాయింటర్లు (converging):** sorted ఇన్‌పుట్, pair/triplet సెర్చ్, palindrome తనిఖీలు.
- **రెండు పాయింటర్లు (అదే-direction):** లో-place modifications, వేగంగా/నెమ్మది runner సమస్యలు.
- **స్థిర స్లైడింగ్ విండో:** తెలిసిన విండో పరిమాణం మీద aggregate.
- **Variable స్లైడింగ్ విండో:** ఒక condition ను satisfy చేసే అతి చిన్న లేదా అతి పెద్ద విండో కనుగొనడం.

## కీ Takeaways

1. రెండు పాయింటర్లు ordering లేదా partitioning ను ఉపయోగించి nested loops ను eliminate చేస్తాయి.
2. స్లైడింగ్ windows నడుస్తున్న స్థితి నిర్వహించండి చేస్తాయి, తద్వారా ప్రతి ఎలిమెంట్ గరిష్ఠంగా రెండుసార్లు ప్రక్రియ అవుతుంది.
3. రెండు నమూనాలు రియల్ టైమ్ AI పైప్‌లైన్‌లు లో foundational - anomaly గుర్తింపు నుండి సెర్చ్ ర్యాంకింగ్ వరకు.
