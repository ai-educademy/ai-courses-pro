## ఇంటర్వల్ Representation

ఒక ఇంటర్వల్ అంటే `[start, end]` జత. చాలా ఇంటర్వల్ సమస్యలు ఒక కీలకమైన దశ తో మొదలవుతాయి: **ప్రారంభించండి సమయం ప్రకారం క్రమబద్ధీకరించండి చేయడం**. ఇది ఒక అస్తవ్యస్తమైన జాబితా ను ఎడమ నుండి కుడికి సులభమైన comparisons తో ప్రక్రియ చేయగల sequence గా మారుస్తుంది.

```
Unsorted: [3,6] [1,4] [8,10] [2,5]
Sorted:   [1,4] [2,5] [3,6] [8,10]
```

## Overlapping ఇంటర్వల్‌లు ను మర్జ్ చేయడం

ఇది foundational ఇంటర్వల్ సమస్య (LeetCode 56). క్రమబద్ధీకరించండి చేసిన తర్వాత, ప్రస్తుత ప్రారంభించండి ≤ మునుపటి ముగింపు అయితే రెండు consecutive ఇంటర్వల్‌లు ఓవర్‌ల్యాప్ అవుతాయి.

```python
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```

`[1,4] [2,5] [3,6] [8,10]` ను చూద్దాం:
- `[2,5]` `[1,4]` తో ఓవర్‌ల్యాప్ అవుతుంది → `[1,5]` గా మర్జ్
- `[3,6]` `[1,5]` తో ఓవర్‌ల్యాప్ అవుతుంది → `[1,6]` గా మర్జ్
- `[8,10]` ఓవర్‌ల్యాప్ లేదు → కొత్త ఇంటర్వల్

ఫలితం: `[1,6] [8,10]`

## చేర్చండి ఇంటర్వల్

Sorted non-overlapping ఇంటర్వల్‌లు మరియు ఒక కొత్త ఇంటర్వల్ ఇవ్వబడ్డాయి, దాన్ని చేర్చండి చేసి అవసరమైతే మర్జ్ చేయండి (LeetCode 57). మూడు phases గా విభజించండి:

1. కొత్త ఇంటర్వల్ మొదలయ్యే ముందే అయిపోయే ఇంటర్వల్‌లు అన్నీ జోడించు చేయండి
2. కొత్త ఇంటర్వల్ తో ఓవర్‌ల్యాప్ అయ్యే ఇంటర్వల్‌లు అన్నింటినీ మర్జ్ చేయండి
3. మిగిలిన ఇంటర్వల్‌లు ను మార్పులు లేకుండా జోడించు చేయండి

<ThinkAboutIt>చేర్చండి ఇంటర్వల్ తరచుగా మర్జ్ దశ స్పష్టంగా కనిపించకుండా present చేయబడుతుంది. ఇంటర్వ్యూ లో దీన్ని మర్జ్ సమస్య గా మీరు ఎలా గుర్తిస్తారు?</ThinkAboutIt>

## సమావేశం Rooms I - అన్నీ హాజరుకండి చేయగలరా?

ప్రారంభించండి సమయం ప్రకారం క్రమబద్ధీకరించండి చేయండి. ఏదైనా ఇంటర్వల్ యొక్క ప్రారంభించండి మునుపటి ఇంటర్వల్ యొక్క ముగింపు కంటే ముందు ఉంటే, ఘర్షణ ఉంది.

```python
def can_attend(intervals):
    intervals.sort()
    for i in range(1, len(intervals)):
        if intervals[i][0] < intervals[i - 1][1]:
            return False
    return True
```

## సమావేశం Rooms II - కనీసం ఎన్ని Rooms కావాలి

ఇక్కడ **ఈవెంట్-ఆధారిత విధానం** ప్రకాశిస్తుంది. Starts మరియు ends ను రెండు sorted lists గా విడదీయండి, తర్వాత sweep చేయండి:

```python
import heapq

def min_rooms(intervals):
    intervals.sort()
    heap = []
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```

హీప్ అత్యంత త్వరగా అయిపోయే సమావేశం ను ట్రాక్ చేస్తుంది. అది తదుపరి సమావేశం మొదలయ్యే ముందు అయిపోతే, మనం గది ను reuse చేస్తాము. హీప్ యొక్క గరిష్ట పరిమాణంే సమాధానం.

## Non-Overlapping ఇంటర్వల్‌లు - కనీసం ఎన్ని తొలగించండి చేయాలి

ఇంటర్వల్‌లు ఇవ్వబడ్డాయి, ఏ ఓవర్‌ల్యాప్ లేకుండా ఉండేందుకు కనీసం ఎన్ని తొలగించండి చేయాలో కనుగొనండి (LeetCode 435). Greedy: **ముగింపు సమయం** ప్రకారం క్రమబద్ధీకరించండి చేయండి, ఎల్లప్పుడూ అత్యంత త్వరగా అయిపోయే ఇంటర్వల్ ను ఉంచండి - ఇది భవిష్యత్ ఇంటర్వల్‌లు కోసం ఎక్కువ స్థలం మిగులుస్తుంది.

```python
def erase_overlap(intervals):
    intervals.sort(key=lambda x: x[1])
    count, prev_end = 0, float('-inf')
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end
        else:
            count += 1
    return count
```

## ఇంటర్వల్ జాబితా Intersections

రెండు sorted ఇంటర్వల్ lists ఇవ్వబడ్డాయి, అన్ని intersections కనుగొనండి (LeetCode 986). రెండు పాయింటర్లు ఉపయోగించండి - ప్రతి జాబితా కు ఒకటి. `[a1, a2]` మరియు `[b1, b2]` యొక్క intersection `[max(a1, b1), min(a2, b2)]` - ఇది valid అయితే (ప్రారంభించండి ≤ ముగింపు). ఏ పాయింటర్ యొక్క ఇంటర్వల్ ముందు అయిపోతుందో దాన్ని ముందుకు జరపండి.

## Sweep లైన్ Technique

ఇంటర్వల్‌లు ను pairwise పోల్చండి చేయడానికి బదులు, ప్రతి ఇంటర్వల్ ను ఈవెంట్లు గా విడగొట్టండి:

```
[1,4] → +1 at 1, -1 at 4
[2,6] → +1 at 2, -1 at 6
```

ఈవెంట్లు ను సమయం ప్రకారం క్రమబద్ధీకరించండి చేయండి. ఎడమ నుండి కుడికి sweep చేయండి, నడుస్తున్న లెక్క నిర్వహించండి చేస్తూ. పీక్ లెక్క "గరిష్ట ఓవర్‌ల్యాప్" ప్రశ్నలకు సమాధానం ఇస్తుంది. ఇది సమావేశం Rooms II ను arbitrary ఈవెంట్-ప్రాసెసింగ్ సమస్యలు కు generalise చేస్తుంది.

## Calendar Booking

**My Calendar I** (LeetCode 729): booked ఇంటర్వల్‌లు నిర్వహించండి చేయండి మరియు overlaps తిరస్కరించండి చేయండి. **My Calendar II**: ఒకే overlaps అనుమతించండి చేయండి కానీ triple-bookings తిరస్కరించండి చేయండి. Sweep లైన్ బహుళ-పొర ఓవర్‌ల్యాప్ గుర్తింపు ను straightforward గా చేస్తుంది.
