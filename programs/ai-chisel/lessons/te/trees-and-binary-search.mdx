## AIలో వృక్షాలు ప్రతిచోటా ఉన్నాయి

స్పామ్ ఫిల్టర్ ఒక ఇమెయిల్ ను వర్గీకరించినప్పుడు చేసినప్పుడు లేదా డేటాబేస్ మిల్లీసెకన్లలో మీ క్రమం తిరిగి పొందినప్పుడు చేసినప్పుడు, వెనుక ఒక వృక్షం డేటా నిర్మాణం పని చేస్తుంటుంది. వృక్షాలు **శ్రేణీకృత నిర్ణయాలు** ను మోడల్ చేస్తాయి - ప్రతి నోడ్ సెర్చ్ స్థలం ను తగ్గిస్తుంది, మీరు సమాధానం కు చేరుకునే వరకు.

## బైనరీ సెర్చ్ వృక్షాలు (BSTs)

BST ఎలిమెంట్‌లను ఇలా నిల్వ చేస్తుంది - ఏ నోడ్ కైనా, దాని **మిగిలిన** ఉపచెట్టు లోని అన్ని విలువలు చిన్నవిగా మరియు **సరైన** ఉపచెట్టు లోని అన్ని విలువలు పెద్దవిగా ఉంటాయి.

### సెర్చ్

```
function search(node, target):
    if node is null: return null
    if target == node.value: return node
    if target < node.value: return search(node.left, target)
    return search(node.right, target)
```

ప్రతి పోలిక మిగిలిన నోడ్‌లలో లో సగాన్ని తొలగిస్తుంది - సమతుల్య వృక్షం పై O(లాగ్ n).

### Insertion

```
function insert(node, value):
    if node is null: return new Node(value)
    if value < node.value:
        node.left = insert(node.left, value)
    else:
        node.right = insert(node.right, value)
    return node
```

### Deletion

Deletion అత్యంత కష్టమైన చర్య. మూడు సందర్భాలు ఉంటాయి:

1. **Leaf నోడ్** - దాన్ని తీసేయండి.
2. **ఒక పిల్ల** - నోడ్ ను దాని పిల్ల తో మార్చండి.
3. **రెండు పిల్లలు** - నోడ్ విలువ ను దాని లో-క్రమం తర్వాతి వారసుడు (కుడి ఉపచెట్టు లో అత్యంత చిన్న విలువ) తో మార్పిడి చేసి, ఆ తర్వాతి వారసుడు ను తొలగించండి.

## సమతుల్య వర్సెస్ అసమతుల్య

క్రమబద్ధమైన డేటా ను సాధారణ BST లో చేరిస్తే, అది లింక్డ్ జాబితా గా మారిపోతుంది - ప్రతి చర్య O(n). **Self-balancing** వృక్షాలు దీన్ని సరిచేస్తాయి:

| వృక్షం | బ్యాలెన్స్ Rule | సాధారణ వాడుక |
|------|-------------|--------------|
| AVL | ఉపచెట్లు మధ్య ఎత్తు తేడా ≤ 1 | లో-మెమరీ లుక్‌అప్‌లు |
| Red-Black | రంగు ఆధారిత భ్రమణ నియమాలు | భాష ప్రామాణిక లైబ్రరీలు (ఉదా. Java TreeMap) |
| B-వృక్షం | ప్రతి నోడ్ లో అనేక కీలు, అన్ని leaves ఒకే లోతు లో | డేటాబేస్‌లు మరియు ఫైల్ సిస్టమ్‌లు |

<FunFact>PostgreSQL మరియు MySQL రెండూ B-వృక్షం రకాలు ను డిఫాల్ట్ ఇండెక్స్ నిర్మాణం గా వాడతాయి. శాఖల గుణకం 100 ఉన్న B-వృక్షం కేవలం ఐదు స్థాయులు లో ఒక బిలియన్ వరుసలు ను ఇండెక్స్ చేయగలదు.</FunFact>

## వృక్ష సంచారాలు

సంచారాలు ప్రతి నోడ్ ను సరిగ్గా ఒకసారి సందర్శిస్తాయి. మూడు సాంప్రదాయ ఆర్డర్లు లో తేడా ఏమిటంటే ప్రస్తుత నోడ్ ను దాని పిల్లలు కంటే **ఎప్పుడు** ప్రాసెస్ చేస్తారు అనేది మాత్రమే.

| సంచారం | క్రమం | వాడుక |
|-----------|-------|-------|
| **ఇన్-క్రమం** | ఎడమ → నోడ్ → కుడి | BST నుండి క్రమబద్ధమైన అవుట్‌పుట్ ఇస్తుంది |
| **ప్రీ-క్రమం** | నోడ్ → ఎడమ → కుడి | వృక్షం ను సీరియలైజ్ / క్లోన్ చేయడం |
| **పోస్ట్-క్రమం** | ఎడమ → కుడి → నోడ్ | వృక్షం ను సురక్షితంగా తొలగించడం; వ్యక్తీకరణ వృక్షాలు మూల్యాంకనం చేయడం |

```
function inOrder(node):
    if node is null: return
    inOrder(node.left)
    process(node)
    inOrder(node.right)
```

## హీప్‌లు మరియు ప్రాధాన్యం క్యూలు

**Heap** అనేది ఒక పూర్తి చేయండి ద్విమానం వృక్షం, దీనిలో ప్రతి తల్లి నోడ్ దాని పిల్లలు కంటే పెద్దది (max-హీప్) లేదా చిన్నది (నిమి-హీప్). ఇది మద్దతు చేస్తుంది:

- **చేర్చండి** - చివర జోడించి, పైకి జార్చండి. O(లాగ్ n).
- **Extract నిమి/max** - రూట్ తీసేసి, చివరి ఎలిమెంట్ ను రూట్‌కు మార్చి, కిందికి జార్చండి. O(లాగ్ n).

హీప్‌లు పై నిర్మించిన ప్రాధాన్యం క్యూలు వీటిని శక్తి చేస్తాయి:
- **Dijkstra's అల్గారిథమ్** (తదుపరి పాఠం!) - ఎల్లప్పుడూ అత్యంత సమీప సందర్శించని నోడ్ ను విస్తరించండి.
- **పని షెడ్యూలింగ్** - OS షెడ్యూలర్లు అత్యున్నత ప్రాధాన్యం ప్రక్రియ ను ఎంచుకుంటాయి.
- **Beam సెర్చ్ in NLP** - ముఖ్యమైన k అత్యంత ఆశాజనక వాక్య పూర్తి సూచనలు ను ఉంచండి.

```
function siftUp(heap, index):
    while index > 0:
        parent = (index - 1) / 2
        if heap[index] < heap[parent]:
            swap(heap, index, parent)
            index = parent
        else: break
```

## నిజమైన AI అప్లికేషన్‌లు

- **నిర్ణయం వృక్షాలు** మెషిన్ లెర్నింగ్ లో ప్రతి నోడ్ వద్ద తరగతులు ను బాగా వేరు చేసే ఫీచర్ ద్వారా డేటా ను విభజిస్తాయి - వృక్షం నిర్మాణం యొక్క ప్రత్యక్ష అప్లికేషన్.
- **Syntax వృక్షాలు** NLP లో వ్యాకరణ నిర్మాణం ను ప్రతినిధ్యం చేస్తాయి, భావ విశ్లేషణ మరియు యంత్ర అనువాదం వంటి పనులు ను సాధ్యం చేస్తాయి.
- **Monte Carlo వృక్షం సెర్చ్ (MCTS)** AlphaGo వంటి ఆట ఆడే AI ను శక్తి చేస్తుంది, సాధ్యమైన కదలికలను ఆట స్థితుల వృక్షంగా అన్వేషిస్తుంది.
- **Huffman వృక్షాలు** తరచుగా వచ్చే చిహ్నాలు కు చిన్న కోడ్‌లు కేటాయించి డేటా కుదిస్తాయి - మోడల్ బరువు కుదింపు లో వాడతారు.

## ముఖ్యమైన విషయాలు

1. BSTs O(లాగ్ n) సెర్చ్, చేర్చండి, మరియు తొలగించడం అందిస్తాయి - కానీ సమతుల్య అయినప్పుడు మాత్రమే.
2. సంచారం క్రమం వృక్షం నుండి ఏ సమాచారం తీయడానికి చేస్తారో నిర్ణయిస్తుంది.
3. హీప్‌లు అత్యంత విలువ కు O(1) యాక్సెస్ మరియు O(లాగ్ n) చొప్పింపు ఇస్తాయి - ప్రాధాన్యం-ఆధారిత AI అల్గారిథమ్‌లు కు అనుకూలం.
4. వృక్షాలు ML, డేటాబేస్‌లు, కంపైలర్లు, మరియు ఆట AIలో నిర్ణయం-తీసుకోవడం కు ఆధారం.
