## AIలో వృక్షాలు ప్రతిచోటా ఉన్నాయి

Spam ఫిల్టర్ ఒక ఇమెయిల్ ను classify చేసినప్పుడు లేదా డేటాబేస్ మిల్లీసెకన్లలో మీ క్రమం retrieve చేసినప్పుడు, వెనుక ఒక వృక్షం డేటా నిర్మాణం పని చేస్తుంటుంది. వృక్షాలు **hierarchical నిర్ణయాలు** ను మోడల్ చేస్తాయి - ప్రతి నోడ్ సెర్చ్ స్థలం ను తగ్గిస్తుంది, మీరు సమాధానం కు చేరుకునే వరకు.

## బైనరీ సెర్చ్ వృక్షాలు (BSTs)

BST ఎలిమెంట్‌లు ను ఇలా నిల్వ చేస్తుంది - ఏ నోడ్ కైనా, దాని **మిగిలిన** subtree లోని అన్ని విలువలు చిన్నవిగా మరియు **సరైన** subtree లోని అన్ని విలువలు పెద్దవిగా ఉంటాయి.

### సెర్చ్

```
function search(node, target):
    if node is null: return null
    if target == node.value: return node
    if target < node.value: return search(node.left, target)
    return search(node.right, target)
```

ప్రతి పోలిక మిగిలిన నోడ్‌లు లో సగాన్ని eliminate చేస్తుంది - balanced వృక్షం పై O(లాగ్ n).

### Insertion

```
function insert(node, value):
    if node is null: return new Node(value)
    if value < node.value:
        node.left = insert(node.left, value)
    else:
        node.right = insert(node.right, value)
    return node
```

### Deletion

Deletion అత్యంత కష్టమైన operation. మూడు సందర్భాలు ఉంటాయి:

1. **Leaf నోడ్** - దాన్ని తీసేయండి.
2. **ఒక child** - నోడ్ ను దాని child తో మార్చండి చేయండి.
3. **రెండు children** - నోడ్ విలువ ను దాని లో-క్రమం successor (సరైన subtree లో అత్యంత చిన్న విలువ) తో swap చేసి, ఆ successor ను delete చేయండి.

## Balanced వర్సెస్ Unbalanced

Sorted డేటా ను plain BST లో చేర్చండి చేస్తే, అది linked జాబితా గా మారిపోతుంది - ప్రతి operation O(n). **Self-balancing** వృక్షాలు దీన్ని fix చేస్తాయి:

| వృక్షం | బ్యాలెన్స్ Rule | సాధారణ వాడుక |
|------|-------------|--------------|
| AVL | Subtrees మధ్య height difference ≤ 1 | లో-మెమరీ లుక్‌అప్‌లు |
| Red-Black | Colour-ఆధారిత rotation rules | భాష ప్రామాణిక libraries (ఉదా. Java TreeMap) |
| B-వృక్షం | ప్రతి నోడ్ లో అనేక కీలు, అన్ని leaves ఒకే లోతు లో | డేటాబేస్‌లు మరియు ఫైల్ సిస్టమ్‌లు |

<FunFact>PostgreSQL మరియు MySQL రెండూ B-వృక్షం variants ను డిఫాల్ట్ ఇండెక్స్ నిర్మాణం గా వాడతాయి. Branching factor 100 ఉన్న B-వృక్షం కేవలం ఐదు స్థాయులు లో ఒక బిలియన్ వరుసలు ను ఇండెక్స్ చేయగలదు.</FunFact>

## వృక్షం Traversals

Traversals ప్రతి నోడ్ ను సరిగ్గా ఒకసారి సందర్శన చేస్తాయి. మూడు సాంప్రదాయ ఆర్డర్లు లో తేడా ఏమిటంటే ప్రస్తుత నోడ్ ను దాని children కంటే **ఎప్పుడు** ప్రక్రియ చేస్తారు అనేది మాత్రమే.

| Traversal | క్రమం | వాడుక |
|-----------|-------|-------|
| **In-క్రమం** | మిగిలిన → నోడ్ → సరైన | BST నుండి sorted అవుట్‌పుట్ ఇస్తుంది |
| **Pre-క్రమం** | నోడ్ → మిగిలిన → సరైన | వృక్షం ను serialise / clone చేయడం |
| **పోస్ట్-క్రమం** | మిగిలిన → సరైన → నోడ్ | వృక్షం ను safely delete చేయడం; expression వృక్షాలు మూల్యాంకనం చేయండి చేయడం |

```
function inOrder(node):
    if node is null: return
    inOrder(node.left)
    process(node)
    inOrder(node.right)
```

<ThinkAboutIt>Compiler మీ కోడ్ ను Abstract Syntax వృక్షం (AST) గా parse చేస్తుంది. `(3 + 5) * 2` expression ను వృక్షం గా నిల్వ చేసి మూల్యాంకనం చేయండి చేయడానికి ఏ traversal క్రమం వాడతారు? ఎందుకు?</ThinkAboutIt>

## Heaps మరియు ప్రాధాన్యం క్యూలు

**Heap** అనేది ఒక పూర్తి చేయండి binary వృక్షం, దీనిలో ప్రతి parent దాని children కంటే పెద్దది (max-హీప్) లేదా చిన్నది (నిమి-హీప్). ఇది మద్దతు చేస్తుంది:

- **చేర్చండి** - చివర జోడించు చేసి, bubble up చేయండి. O(లాగ్ n).
- **Extract నిమి/max** - రూట్ తీసేసి, last ఎలిమెంట్ ను రూట్ కు మారడం చేసి, sift down చేయండి. O(లాగ్ n).

Heaps పై నిర్మించిన ప్రాధాన్యం క్యూలు వీటిని శక్తి చేస్తాయి:
- **Dijkstra's అల్గారిథమ్** (తదుపరి పాఠం!) - ఎల్లప్పుడూ nearest unvisited నోడ్ ను expand చేయండి.
- **పని scheduling** - OS schedulers highest-ప్రాధాన్యం ప్రక్రియ ను pick చేస్తాయి.
- **Beam సెర్చ్ in NLP** - ముఖ్యమైన-k అత్యంత promising sentence completions ను ఉంచండి.

```
function siftUp(heap, index):
    while index > 0:
        parent = (index - 1) / 2
        if heap[index] < heap[parent]:
            swap(heap, index, parent)
            index = parent
        else: break
```

## నిజమైన AI అప్లికేషన్‌లు

- **నిర్ణయం వృక్షాలు** మెషిన్ లెర్నింగ్ లో ప్రతి నోడ్ వద్ద classes ను బాగా separate చేసే ఫీచర్ ద్వారా డేటా ను split చేస్తాయి - వృక్షం నిర్మాణం యొక్క ప్రత్యక్ష అప్లికేషన్.
- **Syntax వృక్షాలు** NLP లో grammatical నిర్మాణం ను ప్రతినిధ్యం చేస్తుంది చేస్తాయి, sentiment విశ్లేషణ మరియు machine translation వంటి పనులు ను enable చేస్తాయి.
- **Monte Carlo వృక్షం సెర్చ్ (MCTS)** AlphaGo వంటి game-playing AI ను శక్తి చేస్తుంది, సాధ్యమైన moves ను game states వృక్షం గా అన్వేషించండి చేస్తుంది.
- **Huffman వృక్షాలు** frequent symbols కు shorter కోడ్‌లు assign చేసి డేటా compress చేస్తాయి - మోడల్ బరువు compression లో వాడతారు.

## ముఖ్యమైన విషయాలు

1. BSTs O(లాగ్ n) సెర్చ్, చేర్చండి, మరియు delete అందిస్తాయి - కానీ balanced అయినప్పుడు మాత్రమే.
2. Traversal క్రమం వృక్షం నుండి ఏ సమాచారం extract చేస్తారో నిర్ణయిస్తుంది.
3. Heaps extreme విలువ కు O(1) యాక్సెస్ మరియు O(లాగ్ n) insertion ఇస్తాయి - ప్రాధాన్యం-ఆధారిత AI అల్గారిథమ్‌లు కు ideal.
4. వృక్షాలు ML, డేటాబేస్‌లు, compilers, మరియు game AIలో నిర్ణయం-making కు ఆధారం.
