## Revisão de números binários

Cada inteiro é uma sequência de bits. O número 13 em binário é `1101`:

```
Bit position:  3  2  1  0
Bit value:     1  1  0  1
Decimal:       8+ 4+ 0+ 1 = 13
```

A manipulação de bits opera diretamente nesses bits usando operadores bit a bit - geralmente substituindo loops por operações únicas.

## Operações principais bit a bit

| Operador | Símbolo | Exemplo (5 = 101, 3 = 011) | Resultado |
|----------|--------|----------------------------|--------|
| E | `&` | `101 & 011` | `001` (1) |
| OU | `\|` | `101 \| 011` | `111` (7) |
| XOR | `^` | `101 ^ 011` | `110` (6) |
| NÃO | `~` | `~101` | `...010` |
| Deslocamento à esquerda | `<<` | `101 << 1` | `1010` (10) |
| Mudança para a direita | `>>` | `101 >> 1` | `10` (2) |

## Truques essenciais

### Verifique se a potência de dois

Uma potência de 2 tem exatamente um bit definido: `n & (n - 1) == 0`.

```
  n = 8:  1000          n = 6:  0110
  n-1=7:  0111          n-1=5:  0101
  &    :  0000 ✓ power  &    :  0100 ✗ not power
```

### Contagem de bits definidos (algoritmo de Brian Kernighan)

Cada `n & (n - 1)` remove o bit definido mais baixo. Conte as iterações até n = 0.

```python
def count_bits(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

Isso é executado em O(k), onde k é o número de bits definidos - não O(32).

### Troca sem variável de temperatura

```python
a ^= b
b ^= a
a ^= b
```

Funciona porque XOR é seu próprio inverso: `a ^ b ^ b = a`.

## Número Único - Cancelamento XOR

Cada elemento aparece duas vezes, exceto um. Encontre-o. Desde `a ^ a = 0` e `a ^ 0 = a`, XOR todos os elementos - pares são cancelados, deixando o número único.

```python
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

Tempo O(n), espaço O(1). Não é necessário mapa hash.

## Número Único III - Dois Números Únicos

Quando *dois* números são únicos, faça um XOR de tudo para obter `x = a ^ b`. Encontre qualquer bit definido em `x` (os números diferem aí). Particione todos os números por esse bit e faça XOR em cada grupo - cada grupo contém exatamente um número exclusivo.

```python
def single_number_iii(nums):
    xor = 0
    for n in nums:
        xor ^= n
    diff_bit = xor & (-xor)  # isolate rightmost set bit
    a = b = 0
    for n in nums:
        if n & diff_bit:
            a ^= n
        else:
            b ^= n
    return [a, b]
```

## Mascaramento de bits para subconjuntos

Uma máscara de bits de comprimento n representa um subconjunto de n itens. O bit `i` sendo definido significa que o item `i` está incluído. Iterar de `0` a `2^n - 1` gera todos os subconjuntos.

```python
def all_subsets(items):
    n = len(items)
    for mask in range(1 << n):
        subset = [items[i] for i in range(n)
                  if mask & (1 << i)]
        yield subset
```

Esta técnica fornece soluções para problemas com n ≤ 20 - pequeno o suficiente para enumeração 2^n.

<FunFact>As permissões de arquivo do Linux (rwxr-xr-x = 755) são uma máscara de bits do mundo real. Cada dígito codifica três bits de permissão: leitura (4), gravação (2), execução (1), combinado com OR.</FunFact>

## Revertendo bits (LeetCode 190)

Inverta um número inteiro sem sinal de 32 bits, bit a bit. Desloque o resultado para a esquerda e OR no bit mais baixo da entrada e, a seguir, desloque a entrada para a direita.

```python
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result
```

## Número ausente (LeetCode 268)

Matriz de n números de 0 a n com um faltando. XOR todos os elementos da matriz com todos os índices de 0 a n - os pares são cancelados, deixando o número ausente. Como alternativa, use a fórmula da soma, mas o XOR evita um possível estouro.

## Distância de Hamming (LeetCode 461)

O número de posições onde os bits correspondentes diferem. XOR os dois números - os bits definidos no resultado são as posições diferentes. Conte-os com o truque de Brian Kernighan.

```python
def hamming_distance(x, y):
    return count_bits(x ^ y)
```
