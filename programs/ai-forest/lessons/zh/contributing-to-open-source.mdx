# 为开源做出贡献

开源贡献是学习、建立信誉和与人工智能社区联系的最快方式。本课程将向您展示如何开始并做出重要的贡献。

## 为什么要贡献？

为开源做出贡献不是慈善事业 - 这是一项战略性职业举措。

**学习** - 阅读和修改生产质量的代码会教您教程从未涵盖的模式。您将了解真实系统如何处理边缘情况、测试和扩展。

**网络** - 您的公关审核者和共同贡献者通常会成为合作者、裁判员，甚至联合创始人。人工智能开源社区的联系非常紧密。

**职业影响** - 顶级人工智能公司的招聘经理会积极查看 GitHub 个人资料。合并到一个受人尊敬的项目的 PR 所表明的能力远比认证更重要。

**回馈** - 您几乎肯定已经从开源工具中受益。贡献是生态系统维持自身的方式。

<FunFact>2024 年 GitHub 的一项调查发现，87% 的 AI/ML 招聘经理在评估候选人时考虑开源贡献，这使其成为仅次于相关工作经验的第二个最有价值的信号。
</FunFact>

## 寻找合适的项目

不要从为 PyTorch 或 TensorFlow 做出贡献开始。从你的贡献会被注意到和重视的地方开始。

**去哪里看：**
- **GitHub 主题** - 浏览 `good-first-issue` + `machine-learning` 或 `artificial-intelligence`
- **Hugging Face** - 他们的 `transformers`、`datasets` 和 `diffusers` 库积极欢迎贡献者
- **LangChain / LlamaIndex** - 快速发展的项目，有许多未解决的问题
- **较小的工具** - 具有 500-5,000 颗星的库通常拥有响应迅速且感谢帮助的维护人员

**如何评估项目：**
1. 检查最后提交日期 - 是否得到积极维护？
2. 阅读 CONTRIBUTING.md - 是否存在？
3. 查看公开的 PR - 它们是否正在被审查或被忽略？
4. 检查问题响应时间 - 维护人员是否参与？

## 贡献工作流程

每个贡献都遵循相同的模式。一旦掌握了这一点，您就可以在任何地方做出贡献。

### 第 1 步：分叉和克隆

```bash
gh repo fork owner/project --clone
cd project
git remote add upstream https://github.com/owner/project.git
```

### 第 2 步：创建分支

```bash
git checkout -b fix/improve-tokeniser-docs
```

使用描述性分支名称。 `fix/`、`feat/` 或 `docs/` 等前缀可帮助维护人员一目了然地了解意图。

### 第 3 步：做出改变

- 完全遵循项目的编码风格
- 在更改之前和之后运行现有测试
- 添加新功能的测试
- 保持变更重点 - 每个 PR 关注一个问题

### 第 4 步：提交并推送

```bash
git add .
git commit -m "docs: clarify tokeniser padding behaviour for batch inputs"
git push origin fix/improve-tokeniser-docs
```

### 第 5 步：打开拉取请求

撰写清晰的 PR 描述，解释您更改的**内容**、更改的**原因**以及更改的**方式**。如果存在，请参考问题编号。

<ThinkAboutIt>考虑一下您在开源人工智能工具中遇到的错误。你能自己修复它并提交 PR 吗？通常答案是肯定的——而第一个贡献是最难克服的心理障碍。
</ThinkAboutIt>

## 撰写出色的 PR 和提交

您的公关是您的专业名片。让它算数。

**提交消息** - 使用常规提交：`feat:`、`fix:`、`docs:`、`test:`、`refactor:`。将主题控制在 72 个字符以内。添加主体以进行复杂的更改。

**公关描述应包括：**
- 变更的一行摘要
- 背景：这解决了什么问题？
- 如何测试更改
- 屏幕截图或输出示例（如果相关）
- 您做出的任何权衡或决定

**要避免的常见错误：**
- 在一个 PR 中混合不相关的更改
- 忽略项目的 linting 和格式化规则
- 没有及时回复评论反馈
- 审核时无警告强行推送

## 超越代码

一些最有价值的贡献涉及零代码。

**文档** - 修复拼写错误、改进示例、翻译文档。许多项目都迫切需要文档帮助，这是一个很好的切入点。

**问题分类** - 重现错误、添加上下文、标签问题。这对于陷入未处理问题的维护人员来说非常有价值。

**翻译** - 帮助人工智能工具在全球范围内使用。像 Hugging Face 这样的项目正在积极寻找翻译人员。

**社区支持** - 回答 Discord、Stack Overflow 或 GitHub 讨论上的问题。帮助别人也是一种贡献。

<Callout>**专业提示：** 文档 PR 在所有贡献类型中具有最高的接受率。它们是学习代码库、与维护者建立信任以及为以后贡献更大的代码做好准备的完美方式。
</Callout>

## 建立公众形象

持续的贡献会形成强大的专业资产。

**实际步骤：**
1. 将您的最佳贡献放在您的 GitHub 个人资料上
2. 撰写简短的博客文章，介绍您从每项贡献中学到的知识
3. 参与项目讨论——深思熟虑的评论会受到关注
4. 参加与您的项目相关的虚拟聚会或会议
5. 将开源作品添加到您的简历中，并附上合并 PR 的链接

<FunFact>Andrej Karpathy 早在加入 Tesla 或 OpenAI 之前就对神经网络库做出了早期开源贡献，帮助他建立了声誉。您的 GitHub 个人资料是一个活生生的作品集。
</FunFact>

<ThinkAboutIt>您理想的开源贡献是什么样的？选择一个你经常使用的人工智能项目，并找到一个你本周可以解决的问题。现在是开始贡献的最佳时机。
</ThinkAboutIt>

## 要点

- 开源贡献加速学习、网络和职业发展
- 从较小的、积极维护的项目开始 - 而不是大型回购
- 掌握分叉 → 分支 → PR 工作流程并在任何地方使用
- 编写清晰、重点突出的 PR，并包含描述性提交消息
- 文档和问题分类是不需要代码的有价值的贡献
- 一致性比规模更重要 - 定期小额捐款会带来复合效应
