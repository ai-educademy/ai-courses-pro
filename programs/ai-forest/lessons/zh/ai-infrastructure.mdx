# 人工智能基础设施

每一次人工智能突破的背后都是一个巨大的基础设施故事。据报道，训练 GPT-4 仅在计算方面就花费了超过 1 亿美元。了解支持现代人工智能的硬件、云平台和优化技术对于任何大规模构建的人来说都是至关重要的。

## 为什么 GPU 在 AI 方面击败了 CPU

CPU 针对顺序任务进行了优化 - 一些强大的内核处理复杂的逻辑。 GPU 针对并行性进行了优化 - 数千个简单核心同时对不同数据执行相同的操作。

神经网络训练本质上是大规模矩阵乘法。大型模型的单个训练步骤涉及将矩阵与数十亿个元素相乘。 CPU 按顺序处理这些。 GPU 并行处理数千个元素。

NVIDIA H100 GPU 可提供大约 **4,000 TFLOPS** 的 FP8 计算。高端服务器 CPU 的处理能力可能为 2 TFLOPS。对于深度学习中令人尴尬的并行工作负载，GPU 胜出三个数量级。

## NVIDIA 的统治地位

NVIDIA 控制着大约 80-90% 的 AI 加速器市场。他们的护城河不仅仅是硬件 - 它是 **CUDA 生态系统**。几乎每个 ML 框架（PyTorch、TensorFlow、JAX）都是基于 CUDA 构建的。转向竞争对手意味着重写低级内核并接受潜在的不兼容性。

### GPU阵容

|图形处理器 |内存| FP8 性能 |使用案例|
|-----|--------|-----------------|----------|
| **A100** | 80 GB HBM2e | 624 万亿次浮点运算 |当前数据中心的主力|
| **H100** | 80 GB HBM3 | 80 GB 3,958 TFLOPS |前沿模型培训|
| **H200** | 141 GB HBM3e | 141 GB 3,958 TFLOPS |受内存限制的 LLM 推理 |
| **B200** | 192 GB HBM3e | 192 GB 9,000 TFLOPS |下一代训练和推理 |

H100 到 B200 的跳跃代表着 2.3 倍的性能提升 - 但真正的瓶颈通常是**内存带宽**，而不是原始计算。 H200 的 141 GB HBM3e 内存专门针对 LLM 推理，其中 KV 缓存主导内存使用。

<FunFact>单个 NVIDIA B200 GPU 的成本约为 30,000 至 40,000 美元。配备 8 个 GPU 的 DGX B200 服务器成本超过 300,000 美元。据报道，Meta 订购了 35 万个 H100 GPU 用于 Llama 训练 - 硬件投资超过 100 亿美元。</FunFact>

## 谷歌 TPU

Google 的张量处理单元是专门为矩阵运算设计的定制 ASIC。与处理图形和计算的 GPU 不同，TPU 是专门为神经网络构建的。

- **TPU v5p** - Google 最新的训练芯片，可在通过高速互连连接的多达 8,960 个芯片的 Pod 中使用
- **TPU v5e** - 针对推理工作负载进行成本优化
- 主要优势：与 JAX 和 XLA 编译器紧密集成
- 主要限制：仅通过 Google Cloud 提供 - 没有本地选项

Google 在 TPU 上训练其所有基础模型（Gemini、PaLM），证明它们在前沿领域可与 NVIDIA 竞争。

## AMD 和竞争

AMD 的 **MI300X** 是最可靠的 NVIDIA 替代品：
- 192 GB HBM3 内存（高于 H100）
- 强大的 ROCm 软件堆栈（有所改进，但仍落后于 CUDA）
- 显着的价格优势 - 比同等 NVIDIA 便宜大约 30-40%
- 具有本机 ROCm 支持（PyTorch、JAX）的不断发展的 ML 框架生态系统

Microsoft、Meta 和 Oracle 均采用 MI300X 来处理推理工作负载。对于 KV 缓存是主要瓶颈的大型语言模型来说，内存优势尤其引人注目。

英特尔的 **Gaudi 3** 加速器也加入其中，提供具有竞争力的培训性能，重点关注企业性价比。人工智能加速器市场最终正在成为一个多供应商生态系统。

## 云提供商比较

除了超大规模企业之外，没有任何一家公司有能力为前沿人工智能构建自己的 GPU 集群。云战激烈：

|平台|主要产品|实力|
|----------|-------------|----------|
| **AWS SageMaker** |端到端机器学习平台 |最广泛的 GPU 选择，Inferentia 定制芯片 |
| **GCP Vertex AI** |具有 TPU 访问权限的托管机器学习 | TPU 可用性、BigQuery 紧密集成 |
| **Azure ML** |企业机器学习平台 | OpenAI 合作伙伴关系、企业合规 |
| **拉姆达实验室** |面向 AI 的 GPU 云 |简单、有竞争力的 H100 定价 |
| **核心编织** | GPU 原生云 |专为 AI 打造，与 NVIDIA 合作 |

**竞价实例**可以降低 60-90% 的培训成本。权衡：您的训练工作可以随时中断。 **PyTorch Lightning** 和 **DeepSpeed** 等框架支持检查点，以便在抢占后无缝恢复训练。

## GPU 短缺和地缘政治

人工智能基础设施现在是一个地缘政治问题：

- **台积电**（台湾）为 NVIDIA、AMD、Apple 和 Google 制造几乎所有先进的人工智能芯片。台积电的中断将阻碍全球人工智能的进步。
- **美国出口管制**限制中国获得先进芯片（A100、H100 被禁止）。中国正在大力投资国内替代品（华为Ascend、Biren）。
- **NVIDIA 的中国专用芯片** (H20) 降低了性能，以符合出口规则，同时保持市场准入。
- **CHIPS 法案**（美国）以及欧盟和日本的类似计划旨在实现半导体制造多元化。

## 定制芯片初创公司

几家初创公司正在彻底挑战 GPU 范式：

- **Groq** - LPU（语言处理单元）架构提供确定性、超低延迟的推理。无需批处理。
- **Cerebras** - 晶圆级芯片（餐盘大小）消除了训练的内存带宽瓶颈。
- **SambaNova** - 针对企业 AI 优化的可重新配置数据流架构。
- **Graphcore**（被 SoftBank 收购）- IPU 架构，具有用于图形结构工作负载的大量片上 SRAM。

这些并不是当今 NVIDIA 的替代品。但它们代表了真正的架构创新，随着人工智能工作负载的多样化，超越了变压器，可能会重塑市场。

## 推理优化

培训成为头条新闻，但推理才是赚钱的地方。降低推理成本的技术：

- **动态批处理** - 对传入请求进行分组以最大限度地提高 GPU 利用率
- **KV缓存管理** - vLLM的PagedAttention避免内存碎片
- **推测性解码** - 使用小模型起草令牌，由大模型并行验证（2-3×加速）
- **连续批处理** - 处理新请求，无需等待所有当前请求完成
- **模型并行性** - 将大型模型拆分到多个 GPU 上以实现对延迟敏感的服务

## 人工智能基础设施的总成本

基础设施成本远远超出 GPU 租赁成本。一张完整的图片包括：

- **计算** - 用于训练和推理的 GPU 时间（通常占总成本的 60-70%）
- **存储** - 训练数据、检查点、模型制品和日志
- **网络** - GPU、区域之间以及最终用户之间的数据传输
- **工程** - 机器学习工程师、平台工程师和 DevOps 人员来操作堆栈
- **电力** - 单个 H100 服务器消耗 10+ kW；数据中心电力是一个日益严重的限制

从规模上看，Meta 这样的公司每年在人工智能基础设施上的支出超过 100 亿美元。对于初创公司来说，单个前沿模型训练运行的云成本可能超过 100 万美元。理解和优化这个成本堆栈是一项核心能力。
