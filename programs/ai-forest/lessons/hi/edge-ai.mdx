# Edge AI

हर पूर्वानुमान को cloud तक जाकर वापस नहीं आना चाहिए। Edge AI मॉडल को सीधे डिवाइस पर चलाता है: आपका phone, ब्राउज़र, camera या कार। लाभ मजबूत हैं: zero network लेटेंसी, पूरी privacy (डेटा डिवाइस से बाहर नहीं जाता), offline capability और सर्विंग लागत में भारी कमी।

चुनौती? आपको ऐसा मॉडल चाहिए जो megabytes में फ़िट हो, limited हार्डवेयर पर चले और फिर भी useful सटीकता दे।

## Cloud के बजाय edge क्यों?

Edge और cloud के बीच निर्णय binary नहीं है: अधिकतर प्रोडक्शन सिस्टम hybrid दृष्टिकोण इस्तेमाल करते हैं। लेकिन trade-offs समझना महत्वपूर्ण है:

| Factor | Cloud इन्फ़रेंस | Edge इन्फ़रेंस |
|--------|----------------|----------------|
| **Latency** | 100-500ms (network राउंड trip) | 5-50ms (ऑन-डिवाइस) |
| **Privacy** | डेटा sent to server | डेटा stays on डिवाइस |
| **Cost** | Per-request GPU लागत | Zero marginal लागत |
| **Offline** | Requires connectivity | Works anywhere |
| **Scalability** | Server bottleneck | Scales with डिवाइस |
| **मॉडल Size** | Unlimited | Constrained by डिवाइस memory |

रीयल-टाइम अनुवाद, keyboard पूर्वानुमान, face unlock या स्वास्थ्य मॉनिटरिंग जैसे अनुप्रयोग के लिए edge सिर्फ़ preferable नहीं है: यह एकमात्र व्यवहार्य option है।

## मॉडल compression techniques

प्रोडक्शन मॉडल edge डिवाइस के लिए बहुत बड़े होते हैं। FP32 प्रिसिशन पर GPT-class मॉडल gigabytes memory खा लेगा। Compression techniques डिप्लॉयमेंट को feasible बनाती हैं।

### Quantisation

Quantisation मॉडल वेट की numerical प्रिसिशन को 32-bit floating बिंदु (FP32) से छोटे representations में घटाता है:

- **FP16** - Half प्रिसिशन। 2× memory reduction, minimal सटीकता हानि। GPU इन्फ़रेंस के लिए मानक।
- **INT8** - 4× memory कमी। अधिकतर edge डिप्लॉयमेंट के लिए sweet बेहतर संतुलन।
- **INT4** - 8× memory कमी। aggressive, लेकिन careful calibration के साथ large language मॉडल के लिए व्यवहार्य।

Post-प्रशिक्षण quantisation (PTQ) already-प्रशिक्षित मॉडल को convert करता है। Quantisation-aware प्रशिक्षण (QAT) बेहतर सटीकता रिटेंशन के लिए प्रशिक्षण के दौरान low प्रिसिशन simulate करता है।

<FunFact>iPhone 15 Pro पर Apple का Neural Engine INT8 operations को 35 TOPS (trillion operations per second) पर प्रक्रिया करता है: लगभग पांच साल पहले के mid-range डेटा centre GPU के बराबर।</FunFact>

### Pruning

Pruning उन वेट (या पूरे neurons) को हटाता है जो मॉडल आउटपुट में सबसे कम योगदान देते हैं। Unstructured pruning individual वेट को zero करती है; structured pruning हार्डवेयर पर actual speedups के लिए पूरे channels या attention heads हटाती है।

अच्छी तरह pruned मॉडल 1% से कम सटीकता गिरावट के साथ 50-90% parameters हटा सकता है, लेकिन प्रदर्शन recover करने के लिए pruned मॉडल को बाद में fine-tune करना ज़रूरी है।

### Knowledge Distillation

छोटे "student" मॉडल को बड़े "teacher" मॉडल के आउटपुट mimic करने के लिए train करें। student सिर्फ़ correct लेबल नहीं सीखता, बल्कि teacher का पूरा probability वितरण सीखता है: इसमें वे wrong answers भी शामिल हैं जो "almost right" हैं। यह soft information आश्चर्यजनक रूप से अच्छी तरह transfer होती है।

उदाहरण के लिए DistilBERT, BERT की 97% सटीकता को उसके 60% size और 2× speed पर बनाए रखता है।

## ONNX: Universal फ़ॉर्मैट

**Open Neural Network Exchange (ONNX)** फ़्रेमवर्क-agnostic मॉडल फ़ॉर्मैट है। PyTorch में train करें, ONNX में export करें, कहीं भी deploy करें: TensorFlow Lite, Core ML, ONNX Runtime या ब्राउज़र।

ONNX Runtime एक API के साथ CPUs, GPUs और NPUs पर ऑप्टिमाइज़्ड इन्फ़रेंस देता है। यह operator fusion, memory planning और हार्डवेयर-specific acceleration अपने आप संभालता है।

## Platform-specific रनटाइम

### TensorFlow Lite (Mobile / IoT)

Android, iOS और microcontrollers के लिए Google का रनटाइम। TFLite मॉडल flat buffers होते हैं: छोटे, load करने में तेज़ और dynamic memory allocation नहीं। interpreter 1 MB से कम है। Delegate APIs computation को GPU, DSP या NPU हार्डवेयर पर offload करते हैं।

### Core ML (Apple Ecosystem)

Apple का फ़्रेमवर्क computation को CPU, GPU और dedicated Neural Engine में अपने आप route करता है। अगर आप ML फ़ीचर वाला iOS app ship कर रहे हैं, तो Core ML सबसे आसान रास्ता है। यह IP protection के लिए मॉडल encryption समर्थन करता है।

### WebAssembly + ONNX Runtime Web

Browser में near-native प्रदर्शन के साथ ML मॉडल चलाएं। ONNX Runtime Web मॉडल को WebAssembly में compile करता है और GPU acceleration के लिए WebGL या WebGPU इस्तेमाल करता है। कोई server नहीं, कोई installation नहीं, डेटा ब्राउज़र से बाहर नहीं जाता।

Use cases: video calls में रीयल-टाइम background removal, on-page सामग्री moderation और ब्राउज़र-based दस्तावेज़ित OCR है।

## On-डिवाइस large language मॉडल

दो साल पहले उपभोक्ता हार्डवेयर पर LLM चलाना असंभव लगता था। आज 4 billion parameters से कम क्वांटाइज़्ड मॉडल flagship phones पर आराम से चलते हैं:

- **Gemma 2B/7B** (Google) - TFLite और MediaPipe के ज़रिए mobile के लिए ऑप्टिमाइज़्ड
- **Phi-3 Mini** (Microsoft) - 3.8B parameters, अपने size के हिसाब से strong तर्क
- **Small Llama-family मॉडल** (Meta) - ऑन-डिवाइस डिप्लॉयमेंट के लिए उद्देश्य-निर्मित
- **Gemini Nano** (Google) - AICore के ज़रिए Android 14+ में integrated

ये मॉडल बिना network call summarisation, अनुवाद, smart replies और code completion संभालते हैं।

<ThinkAboutIt>On-डिवाइस LLMs का मतलब है कि आपके private messages, स्वास्थ्य डेटा और browsing history phone से बाहर नहीं जाते। लेकिन इसका मतलब सुरक्षा मॉनिटरिंग के लिए कम visibility भी है। डिवाइस manufacturers privacy और सामग्री सुरक्षा का संतुलन कैसे रखें?</ThinkAboutIt>

## Edge पर हार्डवेयर एक्सेलरेटर

Modern डिवाइस में neural network इन्फ़रेंस के लिए dedicated silicon शामिल है:

- **Apple Neural Engine** - M-series और A-series chips में 16-मूल NPU है। Core ML के साथ tight एकीकरण।
- **Qualcomm Hexagon NPU** - Snapdragon chips पर Android AI चलाता है। INT4 को natively समर्थन करता है।
- **Google Tensor TPU** - Pixel phones में ऑन-डिवाइस speech, अनुवाद और photos के लिए कस्टम चिप।
- **Intel Movidius** - IoT cameras और drones के लिए low-power VPU है।

Trend साफ़ है: हर major chipmaker अब AI acceleration को प्रथम-श्रेणी फ़ीचर मानता है, afterthought नहीं।

## Real-world Edge AI अनुप्रयोग

- **कीबोर्ड पूर्वानुमान** (GBoard, SwiftKey) - निजीकृत मॉडल का उपयोग करके अगले शब्द का पूर्वानुमान पूरी तरह ऑन-डिवाइस चलता है
- **रीयल-टाइम अनुवाद** (Google Translate offline) - connectivity के बिना पूरा neural machine अनुवाद
- **Face recognition** (Face ID) - Apple का TrueDepth सिस्टम Neural Engine पर 3D face maps प्रक्रिया करता है
- **Smart cameras** - retail analytics, wildlife मॉनिटरिंग और traffic management edge पर
- **Hearing aids** - sub-millisecond लेटेंसी के साथ ऑन-डिवाइस noise cancellation और speech enhancement
