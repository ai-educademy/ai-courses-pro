# 📊 మోడల్ మూల్యాంకనం డీప్ డైవ్స్

"మీ మోడల్‌కు 95% ఖచ్చితత్వం ఉంది - దానిని రవాణా చేయండి!" ఆ వాక్యం వెంటనే మీకు అసౌకర్యాన్ని కలిగించకపోతే, ఈ పాఠం మీకు అవసరమైనది. మోడల్ మూల్యాంకనం అనేది ఇంటర్వ్యూ అంశం, ఇది *శిక్షణ పొందిన* మోడల్‌లను *ప్రయోగించిన* వారి నుండి వేరు చేస్తుంది. ఇంటర్వ్యూయర్లు మూల్యాంకన పరిజ్ఞానాన్ని పరిశీలిస్తారు ఎందుకంటే మోడల్ వాస్తవానికి ఏమి చేస్తుందో మీకు అర్థమైందా - మరియు దానిని విశ్వసించాలా వద్దా అని ఇది వెల్లడిస్తుంది.

## 🎯 వర్గీకరణ కొలమానాలు: ఖచ్చితత్వానికి మించి

ఖచ్చితత్వం - సరైన అంచనాల శాతం - ప్రతి ఒక్కరూ ముందుగా నేర్చుకునే మెట్రిక్ మరియు చాలా తరచుగా తప్పుదారి పట్టించే మెట్రిక్. కేవలం 0.5% లావాదేవీలు మాత్రమే మోసపూరితమైన డేటాసెట్‌లో మోసాన్ని గుర్తించే నమూనాను పరిగణించండి. ప్రతిదానికీ "మోసం కాదు" అని అంచనా వేసే మోడల్ సున్నా మోసాన్ని పట్టుకున్నప్పుడు **99.5% ఖచ్చితత్వాన్ని** సాధిస్తుంది.

### ప్రెసిషన్, రీకాల్ మరియు F1

ఈ మూడు కొలమానాలు వర్గీకరణ మూల్యాంకనం యొక్క వెన్నెముకను ఏర్పరుస్తాయి:

- **Precision** = TP / (TP + FP) — "నేను పాజిటివ్‌గా ఫ్లాగ్ చేసిన ప్రతిదానిలో, వాస్తవానికి ఎంత ఉంది?"
- **రీకాల్** = TP / (TP + FN) — "వాస్తవానికి సానుకూలంగా ఉన్న ప్రతిదానిలో, నేను ఎంత పట్టుకున్నాను?"
- **F1 స్కోరు** = 2 × (Precision × Recall) / (Precision + Recall) — హార్మోనిక్ మీన్, రెండింటినీ బ్యాలెన్స్ చేస్తుంది

```
              Predicted Positive    Predicted Negative
Actual Positive       TP                   FN
Actual Negative       FP                   TN
```

<ThinkAboutIt>మీరు వైద్య చిత్రాల నుండి క్యాన్సర్‌ను గుర్తించడానికి ఒక నమూనాను రూపొందిస్తున్నారు. మీరు ఖచ్చితత్వం కోసం ఆప్టిమైజ్ చేస్తారా లేదా రీకాల్ చేస్తారా? ప్రతి దిశలో దీన్ని తప్పుగా పొందడం వల్ల వాస్తవ ప్రపంచ పరిణామాలు ఏమిటి?
</ThinkAboutIt>

## 📈 AUC-ROC మరియు AUC-PR: పూర్తి చిత్రం

### ROC కర్వ్

ప్రతి వర్గీకరణ థ్రెషోల్డ్ వద్ద **ఫాల్స్ పాజిటివ్ రేట్** (FP / (FP + TN))కి వ్యతిరేకంగా రిసీవర్ ఆపరేటింగ్ క్యారెక్టరిస్టిక్ కర్వ్ ప్లాట్లు **నిజమైన సానుకూల రేటు** (రీకాల్). ఈ వక్రరేఖ కింద ఉన్న ప్రాంతం (**AUC-ROC**) మోడల్ నాణ్యత యొక్క థ్రెషోల్డ్-స్వతంత్ర కొలతను ఇస్తుంది.

- **AUC = 1.0**: ఖచ్చితమైన విభజన
- **AUC = 0.5**: యాదృచ్ఛికంగా ఊహించడం (వికర్ణ రేఖ)
- **AUC <0.5**: యాదృచ్ఛికం కంటే అధ్వాన్నంగా ఉంది (మీ లేబుల్‌లు తిప్పబడవచ్చు!)

### ప్రెసిషన్-రీకాల్ కర్వ్

తరగతులు చాలా అసమతుల్యతతో ఉన్నప్పుడు, AUC-ROC తప్పుదారి పట్టించే విధంగా ఆశాజనకంగా ఉంటుంది. **ప్రిసిషన్-రీకాల్ కర్వ్** ఖచ్చితత్వం vs రీకాల్‌ను ప్లాట్ చేస్తుంది మరియు అరుదైన సంఘటన గుర్తింపు కోసం మరింత సమాచారంగా ఉంటుంది.

```python
from sklearn.metrics import precision_recall_curve, auc

precision, recall, thresholds = precision_recall_curve(y_true, y_scores)
pr_auc = auc(recall, precision)
```

## 📐 రిగ్రెషన్ మెట్రిక్స్

ప్రతిదీ వర్గీకరణ కాదు. నిరంతర విలువలను అంచనా వేసేటప్పుడు, ఈ కొలమానాలు ముఖ్యమైనవి:

### మీన్ స్క్వేర్డ్ ఎర్రర్ (MSE)

$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

పెద్ద తప్పులకు భారీగా జరిమానా విధిస్తుంది (క్వాడ్రాటిక్ పెనాల్టీ). చిన్న పొరపాట్ల కంటే పెద్ద తప్పులు చాలా ఘోరంగా ఉన్నప్పుడు మంచిది - ఉదా., £100కి తగ్గడం కంటే £10K తగ్గితే ఇంటి ధరలను అంచనా వేయడం చాలా దారుణం.

### అంటే సంపూర్ణ లోపం (MAE)

$$MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$$

అన్ని లోపాలను సరళంగా పరిగణిస్తుంది. MSE కంటే అవుట్‌లైయర్‌లకు మరింత బలమైనది. అవుట్‌లైయర్‌లు ఆశించినప్పుడు ఉపయోగించండి మరియు మీ మెట్రిక్‌పై ఆధిపత్యం వహించకూడదు.

### R² (నిర్ణయ గుణకం)

$$R^2 = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

సగటును అంచనా వేయడంతో పోలిస్తే మీ మోడల్ ఎంత వ్యత్యాసాన్ని వివరిస్తుందో కొలుస్తుంది. R² = 1 అంటే పర్ఫెక్ట్ ఫిట్; R² = 0 అంటే మీ మోడల్ సగటును అంచనా వేయడం కంటే మెరుగైనది కాదు.

<FunFact>R² నిజానికి ప్రతికూలంగా మారవచ్చు! ప్రతి ఇన్‌పుట్ కోసం టార్గెట్ వేరియబుల్ సగటును అంచనా వేయడం కంటే మీ మోడల్ అంచనాలు అధ్వాన్నంగా ఉన్నప్పుడు ఇది జరుగుతుంది. ఏదో చాలా తప్పు జరిగిందని ఇది సంకేతం.
</FunFact>

## 🔄 క్రాస్ ధ్రువీకరణ వ్యూహాలు

ఒకే పరీక్ష సెట్‌ను పట్టుకోవడం పెద్ద డేటాసెట్‌ల కోసం పని చేస్తుంది, అయితే క్రాస్ ధ్రువీకరణ సాధారణీకరణ పనితీరు యొక్క మరింత విశ్వసనీయ అంచనాలను ఇస్తుంది.

### K-ఫోల్డ్ క్రాస్ ధ్రువీకరణ

డేటాను K సమాన మడతలుగా విభజించండి. K-1 ఫోల్డ్స్‌పై ట్రైన్ చేయండి, మిగిలిన మడతపై ధృవీకరించండి. K సార్లు పునరావృతం చేయండి. మీ మెట్రిక్ యొక్క సగటు మరియు ప్రామాణిక విచలనాన్ని నివేదించండి.

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(model, X, y, cv=5, scoring='f1')
print(f"F1: {scores.mean():.3f} ± {scores.std():.3f}")
```

### స్ట్రాటిఫైడ్ K-ఫోల్డ్

ప్రతి మడతలో తరగతి పంపిణీని సంరక్షిస్తుంది - అసమతుల్య డేటాసెట్‌లకు అవసరం.

### టైమ్-సిరీస్ స్ప్లిట్

తాత్కాలిక డేటా కోసం, **ఎప్పటికీ** యాదృచ్ఛిక విభజనలను ఉపయోగించవద్దు. సమయ క్రమాన్ని గౌరవించడానికి విస్తరించే లేదా స్లైడింగ్ విండో క్రాస్ ధ్రువీకరణను ఉపయోగించండి:

```
Fold 1: Train [Jan-Mar]  → Test [Apr]
Fold 2: Train [Jan-Apr]  → Test [May]
Fold 3: Train [Jan-May]  → Test [Jun]
```

## 🌐 ఆఫ్‌లైన్ vs ఆన్‌లైన్ మూల్యాంకనం

ఆఫ్‌లైన్ కొలమానాలు (చారిత్రక డేటాపై లెక్కించబడ్డాయి) ఎల్లప్పుడూ ఆన్‌లైన్ పనితీరును అంచనా వేయవు. మెరుగైన AUC ఉన్న మోడల్ వాస్తవానికి ఒకసారి అమలు చేసిన తర్వాత వినియోగదారు నిశ్చితార్థాన్ని తగ్గించవచ్చు.

| కోణం | ఆఫ్‌లైన్ మూల్యాంకనం | ఆన్‌లైన్ మూల్యాంకనం (A/B పరీక్ష) |
|---|---|---|
| వేగం | ఫాస్ట్ — సేవ్ చేసిన డేటాపై రన్ | నెమ్మదిగా — నిజమైన ట్రాఫిక్ అవసరం |
| ఖర్చు | తక్కువ | అధిక (ఇంజనీరింగ్ + అవకాశ ఖర్చు) |
| చర్యలు | చారిత్రక డేటాపై మోడల్ నాణ్యత | వాస్తవ వ్యాపార ప్రభావం |
| పరిమితి | వినియోగదారు ప్రవర్తన మార్పులను సంగ్రహించదు | గణాంక కఠినత అవసరం |

### ML మోడల్‌ల కోసం A/B పరీక్ష

కొత్త మోడల్ కోసం A/B పరీక్షను అమలు చేస్తున్నప్పుడు:

1. **ప్రాధమిక కొలమానాన్ని నిర్వచించండి** (ఉదా., వినియోగదారుకు ఆదాయం) మరియు గార్డ్‌రైల్ కొలమానాలు (ఉదా., జాప్యం, లోపం రేటు)
2. గణాంక ప్రాముఖ్యత కోసం **అవసరమైన నమూనా పరిమాణాన్ని లెక్కించండి**
3. **కరెక్ట్‌గా రాండమైజ్ చేయండి** — అభ్యర్థన స్థాయిలో కాకుండా వినియోగదారు స్థాయిలో విభజించండి
4. **తగినంత కాలం నడపండి** — కొత్తదనం ప్రభావాలు మరియు వారపు కాలానుగుణత కోసం ఖాతా
5. **జోక్యాన్ని తనిఖీ చేయండి** — చికిత్స సమూహం యొక్క ప్రవర్తన నియంత్రణ సమూహాన్ని ప్రభావితం చేస్తుందా?

<ThinkAboutIt>మీ కొత్త సిఫార్సు మోడల్ AUC-ROC ఆఫ్‌లైన్‌లో 3% మెరుగుదలని చూపుతుంది, అయితే A/B పరీక్ష సమయంలో క్లిక్-త్రూ రేట్‌లో 1% *తగ్గింది*. ఈ వైరుధ్యాన్ని ఏమి వివరించగలదు మరియు మీరు ఏమి పరిశోధిస్తారు?
</ThinkAboutIt>

## ⚖️ అసమతుల్య డేటాసెట్‌లతో వ్యవహరించడం

అసమతుల్య డేటా శిక్షణ మరియు మూల్యాంకనం రెండింటినీ ప్రభావితం చేస్తుంది. సాధారణ వ్యూహాలు:

** శిక్షణ సమయంలో:**
- మైనారిటీ తరగతి (SMOTE)ని అతిగా నమూనా చేయండి
- మెజారిటీ వర్గాన్ని తక్కువగా అంచనా వేయండి
- లాస్ ఫంక్షన్‌లో క్లాస్ వెయిట్‌లను ఉపయోగించండి
- సింథటిక్ ఉదాహరణలను రూపొందించండి

**మూల్యాంకనం సమయంలో:**
- ఖచ్చితత్వానికి బదులుగా ఖచ్చితత్వం, రీకాల్, F1 ఉపయోగించండి
- AUC-ROCకి బదులుగా AUC-PRని ఉపయోగించండి
- తరగతికి కొలమానాలను నివేదించండి
- స్ట్రాటిఫైడ్ క్రాస్ ధ్రువీకరణను ఉపయోగించండి

```python
from sklearn.ensemble import RandomForestClassifier

# Class weight approach — inversely proportional to class frequency
model = RandomForestClassifier(class_weight='balanced')
```

## 🔑 కీలక టేకావేలు

- ** ఎప్పుడూ ఖచ్చితత్వంపై మాత్రమే ఆధారపడవద్దు** — ముఖ్యంగా అసమతుల్య డేటాతో
- **వ్యాపార లక్ష్యానికి మెట్రిక్‌ను సరిపోల్చండి**: తప్పుడు పాజిటివ్‌లు ఖరీదైనవి అయినప్పుడు భద్రత-క్లిష్టమైన, ఖచ్చితత్వం కోసం రీకాల్ చేయండి
- **AUC-PR ద్వారా AUC-ROC** అసమతుల్య సమస్యల కోసం — ఇది హై-సిగ్నల్ ఇంటర్వ్యూ చిట్కా
- **తాత్కాలిక డేటా కోసం సమయ-ఆధారిత విభజనలను ఉపయోగించండి** — యాదృచ్ఛిక విభజనలు డేటా లీకేజీకి కారణమవుతాయి
- **ఆఫ్‌లైన్ కొలమానాలు సరిపోవు** — వాస్తవ ప్రపంచ ప్రభావాన్ని ధృవీకరించడానికి A/B పరీక్ష కోసం ప్లాన్ చేయండి
- **ఫార్ములాలను తెలుసుకోండి** — ఇంటర్వ్యూ చేసేవారు మిమ్మల్ని ఖచ్చితత్వం, రీకాల్, F1, MSE, మరియు R² పొందమని లేదా వివరించమని అడగవచ్చు.
