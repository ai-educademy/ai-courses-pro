# 💬 NLP మరియు LLM ఇంటర్వ్యూ అంశాలు

రెండు సంవత్సరాల క్రితం, NLP ఇంటర్వ్యూ ప్రశ్నలు అంటే వర్డ్ ఎంబెడ్డింగ్‌లు మరియు LSTM వానిషింగ్ గ్రేడియంట్‌లను వివరించడం. ఈరోజు, ఇంటర్వ్యూ చేసే వ్యక్తి కూడా ఇలా అడిగే అవకాశం ఉంది, "మీరు మోడల్‌ను ఎప్పుడు RAGని ఉపయోగించడం కంటే చక్కగా తీర్చిదిద్దుతారు?" NLP ల్యాండ్‌స్కేప్ నాటకీయంగా మారింది మరియు దానితో ఇంటర్వ్యూలు మారాయి. ఈ పాఠం ఇప్పుడు సంభాషణలో ఆధిపత్యం చెలాయించే *మరియు* LLM-యుగం టాపిక్‌లను ఇప్పటికీ పరీక్షిస్తున్న ప్రాథమిక అంశాలని కవర్ చేస్తుంది.

---

## 📚 NLP ఫండమెంటల్స్ ఇంటర్వ్యూయర్లు ఇంకా ఆశిస్తున్నారు

GPT యుగంలో కూడా, ఈ మోడల్‌లు పని చేయడం మాత్రమే కాకుండా *ఎందుకు* పని చేస్తాయని మీరు అర్థం చేసుకున్నారని మీరు ప్రదర్శించాలి.

### టోకనైజేషన్

టోకనైజేషన్ ముడి వచనాన్ని మోడల్ ప్రాసెస్ చేయగల వివిక్త యూనిట్‌లుగా మారుస్తుంది. విధానం ముఖ్యం:

- **పద-స్థాయి**: సరళమైనది కానీ పదజాలం లేని పదాలను నిర్వహించలేము ("అనుకూలత" → తెలియదు)
- **అక్షర-స్థాయి**: ఏదైనా పదాన్ని నిర్వహిస్తుంది కానీ సీక్వెన్సులు చాలా పొడవుగా ఉంటాయి
- **సబ్‌వర్డ్ (BPE, WordPiece, SentencePiece)**: ఆధునిక ప్రమాణం — అరుదైన పదాలను అర్ధవంతమైన ముక్కలుగా విభజిస్తుంది

```
"unfriendliness" → ["un", "friend", "li", "ness"]  (BPE)
"playing"        → ["play", "##ing"]                (WordPiece)
```

<Callout>ఇంటర్వ్యూ చిట్కా: టోకనైజేషన్ గురించి అడిగితే, టోకనైజేషన్ ఎంపికలు పదజాలం పరిమాణం, క్రమం పొడవు మరియు అరుదైన లేదా తప్పుగా వ్రాసిన పదాలను నిర్వహించగల మోడల్ సామర్థ్యాన్ని ప్రభావితం చేస్తాయని పేర్కొనండి. ఇది మీరు మెకానిక్స్ మాత్రమే కాకుండా దిగువ చిక్కులను అర్థం చేసుకున్నారని చూపిస్తుంది.
</Callout>

### ఎంబెడ్డింగ్‌లు

ఎంబెడ్డింగ్‌లు వివిక్త టోకెన్‌లను దట్టమైన నిరంతర వెక్టర్‌లకు మ్యాప్ చేస్తాయి, ఇక్కడ అర్థ సంబంధాలు భద్రపరచబడతాయి:

- **Word2Vec / GloVe**: స్టాటిక్ ఎంబెడ్డింగ్‌లు — సందర్భంతో సంబంధం లేకుండా ప్రతి పదం ఒక వెక్టర్‌ను పొందుతుంది ("బ్యాంకు" అంటే నది ఒడ్డు లేదా ఆర్థిక సంస్థ అని అర్ధం)
- ** సందర్భోచిత ఎంబెడ్డింగ్‌లు (BERT, GPT)**: ప్రతి టోకెన్ యొక్క పొందుపరచడం పరిసర సందర్భంపై ఆధారపడి ఉంటుంది — "బ్యాంక్" వివిధ వాక్యాలలో విభిన్న ప్రాతినిధ్యాలను పొందుతుంది

### అటెన్షన్ మెకానిజం

ట్రాన్స్‌ఫార్మర్‌లను పని చేసేలా చేసే కీలక ఆవిష్కరణ శ్రద్ధ. దాని ప్రధాన భాగంలో:

$$\text{అటెన్షన్}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\కుడి)V$$

సాదా ఆంగ్లంలో: ప్రతి టోకెన్‌కు, అటెన్షన్ అన్ని ఇతర టోకెన్‌ల కంటే వెయిటెడ్ సగటును గణిస్తుంది, ఇక్కడ బరువులు ప్రతి టోకెన్ ప్రస్తుతానికి ఎంత సంబంధితంగా ఉందో ప్రతిబింబిస్తుంది. స్కేలింగ్ కారకం √d_k డాట్ ఉత్పత్తులు చాలా పెద్దగా పెరగకుండా నిరోధిస్తుంది.

**సెల్ఫ్-అటెన్షన్** ప్రతి టోకెన్‌ను క్రమంలో ప్రతి ఇతర టోకెన్‌కు హాజరు కావడానికి అనుమతిస్తుంది, RNNలు కష్టపడే దీర్ఘ-శ్రేణి డిపెండెన్సీలను సంగ్రహిస్తుంది.

### ట్రాన్స్ఫార్మర్ ఆర్కిటెక్చర్

ట్రాన్స్ఫార్మర్ వీటిని కలిగి ఉంటుంది:
- **ఎన్‌కోడర్**: పూర్తి ఇన్‌పుట్‌ను ప్రాసెస్ చేస్తుంది (అర్థం చేసుకోవడానికి BERT-శైలి నమూనాలలో ఉపయోగించబడుతుంది)
- **డీకోడర్**: టోకెన్ ద్వారా అవుట్‌పుట్ టోకెన్‌ను ఉత్పత్తి చేస్తుంది (జనరేషన్ కోసం GPT-శైలి మోడల్‌లలో ఉపయోగించబడుతుంది)
- **ఎన్‌కోడర్-డీకోడర్**: రెండింటినీ మిళితం చేస్తుంది (T5లో ఉపయోగించబడుతుంది, అనువాదం కోసం అసలైన ట్రాన్స్‌ఫార్మర్)

| ఆర్కిటెక్చర్ | ఉదాహరణలు | ఉత్తమం |
|---|---|---|
| ఎన్‌కోడర్-మాత్రమే | BERT, RoBERTa | వర్గీకరణ, NER, ఎంబెడ్డింగ్‌లు |
| డీకోడర్-మాత్రమే | GPT, Llama, Mistral | టెక్స్ట్ జనరేషన్, చాట్, రీజనింగ్ |
| ఎన్‌కోడర్-డీకోడర్ | T5, BART | అనువాదం, సారాంశం |

## 🤖 LLM-నిర్దిష్ట ఇంటర్వ్యూ ప్రశ్నలు

ఇవి గత రెండేళ్లలో ఉద్భవించిన ప్రశ్నలు మరియు ఇప్పుడు దాదాపు ప్రతి ML ఇంటర్వ్యూలో కనిపిస్తున్నాయి.

### ఫైన్-ట్యూనింగ్ vs ప్రాంప్టింగ్

| అప్రోచ్ | ఎప్పుడు ఉపయోగించాలి | ప్రోస్ | ప్రతికూలతలు |
|---|---|---|---|
| **జీరో/కొన్ని-షాట్ ప్రాంప్టింగ్** | త్వరిత నమూనా, సాధారణ పనులు | శిక్షణ అవసరం లేదు, అనువైన | పరిమిత నియంత్రణ, ప్రతి ప్రశ్నకు ఖర్చులు |
| **ప్రాంప్ట్ ఇంజనీరింగ్** | మోడరేట్ అనుకూలీకరణ | వేగవంతమైన పునరావృతం, GPU ఖర్చులు లేవు | పెళుసుగా, సంస్కరణకు కష్టం |
| **ఫైన్-ట్యూనింగ్ (పూర్తి)** | లేబుల్ చేయబడిన డేటాతో డొమైన్-నిర్దిష్ట పనులు | ఉత్తమ నాణ్యత, చిన్న మోడల్ సాధ్యం | ఖరీదైనది, డేటా మరియు GPU అవసరం |
| **లోరా / క్యూలోరా** | పరిమిత వనరులతో ఫైన్-ట్యూనింగ్ | సమర్థవంతమైన, చిన్న అడాప్టర్ బరువులు | పూర్తి ఫైన్-ట్యూనింగ్ కంటే కొంచెం తక్కువ వ్యక్తీకరణ |
| **రాగ్** | నాలెడ్జ్-ఇంటెన్సివ్, అప్-టు-డేట్ సమాచారం అవసరం | తిరిగి శిక్షణ లేదు, ఉదహరించదగిన మూలాలు | పునరుద్ధరణ నాణ్యత అడ్డంకి |

### రిట్రీవల్-అగ్మెంటెడ్ జనరేషన్ (RAG)

RAG భాషా నమూనాతో తిరిగి పొందే వ్యవస్థను మిళితం చేస్తుంది:

```
User query → Embed query → Search vector DB → Retrieve top-K documents
    → Construct prompt (query + retrieved docs) → LLM generates answer
```

**కీలక ఇంటర్వ్యూ చర్చా పాయింట్లు**:
- **చంకింగ్ స్ట్రాటజీ**: మీరు డాక్యుమెంట్‌లను ఎలా విభజించారు అనేది తిరిగి పొందే నాణ్యతను ప్రభావితం చేస్తుంది
- **ఎంబెడ్డింగ్ మోడల్ ఎంపిక**: డొమైన్-నిర్దిష్ట vs సాధారణ ఎంబెడ్డింగ్‌లు
- **రీర్యాంకింగ్**: LLMకి ఫీడ్ చేయడానికి ముందు తిరిగి పొందిన భాగాలను మళ్లీ ర్యాంక్ చేయడానికి క్రాస్-ఎన్‌కోడర్‌ను ఉపయోగించండి
- **RAG విఫలమైనప్పుడు**: సమాధానానికి అనేక పత్రాలలో తార్కికం అవసరమైనప్పుడు లేదా సంబంధిత పత్రం లేనప్పుడు

### RLHF (మానవ అభిప్రాయం నుండి ఉపబల అభ్యాసం)

ChatGPT యొక్క సహాయానికి వెనుక ఉన్న సాంకేతికత:

1. **పర్యవేక్షించబడిన ఫైన్-ట్యూనింగ్**: క్యూరేటెడ్ ప్రాంప్ట్-రెస్పాన్స్ జతలపై శిక్షణ
2. **రివార్డ్ మోడల్ శిక్షణ**: మానవులు మోడల్ అవుట్‌పుట్‌లను ర్యాంక్ చేస్తారు; ఈ ప్రాధాన్యతలపై రివార్డ్ మోడల్‌కు శిక్షణ ఇవ్వండి
3. **PPO ఆప్టిమైజేషన్**: రీన్‌ఫోర్స్‌మెంట్ లెర్నింగ్ ద్వారా LLMని చక్కగా ట్యూన్ చేయడానికి రివార్డ్ మోడల్‌ని ఉపయోగించండి

- **మధ్యలో కోల్పోయింది**: మోడల్‌లు సుదీర్ఘ సందర్భాల మధ్యలో సమాచారంపై తక్కువ శ్రద్ధ చూపుతాయి

## 🎯 మోడల్ ఎంపిక: ఎప్పుడు ఏది ఉపయోగించాలి

ఇది ఇష్టమైన ఇంటర్వ్యూ ప్రశ్న: "ఈ వినియోగ సందర్భాన్ని బట్టి, మీరు ఏ మోడల్‌ని ఎంచుకుంటారు?"

**పెద్ద frontier model (GPT-6 Astra, Claude Opus 5.5) ఎప్పుడు ఉపయోగించండి:**
- విధికి సాధారణ తార్కికం లేదా సంక్లిష్ట సూచనలను అనుసరించడం అవసరం
- మీ వద్ద లేబుల్ చేయబడిన శిక్షణ డేటా లేదు
- అనుమితి ధర కంటే ప్రోటోటైపింగ్ వేగం ముఖ్యం

**Fine-tuned smaller model (Mistral, Llama) ఎప్పుడు ఉపయోగించండి:**
- మీకు డొమైన్-నిర్దిష్ట డేటా ఉంది మరియు స్థిరమైన, ప్రత్యేకమైన అవుట్‌పుట్‌లు అవసరం
- అనుమితి వ్యయ విషయాలు (స్కేల్‌లో అందించడం)
- జాప్యం అవసరాలు కఠినంగా ఉంటాయి
- మీరు డేటా గోప్యత కోసం ప్రాంగణంలో అమలు చేయాలి

** సంప్రదాయ NLP మోడల్‌ని (BERT, RoBERTa) ఎప్పుడు ఉపయోగించండి:**
- విధి వర్గీకరణ, NER లేదా వెలికితీత (తరం కాదు)
- మీకు చాలా ఎక్కువ నిర్గమాంశ వద్ద వేగవంతమైన అనుమితి అవసరం
- స్పష్టమైన లేబుల్ డేటాతో టాస్క్ బాగా నిర్వచించబడింది

## 🔬 LLM అవుట్‌పుట్‌లను మూల్యాంకనం చేస్తోంది

వర్గీకరణదారులను మూల్యాంకనం చేయడం కంటే ఉత్పాదక నమూనాలను మూల్యాంకనం చేయడం కష్టం. సాధారణ విధానాలు:

- **ఆటోమేటెడ్ మెట్రిక్‌లు**: BLEU, ROUGE, BERTScore (ఉపయోగకరమైనది కానీ అసంపూర్ణమైనది)
- **LLM-గా న్యాయమూర్తి**: బలహీనమైన మోడల్ అవుట్‌పుట్‌లను అంచనా వేయడానికి బలమైన మోడల్‌ని ఉపయోగించండి
- **మానవ మూల్యాంకనం**: బంగారు ప్రమాణం కానీ ఖరీదైనది మరియు నెమ్మదిగా ఉంటుంది
- **టాస్క్-నిర్దిష్ట మూల్యాంకనం**: QA బెంచ్‌మార్క్‌లపై ఖచ్చితత్వం, కోడ్ అమలు పాస్ రేట్లు
- **రెడ్-టీమింగ్**: భద్రత, పక్షపాతం మరియు హానికరమైన అవుట్‌పుట్‌ల కోసం విరోధి పరీక్ష

```python
# BERTScore example
from bert_score import score

precision, recall, f1 = score(
    cands=["The cat sat on the mat"],
    refs=["A cat was sitting on a mat"],
    lang="en"
)
```
