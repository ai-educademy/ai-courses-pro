# 🔧 ఫీచర్ ఇంజనీరింగ్ ప్రశ్నలు

అనుభవజ్ఞులైన ML ఇంజనీర్‌లకు తెలిసిన రహస్యం ఇక్కడ ఉంది: **మీరు ఎంచుకునే మోడల్ మీరు ఫీడ్ చేసే ఫీచర్‌ల కంటే చాలా తక్కువగా ఉంటుంది.** అద్భుతమైన ఫీచర్‌లతో కూడిన సాధారణ లాజిస్టిక్ రిగ్రెషన్ దాదాపు ప్రతిసారీ పేలవమైన ఫీచర్‌లతో కూడిన డీప్ న్యూరల్ నెట్‌వర్క్‌ను బీట్ చేస్తుంది. అందుకే ఇంటర్వ్యూ చేసేవారు ఫీచర్ ఇంజినీరింగ్ ప్రశ్నలను ఇష్టపడతారు — మీరు కేవలం అల్గారిథమ్‌లను మాత్రమే కాకుండా మెషిన్ లెర్నింగ్ యొక్క *డేటా* వైపు అర్థం చేసుకున్నారో లేదో పరీక్షిస్తారు.

## 🤔 ఇంటర్వ్యూయర్లు ఫీచర్ ఇంజనీరింగ్ గురించి ఎందుకు శ్రద్ధ వహిస్తారు

ఫీచర్ ఇంజనీరింగ్ డొమైన్ నాలెడ్జ్, డేటా ఇంట్యూషన్ మరియు ఇంజనీరింగ్ స్కిల్ యొక్క ఖండన వద్ద కూర్చుంటుంది. "రైడ్-షేరింగ్ ETA ప్రిడిక్షన్ సిస్టమ్ కోసం ఫీచర్లను డిజైన్ చేయమని" ఒక ఇంటర్వ్యూయర్ మిమ్మల్ని అడిగినప్పుడు, వారు పరీక్షిస్తున్నారు:

- డేటాలో ఏ సంకేతాలు ఉన్నాయో మీరు సృజనాత్మకంగా ఆలోచించగలరా?
- ముడి డేటా మోడల్ ఇన్‌పుట్‌లుగా ఎలా మారుతుందో మీకు అర్థమైందా?
- లీకేజీ, స్పార్సిటీ మరియు స్కేల్ వంటి సమస్యలను మీరు ఊహించగలరా?
- మీరు ఉత్పత్తి పరిమితుల (జాప్యం, నిల్వ, తాజాదనం) గురించి ఆలోచిస్తున్నారా?

<Callout>ఒక సాధారణ ఇంటర్వ్యూ నమూనా: ఇంటర్వ్యూయర్ వ్యాపార సమస్యను వివరిస్తాడు మరియు ఫీచర్లను ఆలోచనాత్మకంగా మార్చమని మిమ్మల్ని అడుగుతాడు. అందుబాటులో ఉన్న డేటా మూలాధారాల గురించి అడగడం ద్వారా ప్రారంభించండి - ఇది మీరు సిద్ధాంతం మాత్రమే కాకుండా సాధ్యత గురించి ఆలోచిస్తున్నట్లు చూపుతుంది.

## 📦 ఫీచర్ల రకాలు

### సంఖ్యా లక్షణాలు

నేరుగా మోడల్‌లలోకి అందించబడే ముడి సంఖ్యలు — కానీ తరచుగా పరివర్తన నుండి ప్రయోజనం పొందుతాయి:

- **ప్రమాణీకరణ**: కేంద్రం నుండి అర్థం 0, స్కేల్ నుండి యూనిట్ వ్యత్యాసం (SVM, KNN వంటి దూర-ఆధారిత మోడల్‌లకు అవసరం)
- **లాగ్ ట్రాన్స్‌ఫర్మేషన్**: కుడివైపు వక్రీకృత పంపిణీలను కుదించండి (ఆదాయం, పేజీ వీక్షణలు)
- **బిన్నింగ్**: నిరంతర విలువలను వివిక్త బకెట్‌లుగా మార్చండి (వయస్సు → వయస్సు_సమూహం)

```python
import numpy as np
from sklearn.preprocessing import StandardScaler

# Log transform for skewed feature
df['log_income'] = np.log1p(df['income'])

# Standardisation
scaler = StandardScaler()
df[['age_scaled', 'income_scaled']] = scaler.fit_transform(df[['age', 'income']])
```

### వర్గీకరణ లక్షణాలు

దేశం, ఉత్పత్తి వర్గం లేదా వినియోగదారు విభాగం వంటి సంఖ్యా రహిత డేటా. ఎన్‌కోడింగ్ వ్యూహం ముఖ్యమైనది:

| పద్ధతి | ఎప్పుడు ఉపయోగించాలి | ప్రోస్ | ప్రతికూలతలు |
|---|---|---|---|
| వన్-హాట్ ఎన్‌కోడింగ్ | తక్కువ కార్డినాలిటీ (< 20 వర్గాలు) | సాధారణ, సాధారణ ఊహ లేదు | చిన్న, అధిక డైమెన్షనల్ |
| లేబుల్ ఎన్‌కోడింగ్ | సాధారణ వర్గాలు (తక్కువ/మధ్యస్థం/అధిక) | కాంపాక్ట్ | నాన్-ఆర్డినల్ | కోసం తప్పుడు క్రమాన్ని సూచిస్తుంది
| టార్గెట్ ఎన్‌కోడింగ్ | అధిక కార్డినాలిటీ (నగరం, పోస్ట్‌కోడ్) | వర్గం-లక్ష్య సంబంధాన్ని సంగ్రహిస్తుంది | డేటా లీకేజీ ప్రమాదం |
| పొందుపరచడం | చాలా ఎక్కువ కార్డినాలిటీ, లోతైన అభ్యాసం | దట్టమైన ప్రాతినిధ్యాలను నేర్చుకుంటుంది | న్యూరల్ నెట్‌వర్క్ అవసరం |

</ThinkAboutIt>

### తాత్కాలిక లక్షణాలు

సమయ-ఆధారిత డేటా సిగ్నల్‌తో సమృద్ధిగా ఉంటుంది - మీరు దానిని సరిగ్గా సంగ్రహిస్తే:

- **చక్రీయ ఎన్‌కోడింగ్**: రోజు గంట, వారంలోని రోజు (చక్రీయ స్వభావాన్ని సంగ్రహించడానికి sin/cos ఉపయోగించండి)
- **లాగ్ ఫీచర్‌లు**: t-1, t-7, t-30 వద్ద విలువ (సమయ శ్రేణికి కీలకం)
- **రోలింగ్ గణాంకాలు**: 7-రోజుల చలన సగటు, 30-రోజుల రోలింగ్ std
- ** ఈవెంట్ నుండి సమయం**: చివరి కొనుగోలు నుండి రోజులు, చివరి లాగిన్ నుండి గంటలు

```python
# Cyclical encoding for hour of day
df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)

# Lag and rolling features
df['sales_lag_7'] = df['sales'].shift(7)
df['sales_rolling_mean_7'] = df['sales'].rolling(window=7).mean()
```

### టెక్స్ట్ ఫీచర్లు

మోడల్‌లు టెక్స్ట్ డేటాను వినియోగించాల్సిన అవసరం వచ్చినప్పుడు:

- **బ్యాగ్ ఆఫ్ వర్డ్స్ / TF-IDF**: సరళమైనది, అర్థం చేసుకోదగినది, సాంప్రదాయ MLతో బాగా పనిచేస్తుంది.
- **వర్డ్ ఎంబెడ్డింగ్‌లు**: పదం2Vec, GloVe — అర్థ అర్థాన్ని సంగ్రహించే దట్టమైన ప్రాతినిధ్యాలు
- **వాక్య ఎంబెడ్డింగ్‌లు**: BERT, Sentence-BERT — సందర్భోచిత ప్రాతినిధ్యాలు
- **హ్యాండ్‌క్రాఫ్ట్**: పదాల సంఖ్య, సగటు పద నిడివి, సెంటిమెంట్ స్కోర్, నిర్దిష్ట కీలకపదాల ఉనికి

సంబంధాలను సంగ్రహించే లక్షణాల కలయికలు మోడల్ స్వంతంగా నేర్చుకోకపోవచ్చు:

- **ఫీచర్ క్రాస్‌లు**: `city × device_type` (పట్టణ మొబైల్ వినియోగదారులు గ్రామీణ డెస్క్‌టాప్ వినియోగదారులకు భిన్నంగా ప్రవర్తిస్తారు)
- **నిష్పత్తులు**: `clicks / impressions` = క్లిక్-త్రూ రేట్
- **తేడాలు**: `current_price - avg_price` = సంబంధిత ధర సంకేతం

## 🧹 మిస్సింగ్ డేటాను హ్యాండిల్ చేస్తోంది

ఉత్పత్తిలో ప్రతిచోటా డేటా మిస్ అవుతుంది. మీ విధానం మీ అనుభవ స్థాయిని సూచిస్తుంది:

** సాధారణ వ్యూహాలు:**
- అడ్డు వరుసలను వదలండి (డేటా తప్పిపోయినట్లయితే, అరుదుగా మరియు యాదృచ్ఛికంగా ఉంటే మాత్రమే)
- సగటు/మధ్యస్థ (సంఖ్యా) లేదా మోడ్ (వర్గీకరణ)తో పూరించండి
- సెంటినల్ విలువతో పూరించండి (-1 లేదా "తెలియని")

**మంచి వ్యూహాలు:**
- బైనరీ సూచిక లక్షణాన్ని సృష్టించండి: `is_income_missing` (డేటా తప్పిపోయిన *వాస్తవం* సమాచారంగా ఉంటుంది!)
- మోడల్ ఆధారిత ఇంప్యుటేషన్ ఉపయోగించండి (KNN ఇంప్యూటర్, ఇటరేటివ్ ఇంప్యూటర్)
- చెట్టు-ఆధారిత నమూనాల కోసం, అనేక అమలులు తప్పిపోయిన విలువలను స్థానికంగా నిర్వహిస్తాయి

```python
# Indicator feature + median imputation
df['is_income_missing'] = df['income'].isna().astype(int)
df['income'] = df['income'].fillna(df['income'].median())
```

## 🔍 ఫీచర్ ఎంపిక పద్ధతులు

మరిన్ని ఫీచర్లు ఎల్లప్పుడూ మెరుగ్గా ఉండవు. ఫీచర్ ఎంపిక ఓవర్ ఫిట్టింగ్‌ను తగ్గిస్తుంది, జాప్యాన్ని మెరుగుపరుస్తుంది మరియు మోడల్‌లను అర్థమయ్యేలా చేస్తుంది.

### వడపోత పద్ధతులు
లక్ష్యంతో గణాంక సహసంబంధం ద్వారా లక్షణాలను ర్యాంక్ చేయండి — వేగవంతమైనది కానీ ఫీచర్ పరస్పర చర్యలను విస్మరిస్తుంది:
- సహసంబంధ గుణకం (సంఖ్యా లక్ష్యాలు)
- పరస్పర సమాచారం (ఏదైనా ఫీచర్ రకానికి పని చేస్తుంది)
- చి-స్క్వేర్డ్ టెస్ట్ (వర్గీకరణ లక్షణాలు)

### రేపర్ పద్ధతులు
విభిన్న ఫీచర్ ఉపసమితులతో రైలు నమూనాలు — ఖచ్చితమైన కానీ ఖరీదైనవి:
- ఫార్వర్డ్ ఎంపిక: ఖాళీగా ప్రారంభించండి, ఒక్కోసారి ఉత్తమ ఫీచర్‌ని జోడించండి
- బ్యాక్‌వర్డ్ ఎలిమినేషన్: అన్ని ఫీచర్‌లతో ప్రారంభించండి, ఒక్కోసారి తక్కువ ఉపయోగకరమైనదాన్ని తీసివేయండి

### పొందుపరిచిన పద్ధతులు
ఫీచర్ ఎంపిక మోడల్ శిక్షణ ప్రక్రియలో నిర్మించబడింది:
- **L1 క్రమబద్ధీకరణ** (లాస్సో): అప్రధానమైన ఫీచర్ బరువులను సరిగ్గా సున్నాకి నడిపిస్తుంది
- **చెట్టు-ఆధారిత ప్రాముఖ్యత**: గ్రేడియంట్-బూస్ట్డ్ ట్రీస్ ఫీచర్ ప్రాముఖ్యత స్కోర్‌లను నివేదించాయి

```python
from sklearn.feature_selection import SelectKBest, mutual_info_classif

# Select top 20 features by mutual information
selector = SelectKBest(mutual_info_classif, k=20)
X_selected = selector.fit_transform(X, y)
```

## 🏭 ఉత్పత్తిలో ఫీచర్ ఇంజనీరింగ్

ఇంటర్వ్యూ-స్థాయి ఫీచర్ ఇంజనీరింగ్ నోట్‌బుక్‌ల వద్ద ఆగదు. ఉత్పత్తి పరిశీలనలు ఉన్నాయి:

### ఫీచర్ దుకాణాలు

ఫీచర్ స్టోర్ అనేది ఫీచర్లను నిర్వహించడానికి, నిల్వ చేయడానికి మరియు అందించడానికి కేంద్రీకృత వ్యవస్థ. ఇది పరిష్కరిస్తుంది:
- ** స్థిరత్వం**: శిక్షణ మరియు సేవలో అదే ఫీచర్ నిర్వచనం
- **పునర్వినియోగం**: బృందాలు ఫీచర్‌లను మళ్లీ అమలు చేయడానికి బదులుగా వాటిని పంచుకుంటాయి
- **తాజాదనం**: షెడ్యూల్ చేయబడిన పైప్‌లైన్‌లు ఫీచర్‌లను తాజాగా ఉంచుతాయి

ప్రసిద్ధ సాధనాలు: **ఫీస్ట్**, **టెక్టన్**, **హాప్స్‌వర్క్స్**, **AWS సేజ్‌మేకర్ ఫీచర్ స్టోర్**

### ట్రైనింగ్-సర్వింగ్ స్కే

MLలో అత్యంత ప్రమాదకరమైన ఉత్పత్తి బగ్: శిక్షణ వర్సెస్ సేవల సమయంలో విభిన్నంగా గణించబడిన ఫీచర్లు. సాధారణ కారణాలు:
- బ్యాచ్ (శిక్షణ) మరియు నిజ-సమయం (సేవ) కోసం విభిన్న కోడ్ మార్గాలు
- సర్వింగ్ పాత్‌లో పాత ఫీచర్ విలువలు

- **సాధారణ సమస్యల కోసం మెదడును కదిలించే లక్షణాలను ప్రాక్టీస్ చేయండి**: సిఫార్సులు, మోసం, ETA అంచనా, శోధన
