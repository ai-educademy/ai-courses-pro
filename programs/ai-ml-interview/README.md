## Overview

Cover model selection, experimentation, ML system design, RAG and agent evaluation, data quality, MLOps, safety, and the trade-offs interviewers expect you to articulate.

This private repo contains Pro subscriber lessons for this programme.

- ML and GenAI system design
- Experimentation and evaluation

## Outcomes

- Design an ML or GenAI system end to end
- Choose metrics that match user and business outcomes
- Explain deployment and monitoring trade-offs
- Handle safety and failure-mode questions with confidence
